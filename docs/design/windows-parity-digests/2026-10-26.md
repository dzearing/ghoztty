## Feature ideas

### What you see and press

- **Choose a pane's colour yourself** - *High.* Each pane now has its own
  hue in the sidebar. Right-click its icon to pick a different one, and the
  colour stays with that pane across restarts, so "the blue one" always
  means the same pane.
- **Updates wait for your work to finish** - *High.* When you accept an
  update while a pane is busy, Ghoztty waits until the pane is idle and says
  which pane it is waiting for. A long build or an agent run is never cut
  off by an update.
- **A folded strip says what it is running** - *High.* A pane folded into
  its strip shows the running command's name and a gentle shine while it is
  busy. You can fold panes away without losing sight of which ones are
  still working.
- **Send a pane to another window from the sidebar** - *Medium.* New angle
  on moving panes between windows: in the all-windows list, drag a row
  onto another window's heading and the pane moves there, session intact.

### Stability and performance

- **Glides keep their pace while output pours** - *Medium.* A fold or
  slide stays smooth even when a neighbouring pane is printing a fast build
  log. Motion never stutters because another pane is busy.
- **A drag can never strand a pane** - *Medium.* If a drag is interrupted
  (the screen locks, Alt+Tab, the pointer leaves the window), the pane
  glides back to where it started rather than stopping halfway.
