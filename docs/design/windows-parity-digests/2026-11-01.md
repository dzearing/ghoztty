### Reflection

**We measured the wrong thing well.** Yesterday's resize work was careful:
every change was timed, filmed and checked for bad frames. But nothing
measured what you feel, which is how closely the edge tracks your mouse.
Making the inside land in the same frame as the edge (T2578) may have cost
exactly that. A resize harness that scores pointer-to-edge lag and steps
per second should stand next to the frame-correctness one, and every
resize change should report both.

**Your reports keep landing faster than the proof.** The divider sliver,
the chain-fold recording and the frame lab all wait on your real screen
and mouse. D104 is still the unlock.

**The composition work is now a long staircase.** Splitting it into
one-turn slices keeps each step safe. Yesterday 4 cards were split into
14, and 7 more compositor steps (T2559, T2570-T2574) are still queued at
P0 outside M1. It is worth asking, after T2603, whether those steps still
serve the resize goal or are now their own project.

**Toward the cutover:** still gated on T87 (the Mac regression build) and
T1179 (your install walkthrough). The merge task (T2490) is open. The
skill report adds one more first-run item that a clean-machine walk would

## Feature ideas

### What you see and press

- **See which of your coding agents know Ghoztty** - *High.* A palette
  page lists every coding agent on the machine (Claude Code, Copilot and
  others), whether each has the Ghoztty skill, and whether it matches this
  version. One button installs or updates it. An agent you install next
  week shows up there the day you install it.
- **Make your own words clickable** - *High.* Tell Ghoztty that "T1234",
  "JIRA-88" or a build number is a link, and where it should go. Every pane
  underlines those words from then on, and a click opens your tracker.
- **A comfortable reading width in a wide pane** - *Medium.* In a very wide
  pane, text wraps at a width you choose, say 120 columns, and sits in the
  middle. A long agent answer reads like a page instead of one line across
  a 4K screen.
- **Agent panes show how much room they have left** - *Medium.* When an
  agent reports it, a small meter on the pane's strip shows how full its
  context is. You can see a long run is about to compact before it does.

### Stability and performance

- **Typing never waits for a resize** - *High.* While you drag a window
  edge or a divider, keystrokes and output keep moving at full speed. The
  drag gives way to your typing, never the other way round.
- **"That felt slow" captures the last ten seconds** - *High.* (New angle
  on the slowness readout: after the fact, not set up in advance.) One
  palette command saves the timing of whatever just happened (a resize, a
  fold, a burst of typing) into a feedback report. "It feels choppier"
  arrives with numbers.
