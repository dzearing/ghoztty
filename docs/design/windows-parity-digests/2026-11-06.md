## Feature ideas

### What you see and press

- **Click a past command to run it again** - *High.* Click any earlier
  prompt line in the scrollback and that command is placed at the current
  prompt, ready to edit or run. No more arrow-key hunting through history
  for the command you can already see.
- **Talk to your agent** - *High.* Windows voice typing (Win+H) types into
  the pane, with a small microphone chip on the pane while it listens. Long
  prompts to Claude Code without typing them.
- **Bring back what Clear wiped** - *Medium.* `cls` or Ctrl+L keeps the
  cleared screen in scrollback behind a thin "cleared at 10:42" line. An
  accidental clear never loses the error you were about to read.
- **A chime when the agent is done** - *Medium.* An optional short sound
  when a busy pane finishes or asks a question, using your Windows sound
  settings. You hear it while you are in another app.
- **Save a pane's output to a file** - *Medium.* Right-click, Save output:
  the whole scrollback, or just the last command's output, goes to a text
  file and its folder opens. Easy to attach to a bug report.

### Stability and performance

- **Smooth for the people watching your screen share** - *Medium.* While
  Teams or Zoom is sharing the screen, Ghoztty paces its animations to what
  the share can carry. Viewers see clean folds and resizes, not stutter.
