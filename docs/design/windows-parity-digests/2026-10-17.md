## Feature ideas

### What you see and press

- **Click an error, land on the line** — *High.* A compiler or test location
  like `src/main.zig:120:5` in a pane is clickable. It opens the file in a
  side pane, scrolled to that line and highlighted, so you go from a red
  build to the code in one click.
- **Every sidebar row shows its latest line** — *High.* Under each pane's
  name, the sidebar shows the last line it printed, dimmed. You can scan ten
  panes and see which build failed without opening any of them.
- **Do not let the PC sleep mid-job** — *High.* While any pane is busy,
  Ghoztty can keep Windows awake, and the sidebar shows a small moon to say
  so. An overnight build or agent run is not cut off by the power timer.
- **Even out the whole window** — *Medium.* *New angle on evening out a
  divider:* one command makes every pane in the window the same size, and
  doing it again puts your sizes back.

### Stability and performance

- **A huge paste cannot freeze the window** — *Medium.* *New angle on the
  paste preview:* a megabyte paste streams in with a small progress line, and
  Esc stops it partway. The window keeps redrawing the whole time.
- **Typing never waits on a save** — *Medium.* Saving sessions and layout
  runs entirely away from your keystrokes. A slow or sleeping disk can delay
  a save, never a character you typed.
