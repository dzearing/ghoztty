## Feature ideas

### What you see and press

- **Tell me when it says this** - *High.* Pick a phrase for a pane, such as
  "listening on" or "password:". When it prints, you get a toast and the
  pane's row lights up. You can stop watching a server boot and come back
  when it is ready.
- **Click an error, land on the line** - *High.* A compiler error like
  `src/app.ts:42:7` opens your editor at that line and column, not just the
  file. (New angle on clickable file paths: the line and column come too.)
- **A long line you can read** - *Medium.* One very long line, such as
  minified JSON or a one-line stack trace, shows folded with a "+2,400
  characters" chip. Click to unfold it, or open it formatted in a side pane.
- **Fold any command's output by hand** - *Medium.* Click beside a command
  to fold its output to one line ("npm install - 1,204 lines"), the way an
  editor folds code. (New angle on folding huge output: you choose what
  folds, at any size.)

### Stability and performance

- **A full disk cannot cost you your layout** - *Medium.* When the disk
  fills up, Ghoztty keeps the last good copy of your saved windows and shows
  a banner that saving has paused. It never writes half a file that loses
  every window at the next start.
- **A giant log opens at once** - *Medium.* Opening a log file of several
  gigabytes in a side pane shows the first screen right away. You can
  search it while the rest loads.
