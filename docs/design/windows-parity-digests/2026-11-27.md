## Feature ideas

### What you see and press

- **Every pane shows how old its shell is** - *High.* Hover a pane's
  header and it says "bash, started 12 s ago" or "re-attached, running
  since 09:14". You can tell a fresh shell from a reused one at a glance,
  which is the doubt behind this week's WSL report.
- **The tab names the program, not only the title** - *High.* While a
  shell runs vim, a test run or an agent, its tab shows that program's
  name with a small mark. When the program exits, the tab goes back to
  the folder name.
- **Reopen this whole window on another shell** - *Medium.* New angle on
  Restart Pane with Shell: one command rebuilds every split of the window
  on WSL or PowerShell, each pane in its translated folder.
- **The new-tab menu shows which distros are awake** - *Medium.* A distro
  that is already running has a dot beside it, so you know which choice
  opens at once and which needs a few seconds.

### Under the hood

- **Old copies clean up after themselves** - *Medium.* An update keeps
  only the last two versions of the app and says how much space it freed.
  Today old copies pile up into gigabytes until someone deletes them.
- **Opening the app never waits on the network** - *Medium.* With no
  network, or a sleeping network drive, the window opens at once. Sign-in
  and the update check catch up afterwards.
