## Feature ideas

### What you see and press

- **A new window in a project starts in that project** - *High.* The + on
  a project group opens the window in that project's folder, with the same
  kind of shell its panes use (PowerShell, cmd or WSL). No more `cd` back to
  where you were.
- **Find any pane by typing** - *High.* With the sidebar focused, start
  typing and the list narrows to panes whose name or folder match. Enter
  jumps to the pane, in whichever window it lives.
- **See which panes printed while you were away** - *High.* A pane that
  printed something since you last looked at it gets a small dot on its
  sidebar row. Focusing the pane clears it.
- **Gather a project's panes into one window** - *Medium.* Right-click a
  project group in the all-windows list and choose "Bring together". Its
  panes leave their scattered windows and line up in one, sessions intact.

### Stability and performance

- **The all-windows list stays instant with fifty windows** - *Medium.*
  Opening and scrolling the list with fifty windows and hundreds of panes
  is as smooth as with three, because only the rows on screen are drawn.
- **A + that cannot do what you asked says why** - *Medium.* If a project's
  folder was moved or deleted, its + still opens a window, in your home
  folder, and a short note says where it looked and why it gave up.
