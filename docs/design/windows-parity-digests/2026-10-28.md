## Feature ideas

### What you see and press

- **A failed command marks its row** - *High.* When a pane's last command
  fails, its sidebar row gets a small red mark. You can see which of
  twenty panes went wrong without opening each; focusing the pane clears
  it.
- **Lay out a project's windows in one click** - *High.* New windows open
  maximized now, so a project's windows pile on top of each other.
  Right-click the project group and choose "Side by side" to tile its
  windows across the screen.
- **New windows open on the screen you are using** - *Medium.* With two
  monitors, a new window opens maximized on the screen holding the window
  you came from, not always on the main one.

### Stability and performance

- **An update that will not start puts the old version back** - *High.* If
  the new version fails to open after an install, the previous one comes
  back on its own. A note in the window says what happened, so a bad
  release never leaves you without a terminal.
- **A maximized window appears at full size** - *Medium.* A new window's
  first frame is already full-screen. You never see it start small and
  then jump.
