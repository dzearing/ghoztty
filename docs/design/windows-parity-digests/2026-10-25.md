## Feature ideas

### What you see and press

- **Tick off files as you review a diff** - *High.* In a diff pane, mark a
  file as reviewed and it folds away, with the list showing how many are
  left. A mark stays until that file changes again, so a long review
  survives a refresh.
- **Session cards show what was last on screen** - *High.* In the machine
  chooser, each saved session shows its last two lines of output. You pick
  the right session by what it was doing, not by remembering its name.
- **Go back to the release before** - *High.* If an update misbehaves,
  About offers "Reinstall the previous version" in one click, with your
  sessions intact. A bad release never leaves you stuck until the next one.
- **A pane says who opened it** - *Medium.* A pane opened by a script or an
  agent shows "opened by <pane>" in its banner for a few seconds, and a click
  jumps back. You never wonder where a new pane came from.

### Stability and performance

- **Typing through an animation is never lost** - *Medium.* Keys typed while
  a pane folds, slides or resizes arrive in order, in the pane that had the
  caret. A fast typist never loses a character to an animation.
- **Idle windows cost nothing** - *Medium.* A window with no output and no
  pointer over it stops repainting until something changes. Ten open windows
  use the same CPU as one, plugged in or not.
