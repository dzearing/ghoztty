### Reflection

**Flipping the default was the right call, and it showed what it costs.**
The flip itself was one constant. Then about forty harnesses fell due at
once, because so many files moved under them. This morning's claim listed
roughly forty `GUARD DUE` rows. Proving one change drags in every test
that touches the same files. A sweep scoped to "harnesses whose verdict
could have changed" would be cheaper than "harnesses whose files changed".
That is now T2790 (P2).

**Leak tests earn their keep.** The 52 MB per-window leak was not seen by
anyone using the app. A memory guard caught it the day the compositor
became the default. More of the new engine's resources (devices, swap
chains, threads) need the same open-close-measure treatment before it
ships wider.

**Duplicates still slip through between lanes.** Three of yesterday's
seven skips were duplicates (T2751, T2754, T2759). In each case the second
lane filed what the first had just watched go red. The SIMILAR check warns
by title. A red harness re-filed by name could be caught by the harness
name instead.

**Most P0s still wait on one question to you.** D104, D107 and now D108
all ask whether the loop may run the resize films while you are near or
away from the PC. T2400, T2485, T2577 and the fold P0s are built and
waiting for that proof.

**Toward the cutover:** unchanged. Still gated on T87 (the Mac regression
build) and T1179 (your install walkthrough). Main has not moved since
yesterday's intake.

## Feature ideas

### What you see and press

- **Line up the next command** - *High.* While a long command runs, type
  the next one and press Enter. It waits in a small chip under the prompt
  and runs when the first one ends, or only if it succeeded. No more
  watching a build just to type the deploy.
- **Continue on your other PC** - *High.* A pane's menu offers "Continue
  on..." with your other signed-in machines. Pick one and the same live
  session opens there, scrollback and all. You leave your desk and pick up
  on the laptop.
- **Open this link on your phone** - *Medium.* Right-click a link and get a
  QR code card. Scan it to open the page on your phone, which helps with
  sign-in codes and pages you want to read away from the desk.
- **A pasted key stays hidden** - *Medium.* When you paste something that
  looks like an API key or password, the program gets it but the screen
  and scrollback show dots. A screen share or a later screenshot never
  shows it. (New angle on secret redaction: it covers the live screen, not
  only captures.)
- **Quiet while you focus** - *Medium.* When Windows Focus or Do not
  disturb is on, Ghoztty holds its finish toasts and chimes. When it ends,
  one card lists what finished. (New angle on the demo quiet mode: it
  follows Windows by itself.)

### Stability and performance

- **Stays light after days open** - *Medium.* A window kept open for a week
  of opening and closing panes uses the same memory as a fresh one. Settings
  shows the number, so you can see there is nothing to restart for.
