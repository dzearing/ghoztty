## Feature ideas

### What you see and press

- **A WSL pane that is still waking says so** - *High.* When a distro
  starts cold, the pane says "Starting Ubuntu..." and counts the seconds.
  Today you get a black pane for several seconds and cannot tell it from
  a broken one.
- **Same folder, other side** - *High.* One key opens a split beside a
  WSL pane on PowerShell in the same folder, with the path translated, and
  the same key from PowerShell goes back to WSL. It is the quickest way
  to run a Windows tool on Linux files.
- **The shell menu puts your favourites first** - *Medium.* The chevron
  menu lists the shells you open most at the top. You can also choose to
  make `+` open the shell you picked last, not the default.
- **Make it my default, right from the menu** - *Medium.* Each shell in
  the new-tab menu has "Use as default", so you never hunt through
  Settings to change it.
- **Closing a distro's last pane can give its memory back** - *Medium.*
  When the last pane on a WSL distro closes, a quiet note offers to shut
  that distro down. A sleeping distro can hold gigabytes of memory long
  after you are done with it.

### Under the hood

- **Windows you put away give their memory back** - *High.* New angle on
  idle windows costing nothing: a window minimized or covered for a few
  minutes releases its drawing buffers and graphics memory, and redraws
  when you return. It goes after the 55 MB plus 22 MB each window holds
  today.
- **A slow-starting shell shows where the time went** - *Medium.* When a
  new pane takes more than a second to reach its prompt, its header
  tooltip says why, for example "PowerShell profile: 2.4 s". The slow part
  is then visible to you, and you can see it is not Ghoztty.
