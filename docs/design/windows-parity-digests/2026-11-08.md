### Reflection

**The compositor move is now a production line.** Yesterday's eleven motion
cards each followed the same recipe: hand the visual to the compositor, prove
it holds through a stall, file the live film as a separate card. That is
good for pace. It also leaves a trail of "live run on an idle box" cards
(T2797, T2800, T2809) that only you can start. They pile up quietly.

**Harnesses aimed at the old path go red one by one.** Frame-clock (T2820),
overlay z-order (T2794) and device-lost (T2792) all went red because the
thing they measure moved to the compositor, not because anything broke. Each
one cost a lane a turn to diagnose. When a default flips, a sweep of every
harness that names the old path, run the same day, would find them in one
pass.

## Feature ideas

### What you see and press

- **Pop a pane out on top** - *High.* Pop any pane into a small window that
  stays above your other apps, like a video's picture-in-picture. Watch a
  build or an agent while you work in the browser. Click it to send it back
  to its place in the layout.
- **Run the line you selected** - *High.* Select a command anywhere, in a
  README in a viewer pane or in another pane's output, and press one key.
  It lands at the prompt of the pane beside it, ready to edit or run. No
  more copy, click, paste.
- **Read only what is new** - *Medium.* When you come back to a pane after
  working elsewhere, a faint line marks where the screen ended when you last
  looked. You read from there instead of hunting. (New angle on the
  unread-output dot: it marks the place inside the pane, not only that
  something changed.)
- **The taskbar preview shows your panes** - *Medium.* Hovering Ghoztty's
  taskbar button shows each window's pane layout with names, and which panes
  are busy or waiting on you. Click a pane in the preview to jump straight
  to it. (New angle on taskbar badges: the preview itself is the map.)
- **Share a selection the Windows way** - *Medium.* Right-click selected
  text and pick Share. The Windows share panel sends it to Teams, mail or a
  nearby PC as a tidy snippet with the command that produced it.

### Stability and performance

- **Many saved sessions never slow the first window** - *Medium.* With
  thirty sessions to restore, the window you opened shows its prompt first.
  The rest come back behind it, one by one, without stalling your typing.
