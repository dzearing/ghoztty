## Feature ideas

### What you see and press

- **Hold Alt to see what every button does** — *High.* Holding Alt puts a
  short label on every button, pill and badge in the window at once, the way
  Office shows its key tips. Tooltips answer one control at a time, and only
  if you already suspect it does something.
- **Your running sessions in the notification area** — *High.* When the last
  window closes but sessions are still running, a tray icon stays behind. Its
  menu lists machines and live sessions, and a click brings one back. Today
  those sessions are alive and invisible until you open the app again.
- **Save what you just ran as a palette command** — *High.* Pick a command
  from a pane's recent history, give it a name, and it becomes a palette
  entry. Your config's palette entries now appear, but writing one by hand is
  the only way to add one.
- **Change a shortcut from the palette row that shows it** — *Medium* (new
  angle on the keybinding cheat sheet). Each palette row already names its
  shortcut. Pressing a key on that row reassigns it and warns about a clash.
  Finding the config line is the step people give up at.
- **A palette that learns what you use** — *Medium.* The commands you run most
  from a given kind of pane rise to the top of the empty palette. The first
  screen then fits you, not the alphabet.

### Stability and performance

- **cmd.exe panes that know where each command starts and ends** — *Medium.*
  cmd gets the same command marks as PowerShell: timing, jump to the last
  failure, and copy last output work there too. It also removes the reason a
  resize can wipe a running command's output.
