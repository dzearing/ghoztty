## Feature ideas

### What you see and press

- **See what you missed while the link was down** - *High.* New angle on
  remote panes that reconnect visibly: the pane's history carries a thin
  line where the connection dropped and another where it came back, with
  how long it was gone. Output that arrived in between is marked, so you
  know what you have not read.
- **Updates that change nothing you would see wait quietly** - *High.*
  New angle on holding an update: a release that carries only test or
  Linux work is not offered on its own. It rides along with the next
  release that changes something on Windows.
- **A page from another machine says whose `localhost` it is** -
  *Medium.* When a viewer shows a page fetched through another machine,
  its address bar leads with that machine's name, so two `localhost:3000`
  pages are never confused.
- **A new window opens on the screen your pointer is on** - *Medium.*
  With two or more monitors, a new window from the keyboard or a script
  lands on the monitor you are working on, not the one the last window
  used.

### Under the hood

- **A page from another machine reloads from what it already has** -
  *Medium.* A remote page keeps its unchanged pictures and scripts on this
  PC, so a reload over a slow link fetches only what changed.
