## Feature ideas

### What you see and press

- **A strip shows the pane's last line** - *High.* A folded strip's title
  is followed by the last line the pane printed. You can watch a build tick
  or a test count climb without unfolding it.
- **Keep this pane on show** - *High.* Mark one pane, such as the log you
  are watching, so a stacked row folds every other pane before it folds
  that one.
- **Drop a folder on a pane's edge** - *Medium.* (New angle on dropping a
  file to insert its path.) Drag a folder from File Explorer onto a pane's
  edge and a new split opens with a shell already in that folder.

### Stability and performance

- **A stuck program never freezes the window** - *Medium.* If a program
  stops reading its output, only its pane stalls, and it says so. Typing,
  tabs and the other panes stay live.
- **The first key after the PC wakes is instant** - *Medium.* After sleep,
  panes repaint from their last frame at once and catch up in the
  background, so the window never sits blank or ignores the first keys.
