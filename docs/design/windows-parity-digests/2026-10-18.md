## Feature ideas

### What you see and press

- **Copy a file in Explorer, paste its path** — *High.* Press Ctrl+C on a
  file or folder in File Explorer, then paste into a pane. You get its full
  path, quoted the way that shell needs, instead of nothing.
- **See the size while you drag** — *Medium.* While you drag a divider or
  resize the window, a small label shows each pane's columns and rows. You
  can size a pane to exactly 80 columns without guessing.
- **Pinch to zoom on a touch screen** — *Medium.* On a touch laptop, pinching
  a pane changes its text size, and a two-finger swipe scrolls smoothly. Today
  touch treats the pane like a mouse.
- **The emoji panel types into the pane** — *Medium.* Win+. opens the Windows
  emoji and symbol panel, and what you pick lands in the shell like typed
  text.
- **This pane's environment, in a side pane** — *Medium.* One command opens a
  searchable list of the pane's environment variables. You can see why
  `PATH` differs between two panes without printing it.

### Stability and performance

- **One pane cannot eat all your memory** — *Medium.* Each pane's scrollback
  has a memory ceiling. When it trims old lines, the sidebar says so, instead
  of the whole app slowing down.
- **A huge diff opens on its first screen** — *Medium.* A diff pane shows the
  first changed file at once and fills in the rest as it scrolls, so a
  thousand-file diff never shows a blank pane.
