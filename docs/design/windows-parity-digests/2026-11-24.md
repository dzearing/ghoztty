## Feature ideas

### What you see and press

- **A link a program broke across lines still opens whole** - *High.*
  Programs like Claude Code break a long URL with real line breaks.
  Clicking any part of it opens the whole link, not the first half.
- **Keys you type never land in a pane a script just focused** - *High.*
  If a script moves focus while you are typing, the rest of what you
  typed still goes to the pane you were typing in. A command never ends
  up half in the wrong place.
- **A font picker that shows your own screen** - *Medium.* The font list
  in Settings previews each font on the last few lines of your real
  pane, with box drawing and ligatures, so you pick by what you will see.
- **Paste it again from a short list** - *Medium.* One chord shows the
  last twenty things you pasted into any pane, with passwords and keys
  left out. Pick one to paste it again.
- **Settings follows your own edits** - *Medium.* If you edit the config
  file in an editor while Settings is open, the window updates and points
  at the line that changed.
- **Choose what a dropped file becomes** - *Medium.* New angle on drag
  and drop: holding Shift while you drop offers the path, an `@path`
  mention for a coding agent, or the file's text.

### Under the hood

- **Opening and closing panes all day leaves the session service light**
  - *Medium.* New angle on "stays light after days open", for the
  background service instead of the app: a thousand panes opened and
  closed leave it the size it started, and each release checks that.
