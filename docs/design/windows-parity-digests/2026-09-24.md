closes in a day is the best rate in weeks. But M1 only moved from 305 to 313.
The loop does what `next` tells it, and `next` never asked about M1. The

doing its best day.

**The feedback-box retirement is the model for removing anything.** T937 was
split into steps: first give the tests a way to type into the new box. Then
move each of six tests over, one card each. Only then delete the old box. At no
point did a test pass because it was quietly driving the thing about to be
deleted. It took ten cards instead of one. Nothing was silently weakened, and
that should be the default for every removal.

day's slot, and the evening run then said no six times over 64 commits. The
T1294 rule (publish again early when someone is waiting) worked as designed. It
just did not apply, because nobody was waiting. Is one release a day still the
right floor now that most days publish in the morning? A second evening slot,
used only when something user-visible landed after the morning's release, would
close the gap without a release per commit. Worth deciding before it becomes the
permanent shape.

## Feature ideas

### What you see and send

- **Mark the spot where output was lost** — *High.* When the session keeper
  had to drop output it had not saved, leave a visible line in the scrollback
  where the gap is, saying roughly how much went missing. Today the loss is
  logged (T970). But the scrollback reads as if nothing is missing, and that is
  the worst way for it to read.
- **A feedback draft that survives** — *High.* Text typed into the feedback box
  and not yet sent is kept if the pane closes, the window is restarted or the
  app goes away. It comes back the next time the box opens. A long piece of
  feedback is exactly the thing people write slowly, and exactly the thing a
  crash takes.
- **Hand this to the agent next door** *(new angle on the select-and-act
  toolbar)* — *High.* Select lines in a terminal pane and press one key. They
  land, quoted, in the feedback box or agent pane beside it, with the pane name
  and time attached. The earlier idea was a generic toolbar. The new angle is
  that the usual destination for selected output is now another pane in the
  same window.
- **See where a link goes before you click it** — *Medium.* Hovering a link in
  a viewer pane shows its destination at the bottom edge, the way every browser
  does. Links now open in different places depending on the modifier held. It
  matters more now to know where one leads before it opens.
- **Spell-check in the feedback box** — *Medium.* The feedback box is now a web
  page, so it can underline misspellings with the Windows spell-checker and
  offer fixes on right-click, like any other text box on the system.

### Stability

- **A driver reset you do not see** — *Medium.* Windows now survive a graphics
  driver reset (T1690). The next step is keeping the last good frame on screen
  while the drawing surface is rebuilt, so the window never flashes blank. A
  driver update should look like nothing happened.
