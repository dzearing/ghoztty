### Reflection

Windows CLI. It moved the Windows CLI into shared code first, then pointed
the Linux app at it. That means a fix to `+read` now lands on both
platforms at once, and the two cannot drift. The cost is that every one of
those moves touches code Windows ships. So lane L must keep running the
Windows tests on each shared change, as go.md asks. Any Windows test that
goes red right after a lane-L commit should be read with that in mind.

## Feature ideas

### What you see and press

- **A pane that will not close tells you why** - *High.* When you type
  `exit` or press close and the pane stays open, a one-line note in the
  pane names what is holding it (a program still running, a background
  job) and offers "Close anyway".
- **A pane that closes by itself leaves a note** - *Medium.* When a pane
  disappears without you closing it (its program crashed, or something
  outside Ghoztty ended it), a short note shows where it was for a few
  seconds. It names the program and how it ended, with a button to
  reopen it.
- **Your Ghoztty setup follows you into Linux** - *Medium.* The Linux
  Ghoztty in WSL reads the same settings, theme and shortcuts as the
  Windows app, so a Linux window looks and behaves like your others, and
  a change made in one applies to both.

### Under the hood

- **An update proves it can open a pane before it takes over** -
  *Medium.* After an update installs, the new version quietly opens a
  pane and runs one command before it replaces the running one. If that
  fails, you stay on the version that works and see a plain note saying
  why.
- **A busy session service never slows your typing** - *Medium.* New
  angle on "typing never waits": even when the background session service
  is slow (a loaded PC, many sessions), each key still shows up on screen
  within one frame.
- **The same script drives Ghoztty on every platform** - *Medium.* A
  script written against the `ghoztty` command works unchanged on
  Windows, Mac and Linux, and each release proves it by running one shared
  script on all three.
