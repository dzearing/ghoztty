### Yesterday

**Yesterday the performance work moved from the app into the session
agent, the background program that keeps your shells alive. Two Mac
releases also landed, and Windows matched both within hours.**

- **Panes give memory back in more places.** A pane returns its
  full-size picture once a fold or drag is over. Clearing a pane's

  2 MB less to begin with.

  no matching font used to open every installed font, which could freeze
  all panes for a moment. Now it doesn't.

  read once instead of twice. Busy panes no longer wait on each other. An

  another machine no longer freezes Ghoztty while it connects.

  It is filed as P0 and is today's first job.

## Feature ideas

### What you see and press

- **A remote window tells you when the link is slow** - *High.* When
  round trips to the other machine pass a few hundred milliseconds, the
  connection pill turns to "slow link" and shows the delay. A laggy
  keystroke then has a visible cause instead of feeling like Ghoztty is
  stuck.
- **Restore names what it could not bring back** - *High.* After a
  restart, one quiet line lists any pane that did not come back, such as
  a machine that is offline or a folder that is gone, with a Retry
  button. Today a missing pane simply isn't there, and you find out later.
- **Jump between your commands in PowerShell too** - *High.* A chord
  scrolls straight to the previous or next prompt in a pwsh pane, the way
  it works in shells with full integration. Long build logs stop being a
  scroll-and-squint job.
- **Give a workspace a name and a colour** - *Medium.* In single-window
  mode, each workspace in the sidebar can carry a name and a colour you
  choose. "Client work" and "home lab" become easy to tell apart at a
  glance.

### Under the hood

- **An update never drops a live session** - *High.* When a release
  updates the session agent, your running shells move to the new agent
  without a reconnect. Today the old agent is kept running, so an agent
  fix only reaches you after your sessions close.
