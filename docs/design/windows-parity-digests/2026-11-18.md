### Reflection

**A weekly limit cost 17 hours, and nothing saw it coming.** The
watchdog got the diagnosis right. It read "weekly limit" from the pane,
stopped re-typing into it and logged when the limit would clear. But the
limit hit three days before it reset, so the loop spent its week in four
days. The loop has no idea how fast it is spending. A process change is
worth making: track the weekly spend, and when it is on pace to run out
early, pick cheaper work and skip optional sweeps instead of stopping
cold.

**The perf baseline earns its keep, but it runs after the release.**
Baseline-4 caught an idle CPU regression the same night. That was after
1.55.6 had already carried it to you. If the daily publish ran the idle
phase of the baseline and refused a clear regression, it would not have
shipped. The measurement exists; it is just in the wrong place.

**Naming memory that isn't ours closes cards cleanly.** Two big memory
cards (T3130, T3169) ended by showing the leftover belongs to the GPU
driver or a one-time WebView2 warm-up. That is worth as much as a fix:
the backlog stops chasing it, and the follow-up (T3232) asks the one
question still in our hands.

**Your config must never reach a test.** T3214 is the third time
something on your own PC changed what the tests saw. The fix is an empty
config home for every test launch, not a fix per setting.

## Feature ideas

### What you see and press

- **Pop a workspace out into its own window** - *High.* In single-window
  mode, one command lifts a workspace into a real window for your second
  monitor. Putting it back folds it in again. You keep the one-window
  habit without giving up the second screen.
- **Hold the view still while output pours in** - *High.* Scroll up once
  and the view stays put while the program keeps printing. A small "312
  new lines" pill sits at the bottom, and a click on it catches you up.
  You can finally read the line that scrolled past.
- **See how long a pane has been quiet** - *Medium.* A pane's tab and
  sidebar tile say "quiet for 14 min" or "printing now" when you hover
  them. You can tell a stuck build from a slow one without switching to
  it.
- **Start a new workspace in this folder** - *Medium.* A pane's context
  menu offers "New workspace here", which opens a workspace in that
  pane's folder. Splitting off a side job becomes one click.

### Under the hood

- **Dumping a big log doesn't spin up the fans** - *Medium.* Output
  floods travel in large chunks from the program all the way to the
  screen, so `cat` of a huge file costs a fraction of the CPU and
  battery.
- **The session service sleeps when nothing is printing** - *Medium.*
  With no session producing output, the background service wakes zero
  times a second. In Task Manager it reads as nothing at all.
- **A release can't make idle Ghoztty heavier** - *Medium.* The daily
  publish measures idle CPU and memory against the last release and holds
  back a build that got worse. New angle on "each release says what it
  costs": it stops the regression instead of reporting it.
