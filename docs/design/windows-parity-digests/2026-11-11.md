## Commentary

### Yesterday

**Windows you are not looking at now stay quiet, the way they do on Mac.
Ghoztty also got harder to knock over: a graphics reset, a crash relaunch
and a dying background service no longer cost you windows.**

- **Background windows stop working when nobody can see them** (T2909,
  T2910, T2912, T2913). Mac shipped this yesterday evening and Windows had
  it by morning. A minimized or covered window no longer animates its busy
  lights, redraws its terminals, updates its title or runs git for a status
  viewer. It catches up the moment you show it. Expect less CPU and battery
  use with many windows open.
- **A graphics driver reset no longer crashes Ghoztty** (T2891). After
  yesterday morning's GPU hang the app now waits for the driver to recover,
  then rebuilds its drawing.
- **After a crash, the reopened Ghoztty says so** (T2862). It shows one note
  naming what happened, and a click opens the crash report. A relaunch right
  after a crash also brings your window back. Before, it handed the window
  to the copy that was still dying (T2892).
- **If the background session service dies, it is back in under a second**
  (T1473). A window you open at that moment still keeps its session.
- **Clear-screen no longer types Ctrl+L into a running command** (T1403).
- **A reopened pane shows its history even after the session service
  restarted** (T1443).
- **Signing back in while offline brings a remote machine back** without
  restarting the app (T1428).
- **Releases now write their own "What's New" notes** (T1444).
- **Defender had started quarantining the test build's session service**
  (T2917). Tests were adding real Windows startup entries, which looks like
  malware. They no longer do, so the agent-backed tests can run again.

### Reflection

**The Mac-to-Windows lag is now hours, not days.** Mac's background-window
work merged at 22:36, the Windows card was filed 42 minutes later, and the
Windows version was done by 06:45. That is the "stream with very low
latency" target in practice. The next step is the release side: 1.54.12
carries it this morning.

**Every P0 is waiting on you, not on code.** The five P0 smoothness cards
all sit behind a run that must happen on your own screen (the frame lab, a
divider-drag film), a Remote Desktop session from a second machine, or one of
D104, D107 and D108. Each of those decisions asks some form of "may the loop
film on this PC when you are away?" Answering one of them would unblock more
than any day of loop work. A single "the loop may film while I am away,
under these rules" answer would cover all three.

**Test scaffolding keeps leaking into the real machine.** Yesterday Defender
quarantined our own debug build, because tests were writing real startup
entries (T2917). The day before, a gate check had been writing into the live
publish log (T2887). Both are the same mistake: a test touching something
the user owns. A harness rule that refuses any write to HKCU Run, a live log
or the real startup folder outside a sandbox would end that class.

**The test audits are finding hollow checks, and that is good news.**
T1404 to T1409 showed that several "it updated on screen" checks could pass
even with the update removed, because taking the screenshot itself redraws
the window. Four follow-up cards (T2894 to T2897) now cover the remaining
groups. Each one replaces a check that could not fail with one that can.

**Toward the cutover:** unchanged. Still gated on T87 (the Mac regression

## Feature ideas

### What you see and press

- **Run it again after a restart** - *High.* After a reboot or update ends
  a pane's program, the restored pane shows what was running there, such as
  `npm run dev`. One click runs it again in the same folder. (New angle on
  reboot-aware restore: it brings back the command, not just the pane.)
- **Stop a program that ignores Ctrl+C** - *High.* Press Ctrl+C a second
  time within a second and the pane asks "Still running - end it?". Enter
  ends that program and everything it started, and your shell and its
  history stay.
- **Undo a clear** - *Medium.* Cleared the screen and lost the error you
  needed? One key brings back what the clear wiped, right where it was.
- **Select a column** - *Medium.* Alt+drag selects a rectangle, so you can
  copy one column of `ls -l`, `docker ps` or any table without the rest of
  each line.
- **A table you can sort** - *Medium.* Output shaped like a table, such as
  `docker ps`, `Get-Process` or a CSV, opens in a side pane as a grid. You
  can sort and filter it by any column.
- **Paste a path that fits this pane** - *Medium.* Paste `C:\My Code\app`
  into a WSL pane and get `'/mnt/c/My Code/app'`, or the reverse, quoted the
  way that shell expects. (New angle on WSL path translation: it happens at
  paste time, for every shell type.)
