## Feature ideas

### What you see and press

- **Shortcuts reach your program when it wants them** - *High.* When a
  program in a pane, such as Claude Code or vim, uses a chord Ghoztty also
  claims, the first press shows a small chip: "Send Ctrl+Enter to Claude
  instead?" Your answer is remembered per program, so a terminal shortcut
  never silently eats a key your tool depends on.
- **Drag a pane to a window you cannot see** - *High.* Hold a dragged pane
  over a sidebar row or a window's taskbar button and that window comes
  forward to take the drop. Moving work between windows no longer needs
  them both visible first.
- **Settings understands plain words** - *Medium.* Searching "bigger
  text", "see-through" or "stop beeping" finds font size, background
  opacity and the bell. You find a setting without knowing what Ghostty
  calls it.
- **A copy that fails says so** - *Medium.* When another app is holding the
  clipboard, Ghoztty retries for a moment. If it still cannot copy, a small
  note names the app holding it, instead of you pasting something old.

### Stability and performance

- **Moving a pane keeps everything it carries** - *Medium.* A pane dragged
  to another window keeps its running program, scrollback, banner, zoom
  and saved-session identity. If a move would lose any of it (a remote
  pane, say), the drop card says so before you let go.
