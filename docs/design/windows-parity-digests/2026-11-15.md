## Commentary

### Yesterday

**Yesterday was a performance day. You asked for a full performance audit
of the Windows port in the morning, and by night the first round of fixes
had roughly halved what Ghoztty costs to run.**

- **The audit happened** (T2957). A one-command baseline now measures
  idle and busy CPU, memory, threads and handles. Six area audits then
  read the code and filed 102 checked findings, each tied to a task.
- **The biggest costs went first.** Every thread used to grab 16 MB up
  front, and every pane made its own graphics device. With ten panes open,
  Ghoztty now uses **115 threads instead of 611** and **695 MB instead of
  1,419 MB**. The session agent idles at **11 MB instead of 167 MB**.
- **Idle panes do less.** A pane no longer redraws itself every 600 ms when
  its cursor cannot blink. NumLock or CapsLock no longer makes every mouse
  move redraw the whole pane. A long-running pane no longer slips into
  redrawing everything after about 100,000 frames.
- **Hidden panes give memory back.** A pane on a background tab, behind a
  zoom, in the stash, or simply sitting still for 3 seconds now returns its
  graphics memory. A window that was once maximized no longer keeps
  maximized-size memory for life.
- **The re-audit agreed** (T3072). A fresh baseline moved 42 numbers past
  tolerance, all of them better, none worse. The next re-audit is set for
  2026-11-21 (T3101).
- **Two everyday fixes from the Mac side.** One stuck `ghoztty` command can
  no longer freeze every other one (T3105). A viewer pane whose page
  process crashes now reloads instead of staying blank (T3107).

## Feature ideas

### What you see and press

- **Ghoztty steps back when your PC runs short of memory** - *High.* When
  Windows says memory is low, hidden panes, stashed panes and background
  viewers give back their caches first. Your PC keeps responding instead
  of stalling while it pages the terminal out.
- **Ghoztty reads as one app in Task Manager** - *High.* Task Manager
  shows Ghoztty as one group, with each pane's shell named by its pane
  title. Today you see a long list of shells, hosts and an agent, and
  cannot tell which pane is which.
- **A tab you come back to is there on the first frame** - *Medium.* After
  a background tab gives its memory back, switching to it shows its last
  picture at once and catches up a moment later. No blank flash when you
  return.
- **A long path in the output still opens** - *Medium.* Clicking a file
  path longer than Windows' old 260-character limit opens it like any
  other. Deep build and node_modules paths stop being dead links.

### Under the hood

- **Each release says what it costs** - *Medium.* What's New shows the
  memory and thread numbers the release measured against the last one, in
  one plain line. You can see the app getting lighter, not just read that
  it did.
- **A slow week cannot creep in unnoticed** - *Medium.* If an update makes
  idle CPU or memory worse on your machine, Ghoztty notices against its
  own past numbers and offers to send a short report. The weekly audit
  then has your machine's numbers too, not just the test PC's.
