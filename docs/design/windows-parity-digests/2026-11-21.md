## Feature ideas

### What you see and press

- **Copy everything a bug report needs** - *High.* One "Copy details"
  button in the About box and the Help menu: version, session service
  build, Windows version, screen scales, graphics card, and how many
  panes and sessions are open. Paste it into a report with nothing to
  look up.
- **Choose which sessions a restart ends** - *Medium.* New angle on
  "quitting says what keeps running": Restart Ghoztty and Background
  Sessions lists the running shells with a tick box each. You can restart
  the service and keep the long build alive.
- **Jump to a hero tile by number** - *Medium.* In hero mode, holding Alt
  shows a small number on each preview card, and Alt+number brings that
  pane forward. No cycling through eight panes to reach the sixth.
- **A window goes back to its screen when you plug it back in** -
  *Medium.* When a second monitor disconnects, the windows that had to
  move off it return to it, at the same place and size, when it comes
  back.

### Under the hood

- **An update puts every window back where it was** - *Medium.* After the
  in-app update restarts Ghoztty, each window reopens on the same monitor,
  at the same size, maximized or not, as it was before.
- **A settings change lands in one smooth frame** - *Medium.* Changing a
  font or theme repaints every window once, with no flash or flicker, even
  with many panes open.
- **Closing a picture or document never freezes the window** - *Medium.*
  A viewer that is still reading a big file is let go in the background,
  so closing it is instant whatever it was doing.
