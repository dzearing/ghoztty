## Feature ideas

### What you see and press

- **Try a setting before you keep it** - *High.* Changing a font, opacity
  or theme applies it at once with "Keep / Undo" and a 15-second count-down.
  If you do nothing it goes back, the way Windows treats a display change.
  You can experiment without fear of losing a look you liked.
- **"What setting is this?" on right-click** - *High.* Right-click the
  padding, the cursor, a tab or a divider and choose "Change this in
  Settings". It opens the exact row that controls it. Most people do not
  know what Ghostty calls the thing they want to change.
- **A project can bring its own look** - *Medium.* A pane whose folder
  holds a small Ghoztty file picks up that project's colours and title
  prefix, and drops them when you leave the folder. Production repos can be
  red and scratch repos calm, without any shell setup.
- **The shortcut guide warns about clashes** - *Medium.* The keyboard
  shortcut guide marks chords that Windows or another running app already
  takes, so they never reach Ghoztty. It offers a free alternative. No more
  wondering why a binding does nothing.

### Stability and performance

- **A bad line in your config never stops the app** - *High.* A typo
  loads everything else, and a banner names the line with a "Fix in
  Settings" button that opens that row. A hand edit never leaves you with a
  terminal that will not start or silently ignores half the file.
- **A settings change repaints once, with no flash** - *Medium.* Switching
  theme or font redraws every open window in a single frame, with no
  flicker, no layout jump and no cursor jump. Trying several themes in a row
  feels smooth rather than jarring.
