# D98 - When a restart finds that every session in a window is gone, should the window still come back with fresh shells?

## Why this needs a call

Mac drops a window when the agent has lost every session in it, so after a bad restart you get one default window instead of your layout. That is what you reported on 2026-10-15. Inside a window that does come back, Windows already gives a lost pane a fresh shell where it was. The question is whether a whole window of lost panes should come back the same way. Either way, it should behave the same on both platforms.
