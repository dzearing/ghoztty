# D104 - When you have stepped away from the PC for a few minutes, may the loop run the frame lab, which opens Ghoztty windows and moves your real mouse pointer?

## Why this needs a call

The frame lab measures how smooth dragging and resizing look, and it can only do that by moving the real pointer over real windows on your screen. Mac has no equivalent prompt because this harness is Windows-only. Five idle minutes does not mean you are away (you saw this yesterday), so the loop now waits for you; this asks whether that is what you want.
