# D105 - While you drag a divider, should the pane that is getting bigger fill its new space right away, or wait until you pause or let go?

## Why this needs a call

Mac holds a shrinking pane's content and lets a growing one follow the hand (resizing it each step). The follow-up for this task asked for one resize per pane per settle while also citing that Mac rule. Both cannot hold for the growing side, so this build holds both sides; the difference is visible only while the hand is moving.
