# D109 - When a remote window is narrow and its connection drops, should the reconnect message shrink so every tab stays visible?

## Why this needs a call

Mac shows tabs in their own bar below the titlebar, so its reconnect status never competes with them. On Windows the tabs share the titlebar row with the connection pill, and when a link drops the pill grows by about 120 DIP of status text. On a ~620 DIP window with 4 tabs that hides two tabs until the link comes back. Something has to give way and Mac offers no precedent.
