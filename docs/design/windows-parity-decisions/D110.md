# D110 - When someone runs the portable (unzipped) Ghoztty and clicks Install and Restart, what should happen?

## Why this needs a call

On the Mac, Sparkle updates the app wherever it lives. On Windows the update is an installer, and the installer always updates the copy installed under Programs - so a portable copy clicking Install and Restart used to install a SECOND copy there and then reopen the old portable, which looked like an update that did nothing. That is now refused. The question is whether the portable should instead learn to update its own folder.
