# D97 - When you close your ONLY Ghoztty window, should there be a way to undo it?

## Why this needs a call

On Mac, closing your last window keeps the app in the menu bar, so Edit > Undo (Cmd+Z) can bring the window back. On Windows there is no menu bar once the last window is gone, so there is nowhere to press Ctrl+Shift+Z. Every OTHER window close is now undoable from any remaining window; only the very last one has no obvious Windows equivalent.
