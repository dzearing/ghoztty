# D108 - May the resize films run as an invisible background window while you are at the PC?

## Why this needs a call

Measuring the window-resize glitches needs the app's real on-screen composition, which Windows only produces on the desktop you are using. The film opens the app as a ghost window: no taskbar entry, never focused, at the bottom of the window stack. go.md forbids anything that pops over you or takes focus, and an earlier turn read that as forbidding this film too. This turn read it the other way, so the call should be yours.
