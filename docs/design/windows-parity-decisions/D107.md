# D107 - May the loop film a divider drag on your own screen once the machine has been quiet for a while?

## Why this needs a call

The divider-flicker check has to photograph a real drag on the real screen; Windows only composes the visible desktop, so it cannot run hidden. go.md says the loop never runs these on your desktop, while the task queue was re-offering it whenever input went quiet. Quiet input does not mean you are away.
