# D96 - When a Windows pane is busy, should the light's soft glow fall outside the pane (on the background) rather than inside it over the text, as on Mac?

## Why this needs a call

On Mac the busy light is drawn inside the pane, so its glow spreads a little over the terminal text. On Windows each pane is a separate window that owns everything inside its border, so the light can only be drawn on the pane's very edge and the background around it without adding a floating window over each busy pane. The line looks the same either way; the difference is which side of the edge the soft glow falls on.
