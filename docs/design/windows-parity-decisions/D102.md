# D102 - When Ghoztty reopens with many saved windows, should they all appear at once, or should it bring back your last window first and the rest gradually or on request?

## Why this needs a call

Session persistence encourages keeping many terminals alive across weeks, and today both Mac and Windows rebuild every one of them in a single burst at launch. Nothing paces it, nothing picks which window comes first, and there is no way to say 'not now'. On 2026-08-23 a burst like this coincided with a system hang on Windows (not proven to be the cause). Each option changes what you see when Ghoztty starts, so it is your call, and whichever you pick will land on both platforms.
