# D106 - When you drag a window edge outward, should the edge keep up with the mouse first, or should the panes never flash blank background?

## Why this needs a call

Since 1.51.6 the panes are laid out before the window frame grows, so content and frame appear together and no blank strip shows. That costs time on every growing step: the app waits for the terminal to draw at the new size before letting the edge move. You reported resize feels slower; this turn removed the part of that cost that bought nothing, and what is left is the wait itself, which is the whole point of the change.
