# D103 - When a web page from another machine shows in your window, should everything it loads come from that machine?

## Why this needs a call

On your own machine a preview's requests obviously come from you. When the page is opened by something running on another machine, either machine could make them, and you would notice the difference: the other machine's localhost and private network only work if it makes them. You said requests should go to the remote machine; this records that choice so you can overturn it.
