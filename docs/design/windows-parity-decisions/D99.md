# D99 - Should Ctrl+Enter keep switching a window to full screen on Windows, now that F11 does it?

## Why this needs a call

On Mac the full-screen key is Cmd+Enter, which no terminal program ever wants. Windows inherited Ctrl+Enter, a key terminal programs (Claude Code included) use all the time, so a window can drop into full screen by accident, which is the report this came from. F11 is the Windows full-screen key and now works too. The open question is whether Ctrl+Enter should stop doing it.
