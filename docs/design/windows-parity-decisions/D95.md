# D95 - Which keys should bring back a pane or tab you just closed on Windows?

## Why this needs a call

On Mac, Cmd+Z right after closing a pane brings it back with its program still running. Windows cannot use the same key: Ctrl+Z belongs to the shell (it suspends or ends input), so a Windows undo key must be something else, and whichever it is will feel different from Mac.
