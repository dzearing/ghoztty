# T2408 - The Windows pane sidebar's all-windows list starts with every window folded, the one it was turned on from included (Mac 7e2d0a9da)

## Summary

Mac main 7e2d0a9da: turning on the all-windows scope now folds EVERY window, including the one the list was turned on from - one row per window, the overview the scope is for (search still unfolds all; PaneSidebarState.isWindowFolded). Previously the current window started unfolded. Windows: change the initial fold state in the win32 sidebar's all-windows mode and update its acceptance (pane-sidebar-all-windows.ps1). Ref docs/reference/pane-sidebar.md on main.

## In plain terms

When you switch the pane sidebar to "all windows", Windows used to open the
window you were in with all its panes listed and fold every other window to
one line. The Mac now folds every window, yours included, so the list starts
as a clean one-line-per-window overview. Windows now does the same; a search
still opens everything, and the chevron opens any window you want.

## Goals

- [x] Turning the all-windows scope on folds every window, the current one included
- [x] Search still unfolds everything; hand-made unfolds still work and are forgotten when the scope goes off
- [x] Every sidebar harness that leaned on "this window starts open" now unfolds it explicitly
