# T2915 - Mac: a window opened the moment the local agent dies should recover first and come up persistent, not wait out the settle window (T1473 port)

## Summary

T1473 fixed this on Windows: a dead agent PROCESS (not a wedged one) now skips the 5s settle window, and a new window that finds the agent dead runs in-place recovery first and gets the fresh agent, instead of opening a silently non-persistent shell. The Mac LocalAgentManager has the same settle window (SharedLinkDropVerdict, 03f0f1f30/e65cfa4d5) and likely the same gap. Check whether a window opened inside it on macOS opens unpersisted, and port the two decisions (src/apprt/win32/agent_recovery.zig settleWaived + newSurfaceVerdict) - a dead pid cannot heal its link, so waiting proves nothing.
