# T1595 - Nothing proves on-box that a debug agent's orphan sweep spares a release holder

## Summary

holder_adopt.reapOrphans is scoped by the holder pipe prefix: username, build mode and (since T1594) the GHOZTTY_AGENT_INSTANCE lineage. T1594 added section E of test\win32\holder-adopt.ps1, which proves the LINEAGE boundary on the box and demonstrates its teeth (strip the segment, E3 goes red). The BUILD-MODE boundary has no such proof - it is asserted only by the isHolderPipe unit test - and it is the boundary that stands between a dev agent and the user's own live shells, since every acceptance run on this box is a debug agent running feet away from the release holders holding the user's panes. Add a section that stands up a release-lineage holder (or a hand-named pipe in the release shape) and shows a debug agent's startup sweep leaves it alone, with the same strip-it-and-watch-it-fail demonstration.
