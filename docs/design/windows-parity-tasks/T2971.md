# T2971 - PA-R05: every drawn frame builds a full viewport string and byte map for link matching even when no link can highlight (Ctrl not held)

## Summary

PA-R05 (audit-1, T2959). link.zig:76-83 renders the viewport into a string plus per-byte coordinate map before the per-link highlight check at :89-101; generic.zig:1591 calls renderCellMap unconditionally. The default link highlights only on hover with Ctrl (config/Config.zig hover_mods), and generic.zig:1557-1563 already computes the exact predicate (`needed`) but only uses it for seams. Cost estimated: cols x rows string and map allocated, grown and freed per frame, up to 120 fps under output and on every blink tick. Fix: skip renderCellMap when !needed. Risk very low. Shared code: Mac half filed with the shared-renderer Mac task.
