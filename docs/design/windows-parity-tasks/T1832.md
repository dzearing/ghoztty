# T1832 - Windows windows all share one backdrop: Mac gives each new window (and +new-window --color=random) its own random one-hue gradient

## Summary

In the elevated style, +new-window --color=random randomizes the window's gradient desk instead of tinting its terminals (fe3f7c8da); a window opened by hand (Cmd-N / New Window menu / palette) gets one by default, while programmatic, moved and restored windows keep theirs (a516200d2). Hue comes from the whole wheel (5ba797c8c); a variant is one hue lit by a soft elliptical spotlight above the top center, the base grading darker toward the bottom-trailing corner (lighter on a light theme) (a34653b2a), with a dim pool of the complementary hue in that corner (b4a3216cc). Persisted as a seed in the session manifest and derived per current theme. Explicit hex, split colors and the flat style keep the terminal tint. Windows: Ctrl+Shift+N / New Window equivalents.
