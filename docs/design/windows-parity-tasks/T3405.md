## Summary

T3394 added test\win32\lib\UserInstallSentinel.ps1 (Get-PackageUserProductReach refuses a package that can act on the shipping product; Get-UserInstallSnapshot/Compare-UserInstallSnapshot + Get-UserProductInstallerEvents prove the user's install did not move) and wired it into update-real-msi and update-graceful only. Four more harnesses still run msiexec /i on a real package: arp-orphan, install-walkthrough, msi-upgrade, one-installer (grep for Start-Process msiexec / '/i'). Wire the same pre-flight before each install and the snapshot+event check in each finally, and add a harness-floor audit row that fails any test\win32 script that runs msiexec /i without loading the sentinel, so the next installer harness cannot ship without it.
