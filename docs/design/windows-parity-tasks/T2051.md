# T2051 - A ReleaseSafe build's app and agent disagree on whose endpoints they use: the app derives the -debug family, its agent the user's

## Summary

Found by T1036, inferred from source and not yet reproduced. agent_build_options.is_debug is optimize==Debug ONLY (src/build/GhosttyAgent.zig:70), while build_config.is_debug - what the app and LocalAgent.zig switch on - is Debug OR ReleaseSafe (src/build_config.zig:109). So a ReleaseSafe zig-out's app derives the -debug pipe/state names, but the agent it spawns takes the release single-instance guard, heartbeat and state dir (main.zig local_instance_base splits by the agent's is_debug): the user's installed agent's. Fix: make the agent's is_debug follow build_config's rule (Debug|ReleaseSafe), then confirm with ghoztty-agent --build-mode on a ReleaseSafe build (expect endpoints: debug) and an end-to-end launch that the user's agent is untouched.
