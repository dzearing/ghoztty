# T2276 - Stashed panes on Windows have no tray in the pane sidebar: Mac lists them after the last pane under a divider, in the same scrolling list, and dragging a pane in stashes it and out restores it (Mac e77422577, d85e4c0e0, 543489bca)

## Summary

Mac e77422577 + d85e4c0e0: the tray of stashed panes is part of the one scrolling list, under a divider that follows the last pane (not pinned to the bar's bottom); a drag slides panes, the tray header and stashed rows as one sequence, so a row crossing between them moves the divider too. Drag any pane in to stash it, out to restore it (sidebarOrder split from .stash at the tray divider). 543489bca: an EMPTY tray is still a visible drop target (dashed well + tray glyph). 0a547522d: the tray divider reads on glass (22% white, was 9%). Windows has +stash/+restore and stash keybinds (T1827) but no tray in the sidebar.
