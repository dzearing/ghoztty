# T2441 - The T2418 divider-ghost probe (real-pointer WGC capture of a divider drag, one bar per frame, no doubled pane column) lives only in lane B's ignored temp\t2418; make it a committed opt-in -Live harness under test\win32 with a planted-defect control

## In plain terms

The user reported that dragging a divider leaves copies of the bar behind it
and the growing pane does not repaint (T2418). The tool that photographs that
drag frame by frame, with the real mouse, existed only as scratch files in one
working copy. Now it is a committed test anyone can run on an idle box, and it
judges the doubled pane edge automatically instead of by eye.

## Goals

- [x] the probe is a committed harness: `test\win32\divider-ghost.ps1`, scorer in `test\win32\lib\DividerGhostScore.ps1`
- [x] it knows the hover colour, so pre-press / post-release frames are not read as a vanished bar
- [x] the doubled first column (class 2) has an automatic oracle: the STRIP reading
- [x] a planted-defect control: `-Live -Control stale` (GHOZTTY_LAB_PLANT=stale@8)
- [x] -Live is opt-in and presence-gated; guard rows `divider-ghost` and advisory `divider-ghost-live`
- [ ] the first green live run (and the control's catch) - owed to T2418's validation, needs an idle box

## Summary

`divider-ghost.ps1` is the T2418 probe (lane B `temp\t2418\ghost-probe*.ps1`)
made permanent. Default run: 22 synthetic assertions proving every scorer
reading on frames with known truth (clean drag, GHOST sliver, SMEAR, STRIP of
the old first column, GONE, hover frames unscored, strip-row selection,
summary). `-Live`: SendInput at 1 kHz via `lib\FrameLabInput.ps1` in three
plays (hover -> learn hover colour; press -> learn drag colour, bar extent,
strip rows; drag+release -> scored by WGC), the right pane filled with text so
its first column is on the strip rows, dim wash off (`-Dim` keeps it, never
stamps), occluded display (T2645) is a SKIP, button always released in the
finally. `-Control stale` asserts the plant fired and was caught.

Decisions (mechanism, mine): a separate small scorer rather than growing
DfScorer (divider-flicker's posted-drag matrix already counts GHOST on banner
rows; this one is the real pointer and the strip oracle); the strip oracle
compares the zone the left pane grew into against the left pane's own blank
colour on rows chosen from the pressed frame, so it needs no theme knowledge.

Not declared in lib\TestDesktop.ps1's `@input-desktop-exception` list:
foreground-audit's detector cannot see input-desktop use through a helper and
reads the declaration as stale - filed as T2730.
