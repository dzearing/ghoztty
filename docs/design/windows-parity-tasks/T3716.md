# T3716 - Remote git status and git diff viewers: the agent runs git in a granted directory, parsing stays local (Windows + shared)

## Summary

Decision 1 of docs/design/remote-viewer-tunnel.md: a diff viewer of a remote worktree renders git output the agent produced on its machine. Add a gated capability and request/reply frame pair (agent runs a FIXED set of read-only git argv - status --porcelain, diff, show - with cwd inside a grant root, output size-capped like max_viewer_file_bytes, no shell), and route the win32 diff viewer (viewer_diff.zig / ViewerDiffProbe.zig) through it for a remote origin. The parser is unchanged; only where the bytes come from moves.
