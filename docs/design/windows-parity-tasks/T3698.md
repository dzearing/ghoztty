# T3698 - Linux L10f3: the GTK pane sidebar's stash tray - stashed panes in a tray under the list, rows dragged into it stash and out of it restore

## Summary

Split from T3607. GTK draws a stashed pane in place in the list (dimmed, not draggable). Mac and win32 move stashed panes into a tray below a divider (PaneDropCandidate.Sidebar.trayTop): any row dragged below the divider stashes, a tray row dragged up into the list restores at that place (win32 pane_sidebar_reorder.slide/trayIndex/trayTargetWithout, Window.placeInPaneSidebar). docs/reference/pane-sidebar.md 'Drag to reorder', 'Stashing invariants'. Extend PaneSidebar.dropRowAt and test/linux/cli-sidebar-drag.sh.
