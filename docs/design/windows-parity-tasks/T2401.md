# T2401 - Pulling out the Windows pane sidebar (the left pane) snaps it open in one frame instead of sliding it out, as Mac's sidebar glides

## Summary

User report 2026-10-28 (interactive, installed build 1.48.4+a691d5f4d): when the user pulls out the left pane (the pane sidebar), it jumps straight to its open width instead of sliding out. A sidebar column glide exists on Windows (T2365 put it on the vsync frame clock; T2391 fires it in the frame lab), so either the path the user takes skips it, or the glide runs but nothing draws its in-between frames. First find which gesture 'pull out' is: the toggle button, the keybind, dragging the collapsed rail's edge outward, or a hover reveal. Test every one, and make each open AND close slide with Mac's duration and curve (read the Mac sidebar code for the reference and cite it). Every glide frame must be fully painted, with no black or stale areas in the panes it pushes over (same bar as T2400). Acceptance: a WGC capture (T2373 camera) of each gesture shows the sidebar width moving through intermediate values over several refreshes, with no single-frame jump and no unpainted frames; and the user sees it slide in the relaunched installed build.
