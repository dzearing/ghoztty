# T3382 - Linux: +new-window --color / --split-color and +split --color tint the new pane on GTK

## Summary

T3370 serves +new-window and +split on GTK but ignores --color and --split-color (T67: #rgb, #rrggbb or random tints the pane background with a contrast foreground and adjusted palette; win32 applyBackgroundTint, the Mac applyColorScheme). Port the tint to the GTK surface using the shared color math. Acceptance: a test/linux/cli-*.sh check that the pane reports the tinted background (+list or a debug seam).

## In plain terms

On Linux, asking for a coloured window or pane (`--color=#a05010`, or
`random`) did nothing: every pane came up in the theme's background. Now the
pane takes that colour, its text switches to black or white so it stays
readable, and a pane split off a coloured one starts in the same colour - the
way it already works on the Mac and Windows.

## Goals

- [x] `+new-window --color` tints the window's first pane
- [x] `--split-color` tints the inline split of `+new-window --split`
- [x] `+split --color` tints the new pane, over any inherited tint
- [x] a split inherits its parent's tint (Mac `newSplit`, win32 `newSplitAt`)
- [x] the contrast foreground and adjusted palette come with the tint
- [x] `+list` reports `background_tint` for a tinted pane

## Design

- `Surface.applyBackgroundTint` (GTK `class/surface.zig`) stores the tint and
  applies it to the core terminal under the renderer mutex in one hold (bg,
  contrast fg, base-16 palette, regenerated 16-255, renderer min-contrast
  floor) - the same steps as win32's. A new window's or split's GL area
  realizes after the IPC handler returns, so a tint set before the core
  surface exists is kept and applied in `initSurface` right after it is made.
  A viewer pane has no terminal and ignores it.
- Split inheritance is in `SplitTree.newSplitAt` through
  `color_math.splitTint`, so a keyboard split inherits too, as on Mac/win32.
- The tint math is win32's pure `color_math.zig`, imported as other GTK files
  import win32's pure modules.
- Not here: the window's gradient desk for `--color` (T3566), and keeping the
  tint across a session restore (T3589). Unfocused-split dimming fills with the
  config colour, not the tint, which is what the Mac does too.
