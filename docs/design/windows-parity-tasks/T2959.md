## In plain terms

Ghoztty's drawing code (the part that paints text and sends frames to the
graphics card) costs memory and graphics power for every pane you open. This
audit reads that code, finds every place it does more work or holds more
memory than it needs to, double-checks each claim, and turns each real one
into a fix in the queue.
