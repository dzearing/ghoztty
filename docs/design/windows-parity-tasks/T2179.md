# T2179 - Add a harness-floor audit that classifies every Start-Sleep in test\win32 and ratchets the bare (non-loop, undeclared) count so it can only fall

## Summary

Split out of T1228 (2026-10-22). A fixed `Start-Sleep` standing in for "by now
the other thing has happened" is a race that goes red only when the box is
busy (T1164's section-M flake). T1228's census, taken with the PowerShell AST
(`[Parser]::ParseFile`, every `CommandAst` named `Start-Sleep`/`sleep`, walked
up through its parents for a loop statement):

- **3287** sites in `test\win32\**\*.ps1`
- **1281** inside a `while`/`do`/`for`/`foreach` body - poll intervals, fine
- **2006** bare - the handshake candidates. The most common shapes are
  `-Seconds 3` (319), `-Seconds 2` (209), `-Milliseconds 800` (174), `500`
  (173), `400` (170).

Worst files by bare count: activity-monitor 45, pane-banner 35, hero-mode 34,
relay-account 32, split-divider 29, palette-order 27, activity-monitor-remote
27, menu-bar 24, conformance 23, tab-strip 22 (T2180 converts these).

Two thousand sites cannot be converted in one context, so the gate comes
first. Build `test\win32\lib\SleepAudit.ps1` (the AST classifier above) and a
harness-floor member `test\win32\sleep-handshake-audit.ps1` that sorts every
site into **poll** (inside a loop, or inside a scriptblock handed to a wait
helper), **settle** (a bare sleep carrying `# settle: <reason>` on its line or
the line above - a debounce the product itself has, where the sleep IS the
subject), and **bare**. It fails when any file's bare count rises above a
committed per-file baseline (a ratchet: conversion lowers the baseline, a new
harness starts at zero), and when a `# settle:` carries no reason. Needs the
usual: a row in `scripts\lib\HarnessFloor.ps1`, a guard-due row, and a
`-NegativeControl` that plants a bare sleep into a fixture and proves it reds.

## Validation criteria

- [ ] the classifier's census matches T1228's numbers on the tree it ran on (or explains the delta)
- [ ] a new bare sleep in any harness fails the audit; a `# settle:` without a reason fails it; `-NegativeControl` proves both
- [ ] the audit is a harness-floor member with a guard-due row, and the floor is green with it
