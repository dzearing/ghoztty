# T2756 - A banner's plain first line names its pane in the sidebar and on stacked strips (Mac 5b0a41036)

## Summary

Mac 5b0a41036 widened PaneSidebarText.bannerTitle: the banner's first line is now the title unless it is a table/rule line, a list item, a bold label, a bold run followed by prose, or a bold line heading more lines. Typing foo at Ctrl+Shift+R must name the pane foo in the sidebar and on a stacked strip. win32 pane_sidebar.zig bannerTitle (src/apprt/win32/pane_sidebar.zig:244) still carries the old heading-or-lone-bold rule; port the new rule and its PaneSidebarStateTests cases into the none-lane unit tests, and check bannerSubtitle/distinct still blank the subtitle when the title is the first line.
