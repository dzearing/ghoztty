# T2879 - Ctrl+V with a picture and its address does not reach Claude Code installed through npm: the pane check looks for claude.exe and npm's Claude runs as node.exe

## In plain terms

Ctrl+V with a copied browser image now reaches Claude Code, but only when
Claude was installed with its own installer. Someone who installed Claude Code
with npm still gets the image's address pasted instead.

## Summary

T2721 decides "this pane runs Claude Code" by looking for `claude.exe` under
the pane's shell (`ProcessTree.claudeRunsUnder`, `claude_image_paste.isClaudeExe`).
A global npm install runs Claude as `node.exe ...\@anthropic-ai\claude-code\cli.js`,
which a process name cannot tell apart from any other node program. Fix: for a
`node.exe` under the shell, read its command line (`NtQueryInformationProcess`
`ProcessCommandLineInformation`, or the PEB) and match the `claude-code` package
path - only on the rare picture + address clipboard, so the cost stays off the
ordinary paste.

## Validation criteria

- [ ] A pure unit test matches an npm Claude command line and rejects other node programs.
- [ ] `test/win32/clipboard-paste.ps1` gains a section with a `node.exe` probe whose command line names `@anthropic-ai/claude-code`: Ctrl+V reaches it as ^V.
