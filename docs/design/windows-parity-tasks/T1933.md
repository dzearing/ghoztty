## In plain terms

When we pull new code from the original Ghostty project, a script puts our own
name back on things. That script only knew a few spots, so about 160 places
where the app shows its name to people (menu items, alerts, help text, the
macOS privacy prompts) would have quietly gone back to saying "Ghostty". Now
the script knows all of them, so a future pull keeps saying "Ghoztty".
