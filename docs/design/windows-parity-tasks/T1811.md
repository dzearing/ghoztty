# T1811 - A CLI-opened background window ignores the remembered maximized state (Windows has no non-activating maximize)

## Summary

Found during T1797. Window.showInBackground shows with SW_SHOWNOACTIVATE because SW_SHOWMAXIMIZED is the only maximize show command and it activates, so a +new-window without --focus opens at its restored size even when the T85 placement memory or the maximize config says maximized. Documented as a known limit in docs/claude/cli.md. Investigate a non-activating maximize that does not produce the T748 hybrid state (e.g. SetWindowPlacement on the still-hidden window, or maximize on first user activation) and, if one holds, apply it in showInBackground with a test-desktop assertion (IsZoomed + active window unchanged).
