# T2085 - Name pane sidebar rows, rail tiles and stacked strips by the banner\u0027s title when it has one

## In plain terms

Claude Code renames its pane with whatever it is doing at the moment, so
the pane sidebar fills with "Reading file..." titles. The pane's banner
title says what the pane is FOR. When the banner has a title, the sidebar
row, the rail tile and (once stacked panes land) the strip show it instead.

## Summary

Mac f9e99a860 (`feat(macos): name stacked strips and sidebar rows by the
banner title`): a minimized pane's strip, its pane sidebar row and its rail
tile show the banner's title when the banner has one, else the pane's own
title. A banner title is an `## ` heading on the first line, or a one-line
banner that opens with a standalone bold run. It updates live on
`+set-banner`, OSC 7778 and Cmd+R, and clearing the banner brings the pane
title back. The sidebar subtitle no longer shows a raw `## ` heading, and a
titled banner leaves the subtitle to the working directory.
(`PaneSidebarState.swift`, `PaneSidebarRow.swift`, `PaneStackTab.swift`,
with PaneSidebarStateTests.)

Windows: `PaneSidebar.zig` already reads `banner_text` (line ~583) for its
rows. Add the same title extraction as a pure function (shared with
`banner_markdown`), use it for the row title, the rail tile tooltip/label
and the subtitle rule. The strip half lands with T2082.

## Goals

- [x] The banner's title names the sidebar row, the rail tile's monogram and

- [x] A titled banner leaves the subtitle to the working directory; an
      untitled banner's first line stays the subtitle.
- [x] The all-windows search still finds a pane by its own title.
- [ ] The stacked strip half - carried by T2082, which must name strips with
      `pane_sidebar.paneLabel`.

## What landed

- `pane_sidebar.zig`: `bannerTitle` (the Mac rule, word for word: an ATX
  heading on the first line, or a ONE-line banner opening with a bold run
  that stands alone or before ` · `, never a `**Label:**`), `paneLabel`
  (banner title, else `displayTitle`), `bannerSubtitle` (no first-line
  subtitle when the banner is titled), and `bannerLine` now strips a heading
  to its text instead of showing a raw `## `.
- `PaneSidebar.zig`: rows (and so tiles and tips) take `paneLabel`; the
  subtitle takes `bannerSubtitle`; the search matches the label AND the
  pane's own title (Mac `searchFields`). No new refresh path was needed: the
  roster signature already hashes `banner_text`, and `setPaneBanner` re-runs
  `layoutSplits`, which syncs the sidebar - so it is live on `+set-banner`,
  OSC 7778 and the banner editor alike.
- New `pane sidebar text` debug line (each row's id, title, subtitle; once
  per change) - the oracle for section 10 of `test\win32\pane-sidebar.ps1`.
