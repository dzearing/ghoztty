# T3364 - acceptance-parallel due sweep aborts mid-run when taskkill cannot terminate a timed-out row's child process

## Summary

scripts\lib\AcceptanceParallel.ps1:796 runs '& taskkill.exe /T /F /PID ... *> $null' under the file's $ErrorActionPreference = 'Stop' (line 91). In PS5.1 a native command's stderr becomes an ErrorRecord, so when taskkill reports 'The process with PID N (child process of PID M) could not be terminated' the whole sweep throws and stops: on 2026-11-21 (lane b, T1767) a 32-script due sweep died after 26 rows with no verdict line, leaving the rest unrun and unstamped. Fix: run taskkill under a local Continue preference (the line-202 pattern) and report the unkillable child instead of throwing; add a harness check that a finish over an unkillable child still yields a verdict.
