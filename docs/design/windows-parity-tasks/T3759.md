# T3759 - Linux L11g2b: the GTK Settings curated color rows get a color well and the starting-folder row a Home / Where launched / Choose Folder picker, instead of a text field

## Summary

T3631 drew the curated pages on GTK; color (cursor-color, unfocused-split-fill, split-divider-color) and folder (working-directory) rows are still edited as value text. Port Mac ColorControl (GtkColorDialogButton, the none_label for unset, #rrggbb via settings_controls.formatHex) and FolderControl (Home folder / Where Ghoztty was launched / Choose Folder via GtkFileDialog, folderLabel with ~). Drive both through the settings seam (color/folder gestures) in test/linux/settings-window.sh.

## In plain terms

In the Linux Settings window, the cursor, dimming and divider colors were
plain text boxes where you had to type a hex code, and "Start new windows in"
was a text box where you had to type a path. Now each color is a swatch that
opens a color picker (with a "Use Theme"-style link to go back to the
default), and the folder row is a menu: Home folder, Where Ghoztty was
launched, the folder you picked, or Choose Folder... - the same as on the Mac.
