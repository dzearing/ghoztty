# T1848 - No Window-menu entries for the pane sidebar on Windows: Show/Hide Pane Sidebar, Stash Pane, Restore Stashed Pane

## Summary

Follow-up of T1828 (Mac: all three sit together in the Window menu after Toggle Rearrange Mode). Add them to the win32 app menu wherever Toggle Rearrange Mode lives, with their chords shown (ctrl+shift+s, ctrl+shift+m, unbound restore).

## In plain terms

On the Mac, the Window menu has three rows for the pane sidebar: show or hide
it, stash the focused pane, and bring a stashed pane back. Windows had none of
them, so you could only find these features if you already knew the keyboard
shortcut. After this, the Windows menu has the same three rows in the same
place, showing their shortcuts and graying out when they cannot do anything.

## Goals

- [x] Window menu gains Show/Hide Pane Sidebar, Stash Pane, Restore Stashed Pane after Toggle Rearrange Mode, behind a separator (Mac's MainMenu.xib order)
- [x] The sidebar row reads "Hide" while the sidebar shows and "Show" while it is hidden (Mac validateMenuItem retitle)
- [x] Gating matches Mac: no sidebar (quick terminal) grays all three; Stash needs a second pane on screen; Restore needs something stashed
- [x] Chords come from the live keybind set: Ctrl+Shift+S, Ctrl+Shift+M, none for restore
- [x] The three commands join the win32 command registry, so the palette's rows are the registry's (the core defaults they replace are deduped by coversDefault)
