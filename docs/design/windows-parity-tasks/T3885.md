# T3885 - Every perf-baseline -Exe A/B before T3880 measured the repo's own build on both sides: re-check the conclusions of T3234/T3242, T3236, T3231 and T3111 that rest on one

## Summary

T3880 found that scripts\perf-baseline.ps1 overwrote its -Exe parameter (PowerShell names are case-insensitive: the default '$exe = Join-Path ...' assignment WAS '$Exe') before reading it, so from a23d3b36e0 (T3111) until the T3880 fix every '-Exe <base>' run measured zig-out(-release) - the same binary as the other side. Conclusions that rest on such an A/B are therefore unproven: T3234's 'no gap beyond spread' (closed as box drift via T3242), T3236's agent_cpu_s -28% (base = same tree with coalescing short-circuited), T3231, and any T3111 A/B. For each: read its evidence, decide whether the claim rested on the -Exe side, and re-run it with the fixed script (base built into an in-repo zig-out-<name>\ prefix; outside-repo exes are refused by Stop-RepoGhoztty). Reopen or re-file what does not hold.
