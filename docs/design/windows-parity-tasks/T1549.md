# T1549 - Activity Monitor never says its %CPU figures may be untrustworthy on an older agent

## Summary

Mac titles the column '% CPU (?)' and greys its numbers when the machine's agent does not advertise cpu_units (RemoteActivityMonitorView.swift:1101-1108, 1205-1216), because a pre-fix agent can report per-process CPU up to ~24x low and nothing on the client side can tell. The header tooltip and a control-bar warning both read the one explanation string. The win32 panel prints the number as fact whatever the agent is. Relative ordering is unaffected either way, which is why this is a marking rather than a correctness fix; it needs the capability to reach the panel and a place to put the explanation (see T1548, which is the tooltip half).
