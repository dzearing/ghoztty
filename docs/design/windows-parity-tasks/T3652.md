# T3652 - Linux L11k5: single-window mode on GTK - closing the workspace on show hands the window to the one shown before it, a parked one closes in place, the last closes the window, undo brings it back on show

## Summary

Closing semantics (Mac workspaceWillClose/didClose; win32 T3184, T3200): Ctrl+Shift+W, the headerbar close, +close, the sidebar x and a last pane exiting; a close that needs confirming puts a parked workspace on show first so the dialog has a window; undo of a close brings the workspace back on show; the window closing with workspaces left (not at quit) gives the next one a window. Spec: docs/reference/window-modes.md (Closing).
