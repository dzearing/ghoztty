## Summary

test\win32\sleep-handshake-audit.ps1 section B extracts ee8597405's test\win32 with a bare 'tar.exe -xf'. Under a PATH inherited from Git Bash (the Bash tool, or acceptance-parallel launched from it) that resolves to Git's usr\bin\tar.exe, which treats 'C:\...' as host:path, extracts nothing, and B1 reads 0 .ps1 files. From PowerShell the same run is ALL PASS 26 (System32 tar). Fix: call System32's tar.exe by full path and sweep test\win32 for other bare tar.exe calls. Found by T2193 on 2026-11-24.
