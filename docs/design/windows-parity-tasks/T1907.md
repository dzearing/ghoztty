# T1907 - A glass pane's desk slice is re-rendered on the UI thread for every pane on every divider-drag mouse move: about 4.7ms per large pane in Debug

## Summary

syncGlassBackdrops keys each pane's backdrop on its rect, so a divider drag re-renders (desk_palette.renderDeskRegionRgba, quarter resolution, per-pixel gradient math) and ships a new slice for both resized panes every move: 4658us for a 1250x1350 pane in Debug (microbench 2026-10-13), inside drag-perf's paint term. Options: hand the renderer the whole desk once and a sub-rect per move; or crop from PaneDesk's cached quarter-size desk instead of re-evaluating the gradient; or defer the slice to drag end. Must keep the glass seam-free during the drag.
