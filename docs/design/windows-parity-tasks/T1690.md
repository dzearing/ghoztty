# T1690 - Every Ghoztty window dies when Windows updates or resets the graphics driver

## Summary

On 2026-09-20 Windows Update replaced the NVIDIA display driver under a running app; the renderer logged three 'software processing fallback in framebuffer pipeline' warnings and the whole process died, taking every window with it (the agents kept the sessions). The app must survive a GPU device loss / driver swap: detect the lost OpenGL context and rebuild the renderer (or fall back) instead of dying. Reproduce with a driver reset (e.g. Win+Ctrl+Shift+B, or disabling/enabling the display adapter) against a zig-out build; the T1686 exit ledger names what happened.
