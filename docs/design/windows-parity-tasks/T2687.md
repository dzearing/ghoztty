# T2687 - Settings > Sessions & Agent: show the running agent's session count (Mac 'Running - N sessions') without blocking the GUI thread

## Summary

Split from T2680. Mac's Agent status reads 'Running - 3 sessions' from LocalAgentManager.listLocalSessions on a running agent. Windows (T2680) shows 'Running - pid N' because counting sessions needs a request to the agent, which Settings must not make on the GUI thread and must never make by dialing/spawning. Ask the WARM shared connection only (LocalAgent.sharedConnectionIfWarm) for its session list on a worker, post the count back, and paint it in settings_live.statusLine; assert in settings-window.ps1 section J with a real agent under the test lineage.
