# T2525 - Windows pane sidebar: renaming a grouped window edits its own name only and keeps the group (empty changes nothing); typing <group>: moves it to that group (Mac 7bee055c9, a0f6090a3)

## Summary

Mac 7bee055c9 + a0f6090a3 (PaneSidebarWindowGrouping.renamed): a grouped window's rename field holds its own name without the <project>: prefix and keeps the prefix on commit, so retyping or clearing cannot ungroup it by accident; empty changes nothing. Typing a <project>: prefix names the group outright (dzearing: foo moves it to group dzearing as foo). Leaving a group is explicit only (Remove from Group or a drag out). An ungrouped window's field still holds its whole title, empty returns to following the window's own title. Mac reference: docs/reference/pane-sidebar.md, Reordering > renaming.
