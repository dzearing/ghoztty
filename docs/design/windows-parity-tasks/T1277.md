# T1277 - New Window on a relay window fails when the app is signed out, even though the window itself is connected

## Summary

openRemoteWindowFrom resolves the relay bearer from the account/env store only (IpcHandlers.resolveToken), so 'New Window' on a window opened with an explicit --token answers 'no relay credential (signed out)' and shows the couldn't-reach-the-machine dialog - on a window whose own link is live. Same root cause class as T1276, which fixed the reconnect half by recording the dial bearer on Window.RemoteMachine.relay; this path should use the same fallback (remote_reconnect.chooseRelayToken).

## In plain terms

If you opened a remote window by handing Ghoztty a relay token directly
(rather than signing in), pressing New Window in it failed with "couldn't
reach the machine — are you signed in?", even though the window you were
looking at was connected and working. Now New Window reuses the same
credential that window was opened with, so a second window on the same
machine just opens.
