# T3858 - Seven direct XDG_*_HOME readers still accept a relative value (enroll, single_instance, relay_account, viewer_prefs, four GTK path helpers)

## Summary

T3745 fixed os/xdg.zig so a relative XDG_CONFIG_HOME/CACHE/STATE is ignored per the XDG spec (it used to crash the app at launch). Several sites read the variable themselves and still join a relative value: src/remote/agent/enroll.zig:300, src/remote/agent/single_instance.zig:661, src/remote/relay_account.zig:138/146, src/apprt/win32/viewer_prefs.zig:54, and the GTK helpers (LocalAgent.zig:461 paths.configRoot, PaneSidebar.zig:174/180, RelayWindows.zig:87, SessionLayout.zig:108, ShortcutGuideWindow.zig:800). None crash, but each would put its file under the process cwd instead of the platform default. local_agent_paths.zig already ignores a relative value - route the rest through one absolute-only helper (or os/xdg) and unit-test a relative value for each.
