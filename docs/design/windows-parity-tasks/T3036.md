# T3036 - PA-V04: a viewer rebuilt into a background tab starts its renderer and loads its page before anyone can see it (Window.zig:3997)

## Summary

PA-V04 (audit-1, T2963). Window.zig:3997 calls viewer.start unconditionally; setTabSurfacesVisible (Window.zig:4425-4427) says rebuilt background tabs start visible and are hidden afterwards. Session restore taking this path is inferred, not traced. Cost (estimated): one renderer (50-150 MB) and a full page load per never-shown viewer. Fix: defer start() to the first setVisible(true), keeping title from restore metadata. Risk: +read and screenshots of a never-shown viewer need start on demand; first reveal shows a load flash. Findings: docs/design/perf-audit/audit-1/V-findings.md.
