# T2290 - The expanded Windows pane sidebar is a flat panel down the window's side; Mac's is the rail's own raised card, wider, in the same gutters, top and height with every row one height, drawn in the elevated style as an unfocused pane's card (Mac 0a547522d, 351868cb5; split from T2274)

## Summary

Expanded = same card as the rail (same insets/top/height), the column = the rail's insets + the panel width (Mac `columnWidth`), the edge grip in the gutter beside the card (Mac `edgeGrip`), clicks only on the card. Elevated pane style: the card - in BOTH modes, since it is one card - is painted like an unfocused pane card (pane corner radius, pane hairline rim, pane sheet and shadow); flat keeps the side-panel card. The "every row one height, so icons do not move on toggle" half is T2279's: it is the rail-as-rows-minus-text change (Mac 75dc046e3, `PaneSidebarRow.height` 38 for rows AND tiles), which cannot land on the Windows rail's 28 DIP square tiles without that redesign.

## In plain terms

When you opened the pane list on Windows it turned into a flat strip
running down the whole left edge of the window, while the narrow version
was a small floating card. On Mac both are the same floating card - the
open one is just wider - and in the raised style it looks exactly like
the panes beside it. Now Windows does the same: opening the list widens
the card in place, with the same margins, and it wears the same glass,
edge and shadow as a pane.
