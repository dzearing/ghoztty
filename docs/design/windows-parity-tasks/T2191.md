# T2191 - floor-lane parallel says CONTENTION (the box, not the code) when the source changed between the side-by-side run and the solo re-run

## Summary

On 2026-10-23 (T2169) win32 and agent failed side by side on a real GPA leak in install_location tests; the leak was fixed before the solo re-runs, which passed, and the summary printed FLOOR PARALLEL CONTENTION ... the box, not the code. A solo re-run must compare the tree it builds against the one the side-by-side run built (e.g. git diff hash / newest source mtime) and, when they differ, say SOURCE CHANGED instead of blaming contention - otherwise a genuine code defect gets reported as box flakiness.
