# T2068 - Mac: a waiting background-process update has no menu row (Windows got 'Background Update Ready...' in T1068)

## In plain terms

When a newer background process (the thing that keeps your terminal sessions
alive) is installed but cannot take over yet because sessions are open, Mac says
nothing at all. Windows now shows a quiet "Background Update Ready…" menu row
that explains the wait and lets you install it early on purpose. Mac needs the
same row.

## Summary

T1068 landed the Windows half. Port it to `LocalAgentManager` / the app menu:

- When the staleness check lands on the two leave-alone outcomes (stale with
  live sessions and no self-handoff; or handoff-capable but still draining
  directly-owned sessions), set a "pending" state; any check that answers the
  question (current / newer / idle refresh / handoff under way) clears it. Skew
  and unknown-bundled checks leave it untouched. Windows' pure policy is
  `agent_upgrade.pendingFor` / `settlesPending` in
  `src/apprt/win32/agent_upgrade.zig`.
- A conditional app-menu item titled **Background Update Ready…** (no badge or
  dot: waiting costs nothing), plus a palette row **Install Background Process
  Update…** listed only while pending (not pinned, not emphasized).
- Choosing it re-runs the check first (idle ⇒ silent refresh, no dialog), then
  asks with title "Install the background process update now?", body from
  `installNowText` (says waiting is free BEFORE it names the N sessions that
  end), buttons **Restart Now** / **Later**, default Later. Restart Now = the
  existing "Restart Ghoztty and Background Sessions" restart, not asked twice.
- Never a modal or notification on its own; nothing ends a session unless the
  user chose the row and then Restart Now.

## Validation criteria

- [ ] stale agent + live session ⇒ the menu item appears, no dialog, agent pid unchanged
- [ ] closing the last session ⇒ silent refresh, menu item gone
- [ ] choosing it ⇒ dialog defaults to Later; Later changes nothing; Restart Now relaunches onto the bundled agent
- [ ] current agent ⇒ no menu item
