# T3859 - frame-lab.ps1 -Live and divider-ghost -Live still lose the own-input discount across processes: adopt the T2633 own-input ledger (Start-OwnInputClock / Save-OwnInputLedger / -CarryOwnInput)

## Summary

T2633 added a cross-process own-input ledger to lib\UserPresence.ps1 and wired it into the chain-fold recorder only. lib\FrameLabDriver.ps1 still discounts its own injected input within one process (Set-FrameLabOwnInput / Get-FrameLabPresence, T2395), so a second frame-lab -Live run (or divider-ghost -Live, which calls Set-FrameLabOwnInput) right after a first still reads the first run's drag as a person and SKIPs for up to 5 minutes. Fix: Start-FrameLabPresenceClock calls Start-OwnInputClock and seeds FrameLabIdleAtStart from Get-CarriedHumanIdle; Set-FrameLabOwnInput also calls Save-OwnInputLedger; Get-FrameLabPresence asks Get-UserPresence -CarryOwnInput first. Also the first real back-to-back chainfold -Live pair after T2633 is the live proof that the ledger carries (the second run should not SKIP on 'input Ns ago').
