# T3728 - Linux: the tab overview's thumbnails show the panes without the window's gradient desk

## Summary

Since T3623 the GTK window, not the split tree, paints the gradient desk (so it can run under the header bar and the pane sidebar). Adw.TabOverview renders each tab's thumbnail from the tab widget alone, so a thumbnail now shows the elevated cards over no desk. Give the thumbnail the desk back (e.g. the split tree draws the window's desk texture, offset to its own bounds, only when it is being rendered outside the window), and add a check to test/linux/pane-style.sh that renders a tab thumbnail.
