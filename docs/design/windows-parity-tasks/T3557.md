# T3557 - Linux L10b: the pane sidebar on GTK - every pane of the window in a list, collapsed rail and expanded panel, the toggle shortcut

## Summary

Port docs/reference/pane-sidebar.md core to GTK (split from T3339): a per-window list of every pane (a row names its pane by banner title, else title; subtitle cwd), the 44pt rail and the expanded panel switched by one button, toggle_pane_sidebar wired in application.zig (it still logs not ported), shared expanded/hidden state across windows, the macos-pane-sidebar start config. libadwaita widgets; parity is behavior and information, not pixels. Acceptance as a test/linux/cli-*.sh script reading the sidebar back through a debug dump seam like PaneBanner.zig.

## In plain terms

On the Mac and on Windows, every window has a sidebar listing its panes; the
Linux app had none, and the shortcut to show it only logged "not ported".
After this, a Linux window has the same column: a list of its panes named the
way the Mac names them, narrow or wide at the click of one button, hidden and
shown with Ctrl+Shift+S, and the same in every window.

## Goals

- [ ] a per-window list of the active tab's panes: banner title else title, the directory under it, the focused one selected, a click focuses
- [ ] the rail and the panel, switched by one button; a window under 720 holds the rail
- [ ] toggle_pane_sidebar (Ctrl+Shift+S on Linux) hides and shows it
- [ ] one state for every window, kept across launches, forced by macos-pane-sidebar without being written over
- [ ] acceptance: test/linux/cli-sidebar.sh through the debug pane-sidebar seam
