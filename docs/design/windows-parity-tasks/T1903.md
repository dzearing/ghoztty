# T1903 - The busy light and percentage line (T1899) are elevated-style only: a flat-style Windows pane still shows progress only on the taskbar, while Mac draws the light square round the pane

## Summary

Mac SurfaceView passes cornerRadius 0 in the flat style and draws the same light inside the pane. On Windows the flat style has no desk gap - the pane children meet at a 2 DIP band - so the parent has no pixels round a pane to paint the ring on. Options: a layered overlay per busy pane (see D96 for the trade-offs), or drawing the light in the terminal renderer. Flat is not the default, hence P3.
