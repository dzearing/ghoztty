## In plain terms

The shared engine underneath every terminal pane reads the shell's output, understands it, and reacts to your mouse and keyboard. This task reads that code closely for wasted CPU, memory and waiting, and puts each fix in the queue. The biggest catch is that with NumLock on, simply moving the mouse over a pane makes it redraw everything, over and over.
