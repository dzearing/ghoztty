## Summary

Found under T1561. frame-clock.ps1 (banner block, ~line 315) looks for a VISIBLE GhozttyBannerOverlay to click and breaks when there is none. Since T2514 made the composition present the default, the banner is a visual inside the pane and the popup stays hidden, so the banner 'card'/'copy' glide rows are empty on every default run - the same shape T1561 found in float-on-top.ps1 section B (fixed there by pinning GHOZTTY_COMP_PRESENT=0, as pane-banner/overlay-zorder/close-overlays do per T2747). Decide per row: pin the popup path for the popup measurement, and/or measure the composition card via the app's log lines; either way an empty banner row must read as SKIP/FAIL with a reason, never as a silent zero.
