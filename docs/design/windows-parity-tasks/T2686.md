# T2686 - Settings > Remote Machines: the live machine list with online status and Host Settings... per machine, read without blocking (Mac RemoteMachinesSection)

## Summary

Split from T2680. Mac's Remote Machines page shows the sign-in state, New Remote Window..., and every enrolled remote machine with an online/offline/checking dot, its folder and shell defaults, and Host Settings... (MachineHostSettings.prompt). Windows still paints a one-line pointer to the machine chooser (SettingsWindow.paintCustom .remote_machines). Seed the rows from machine_cache (no network on the GUI thread, as MachineChooser.seedFromCache), confirm presence with a background relay fetch, and open HostSettingsDialog.prompt + host_defaults.update exactly as MachineChooser.promptHostSettings does. Extend ipc_settings's live state and settings-window.ps1 section J.

## In plain terms

Settings > Remote Machines on Windows used to show one sentence pointing at the
machine chooser. Now it looks like the Mac page: who you are signed in as, a
New Remote Window... button, and every machine on your account with a green /
grey / amber dot for online / offline / checking, the folder and shell new
sessions there start in, and a Host Settings... button to change them. The
page opens instantly from what the app remembers and fills in who is online a
moment later.
