# T2392 - Frame lab live driver + first live run (T2389 split): frame-lab.ps1 input-desktop exception that launches the card scene per matrix cell (panes/theme/DPI/sidebar), bridges FrameScore as a C# GfcScorer, runs Invoke-FrameLabCell live when the box is idle, asserts GetCursorPos equals every injected point on its first run, and carries the WGC-drop positive control (Buffers=1 held handler; duplication must name the dropped presents)

## Summary

Split out of T2389 (2026-10-28). T2389 built the catalogue, the matrix and
the per-cell protocol (`Invoke-FrameLabCell` in
`test\win32\lib\FrameLabCatalogue.ps1`) against fakes. Its `-Driver` is the
live half, and nothing supplies a live one yet. This task builds
`test\win32\frame-lab.ps1`:

- **Presence**: `Get-UserPresence` (lib\UserPresence.ps1); never under the
  user's hands. go.md forbids running an input-desktop exception while the
  user is present, so it runs only on an idle box or when the user starts it.
- **Launch**: start the debug `zig-out` build with the FrameLabCard scene in
  every pane for the cell's panes/theme/DPI/sidebar, read back the geometry
  the gestures need (window rect, work area, caption point, divider, sidebar
  edge) in physical pixels, and close it after.
- **StartCapture/StopCapture**: FrameCapture's `Start-FrameCapture` /
  `Stop-FrameCapture`, with `-Duplication` as the protocol asks.
- **Score**: FrameScore bridged as a C# `GfcScorer` (Add-Type referencing both
  `[GfcFrame].Assembly.Location` and `[FsFrame].Assembly.Location`, per
  T2384's 23:50 note); bleed per non-superseded frame, the tracked edge per
  frame into `Measure-FrameMotion`, `Test-FrameMotionTargets` for the misses.
- **Play**: `Invoke-FrameLabInput`, and on the FIRST live run assert
  `GetCursorPos` (physical) equals every injected point - the proof of
  T2384's absolute-coordinate normalisation against the real decoder.
- **WGC-drop positive control**: hold the frame handler with `Buffers=1`
  while the scene animates; the accounting run must name the dropped presents
  and the cell verdict must read `incomplete`.

Declare it under docs/claude/testing.md's input-desktop-exception rules
(lib\TestDesktop.ps1 header).

## Validation criteria

- [ ] frame-lab.ps1 declared an input-desktop exception and gated on presence (refuses with a present user, demonstrated).
- [ ] First live run: GetCursorPos matched every injected point.
- [ ] WGC-drop positive control reads `incomplete` with the dropped count named.
- [ ] One live cell per pointer interaction produced a verdict with its numbers (T2373's baseline then follows as T2373's own step).
