# T3146 - PA-V28: a hidden viewer whose web renderer was killed is reloaded straight away, re-committing the memory the kill reclaimed

## Summary

Audit-3 (T3101), area V, verified at d0d874326. handleProcessFailed (src/apprt/win32/ViewerPane.zig:6527-6540) reloads on .reload with no visibility check, so a viewer in a background tab or minimized window whose renderer was killed (often by memory pressure) starts a new renderer immediately. Fix: when the pane is not visible, mark it reload-on-show and reload when it becomes visible (the PA-V03/V04 visibility hooks). Detail: docs/design/perf-audit/audit-3/V-findings.md.
