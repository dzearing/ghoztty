## In plain terms

A test said that a pane's banner (the note you pin to the top of a pane) did not
come back after Ghoztty was killed and reopened. On today's build it does come
back every time, so no user-facing bug could be found. The test now also checks
that the banner was saved to disk before the restart, so if it ever goes red
again it says which half failed, saving or restoring.
