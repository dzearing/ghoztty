# T1644 - Confirm the sprite reference test resolves its testdata from any cwd on the Mac seat

## Summary

T820 fixed the sprite-face reference test's cwd dependence in shared-core code (src/font/sprite/Face.zig): the reference images are found by walking up from the cwd for the src/font/sprite/testdata marker, and a failing run writes its artifacts under <root>/zig-out/sprite-face-test instead of the cwd. The fix is platform-neutral and the Mac seat had the same defect, but only the Windows seat validated it. The Mac seat should run the sprite test from a directory other than the repo root (e.g. cd macos, then zig build test --build-file ../build.zig -Dtest-filter=sprite) and confirm it passes and writes no PNGs into the tree. test/win32/sprite-testdata.ps1 is the shape to mirror if the Mac seat wants standing coverage.
