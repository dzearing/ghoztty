# T3403 - A portable Ghoztty updates its own folder in place, the way the Mac app updates its bundle wherever it lives

## Summary

Since T3393 a portable copy that is offered an update refuses to run the MSI (it would install a second copy under Programs\Ghoztty and relaunch the old portable) and sends the user to the releases page. Mac Sparkle updates the app bundle wherever it is. Windows equivalent: download the release's portable ZIP, verify it, and swap the portable folder's files in place with the same sideline/relaunch choreography update_install.zig uses for INSTALLDIR. Only if the user picks that option in the T3393 decision.
