# T3126 - Panes minimized into blades are not minimized after a relaunch - collapses and the stack's focus history are not saved in the session layout (Mac a7fe3e9f8 PaneStackState.Persisted)

## Summary

Mac a7fe3e9f8: the rows the user collapsed and the stack focus history now ride the session layout manifest and AppKit restoration (PaneStackState.Persisted, keyed by leaf position, additive), are re-saved on every collapse change, and a restored window puts the caret in a pane on show rather than the first leaf. Windows: src/apprt/win32/session_layout.zig carries no stack/collapse state at all (pane_stack_state.zig holds it live only). Add the same additive field to the win32 session layout, re-save on collapse change, restore collapses + focus history, and focus the restored focused pane on show.
