# T1845 - No right-click menu, Alt-click swap or trash mode in the Windows pane sidebar

## Summary

Follow-up of T1828 (Mac 597a193cc). Right-click a grid row: Stash / Move to New Window / Close Pane; a stashed row: Restore / Swap with Focused Pane / Move to New Window / Close Pane (Close goes through the normal close path, confirmation and remote Disconnect included). Alt-click a stashed row swaps it with the focused pane (Mac Option-click). Header trash button: every row/tile gets a solid red x that kills with no confirmation and no undo window; Escape or the button again leaves it; never persisted.
