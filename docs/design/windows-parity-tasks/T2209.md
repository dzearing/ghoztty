## Summary

title-font.ps1 ~112-164 scores lit>20 (R+G+B>300) over ClientLeft+8 .. +tabW+plusW-2. The + glyph (28 DIP square, ~14px arms) supplies a few dozen lit pixels in the sampled columns by itself, so the assertion passes with no title drawn. Bound the rect to the tab label, and keep the + box as the positive control. Found by the T1281 inventory.

## In plain terms

The test that checks the tab bar draws its title in the configured font could
pass even if no title were drawn at all: it counted bright pixels over a strip
that also covered the "+" new-tab button, and the "+" alone was bright enough.
Now the test looks only inside the tab's own title box (as the app reports it),
checks the "+" separately to prove the probe can see glyphs, and proves on every
run that a blank title reads dark.
