# T3069 - PA-C16: every OSC 7 does a full URI parse, a computer-name syscall, allocations and a GUI-thread message even when the directory did not change (stream_handler.reportPwd)

## Summary

PA-C16 (audit-1, T2964). src/termio/stream_handler.zig:1283-1420 `reportPwd` parses the URI, calls GetComputerNameA (src/os/hostname.zig:104-110), creates an arena, dupes and flips the path on Windows (:1366-1376), calls setPwd, heap-allocates a WriteReq and posts .pwd_change per OSC 7, with no repeat check (titles have isRepeatTitle at :1179, T2428). Cost: a few us plus a GUI wake per prompt; matters for prompt-spamming loops. Fix: compare against terminal.getPwd() and return early after the first OSC 7 (keep the seen_pwd logic); cache the computer name. Risk: low. Shared: Mac half T3071. Findings: docs/design/perf-audit/audit-1/C-findings.md.
