# T3736 - Mac: choose a pane's shell from the command palette and New Tab submenu (Mac half of T3735)

## Summary

Mac half of T3735 (user request 2026-11-25, made on Windows: choose a pane's shell per pane, not only the one global shell). Same surface on macOS: command palette 'New Tab/Window/Split with Shell' and 'Restart Pane with Shell...', the list being the installed shells from /etc/shells (zsh, bash, fish, ... - the same filter Mac's Settings ShellControl already uses), the same entries in the File > New Tab submenu, and a starting folder per shell. Session restore brings each pane back on its own shell. CLI: +new-window/+split --shell= with no --command opens that shell (T1750). Acceptance: XCUITest/IPC test that opens a tab through each palette entry and asserts the pane's shell process and cwd, plus Restart-with-Shell keeping the pane id.
