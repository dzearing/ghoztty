# T2613 - Mac half of T2604: the agent-integration offer is one CommandLineToolPromptAnswered bit, so an agent installed after the first answer is never offered; keep the answer per agent, re-check on a new pane, and give the palette entry search keywords (skill, claude, copilot, plugin)

## In plain terms

On the Mac, if you set up Ghoztty's skill for one coding agent and install
another agent later, Ghoztty never offers to set up the new one, and
searching the command palette for "skill" finds nothing. Windows fixed this
in T2604; the Mac should behave the same way.

## Summary

`macos/Sources/Features/Setup/AppDelegate+Setup.swift` keeps one
`SetupDefaults.promptAnswered` (`CommandLineToolPromptAnswered`) bool for the
whole offer (lines 7-8, 45, 56), the same shape T2604 removed on Windows.
Port the Windows rule (`src/apprt/win32/agent_offer.zig`, pure, with its unit
tests as the spec):

- One answer per agent (Windows: `agent_offer_<agent>` files; Mac: one
  UserDefaults key per agent).
- An agent whose integration is already installed is recorded accepted and
  never offered; an undetected agent is never offered and never spent.
- The old single answer is folded in once: "declined" stands for the agents
  detected at that moment; "accepted" decides nothing (an agent not set up is
  asked once more).
- Keep writing the old key so an older build still reads the offer answered.
- Look again when a terminal pane opens, spaced 60 s, off the main thread,
  never raising the plugin-migration offer there.
- The palette's "Set Up Agent Integrations…" row gets search keywords:
  skill skills claude copilot plugin hooks banner install integration.

## Validation criteria

- [ ] Fresh profile with only Copilot -> accept -> install Claude -> next launch offers Claude only; Not Now is remembered for Claude alone
- [ ] Old `CommandLineToolPromptAnswered = true` with Claude installed and not set up -> offered once
- [ ] A new pane after installing Claude mid-session offers it
- [ ] Palette search "skill" lists Set Up Agent Integrations…
