# T1262 - A missed digest is visible to a human running health, but the turn itself still never sees it

## Summary

T1223 gave the daily digest a signal on go-loop-health.ps1, which a human or the 2-hourly supervisor check reads. The loop's own turn reads go-loop-exec.ps1 claim, and that still says nothing about the digest - so the exact 2026-09-01 shape (a turn that walks past step 0.5) is caught by whoever looks, not by the turn that owes it. Adding the line to the claim report needs a gate-negatives declaration (T1133): informational or gate, it has to be demonstrated.

## In plain terms

Every morning the loop owes the user a written digest. When it skipped one, the
only place that said so was a health check a person had to run; the loop's own
start-of-turn report stayed silent, so the turn that should have written it
never found out. Now that report says `DIGEST OWED` with the file path when the
digest is missing, so the turn that owes it is told.

## Goals

- [x] the claim report names a missing digest to the turn that owes it
- [x] health and claim answer "is a digest owed?" from one shared function, so they cannot disagree
- [x] a lane that does not own the morning block is told who does, not told to write it
- [x] the new line is registered and demonstrated red/green in gate-negatives (T1133)
