# T890 - Verify the real standalone agent install on this box gets adopted by the first post-T549 release agent

## Summary

T549's acceptance proves the flow against a fake install; this box carries the real MSI ({86AC9CE0-938A-4D20-9E66-C40FFF3C6BE4}) and the real adoption only fires when a RELEASE agent with the code starts, which the lazy-upgrade contract defers to a deliberate agent delivery. When that happens, read back: product unregistered, install dir gone, HKCU Run GhozttyAgent still app-owned, sharing.json enabled beside the release agent's sessions.json, and no local session was stranded. CAUTION: never msiexec /x by name - the 26.7.502 ghost product must stay untouched.

## In plain terms

This PC used to have a second, separate "Ghoztty Agent" program installed
alongside the terminal. The terminal learned how to quietly retire it, but that
clean-up only runs on a real released build, so until now nobody had checked
whether it actually happened here or only in a test fixture. It did happen — on
2026-08-31, when the user installed a release — and nothing was broken by it:
the old program is gone, the "start with Windows" entry belongs to the terminal
again, and no terminal window died in the process. The check is now part of the
test suite, so if the old program ever comes back or steals that entry again,
a run says so.
