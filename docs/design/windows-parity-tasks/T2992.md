# T2992 - PA-W08: the pane grab handle polls the pointer 20 times a second for as long as it is shown (pane_grab_handle.zig:209)

## Summary

PA-W08 (audit-1, T2960). PaneGrabHandle.zig:154 arms a 50 ms timer (pane_grab_handle.zig:206) and keepPolling (:209-213) returns true unconditionally while shown and while over a viewer; the 10-still-tick stop applies only when hidden. Estimated 20 UI wakeups/s while the pointer rests in a pane's top band or anywhere over a viewer. Fix: apply the still-tick stop when shown over a terminal too, re-poked by WM_MOUSEMOVE, with TrackMouseEvent(TME_LEAVE) so the handle still hides when the pointer leaves; keep polling only over viewers (moves invisible to this process). Risk low-medium.

## Validation criteria

- [ ] pointer resting in the top band: polling stops after the still ticks (trace/counter)
- [ ] grab-handle acceptance still green: the handle shows, hides on leave, and drags
