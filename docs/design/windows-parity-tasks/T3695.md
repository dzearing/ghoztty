# T3695 - Linux L10e: the GTK pane sidebar's own list starts with this window's header row, and the rail with a +

## In plain terms

On the Mac, the sidebar's list of a window's panes sits under a heading row
for the window itself: its name, how many panes it has, an arrow to fold the
list away, and (on hover) buttons to add a pane or close the window. When the
sidebar is narrowed to icons, a + sits at the top. On Linux the panes were a
bare list with the window's name only in the caption. Now Linux shows the same
heading row and the same + at the top of the icon strip.
