# T3538 - Linux: a git-diff:/git-status: link clicked in a viewer pane opens a split with no repository ('No directory' card)

## Summary

T3417 gives a diff pane its repository from --working-directory; Surface.viewerOpenSplit (and viewerOpenWindow) open the link's split without one, so a diff link in a markdown pane renders the No directory card. Pass the clicking viewer's file directory (or its own origin dir) as the new pane's working_directory, as win32's origin_directory does.
