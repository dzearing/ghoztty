# T3598 - Linux: launching a different Ghoztty build while one runs asks Switch / Open Window / Cancel, as on Windows

## Summary

The launch half of win32's T1022/T1023/T1070 handoff on GTK. Today a second build's launch on Linux just finds the socket served and joins (or, with --gtk-single-instance=false, runs beside it) without telling the user the window they got is another build's. Port win32 App.zig's launchIdentity/handoffChoice/requestHandoffQuit flow: compare identities via +version, prompt with the shared ipc_handoff.mismatchPrompt (GtkAlertDialog), on Switch send handoff-quit (served since T3595), wait for the pid to exit, bind the socket and restore. Mac has no counterpart (single .app); this is Windows-born parity.
