# T3613 - Linux: a background window whose pane waits on a question does not ask for the user's attention

## Summary

Mac bounces the Dock (requestUserAttention) and win32 flashes the taskbar button when a window's activity aggregate moves into needs_input while it is not the active window (T2907). GTK 4 dropped the urgency hint, so T3561 shows the state only in the title and on the tab (needs-attention). Candidates: xdg-activation (GNOME raises a 'ready' notice for a window that asks with a token), or a desktop notification through the existing notification path when the window is not active; pick whichever the compositors under WSLg and GNOME/KDE actually surface. Depends on T3561's Window.syncActivity, which already sees the transition (window_activity.tabMarks attention=true).
