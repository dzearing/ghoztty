# T3141 - PA-R20/PA-C20: the first frame after 3 s of stillness re-creates the render target and shared D3D texture and re-uploads both font atlases, so the first keystroke after a pause pays it

## Summary

Audit-3 (T3101), areas R and C, verified by reading at d0d874326. T3103's idle release (idle_release_ns = 3 s, src/renderer/generic.zig:1406) frees the swap-chain frames' targets and atlas copies; the next drawn frame (generic.zig:2196-2202, :4204-4210) re-creates the render target, the GL-to-D3D shared texture with its interop register (src/renderer/OpenGL.zig:1653) and re-uploads both atlases in full (about 1.25 MB). That lands on the first keystroke or output after any 3 s pause. Its cost on Windows was never measured (T3103 carries Mac's ~1 ms). Fix shape: measure first (a GHOZTTY_PERF timer around the re-create), then keep one frame's target and atlas across the release, or release later than 3 s, or re-create lazily off the input path. Detail: docs/design/perf-audit/audit-3/R-findings.md (PA-R20) and C-findings.md (PA-C20).
