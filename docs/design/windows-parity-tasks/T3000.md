# T3000 - PA-W16: closed pane windows are parked for reuse on the default composition path, where parking saves nothing and only holds USER objects (Surface.zig:1533)

## Summary

PA-W16 (audit-1, T2960). Surface.zig:1533 parks every closed pane HWND (pane_pool.zig:28 capacity 16 per top-level), but on the default composition-plus-helper path (Surface.zig:1003-1004, on_helper) the pane window never gets a pixel format or a SwapBuffers, which is the allocation T2597 parks windows to reuse. Estimated 9 of the +60 USER objects left after the first baseline cycle. Fix: skip parking when the pane went current on the helper (gl_helper != null); this also removes the PA-R17 hazard (T2983), so land them together or close T2983 by this. Risk low.
