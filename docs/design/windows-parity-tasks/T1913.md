# T1913 - The pane sidebar's search field cannot select text: no Shift+arrows, Ctrl+A, double-click word select or drag-select, and its caret does not blink like a Windows text box's

## Summary

T1877 landed the all-windows search field as a painted field (the hover card is a layered popup, where a native EDIT cannot render). It edits, pastes, word-steps and Ctrl+Backspaces, but has no selection model: Shift+Left/Right/Home/End, Ctrl+A, double-click a word, drag across text, and typing over a selection all do nothing special. Its caret is steady rather than blinking at the system caret rate (GetCaretBlinkTime). Mac's NSTextField has all of these. Add a selection anchor to pane_sidebar_search.Field (unit-tested), paint the selection in the system highlight colors, and blink the caret on a timer that stops when the field loses focus.
