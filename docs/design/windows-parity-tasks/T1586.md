# T1586 - A pane with no known folder turns a banner's dot-relative path into a link to the drive root

## Summary

T539/T758 follow-up: a pane whose cached working directory is the EMPTY string is not null, so BannerOverlay.setText hands banner_markdown a non-null cwd of length 0 and joinPath turns .\a.txt into \a.txt - a link to the root of the current drive. T539's rule is that a dot-relative path with nothing to resolve against stays PLAIN TEXT rather than becoming a link that goes nowhere. The empty string arrives from IpcHandlers' +list seed, which writes surface.setPwd(copy orelse "") on purpose so a pane with no pwd is not re-asked forever. Fix is to treat an empty cached pwd as absent where PathContext is built, with a unit test in banner_markdown and an assertion in section 6k.
