# T1952 - Mac half of T1951: in a Screen Sharing / remote session the Mac app turns off glass, blur, cursor blink, the unfocused dim and pane motion by itself

## In plain terms

On Windows, Ghoztty now notices when it runs over Remote Desktop and turns off
its expensive looks (glass panes, blur, blinking cursor, dimmed panes,
animations) so typing stays fast, then turns them back on at the desk. The Mac
app should do the same when someone drives the Mac over Screen Sharing.

## Summary

T1951 landed the shared half: `src/config/remote_effects.zig` (exported as
`configpkg.remote_effects`) swaps the DEFAULTS of `macos-pane-style` (flat),
`macos-pane-glass`, `background-blur`, `cursor-style-blink` and
`unfocused-split-opacity` (1) into a loaded config, leaves any key the user
set by name alone (and keeps the elevated style when glass was asked for by
name), and records the overrides as replay steps so a light/dark rebuild
keeps them. The Windows apprt calls it on every load
(`App.applyRemoteEffects`) and re-loads on `WM_WTSSESSION_CHANGE`; it also
stops in-window motion while remote (`App.clientAreaAnimationsEnabled`).

What the Mac seat needs:

- **A C API entry** for the Swift app, e.g.
  `ghostty_config_apply_remote_effects(ghostty_config_t, bool remote)`, that
  calls `remote_effects.apply` on a loaded (finalized) config. Additive.
- **Detection**: is the console session being screen-shared / remote?
  `CGSessionCopyCurrentDictionary` (`kCGSSessionOnConsoleKey`, plus the
  screen-sharing state) at launch, and re-check on
  `NSWorkspace.sessionDidBecomeActiveNotification` /
  `sessionDidResignActiveNotification` and the screen-sharing change signal.
- **Live switch**: reload the config through the new call and push it, no
  restart; stop the pane focus-glow move and the sidebar shimmer while remote
  (the Mac equivalent of Windows' motion switch).
- **One notice** on a live switch ("Remote session: visual effects off to keep
  typing fast"), matching Windows' wording.

## Validation criteria

- [ ] Remote at launch: flat panes, no glass, no dim, no blink (by a test seam
      analogous to Windows' `GHOZTTY_TEST_REMOTE_SESSION_FILE`).
- [ ] Live switch both ways restores / removes the effects without restart.
- [ ] A user-set `macos-pane-glass = true` keeps glass while remote.
- [ ] Mac regression build green.
