## In plain terms

Terminal panes have a newer, smoother way to reach the screen (the
"composition" path) that until now was only switched on by a hidden setting.
This makes it the normal behaviour for everyone, keeps a way to turn it off,
and makes sure machines that cannot use it (some graphics drivers, Remote
Desktop) quietly keep drawing the old way.

## Goals

- [x] the composition path is on with no setting (`default_on = true` in `gl_comp_present.zig`)
- [x] `GHOZTTY_COMP_PRESENT=0` turns it off (explicit off wins either way)
- [x] the window and its panes read the setting from one place
- [x] a machine without the graphics interop says so once and keeps drawing
- [x] every test that meant "off" now asks for off explicitly
