# T2564 - The pane sidebar opens in All windows by default and remembers the last scope (Mac 8aefd0c91)

## Summary

Mac 8aefd0c91: the all-windows scope is ON at launch (every window folded, no search) and persists the user's last choice (PaneSidebarShowsAllWindows, on when unset); search and folds still never persist. Windows: Shared.all_windows defaults false (src/apprt/win32/pane_sidebar_shared.zig) and is not persisted. Translate: add the scope to pane_sidebar_prefs.zig (a 4th field, on when absent so old files decode to on), seed Shared.all_windows from it at startup with every window folded, and save on toggle. Mac reference: docs/reference/pane-sidebar.md 'All windows' + persistence bullets.

## In plain terms

On a Mac, the pane sidebar now opens on the "All windows" overview: one folded
row per window. If you switch it back to "This window", it stays that way the
next time you launch. On Windows it always opened on "This window" and forgot
your choice. After this change Windows behaves the same as the Mac.

## Goals

- [x] A first launch (or a defaults file from an older build) opens in All windows, every window folded, no search
- [x] The user's last scope choice is saved and used at the next launch
- [x] Test harness keeps its established "this window" starting state so existing sidebar scripts are unaffected

## Validation criteria

- [x] Prefs file carries a 4th field; a 3-field file decodes to all windows on; malformed 4th field rejected - unit tests `T2564:` in pane_sidebar_prefs.zig (none + win32 lanes)
- [x] Launch seeds the shared scope with no window unfolded and no search - unit test `T2564:` in pane_sidebar_shared.zig
- [x] On the box: a 3-field defaults file launches in all windows with its window folded (`folded=1 search=0`); toggling off writes `1 0 240 0` and relaunches in this window; toggling on writes `1 0 240 1` and relaunches in all windows - section 9 of test/win32/pane-sidebar-persist.ps1, ALL PASS (48 assertions)

## Notes

- Harness: `Clear-TestWindowPlacement` (lib/TestDesktop.ps1) now WRITES `0 0 240 0` before each launch instead of deleting the file, so every sidebar script still starts in "this window" (the T2342 `--maximize=false` precedent). Frame-lab cells pin the scope the same way (`<..> 0`).
- The fold rule for turning the scope on from a window (Mac 7e2d0a9da: the from-window folds too) is T2408, unchanged here; at launch there is no from-window, so every window folds, which matches Mac already.
