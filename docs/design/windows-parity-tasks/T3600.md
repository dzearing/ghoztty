# T3600 - Linux L8f: a stale (older-build) local agent is refreshed, and a protocol-skewed one gets the mandatory-update notice, on GTK

## Summary

T3400 brought in-place recovery when the local agent dies or its link stays down. What it left out is win32's other two LocalAgent behaviours: when the running agent is an OLDER build than the app (agent_upgrade.zig: drain, restart onto the new binary, rebuild panes in place through the same AgentRecovery path) and when the HELLO handshake reports protocol skew (the mandatory-update notice instead of a silent exec fallback). Port both onto src/apprt/gtk/LocalAgent.zig + AgentRecovery.zig, with a test/linux acceptance that plants an older agent build.
