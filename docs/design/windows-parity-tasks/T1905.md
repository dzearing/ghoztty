# T1905 - On a translucent Windows window (background-opacity below 1) the pane sidebar is GDI-painted into a per-pixel-alpha parent with alpha 0 and no opaque layer, and its slice of the elevated desk ignores background-opacity: check what it shows and match the grid's desk (T1852)

## Summary

Follow-up of T1852. Window.syncTranslucency lifts viewers and the rename box onto opaque layers (composeOpaqueLayer) but not the PaneSidebar child, whose expanded panel BitBlts a glass material built from the OPAQUE desk (deskBackdrop) and whose rows are GDI text. On a translucent window that is either see-through ink (GDI alpha 0) or an opaque slab beside a desk that now takes background-opacity. Measure with a WM_PRINTCLIENT/PrintWindow capture of the sidebar on a 0.5 window (the T1852 pane-elevation run 1b2 shape), then make its desk slice premultiplied at the same opacity (desk_palette.translucentPixel) with its rows and chrome opaque.
