# T1968 - daily-publish counts honoured requests as retry attempts: -Status reads 'attempt 4 of 3' after four good releases, and a failed publish later that day would be refused its retry

## Summary

2026-10-15 05:53: -Status printed 'win-v1.39.13 35cc897ab (tagged, attempt 4 of 3 that day)' after four requested publishes (v1.39.10-13), all of which landed. Attempts (T1369) is meant to bound RETRIES of a publish that did not land (MaxAttemptsPerDay, line ~297), but line ~762 increments it for every publish of the day. Consequence: on a request-heavy day a release that then fails CI is refused its retry ('a branch this red needs a person') though it is the first failure. Count only attempts after a non-landed result, or reset on a confirmed publish; add a daily-publish.ps1 section for four honoured requests followed by a failure that still gets one retry.
