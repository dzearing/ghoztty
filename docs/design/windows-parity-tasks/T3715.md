# T3715 - Live reload for tunnelled viewers: the agent watches a granted file and pushes VIEWER_CHANGED; the viewer re-fetches and keeps its scroll (Windows + shared)

## Summary

VIEWER_CHANGED (0x87, {grant, path}) is defined by T2219 and gated on capability.viewer_fetch, but the agent never sends it. Make the agent watch each file it served under an open grant (ReadDirectoryChangesW on Windows, kqueue/inotify on Unix, debounced like viewer_watcher.zig), push VIEWER_CHANGED on the control channel, stop watching on VIEWER_CLOSE and on disconnect, and bound the watch count per connection. The app side re-fetches and keeps scroll position, the same reload path a local file change takes.
