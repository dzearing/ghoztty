# T3640 - Linux L11h3: an acceptance check reaches the shortcut guide through the main menu item and the command palette entry, not only the keybind and the app action

## Summary

T3570 wired three ways in: Ctrl+Shift+/ (G5 of test/linux/shortcut-guide.sh, through press-key), the app action (G19), and two that no check reaches - the main menu's Keyboard Shortcuts item (GAction app.show-keyboard-shortcuts, window.blp) and the command palette entry (removed from command_palette.isActionSupportedOnGtk's unsupported list). ## In plain terms

On Linux the keyboard shortcut guide can be opened four ways, but the
automated test only proved two of them (the key chord and the internal
action). Now it also opens the guide from the main menu's "Keyboard
Shortcuts" item and from the command palette's "Show Keyboard Shortcuts"
entry, so a broken menu item or palette entry turns the test red.
