# T3311 - PA-V31: closing a viewer pane joins its document, resource and image workers with no cancel, so a slow read blocks the GUI thread (ViewerPane.zig:1176-1191)

## Summary

deinit joins image_decode, document_read (T3224) and resource_serve (T3245) at ViewerPane.zig:1176-1191; none of them is cancelled first, so a large or slow file read in flight holds the close (and the GUI thread) until it finishes. Fix: cancel (CancelIoEx / flag) before join. Cost inferred. Audit-4 (T3151), Fable 5.2 area finding at c9af15802; cites read at HEAD by the owning turn.
