# T3536 - Linux diff pane: Back/Forward into a git-diff:/git-status: entry re-renders the wrong thing - the diff loads the bare template URL, so history cannot tell which spec an entry showed

## Summary

T3417 loads a diff as the bare template (scheme.template_url), so syncCommitted's .template_bare keeps whatever the pane last showed: diff -> link to a file -> Back re-renders the FILE in diff mode's place. viewer-image-and-diff.md promises back/forward cross into and out of a diff. Give the diff a template URL that carries the spec (like ?file= for files, viewer_chrome.templateUrlFor) and classify it on commit. Acceptance: extend test/linux/viewer-diff.sh.

## In plain terms

On Linux, a pane showing a git diff could lose track of itself in its own
history: open a file from the diff, press Back, and the pane showed the file
again instead of the diff. Now every diff the pane visits is remembered by
name, so Back and Forward step into and out of diffs exactly like files.
