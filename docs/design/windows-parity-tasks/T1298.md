# T1298 - The dashboard shows the loop is alive but never says whether it is turning

## Summary

T1290 put turn_age / turn_stalled on go-loop-health.ps1, but the dashboard reads neither - it renders 'Supervisor is down' from the watchdog beacon and nothing about whether a turn has completed. A human watching the board still cannot see the 2026-09-03 shape: alive, marked, dashboard up, and inert for fourteen hours.

## In plain terms

The status page could tell you the automated loop was *alive*, but not whether it was actually *getting anything done*. On 2026-09-03 it sat stuck for fourteen hours while the page looked healthy. Now the loop card shows how long the current turn has been running, and once that passes three hours it says "Alive, but not turning" in warning colour and hands you the command that shows what the stuck window last said.
