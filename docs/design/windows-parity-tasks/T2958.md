# T2958 - Perf baseline: scripts/perf-baseline.ps1 measures idle and busy CPU, memory and handle growth over a pane open/close cycle, GPU memory, and the agent, as repeatable JSON (T2957 step 1)

## Summary

Child of T2957 (step 1, Baseline). Write scripts/perf-baseline.ps1 that measures, against the zig-out Debug build AND a ReleaseFast build run under Set-GhozttyTestIsolation -ReleaseSandbox (never the installed app), on the test desktop only (never the user's): idle CPU % and wakeups/sec (1 window, 1 pane, prompt, 60 s); CPU during heavy output; private bytes / working set at start, after 10 panes + 3 tabs, and after closing them all; GDI, USER, kernel handle and thread counts over the same cycle; GPU dedicated+shared memory and engine % (idle, scrolling, resize) where the counters are readable; and ghoztty-agent.exe alone (idle CPU, memory per hosted session, handle growth across attach/detach). Emit JSON with the method for each number, and commit the first run as docs/design/perf-audit/baseline-1.json. A metric the box cannot read is recorded as null with the reason, never guessed.

## Validation criteria

- [ ] scripts/perf-baseline.ps1 runs end to end on the test desktop against zig-out Debug and a sandboxed ReleaseFast build, touching no installed app
- [ ] docs/design/perf-audit/baseline-1.json committed with every metric in T2957 step 1, each carrying its method (or null plus the reason)
- [ ] a second run reproduces the numbers within a stated tolerance, so a re-audit is a rerun and a diff
