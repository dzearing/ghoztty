# T2699 - Settings theme tiles and tabs have no hover help: Mac's tile tooltip names the theme (and '(your theme)' for a user theme) and the tabs say 'The theme used in light mode' - a long name is only ever seen ellipsized on Windows

## Summary

Mac's `ThemeTile` carries `.help(theme.name + (isUserTheme ? " (your theme)" : ""))` and the tabs carry `.help(follows ? "The theme used in light mode" : "Show light themes")` (and the dark pair). T2682's Windows grid paints the same tiles and tabs but the Settings window has no tooltip at all, so a long name ("Apple System Colors Li...") is never seen whole and a user theme is not marked - T2586's menus said "(your theme)", the tiles do not. Add a tooltip control to the Settings window (TTF_TRACK or a hit-keyed TTN_GETDISPINFO over the recorded hits) and give theme_tile / theme_tab hits Mac's text. Validation: settings-window.ps1 reads the tooltip text a hovered tile would show through the seam (a `tip` field on the painted hit), plus an eye check.
