# T3674 - Linux L11a-2: the GTK machine chooser - Ctrl+Shift+N opens it, rows per machine with their sessions sorted, help, kill, and resuming a session a Disconnect left running

## Summary

Port the Mac machine chooser (docs/reference/remote-machines.md; win32 MachineChooser.zig + chooser_*.zig) to GTK as a libadwaita dialog: Ctrl+Shift+N and the menu open it; one row per machine (relay devices from /v1/client/devices polled every 5s while open), each listing its live sessions in the Mac's sort; help tooltips; kill a session; and RESUME a detached session into a new window. Since T3563 a Disconnect on Linux leaves the remote session running, but nothing on Linux could resume it - this card is what makes Disconnect round-trip. A relay window it opens goes through ipc_remote_window.openWith (RelayWindows.record) so it returns at relaunch. The account row's sign-in is T3575. Split from T3563.

**Landed** (`src/apprt/gtk/MachineChooser.zig`, model `machine_chooser_rules.zig`, seam `ipc_machine_chooser.zig`): an `AdwDialog` (Mac's 840x540) with the account line, Local then the relay's devices (cache-seeded as "Checking status", one directory fetch on a worker, re-polled every `chooser_refresh.poll_ms`), the selected machine's detail (This Computer / the device; its state, hostname and session count; New Window; Host Settings... for a relay machine, the T3635 editor), and its roster: running sessions only (`chooser_sessions.isActionable`), labelled and sorted the win32/Mac way, each with Resume - or Show when one of our panes holds it - and End. Resume ATTACHes a new window to the same session (relay: `openWith` with the session id; local: `Surface.pending_restore`). Opened by Ctrl+Shift+N in the window's capture-phase key controller (win32's `window_chord` table: Ctrl+N stays a local window), the window menu's "New Remote Window…", and Settings > Remote Machines' "New Remote Window…" button.

**Not in this slice, filed**: warm per-machine connection + pushed roster (T3811), CPU meters and sortable column headers (T3812), Restore All (T3813), the management menu - Rename / Remove from Account / See Activity (T3814), keyboard navigation and the machine filter (T3815). Direct host:port rows: Mac's model has them but nothing creates one (win32 T1441), so none here either.

## In plain terms

On Linux you could already step away from a remote terminal with Disconnect, but there was no way to get back to it. Now Ctrl+Shift+N (or the menu, or Settings) opens a picker that lists your machines and what is still running on each; pick one and press Resume, and the terminal comes back exactly where you left it. You can also open a fresh window on any machine or end a session you no longer need.

## Goals

- [x] Ctrl+Shift+N, the window menu and Settings open the chooser

- [x] New Window opens on the selected machine; Host Settings... edits a relay machine's defaults
