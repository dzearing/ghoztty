# T3674 - Linux L11a-2: the GTK machine chooser - Ctrl+Shift+N opens it, rows per machine with their sessions sorted, help, kill, and resuming a session a Disconnect left running

## Summary

Port the Mac machine chooser (docs/reference/remote-machines.md; win32 MachineChooser.zig + chooser_*.zig) to GTK as a libadwaita dialog: Ctrl+Shift+N and the menu open it; one row per machine (relay devices from /v1/client/devices polled every 5s while open, plus direct host:port entries), each listing its live sessions in the Mac's sort; help tooltips; kill a session; and RESUME a detached session into a new window. Since T3563 a Disconnect on Linux leaves the remote session running, but nothing on Linux can resume it yet - this card is what makes Disconnect round-trip. A relay window it opens goes through ipc_remote_window.openWith (RelayWindows.record) so it returns at relaunch, and a device rename calls the record's updateName. The account row's sign-in is T3575. Split from T3563.
