# T2039 - Check by eye that the feedback composer's picture-strip fade blends into the glass material on an overflowing strip (T1926's cue path has no on-screen check)

## Summary

T1926 made the feedback composer paint the nav bar's glass material, and its
carousel overflow cue fade into that material per pixel (`paintCue` builds a
`w` x `h` premultiplied DIB from `glassBand` on glass). The band itself is
checked by the host-floor test in the win32 lane, and the fade ramp and
premultiply are unit-tested, but nothing has photographed the cue over real
tiles on a glass pane. Open a glass viewer pane, paste enough images to
overflow the strip, and screenshot both cues: the tiles must dissolve into
the material with no grey seam at the outer edge. Needs the input desktop
(`@input-desktop-exception`), so run it only when the user is away.

## Validation criteria

- [ ] Screenshot of a glass composer with an overflowing strip shows both cues fading into the material, no solid-grey edge
- [ ] Same off glass: the cue fades into the solid band as before
