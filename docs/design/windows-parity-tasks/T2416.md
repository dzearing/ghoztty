# T2416 - Blade collapse glide, measured (T2415 split): WGC-capture a fold and an unfold at 2, 3 and 4 panes in both pane styles on an idle box, classify every bad frame (unpainted, stale trail, torn between pane move / region cut / desk paint, uneven step), and fix what the capture names

## In plain terms

The user said collapsing panes into blades looks janky and flickery. T2415
fixed the two defects that could be found by reading the code. Whether the
glide now looks smooth can only be settled by recording what the screen
actually showed, frame by frame, and that needs the computer idle with nobody
using it.

## Summary

Split out of T2415 (2026-10-28). T2415 landed two code-level fixes for the
fold glide (no GL repaint per frame for a shrinking cut; the flat style's
gutter paint no longer leaves a gliding card's destination slot unpainted).
What T2415's acceptance asked for and could not get on the day is the
measurement: the frame lab (T2373/T2395/T2396) captures on the INPUT desktop,
and go.md forbids running it while the user is at the machine.

On an idle, unlocked box (the same precondition as T2396), record a
Windows.Graphics.Capture of a fold and an unfold at 2, 3 and 4 panes, flat and
elevated+glass (the default), with the release-lineage build per the lab's
rules. Classify every bad frame:

- unpainted / black / stale-pixel trail in the area a card has left;
- torn: panes at their new place but the region cut or the desk paint a
  frame behind (each glide tick is three separate window-manager commits -
  `EndDeferWindowPos`, the `SetWindowRgn` per pane, the `GetDC` desk paint -
  and DWM can compose between them);
- strip / banner / dim overlay popups a frame behind the cards;
- uneven steps (judder) despite T2365's frame clock;
- any grid reflow mid-glide.

Compare with Mac's glide (`PaneStageView.stepGlide`, 45 ms follower). Fix what
the capture names on the current stack; whatever is structural (the three
commits cannot be made atomic with child HWNDs) goes to T2360 with the
capture as its evidence.

- [ ] The user sees a graceful glide in the installed build.
