# T3589 - Linux: a tinted pane keeps its --color tint across session restore (Leaf.tint on GTK)

## Summary

T3382 made --color / --split-color / +split --color and split inheritance tint GTK panes, but src/apprt/gtk/SessionLayout.zig captureLeaf never writes the schema's Leaf.tint (win32 T3176, Mac Leaf.tint) and restore never applies it, so a relaunch brings every pane back untinted. Write leaf.tint from Surface.backgroundTint() as #rrggbb, carry it on Surface.Restore / pending_restore, and applyBackgroundTint on the restored surface (it already defers until the core surface exists). Acceptance: a test/linux/session-restore.sh section that tints a pane, restarts the app, and reads background_tint from +list plus the pane render through hl_screenshot.
