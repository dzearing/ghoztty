# T1938 - Mac: verify a downloaded update installs itself without a click (Windows T1934 now does, at launch or after 5 idle minutes)

## In plain terms

On Windows, Ghoztty used to download every new version and then wait for a
click that almost never came. It now installs the download by itself, at a
moment that interrupts nobody. The Mac app has to behave the same way: check
that it does, and make it do so if it does not.

## Summary

T1934 (Windows) made a staged update install itself without a click:

- **at launch**, before any window or shell exists;
- **while running**, once the user has been idle for 5 minutes and nothing
  fullscreen is in front, and only with session persistence on (an install
  then costs no shells);
- **once the offer is a day old**, after one idle minute even with something
  fullscreen;
- **never twice in a day for the same version**, so a rejected package cannot
  loop.

`auto-update = check` keeps the click. The policy is
`src/apprt/win32/update_auto_apply.zig`.

On the Mac, `AppDelegate.swift` sets Sparkle's
`automaticallyDownloadsUpdates = (auto-update == .download)`. Sparkle's own
behavior with that flag is to install the downloaded update **when the app
quits**. Ghoztty drives Sparkle through a custom user driver (`UpdateDriver`
and the update pill), so whether that install-on-quit still happens, and
whether a terminal left open for weeks ever quits, is the open question.

## What to check (Mac seat)

1. With `auto-update = download`, publish or fake a newer appcast. Leave the
   app running until the download is staged, then quit it. Does the next
   launch run the new version with no click?
2. Leave the app running for a long time without quitting. Does it ever
   install? If it does not, add the same idle-time install as Windows: idle
   from `CGEventSourceSecondsSinceLastEventType`, fullscreen from the
   frontmost app's presentation options, persistence on, and Sparkle's
   immediate install-and-relaunch.
3. With `auto-update = check`, it must still ask.

## Validation criteria

- [ ] A Mac build with a staged update reaches the new version without a click
      (on quit-and-relaunch at least, and while idle if that is added).
- [ ] `auto-update = check` still asks first.
- [ ] Mac regression run green.
