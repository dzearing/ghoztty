# T3767 - Restart Pane with Shell for a pane on another machine offers that machine's shells (T3752 left it off for remote panes)

## Summary

T3752's picker lists this machine's shells, so it is not offered on a pane in a +new-remote-window window: restarting one with a local program name would ask the remote agent for a shell it may not have. Ask the remote agent for its shell list (a new additive capability over the HELLO handshake, per docs/claude/sessions.md), offer it in the same context submenu and palette rows, and restart via a .remote override on the window's dialed connection. Acceptance: a restart-pane.ps1 section against a loopback remote agent asserting same pane id and a new remote session.
