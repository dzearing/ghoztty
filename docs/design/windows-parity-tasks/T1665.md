# T1665 - --shell= is silently ignored for a pane with no --command when session-persistence is off

## Summary

On the non-agent (exec) path, IpcHandlers builds Overrides with only command_argv/working_directory/env, and command_argv is null unless a --command was given. So 'ghoztty +new-window --shell=pwsh' with session-persistence=false opens the default shell and says nothing. Found while tracing T862. The agent-backed path (the default) honours it via Overrides.remote.shell.

## In plain terms

Asking Ghoztty for a new window or split "in PowerShell" (without also giving it a command to run) only worked with the default settings. If you had turned session persistence off, or you were splitting a pane, you got the ordinary Command Prompt and no error. Now the pane opens in the shell you asked for either way.
