# T2451 - drag-perf.ps1 has no glide variant: assert the divider glide line (late frames, wm_paints, deferred_moves, desk_reused) on a folding row with a viewer pane

## Summary

T2448 added a `divider glide ticks=... mean_gap_us max_gap_us late fps viewer_ticks
viewer_us period_us deferred_moves wm_paints wm_paint_us desk_composed desk_reused
verdict` line (GHOZTTY_PERF, at button-up) and a `divider drag viewers=...` line, and
measured them with a scratch script (5-pane row, viewer second, the first divider
dragged 720 px out and back at 12 px / 16 ms). Nothing asserts them. Add that
shape to `test\win32\drag-perf.ps1` (or a sibling) and assert the COUNTS, which are
properties of the code: motion ticks under a running glide defer their layout
(`deferred_moves` > 0), the window takes ~no `WM_PAINT`s during the glide
(`wm_paints` <= 2; it was one per glide frame), and the desk memo is live
(`desk_reused` > 0 for a paint with unchanged inputs). Report gaps/late as numbers.
-NegativeControl must go red.

## In plain terms

Dragging a divider far enough folds panes into strips, and the fold animates.
A user saw that animation stutter at about 15 frames a second; T2448 fixed it.
This adds a test that drags across a fold with a document viewer in the row and
fails if the fix is undone, so the stutter cannot quietly come back.

## Goals

- [x] a repeatable scene: five panes in a row with a viewer second, the first divider dragged across a fold and back
- [x] assert the counts the fix depends on (deferred layouts, no repaints during the glide, desk reuse, the viewer really resized)
- [x] report the frame timing as numbers without failing on box noise
- [x] a negative control that goes red

## Validation criteria

- [x] the glide variant runs on the test desktop and asserts deferred_moves, wm_paints and the viewer line - `test\win32\drag-glide.ps1` (sibling of drag-perf.ps1), ALL PASS (7) through `acceptance-parallel.ps1 run -Scripts drag-glide.ps1 -FailFast`: deferred_moves=117, wm_paints=1 over 569 glide ticks, desk reused=583 partial=552 composed=564, viewer line viewers=1 (1.9 ms/pass); glide gap mean 17 ms / max 25 ms, 58 fps, reported only (debug, test desktop, 8.26 ms period)
- [x] -NegativeControl fails it - 2 FAILURE(S): B (deferred_moves) and C (wm_paints) go red
