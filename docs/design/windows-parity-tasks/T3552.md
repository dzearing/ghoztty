# T3552 - Linux L9j-5: the GTK feedback composer follows the light/dark style instead of fixed light colours

## Summary

T3544's composer pushes fixed Adwaita LIGHT colours into composer.js's vars (fg #1e1e1e on bg #ffffff, quote wash, chip ink) from ViewerFeedback.pushVars. On a dark libadwaita style the pill is a white slab in a dark pane. Read AdwStyleManager:dark (and accent colour where available), derive the vars from it like win32 derives them from chrome_theme, re-push vars on the style manager's notify::dark while the composer is open, and add a headless check (force ADW_COLOR_SCHEME prefer-dark via the steps seam or env) that the composer page's computed background follows.
