# T1571 - The harness lane reads red after a .zig edit because -Lane all never rebuilds the app

## Summary

floor-lane.ps1 -Lane all builds the test binaries but never zig-out\bin\ghoztty.exe, so any .zig edit leaves the app binary older than its sources. The next -Lane harness run then scores build-mode-guard, persistence-flag and caller-anchor red on staleness - ten minutes to learn that a rebuild was missing, with three verdicts that name GHOZTTY_TEST_ALLOW_STALE rather than 'rebuild'. Either -Lane all should build the app, or the harness lane should say which rebuild clears it.
