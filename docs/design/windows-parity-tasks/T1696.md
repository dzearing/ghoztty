# T1696 - macOS: confirm the Metal renderer survives losing its GPU (eGPU unplug, GPU switch) the way Windows now survives a driver reset

## Summary

Platform symmetry for T1690. On Windows a graphics driver reset or swap used to close every window; T1690 now rebuilds the pane's OpenGL context and GPU resources in place (src/renderer/generic.zig recoverLostContext, gated on the graphics API having contextLost). The macOS feature is the same one: a window must survive its GPU going away. Metal reports this via MTLDevice removal notifications (MTLCopyAllDevicesWithObserver, MTLDeviceWasRemovedNotification) on eGPU unplug, and automatic graphics switching can move a window between GPUs. Check what Ghoztty does today (unplug an eGPU, or force a GPU switch), and if a window dies or goes blank, implement contextLost/rebuildContext for Metal.zig so the shared recovery path covers it.
