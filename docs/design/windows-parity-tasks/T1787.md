# T1787 - background-opacity fades the text with the background and turns background-blur into a no-op: the window is whole-window LWA_ALPHA, not per-pixel alpha

## Summary

T1016 measured it: every translucent ghoztty window is WS_EX_LAYERED + SetLayeredWindowAttributes(LWA_ALPHA), which fades the WHOLE window uniformly - glyphs, cursor and chrome as well as the background - where Mac's background-opacity makes only the background translucent and keeps text fully opaque. The same layering defeats every DWM blur: over a sharp checker the high-frequency energy under the window is 12.62 with no blur, 12.66 with the shipped accent blur, 12.62 with the Win11 acrylic and Mica backdrops - nothing blurs (the accent only lightens the view). A non-layered window with per-pixel alpha 0 in the client blurs under the same probe (1.13 accent, 0.00 acrylic). The fix is a per-pixel-alpha present path: the renderer clears to background at background-opacity with premultiplied alpha into a surface DWM composes by alpha (candidates: WGL pixel format with alpha plus DwmEnableBlurBehindWindow with an empty region on the top-level, or a DXGI/DirectComposition swapchain), chrome painted alpha-correct, and no LWA_ALPHA. Unblocks the background-blur follow-up.
