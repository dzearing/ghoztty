# T2507 - A translucent window (background-opacity < 1) still leaks ~3 MB of GPU memory per closed pane: its panes keep the plain child because a constant-alpha layer composes opaque

## Summary

T2502 turned per-pane layers on by default, which frees a closed pane's GPU surface. A window whose config allows translucency keeps plain WGL children (pane_layer.wantOwnLayer), so it still holds ~3 MB (default size; 8 MB at 1800x1100) per closed pane until the window closes. Closing it needs a per-pixel-alpha pane layer or the composition present path (T2360). Validation: pane-close-memory.ps1 run with background-opacity = 0.85 reads A8 <= 1 MB, and translucent-window shows the desktop through the panes.
