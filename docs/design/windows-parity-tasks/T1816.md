# T1816 - Mac seat: validate the T1796 merge's shared agent/termio resolution

## Summary

The T1796 merge (b0c7ddb72) took main's 33 commits into this branch, and in
the shared agent and termio it did NOT land main's code verbatim. On the next
cutover/merge to main, the Mac app will run these choices:

- **Resume offset**: the viewer uses this branch's T739 stream position and
  T532 clamp, not main's `Attached.replay_len` / `anchorAppliedOffset` (the
  protocol field stays; this agent never sends it).
- **Reboot history**: `preloadRingSnapshot` keeps main's history/convert/raw
  fallback for holderless records, but holder-backed records keep the raw ring
  (`abandonHolder` converts on failure). `.hist` is written on the 30 s timer
  pass and at checkpoints, not on volume-triggered passes, and its end offset
  is the ring's END (`at`) rather than main's `base + n`.
- **FLOW catch-up**: `sent_offset` is reset at every bind, not only ATTACH.
- **reapExited** goes through the T1771 lost-holder rule and notifies the roster.
- **checkpoint()** is built on this branch's `refreshCwds` (void, persists on
  change, pushes META{cwd}), not main's bool variant.
- The emulator scrollback budget is 4 MiB for both T621 and the history.
- The new EOF-nudge test in `pty_child.zig` (POSIX-only, so a Windows lane
  never compiles its body) now waits on `test_util.Deadline`.

None of the POSIX-only bodies can be compiled from the Windows seat: a test
that opens with a comptime `if (is_windows) return error.SkipZigTest;` is not
analyzed on Windows.

## Validation criteria

- [ ] `zig build -Doptimize=Debug` and `zig build test` + `zig build test-agent` green on macOS at b0c7ddb72 or later.
- [ ] `scripts/e2e/session-persistence.py` passes, including `--winsize` and `--reboot-tui`.
- [ ] Three app restarts of a 3-pane persistence window leave every pane responsive (the freeze main's replay_len fixed, now covered by T739/T532 on this branch).
