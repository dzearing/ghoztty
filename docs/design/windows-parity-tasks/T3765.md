# T3765 - Linux: the Settings Font row is Mac's installed-font picker - a menu of the monospaced families fontconfig knows, Default removes the key, fallbacks kept and counted - not only a chip list

## Summary

T3632 gave the Appearance > Font row (font-family) the list editor (chips + add field). Mac's FontControl (macos/Sources/Features/Settings/SettingsRowView.swift) is a picker over the installed fixed-pitch families: Default (JetBrains Mono) removes the key, a pick replaces the first value and keeps the fallbacks, '+N fallback' shows the rest, and a primary that is not installed says so ('X isn't installed - Ghoztty uses the next font.'). Port it to GTK with fontconfig's monospace families (FC_SPACING mono) on an AdwComboRow, keeping the chip list for the fallbacks; extend test/linux/settings-window.sh. Windows draws the same row as a value list too (T2681's note) - check whether a win task exists before closing.

## In plain terms

On Linux, the Settings window's Font setting was a box where you typed font
names. On the Mac it is a menu of the fixed-width fonts actually installed,
with "Default (JetBrains Mono)" at the top. Linux now gets that menu: pick a
font and it becomes your terminal font, any backup fonts you listed stay, the
row says how many backups there are, and a font you named that is not
installed is called out.
