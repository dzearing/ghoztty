# T3697 - Linux L10f2: drag window rows and project headers to reorder the GTK all-windows list, into and out of groups

## Summary

Split from T3607 (pane rows reorder landed). In the expanded all-windows list a window row drags among its siblings and anywhere into or out of a group (renamed <project>: <name> / <name>, pinned), a project header among the top level; the order is pane_sidebar_window_order keys persisted under the config root (win32 pane_sidebar_window_order.zig, pane_sidebar_cross_drop.zig, pane_sidebar_shared window_order). Dragging folds every window/group first and restores the folds after. docs/reference/pane-sidebar.md 'Reordering windows and groups'. Reuse the T3607 seam shape (--layout, --drag) and cli-sidebar-drag.sh.

## In plain terms

On Linux the sidebar's "all windows" list always sorted windows and groups
by name, and you could not rearrange it. Now you can drag a group's header
to move the whole group, and drag a window up or down, into a group or out
of one, just as on the Mac. The list remembers where you put the groups,
even after a restart, and moving a window between groups from its
right-click menu no longer reshuffles everything else.

## Goals

- [x] a project header drags among the top level, never above the lone windows
- [x] a window row drags anywhere: into a group (retitled `<group>: <name>`), out of one, or within its own
- [x] picking one up folds the list to rows, letting go puts the folds back
- [x] the order is stored under the config root and the groups' order survives a relaunch
- [x] Move to Group / Remove from Group keep the list's place (T3608's note)
- [x] goto_window / goto_tab follow the dragged order (listOrder reads the same order)
