# T1646 - The end-to-end suites still roll their own test deadline instead of the shared one

## Summary

T831 put one wall-clock wait helper in src\remote\test_util.zig (Deadline) and moved connection.zig and pty_child.zig onto it. Four test-only files still build their own: wp4_e2e.zig (ten sites), test_client.zig (two), agent_smoke.zig, remote_backend_e2e.zig, each a bare 'std.time.milliTimestamp() + N' loop with its own number and no label, so a timeout there still says error.Timeout and nothing about what it was waiting for (T436). They measure TIME, so none of them is the spin-count defect T831 existed to kill - which is why they were left rather than swept - but they are the same idea written five more times, and the numbers (5s, 8s, 15s, 20s, 30s) are a spread nobody chose on purpose. Wanted: move them onto test_util.Deadline with plain-words labels, keeping a deliberate non-default budget only where the test is ABOUT the timeout.
