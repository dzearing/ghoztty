# T1941 - Mac releases publish no dSYMs, so a hang or spin in an installed Ghoztty.app cannot be symbolized (Mac half of T1936's symbols asset)

## Summary

T1936 made every win-v release publish Ghoztty-symbols-<version>-x64.zip (a verified symbol store) plus scripts\fetch-symbols.ps1. release.yml's macOS job uploads only the DMG: no Ghoztty.app.dSYM / ghoztty-agent dSYM is kept per release, so a spindump or sample of a user's Ghoztty.app shows unsymbolized frames for good. Mirror it: archive the dSYMs (xcodebuild DEBUG_INFORMATION_FORMAT=dwarf-with-dsym) as Ghoztty-symbols-<version>-macos.zip on the v-release, verify each dSYM's UUID matches the shipped binary (dwarfdump --uuid), add the fetch helper (atos/lldb recipe), and document it beside HACKING.md's Windows section.
