# T2488 - Composition step 2b: prove the composition swap-chain present ON SCREEN (WGC ghost capture: right way up, 0 torn/blank frames across a 9-pane glide), hold the grid during glides like Mac paneContentFreeze, then make GHOZTTY_COMP_PRESENT the default

## Summary

T2466 landed the composition present path (`src/renderer/gl_comp_present.zig`)
opt-in behind `GHOZTTY_COMP_PRESENT=1` and proved on the background test desktop
that it builds, presents, falls back and rebuilds (`test\win32\comp-present.ps1`).
What that desktop cannot show is the picture DWM composes: it is never composed,
and Windows.Graphics.Capture refuses it (T2463).

Left to do:

1. **An on-screen oracle that needs no idle box.** Launch the app as a T2463
   ghost (layered alpha 1/255, click-through, bottom-most, never activated - the
   app needs a debug-only launch knob for this, since a script cannot ghost a
   window without first showing it) on the input desktop and capture it with
   `wgc_capture.zig`. Assert the pane is right way up (prompt rows at the top,
   blank rows at the bottom), matches capture-pane's picture of the same frame,
   and that a 9-pane glide shows 0 torn/blank pane frames - with the knob on,
   next to the same run with it off.
2. **Grid held during glides** like Mac's paneContentFreeze (T2102 ported the
   freeze; confirm it holds on this path, where the visual stretches the last
   frame rather than the window showing a stale redirection bitmap).
3. **Default on**, with the knob inverted to an opt-out, once 1 and 2 are green
   on hardware. Also confirm the Mesa/WARP and RDP machines fall back cleanly
   (no `WGL_NV_DX_interop2` there - the `unavailable` log line, then WGL).

## Validation criteria

- [ ] Ghost-window WGC capture, knob on: pane right way up and pixel-equal (within tolerance) to capture-pane's frame.
- [ ] 9-pane glide, knob on: 0 torn/blank pane frames; same run knob off recorded beside it.
- [ ] Grid hold during a glide observed on this path.
- [ ] Default flipped; comp-present.ps1 D arm becomes the opt-out control; the Mesa fallback path logs `unavailable` and draws.
