# T2265 - The pinned pane sidebar and the viewer side panel on Windows do not resize from the gutter beside them with Mac's accent gutter bar (Mac a81db68f9 + 5e4f30144)

## Summary

Split from T2253. Mac a81db68f9: the pinned sidebar resizes from the gutter beside it (PaneSidebarHost/PaneSidebarState), and 5e4f30144 gave the side panel's resize edge (ViewerSidePanel) the same GutterBar as split dividers: 4pt accent bar, half strength on hover, full while dragged, never lit after release. T2253 built the bar (src/apprt/win32/gutter_bar.zig) for split dividers and stack grips; reuse it for these two edges.

## In plain terms

The pane list on the left and the contents card beside a document can both be
made wider or narrower by dragging their edge, but on Windows nothing showed
that the edge could be taken - only the mouse pointer changed. Now, as on the
Mac, hovering that edge shows the same soft accent-coloured bar the gaps
between panes show, it brightens while you drag, and it goes away when you let
go. In the raised ("elevated") pane style the pinned pane list now resizes
from the whole gap beside it, the way the Mac does, rather than from a thin
strip inside the list.

## Goals

- [x] The pinned sidebar's grip is the gutter beside it in the elevated style (Mac `pinnedEdgeGrip`), a band inside the panel in the flat style
- [x] That grip shows the accent gutter bar: half strength on hover, full while dragged, none after release
- [x] The rail's edge shows the same bar
- [x] The viewer side panel's (contents card's) resize handle shows the same bar
- [ ] The unpinned sidebar's open card edge - filed as T2272 (layered window)
