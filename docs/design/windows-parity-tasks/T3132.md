# T3132 - Ctrl+Alt+PgUp/PgDn (the Windows mirror of Mac Cmd-Shift-Up/Down, 997b26535) is the previous/next window, walking the pane sidebar's all-windows order and wrapping; win32 goto_window did nothing at all; hero mode still takes the chord for its panes

## Summary

Mac 997b26535 (+675ad0b8d docs) rebinds Cmd-Shift-Up/Down from jump_to_prompt to `goto_window` previous/next, walking "the windows in the pane sidebar's all-windows order ... wrapping", with hero mode still taking the chord for its panes; a viewer stops taking the chord from a focused terminal.

Re-measured on claim (the intake card guessed wrong): on Windows ctrl+shift+arrows is `swap_split` (Config.zig, bound after jump_to_prompt), and the Mac chord's Windows mirror is ctrl+alt+page_up/page_down (T1725: win+shift+up/down belongs to the shell), bound to `goto_split` previous/next. And the win32 `goto_window` arm was a bare `return true` - the action did nothing.

Translation (recorded call, not a decision: the chord mirror was settled by T1725 and the behavior is Mac's): ctrl+alt+page_up/page_down becomes `goto_window` previous/next on Windows; `App.gotoWindow` walks `PaneSidebar.allWindowsOrder` (every tab of every window - a Windows tab is the Mac window's counterpart - in name order then the user's drag order), wrapping, and raises the stop the way a sidebar row click does; `Window.heroStep` takes the chord first in hero mode. Previous/next pane keeps ctrl+super+[ and ]. The Mac viewer defect (AppKit offering every key equivalent to every view) has no Windows shape - keys go to the focused HWND only - but a focused viewer must still answer the chord (hero step, viewer-only window), so `goto_window` joins the viewer's native set.

## In plain terms

On Windows the "next window / previous window" shortcut did nothing. Now Ctrl+Alt+Page Down and Ctrl+Alt+Page Up step through your open windows (and their tabs) in the same order the sidebar lists them, wrapping around at the end, just like Cmd-Shift-Down/Up on the Mac. In hero mode the same keys still flip between the panes in the carousel.
