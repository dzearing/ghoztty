# T3832 - ghoztty-cleanup.ps1 and crash-first-chance.ps1 delete a fixed-name HKCU fixture key at start, so the same script running in both lanes at once deletes the other lane's live fixture

## Summary

Both scripts plant a fixed-name scratch key (HKCU\Software\dzearing-cleanup-test, HKCU\Software\ghoztty-test-t808) and Remove-Item it before seeding. With two loop lanes, lane b starting the script while lane a's copy is mid-run wipes lane a's fixture and turns lane a red for a reason that is not a defect. Fix: per-process key names (suffix PID), with the start-of-run sweep removing only siblings whose T2452 fixture claim (test\win32\lib\FixtureClaim.ps1) is no longer live; then show two concurrent copies both pass.
