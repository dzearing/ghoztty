# T3324 - viewer-diff.ps1 sections 3-4: a split diff pane's listing sometimes never arrives within 15s (commit pane, bad-revspec pane and the +reload re-render red together, 1 run in 10)

## In plain terms

The diff-pane check sometimes fails because a newly opened diff pane never
reports its list of changed files. Three such panes in the same run went quiet
together. It may be the check being impatient, or it may be a diff pane
really hanging. Nobody knows yet, and that is what this task is for.

## Summary

Seen 2026-11-21 in run 1 of 10 during T1642 (fresh Debug build, the first run
after it). The other 9 runs were ALL PASS. The run reported
`3 FAILURE(S) (62 assertions passed)`:

- `the commit pane pushed a listing` (section 3, `+split --view=git-diff:<sha>`)
- `the bad-revspec pane pushed a listing` (section 4)
- `+reload re-ran the diff (a fresh listing was pushed)`

The first `git-status:` pane's listing arrived fine in the same run. All three
misses are panes opened by `+split` into the `vd` window, and each waits 15s
(`Wait-DiffLine`) for a `viewer diff pane=<id> spec=...` line on the GUI's
stderr. So either the split panes' diff worker never ran, or it ran and never
logged, or it ran later than 15s.

That run's stderr was NOT kept (only failing runs 4-10 were set up to keep it),
so the first job is to catch one with its log.

## Details

- Harness: `test\win32\viewer-diff.ps1`, `Wait-DiffLine` (15s timeout) and
  sections 3/4/7.
- Cold-start shape: it was the first run after a rebuild. Try a few cold runs
  in a row (rebuild or wipe the WebView2 profile between them) before blaming
  load.
- If the log shows the listing landing after the 15s mark, the remedy is the
  wait. If it shows no listing at all, the defect is in the diff pane, and this
  becomes a fix task.

## Validation criteria

- [ ] A failing run is captured with its stderr log, and the cause is named
      (late listing, missing listing, or a pane that never started its diff)
- [ ] Ten consecutive `viewer-diff.ps1` runs, all ALL PASS, after the fix
