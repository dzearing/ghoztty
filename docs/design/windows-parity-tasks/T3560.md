# T3560 - Linux: pane banners survive session restore and a banner title names its pane on GTK

## Summary

Banners are per-pane session state on Mac and win32 (session-layout manifest keyed by pane id; core Surface.pane_banner_restored). On GTK T3339 keeps the banner only in PaneBanner.zig memory, so a restore or relaunch drops it. Persist it in src/apprt/gtk/SessionLayout.zig and restore it; and use the banner title (first line, or a ## heading) as the pane label wherever GTK names a pane (tab title fallback, the future sidebar), per banners.md and stacked-panes.md Strip labels.
