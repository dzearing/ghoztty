# T1336 - A diff pane's file list has no filter box, so finding one file in a hundred means scrolling

## Summary

Mac pins a search field under the changed-files card's header: type a few letters and the tree flattens to a hit list, Return opens the first match. The win32 card has the tree (T464) and no filter, which is the difference between a usable 30-file diff and a usable 300-file one.

## In plain terms

When a diff pane lists a lot of changed files, the only way to find one on
Windows was to scroll the list. On Mac there is a "Filter files" box at the top
of that list: type part of a name and only the matching files stay, Enter opens
the first one, Escape brings everything back. Windows now has the same box.

## Goals

- [x] a filter box pinned under the FILES caption of a diff pane's file card
- [x] typing narrows the list to files matching every typed word (a renamed file matches by its old name too), shown flat with each file's folder underneath
- [x] Enter opens the top match; Escape and the clear (x) button put the whole list back
- [x] the header says "3 of 120 files" while filtered, and a filter with one match or none never makes the card disappear
