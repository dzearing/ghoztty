# T3209 - The pane sidebar's folded windows unfold after a relaunch on Windows: the session layout saves no window identity for the all-windows list, so a window's fold cannot survive (Mac paneSidebarWindowID)

## Summary

User report 2026-11-17: windows collapsed in the pane sidebar were all expanded after an upgrade relaunch. The Mac manifest saves Entry.paneSidebarWindowID ('the window's identity in the all-windows list: its fold and its place in the list's shared order', macos/Sources/Features/Remote/SessionLayoutManifest.swift ~201) alongside paneSidebarPinned/Hidden/Order; the win32 session_layout.zig saves pane_sidebar_pinned/hidden/order but no window identity and no fold. Verify how the Mac persists the fold set (shared folds keyed by window id) and port it: save each window's sidebar identity and fold additively, restore it before first paint, and prove with an acceptance check that a folded window row is still folded after a kill + relaunch with persistence on (and from a Mac manifest). Do not regress older manifests (absent = today's default).
