# T3186 - Single-window mode: the window shows the most urgent activity of all its workspaces, and a parked workspace that needs input still asks for attention

## Summary

Title suffix is the on-show workspace's own; the window's activity state is the most urgent across workspaces (Mac refreshWindowActivity); a parked needs_input flashes the taskbar button (FlashWindowEx) and its toast click switches to it; bells/banners/manifest updates never pause while parked. Child of T3136 (split 2026-11-16). Design (T3136 Details): ONE shared top-level HWND; every workspace keeps its own Window controller; the workspace on show owns the HWND (GWLP_USERDATA, chrome, sidebar), a parked Window has hwnd=null and its pane child HWNDs are reparented (adoptPane-style SetParent, Window.zig:7278) under a hidden park host so they survive the shared HWND closing. Spec: docs/reference/window-modes.md. Acceptance goes in test/win32/single-window-mode.ps1 (one section per child).
