## In plain terms

The frame lab films every frame a window shows while you drag it, and judges
each one. To judge a frame it has to find the window's edges in it, and on a
real desktop whatever sits behind the window - wallpaper, another app - makes
that guesswork. This puts a plain single-colour sheet behind the window for the
length of each test, works out from the window's real layout which part of
each pane should move with which edge, and refuses to grade a run whose
starting picture it cannot read. Nothing changes for a user; it is what lets
the lab's first live run grade real drags.

## What landed

- `test\win32\lib\FrameLabLiveScene.ps1` (new):
  - `GflBackdrop` / `Show-FrameLabBackdrop`: a borderless WS_POPUP on its own
    pumped thread, WS_EX_NOACTIVATE | WS_EX_TOOLWINDOW, HTTRANSPARENT, placed
    with `SetWindowPos(below = the app)` and never topmost, painting one colour
    (WM_PAINT and WM_PRINTCLIENT). `-Desktop` puts it on a named desktop.
  - The backdrop colour `0x40C080` and `Test-FrameLabBackdropColor`: 32 from
    every palette level on every channel. T2394's synthetic `0x10F010` was 16
    from card 4's ring and is refused.
  - `New-FrameLabCellSceneSpec` (geometry only, no pixels): window-right/bottom
    only where the capture rect leaves backdrop beyond the window; one divider
    edge per pane with a right (`v:<pane>`) or lower (`h:<pane>`) neighbour -
    every edge located on every frame, because in a ratio split an inner
    divider moves with the window; the grabbed divider named `divider` (the
    catalogue's Track); the sidebar edge scanned leftward from inside the first
    column. Window-moving and pane-top interactions are `Unsupported` -> T2398.
  - `New-FrameLabCellScene`: reads the divider/sidebar/padding colours off the
    still frame, refuses a colour a card also uses, calibrates, and requires
    every edge within 3 px of where the geometry puts it. Returns the per-edge
    still-frame `Delta` (a border or shadow) the motion's grab offset carries.
  - `Get-FrameLabSceneScore`: Invoke-FrameLabCell's Score - superseded frames
    not counted, failing frames listed with classes, the tracked edge measured
    on the pointer's clock. Sign trap recorded in the code: the gesture's
    GrabOffset is pointer - edge, Measure-FrameMotion's is edge - pointer.
- `test\win32\lib\FrameLabCatalogue.ps1`: `Invoke-FrameLabCell` takes an
  optional `Scene` hook (refusal = `incomplete`, `scene:` reasons, nothing
  captured or played; the scorer rides the measurement capture only; Score is
  handed the scene). `Get-FrameLabGesture` grows the capture rect by
  `-ReachMargin` (48 px) beyond the farthest edge reach: a capture that ended AT
  the edge's extreme left no backdrop to scan from on the shuttle's turn frames.
- `test\win32\frame-lab-live-scene.ps1` (28 assertions) + guard row
  `frame-lab-live-scene`; frame-lab-catalogue.ps1 B7 updated for the margin.
