# T2397 - Frame lab live scene: put a solid backdrop window behind the app for every matrix cell and wire GfsSceneScorer's edges and cards to the FrameLabCard scene (window-right/bottom from the backdrop, divider and sidebar edge by their measured colours), calibrated on the cell's still frame

## Summary

Filed from T2394 (2026-10-28). `GfsSceneScorer` (`test\win32\lib\FrameLabScene.ps1`) locates
window-right/window-bottom by scanning in from a SOLID BACKDROP behind the
window until the backdrop stops, and a scan that never crosses backdrop is
not located (the frame fails as LOC). Nothing in the live driver puts a
backdrop there yet, and nothing builds the scorer's edges and cards from a
real cell.

To build:

- A borderless, topmost-below-the-app window of one colour (not in any card
  palette, not a Flash colour) covering the capture rect for the cell, so the
  window edge is findable on every frame of a frame/corner drag.
- Per matrix cell: one GfsCard per pane (FrameLabCard index, anchors from
  the interaction - which sides ride window-right/bottom, a divider, the
  sidebar edge), edges whose scan lines sit inside the window at its
  smallest size, the divider and sidebar-edge colours measured on the
  cell's still frame, the theme padding colour as each card's Extra.
- Calibrate on the still frame before the drag; a calibration refusal is the
  cell's verdict (`incomplete`), never a pass.
- Hand `AsScorer()` to Start-FrameCapture and `Get-FrameLabSceneMotion` to
  Measure-FrameMotion.

## Validation criteria

- [ ] A still-frame calibration on the real app succeeds for a 1-pane and a 2-pane cell (cell size and padding equal the config the lab launched with).
- [ ] A live frame-edge drag with the backdrop up tracks window-right on every frame (no LOC), and the edge series feeds Measure-FrameMotion.
- [ ] With the backdrop missing, the cell reads incomplete (LOC), not pass.
