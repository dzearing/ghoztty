# T1979 - Restore All from a Mac opens windows at half size on a 200% Windows display: Mac blob frames are points, read here as pixels

## Summary

Found in T1971. mac_layout_blob.zig converts a Mac blob's frame without a scale, so its points are applied as physical pixels; at 200% a Mac window comes back at half its size (cross-machine Restore All only; position is re-anchored by T336). Fix: set frame_dpi = 96 (points == DIP) on Mac-sourced windows so applyRestoreFrame's fitToMonitor converts them, and cover it in layout-blobs / mac_layout_blob unit tests.

## In plain terms

When you use Restore All on a Windows PC to bring back the windows from your
Mac, and the PC's display is scaled to 200%, every window opened at half the
size it had on the Mac. Now a window comes back the same size it was there,
at any display scale.
