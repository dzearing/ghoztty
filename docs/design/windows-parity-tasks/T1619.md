## Summary

Seam audit (T796) finding. All 49 acceptance scripts that start the agent set GHOSTTY_LOCAL_AGENT_BIN, so LocalAgent.agentBinary's default branch - ghoztty-agent.exe next to our own exe, which is the branch EVERY delivered build takes - has never once run under test. install-walkthrough.ps1 asserts the file is delivered beside ghoztty.exe but never that the app spawns it unaided. Wanted: one arm that launches a hermetic GUI with the override removed, from a directory that has a ghoztty-agent.exe beside the exe under test, and proves a session came up (and, as the negative half, that a missing sibling agent reports rather than hangs).
