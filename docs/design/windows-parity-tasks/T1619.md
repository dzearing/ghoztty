# T1619 - Nothing launches the app with GHOSTTY_LOCAL_AGENT_BIN unset, so the shipped agent-beside-the-exe path is untested

## Summary

Seam audit (T796) finding. All 49 acceptance scripts that start the agent set GHOSTTY_LOCAL_AGENT_BIN, so LocalAgent.agentBinary's default branch - ghoztty-agent.exe next to our own exe, which is the branch EVERY delivered build takes - has never once run under test. install-walkthrough.ps1 asserts the file is delivered beside ghoztty.exe but never that the app spawns it unaided. Wanted: one arm that launches a hermetic GUI with the override removed, from a directory that has a ghoztty-agent.exe beside the exe under test, and proves a session came up (and, as the negative half, that a missing sibling agent reports rather than hangs).

## In plain terms

Every installed copy of Ghoztty finds its background session helper by looking
next to its own program file, but no test ever exercised that lookup — every
test told the app exactly where the helper was. Now one test starts the app with
no hint at all and checks it finds the helper on its own, and that a copy with
the helper missing still opens a working shell and says what is missing instead
of hanging.

## Goals

- [x] An acceptance arm launches the app with GHOSTTY_LOCAL_AGENT_BIN unset and proves the sibling agent is the one spawned and owns the pane's session
- [x] The negative arm: a lone exe with no sibling agent opens a working pane promptly and names the missing path
- [x] The harness has a guard-due row so an edit to the resolution code obliges a re-run

## Validation criteria

- [x] Arm A: with the override removed, the one agent daemon of the run's lineage has ExecutablePath = zig-out\bin\ghoztty-agent.exe, the pane answers an echo round-trip, and `+sessions --json` lists its session — `test\win32\agent-sibling-resolve.ps1`, ALL PASS (20 checks), 2026-11-21 on the test desktop.
- [x] Arm B: a copy of ghoztty.exe alone under temp\ opens an answering pane in ~0.7 s (bound 45 s), starts no agent for the lineage, and logs `local agent binary not found at <dir>\ghoztty-agent.exe` — same run.
- [x] Guard row `agent-sibling-resolve` (covers LocalAgent.zig, self_exe.zig, the script) in `scripts\guard-due.ps1`.
