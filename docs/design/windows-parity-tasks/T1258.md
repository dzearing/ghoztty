# T1258 - Nine acceptance scripts print a SKIP their verdict never names, and the sweep that catches it is red

## In plain terms

Some of the checks that are supposed to prove Ghoztty works quietly decide not
to run - a tool is missing, a precondition is not there - and then the line
everybody reads still says everything passed. The rule that a skipped check has
to be named in that line exists; nine scripts are breaking it, and the sweep
that is supposed to catch them has been failing without anybody noticing.

## Evidence (2026-09-01, found while working T1209)

`powershell -NoProfile -File test\win32\skip-visibility.ps1` exits 1:

```
FAIL B1 no script violates the rule without being a named exception
     build-cache.ps1     L265 uncounted, L311 unreported
     fork-identity.ps1   L633 unreported
     ghoztty-cleanup.ps1 L404 unreported
     install-launch.ps1  L323 unreported
     install-prepare.ps1 L194 unreported
     install-restart.ps1 L174 unreported
     ship-workflow.ps1   L402 unreported
     update-apply.ps1    L219 uncounted, L392 unreported
     viewer-find.ps1     L527 unreported
```

`unreported` = the script has skip sites but its `ALL PASS` line names no skip
count. `uncounted` = a skip site the counter never sees, which is worse: a
number that under-reports reads as audited.

## Why nobody noticed

`skip-visibility` has no row in `scripts\guard-due.ps1`, so nothing ever
reports it as due and nothing fails a commit over it. Every other sweep in this
family (isolation-meta, verdict-exit, cleanslate, stderr-capture, body-complete,
desktop-launch) has one, which is exactly why they were all green when this was
not.

## What to do

- Convert the nine onto the shared scorer's skip counting, the way the rest of
  the suite is. The `$SkipAuditPending` list may only shrink.
- Give `skip-visibility` a guard row covering `test\win32\*.ps1`, so a script
  that regrows the defect makes the sweep due rather than silently red. Its
  sibling `printclient-audit` (203 files) is the precedent for a corpus-sized
  Covers list.
