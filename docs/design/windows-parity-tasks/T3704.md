# T3704 - win32: check a sized popup's page gets the size it asked for now that the pane sidebar takes part of the window (Linux lost 84px to it, T3614)

## Summary

Window.zig sizes an adopted popup (T163) as the asked PAGE size plus the frame (AdjustWindowRectEx), but the pane sidebar column and the elevated grid inset also sit inside the client area. On Linux the same shape left the page 84px narrow and 160px short (T3614, fixed by measuring the page after layout and growing the window by the shortfall). Measure innerWidth/innerHeight of a window.open(url, name, width=500,height=400) popup on win32 in the viewer-popup acceptance; if short, grow the client by what the chrome takes, or measure after layout as Linux does.
