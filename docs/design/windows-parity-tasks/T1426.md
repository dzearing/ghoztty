# T1426 - The chooser never says a machine is still connected to an account you signed out of

## In plain terms

If you sign out anyway after Ghoztty could not remove this machine from your
account, you are told it stays connected — and then nothing ever tells you
whether it still is. The machine list is the one place that could say so, and it
says nothing. You are left to assume the sign-out you were warned about somehow
completed.

## Goals

- [x] The chooser marks a machine that is still connected to an account it was signed out of
- [x] The mark says what to do about it, not just that something is wrong (Mac's sentence: "still removing it" - Ghoztty is already doing the fix, so there is nothing for the user to go and do)
- [x] It clears the moment the pending revocation completes (T1424) - within one 5s poll tick of the record going
- [x] It reads correctly in both themes and at the chooser's narrow widths - the chooser is fixed at 840 DIP, and the note is a wrapped caption capped at 280 so the machine name keeps its room; drawn in the palette's secondary text role, which is derived per theme

## Summary
