# T3390 - The machine chooser has no per-machine Restore for relay windows left open at quit (Mac's contextual Restore reads RemoteSessionManifest.restorableEntries)

## Summary

Mac's chooser offers a contextual Restore for one machine when RemoteSessionManifest holds restorable entries for it (restorableEntries: same relay+device, a session id, not bound to an open window, not in flight), and runs restoreRemoteWindows(matching:) scoped to that machine - the recovery when the launch restore could not reach it. Windows has the record since T3352 but no chooser affordance: add a restorableEntries query to relay_manifest.zig and a scoped RelayWindowRestore.start, and surface it on the chooser's machine row.
