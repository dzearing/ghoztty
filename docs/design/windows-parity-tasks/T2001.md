# T2001 - An idle Claude pane turns into 'question' a minute after every turn on Windows too: the generated Notification hook has no matcher, so idle_prompt runs pause (main eb8162e59)

## Summary

main eb8162e59 fixed this on Mac. Claude fires the idle_prompt Notification ~60s after each turn; src/apprt/win32/ClaudeHookSpec.zig:70 registers Notification with no matcher, so the pane flips to needs_input. Port all four halves: (1) matcher permission_prompt|elicitation_dialog on the Notification hook; (2) the activity-state script's pause reads the payload and ignores any other notification type, failing closed, so hooks installed before the matcher are fixed too; (3) a submitted prompt (UserPromptSubmit) undoes a pause, and session-start drops a marker the pane's previous session left; (4) +list --json reports each terminal pane's state and human +list marks [busy]/[question] (src/cli/list.zig changed in main; the win32 IPC list handler must supply the field). Mac test: scripts/test-activity-state.sh, macos/Tests/Ghostty/ClaudeHookSpecTests.swift. (5) refresh the vendored upstream mirror src/apprt/win32/assets/ghoztty/upstream/hooks/ghoztty-activity-state.sh from origin/main so test/win32/hook-json.ps1 section A goes green, re-checking the Windows fork deliberate differences (T878). T1977 and T1988 (both the mirror half) were folded into this task. Deps T1902 for the shared list.zig half.

## In plain terms

About a minute after Claude finishes answering, every idle Claude pane on
Windows switched to "question" (title suffix and sidebar ring), even though
nothing was being asked. After this fix a pane only shows "question" when a
permission prompt or a real question is on screen, and typing a reply clears it.

## Goals

- [x] Notification hook only fires for permission prompts and MCP dialogs
- [x] the script itself ignores the idle notification, so old installs are fixed too
- [x] typing a reply, or starting a fresh session, clears a stale question
- [x] `+list` shows which pane is busy or asking (landed with T1902's main merge; now tested)
- [x] vendored mirrors match main again
