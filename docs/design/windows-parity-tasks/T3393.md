# T3393 - An installed-release updater running from any folder other than the real install can run msiexec over the user's installed product

## Summary

T3388 closed the test-sandbox route with GHOZTTY_AUTO_UPDATE=off, but the app itself still applies an MSI whenever install_location reads its own folder as the installed release, and msiexec product state is per user: any copy of a release build under some LOCALAPPDATA\Programs\Ghoztty (a sandbox, a second profile path, a stale copy) installs over the real product. Decide in the app: before arming the applier, compare the folder the MSI's product is registered at (MsiGetProductInfo InstallLocation for the UpgradeCode's product) with this exe's own folder, and refuse with a logged reason when they differ. Unit-test the comparison; acceptance: a sandboxed release copy with a staged package logs the refusal and runs no msiexec.
