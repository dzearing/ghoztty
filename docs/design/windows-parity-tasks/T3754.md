# T3754 - Starting folder per shell: a WSL pane starts at a Linux path (default ~), a Windows shell at a Windows path, set per shell in Settings > Shell; splits and tabs inherit a folder only within the same shell family (T3735)

## Summary

Child of T3735. Settings > Shell gets a Starting folder field per shell, the WSL one validated as a Linux path. Inherit-working-directory: a WSL split of a WSL pane keeps its Linux cwd (from OSC 7, passed as wsl --cd); a Windows-shell split of a WSL pane, or the reverse, falls back to that shell's own starting folder instead of a mangled path. Today (T3749) a WSL pane opened with no folder goes to ~, and a split's inherited Windows cwd is overridden by ~ only when no --working-directory was given.
