# T1880 - The pane sidebar's scope switch and folds snap on Windows: Mac slides the list sideways between this window and all windows, and reveals a folding group top-down

## Summary

Split from T1829. Mac animates the sidebar's list: switching between this
window and all windows slides like a navigation push - this window's list lives
on the LEFT, all windows on the RIGHT, each sliding 48 pt and fading over 0.3 s
on an ease-out (0.2, 0.8, 0.2, 1) - and folding a group reveals or covers its
rows from the top down over 0.22 s while the rows below slide to their place.
The Windows outline snaps. Wanted: the same two motions in the panel and open
card, honoring the system's "show animations" setting (SPI_GETCLIENTAREAANIMATION).

## Validation criteria

- [ ] the scope switch slides toward all windows and back the other way, fading
- [ ] a fold reveals / covers top-down while the rows below move
- [ ] with animations off in Windows settings, both snap
