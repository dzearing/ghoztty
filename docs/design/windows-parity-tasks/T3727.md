# T3727 - Folded-strip popups still cost about 1.6 ms per move in a divider drag: at 28 panes a mouse move moves 6 scrollbar and 6 strip-face layered popups

## Summary

T2239 found that a default divider drag moves no popups and the dim washes ride the composition visual. The popup moves that remain are on panes folded into strips: a 28-pane drag-perf run (glass off) reported chrome_moves=12 (sb 6, dim 6 counted from StripFace) costing 19.3 ms of a 34.7 ms mouse move, about 1.6 ms each. Find what each SetWindowPos synchronously triggers (layered resize, WM_ERASEBKGND/WM_PAINT, a DWM sync), or move the strip faces and their scrollbars onto the composition visual the way the washes went. Oracle: drag-perf mean_chrome_move_us with a pane count that folds.
