# T1748 - Activity Monitor's Show all checkbox stays clickable when the machine cannot filter to Ghoztty's processes

## Summary

Mac disables the Show all toggle (forced on) when canFilterSpawned is false (RemoteActivityMonitorView.swift:1016-1024): with no root pid and no pane-attributed row there is no spawned set to narrow to, so the checkbox would do nothing. win32 leaves it enabled and clickable in that state (no EnableWindow anywhere in the panel), so unchecking it silently changes nothing. T1634 already gives it the right tooltip for that state (activity_help.showAll's pre-dates sentence); the control's enabled state should follow activity_help.canFilterSpawned, and a harness should drive a source with neither a root nor attribution.
