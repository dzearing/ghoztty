# T1904 - After an update, the installed agent hook scripts (~/.config/ghoztty/hooks) keep their old text until someone opens Agent Integrations and clicks Update, so a fix to the hook (T1823's help text) never reaches the agents running in the terminal; both platforms

## Summary

Found in T1901: the installed ghoztty-banner.sh was dated 2026-09-14 three releases after T1823 fixed its help text, so every Claude session still got the old instruction. BannerScriptInstaller.state() reports .outdated and the dialog shows 'Update available' (same on Mac), but nothing applies it. Ghoztty owns these files (marker line), so refreshing an outdated, marker-carrying script at app launch is safe; decide whether the refresh is silent or surfaced, land on both seats.
