# T2114 - Mac: soften the focus glow's inner edge to match Windows T2112 - PaneFocusGlow peaks on the first desk pixel; ease it in over 2.5pt so the peak sits ~2pt out with the outer falloff unchanged

## Summary

The user said of the Windows focus glow (2026-10-21): "the inner edge of the
glow shouldn't be as bright but the outer edge is fine." T2112 fixed it on
Windows. The Windows glow is a port of Mac `PaneFocusGlow`
(`macos/Sources/Features/Splits/PaneElevation.swift`, struct at ~line 338),
and that has the same shape. It is a 4pt `.stroke` centred on the card edge,
blurred with `.blur(radius: 4)`, then masked off the card. So its brightest
light falls on the first desk pixel and reads as a bright line hugging the
card.

**The profile Windows now has** (`src/apprt/win32/pane_elevation.zig`,
`glowAlpha` + `GLOW_INNER_RAMP_DIP`): the old blurred band, multiplied by a
smoothstep ramp from 0 at the card edge to 1 at 2.5pt out. Measured at 1x:

- The first desk pixel drops from ~67% of the old peak to ~7%.
- The peak now sits ~2pt out, at ~0.43 of the band's strength, where it used
  to be ~0.67 at the edge.
- Past 2.5pt the curve is identical, so the reach (~8pt) and the outer
  falloff do not change.

**Mac fix direction.** Make the mask's inner edge soft instead of the hard
`shape.blendMode(.destinationOut)`. One way is to also knock out a blurred
stroke ~2.5pt wide along the shape's outside, so alpha eases in from the
edge. Tune it by eye beside a Windows build.

## Validation criteria

- [ ] `PaneFocusGlowTests`: a pixel 0.5pt outside the card is clearly dimmer than one ~2pt out, and the light is still gone by the 10pt gap.
- [ ] On screen: a 3-pane window's focused pane shows a soft halo with no bright line hugging the card, matching a Windows build side by side.
