# T3666 - Linux: an undo pressed while a tab's close confirmation is still open (after Close Other Tabs) brings nothing back

## Summary

Seen while building T3590: with confirm-close-surface on, Close Other Tabs parked the tab that needed no confirmation and left the other behind its confirmation dialog; Ctrl+Shift+Z pressed (through the press-key seam) while that dialog was open restored nothing, and the parked tab expired. Then the dialog-pending tab also ignored a later close. Reproduce with cli-undo.sh minus --confirm-close-surface=false; decide whether undo should reach past an open dialog (Mac: the sheet is modal, so the keys never reach the window) and whether a grouped close should ask once for all tabs.
