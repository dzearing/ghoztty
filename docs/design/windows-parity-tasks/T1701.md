# T1701 - task-dashboard.ps1 never returns when its output is redirected to a file

## Summary

Observed 2026-09-23 closing T931: 'task-dashboard.ps1 -NoPane *> file' printed 'serving http://localhost:7788/' and then hung until the tool timed out (300s); the server itself was up and answering 200. Likely the detached node server inherits the redirected stdout/stderr handles, so the caller's pipe never closes (same shape as the GUI-inheriting-stdout hang). A turn that restarts the dashboard from a script stalls. Fix: start the server with its own log redirection / no handle inheritance, and add a harness leg that runs the launcher with output redirected under a timeout.
