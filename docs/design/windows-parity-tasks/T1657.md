## Summary

On 2026-09-18 the 29-audit floor took about 28 minutes of sweeping (test-reach-audit alone 10m) and was then cut during suite-run's confirm-pass re-run, so the lane printed WALL-CLOCK CAP / FLOOR NOT GREEN over a run in which every audit had already produced a verdict and the only two reds were the named pending exceptions (T1123, T1568). go.md step 3 points turns at -Lane harness, so the documented path cannot go green; the guard row's own command (scripts\harness-floor.ps1, no cap) still runs and stamps. Fix the cap for this lane (it is source sweeps, not a build), or make the wrapper score the summary it already has when the cap hits.

## In plain terms

That check takes about 40 minutes, but the wrapper that runs it gives up at 30, so the check was cut off and reported as failed even though everything it had looked at was fine. The morning report then had no answer for "are the test scripts healthy?".
