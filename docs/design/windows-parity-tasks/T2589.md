# T2589 - Honor macos-window-gradient (random / ocean): a hand-opened elevated window gets its own random gradient or the shared ocean desk (Mac 92ab0c9f1)

## Summary

Mac 92ab0c9f1: macos-window-gradient (random default | ocean) decides the gradient a hand-opened window (Cmd-N, New Window menu, palette) gets in the elevated pane style; ocean leaves it on the shared ocean desk; --color keeps its color either way; a restored window keeps its persisted seed; runtime change applies to new windows only; ignored in flat. Windows: App.zig picks desk_palette.Variant.random() for .elevated unconditionally; branch on the key (shared core, arrives with the T2490 merge) with a unit test of the variant choice. Mac reference: docs/reference/pane-style.md; test theOceanGradientLeavesANewWindowOnTheSharedDesk.

## In plain terms

On a Mac, a setting decides whether each new window you open by hand gets its
own random colour gradient (the default) or the shared blue-teal "ocean" one.
Windows ignored that setting and always gave a new window a random gradient.
Now a Windows user who sets it to `ocean` gets ocean windows, just as on Mac.
