# T3003 - PA-M03: the terminal page pool commits whole 1.5x-grown arena nodes on Windows, ~7 MB of never-touched commit per full-scrollback pane, and preheats 4 pages where 1 holds the viewport (PageList.zig:34)

## Summary

PA-M03 (audit-1, T2961). PagePool is a MemoryPool over an arena on std.heap.page_allocator off Darwin (src/terminal/PageList.zig:327, :369-374), preheated with page_preheat = 4 (:34). The arena grows each node by 1.5x and Windows commits each node whole (Zig 0.15.2 PageAllocator MEM_COMMIT|MEM_RESERVE). Estimated: a standard page ~400 KB; a pane at the 10 MB default limit has ~17.7 MB committed (~7 MB untouched); creation commits ~2.1 MB where ~0.4 MB holds the viewport; the alt screen pays the same on first TUI use. Fix: on Windows give the pool a reserve-then-commit-per-page (or fixed-chunk) allocator; preheat 1 when max_scrollback == 0. Risk medium (hot path, shared file): gate on Windows and keep the zeroing assumption at :727-729. macOS maps lazily, so no Mac half is owed. Baseline: docs/design/perf-audit/baseline-1.json (T2958); findings: docs/design/perf-audit/audit-1/M-findings.md.
