# T3788 - Mac: a new tab can open on a chosen shell from a visible control beside the new-tab button, as Windows does (T3753 list + T3768 chevron)

## Summary

Windows now offers the installed shells two ways: a chevron beside the tab strip's + (T3768) and File > New Tab as a submenu (T3753), with Default Shell first under the New Tab chord. The Mac has no counterpart. Build the Mac-native equivalent: a shell list for a new tab reachable from the window's new-tab affordance and the File menu, listing the shells the Mac's shell picker knows, default first; a pick opens the tab on that shell (agent-backed when persistence is on). Validate on the Mac seat.
