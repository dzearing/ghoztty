# T2982 - PA-R16: the occlusion walk runs on every programmatic resize step and the 150 ms hero heartbeat keeps snapshotting a covered window

## Summary

PA-R16 (audit-1, T2959). apprt/win32/Window.zig:22388-22389 calls refreshOcclusion on every SIZE_RESTORED/SIZE_MAXIMIZED (SIZE_RESTORED also fires for every programmatic resize, :22395); occlusion.zig windowHidden calls DwmGetWindowAttribute(cloaked) before the cheap rectangle test for every window above. Window.zig:8002 heroSnapTick returns only when IsIconic, not when self.occluded. Cost small. Fix: refresh occlusion on WM_SIZE only when leaving minimized or already occluded; rect-test before cloaked(); return early in heroSnapTick when occluded. Risk low.

- [ ] perf-baseline.ps1 -Phase resize cpu_pct not worse; occlusion acceptance harness green
