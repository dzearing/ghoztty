# T2366 - A new window's terminal gets the caret, not the sidebar's all-windows search field (Mac 470526d63)

## Summary

Mac main 470526d63: with the shared sidebar showing all windows, a newly ordered-in window (Cmd-N, the sidebar + buttons, a restore) handed the caret to the sidebar's all-windows search field instead of the terminal. Mac removed the search field from the key-view loop so it only takes focus when clicked. Windows: verify that a new window opened by Ctrl+Shift+N / the sidebar + buttons / session restore puts keyboard focus in the terminal (src/apprt/win32/pane_sidebar_search.zig owns the search EDIT), and that the search field never takes focus except by click (or its explicit shortcut). Fix if it does; add an acceptance check either way. Reference: docs/reference/pane-sidebar.md on main.
