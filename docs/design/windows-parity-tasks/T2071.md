# T2071 - The installer carries ghoztty.com as a second 20 MB copy of the terminal: derive it from ghoztty.exe at install time instead

## Summary

Split from T1077. ghoztty.exe and ghoztty.com differ by ONE WORD (PE optional-header Subsystem), yet the MSI and portable ZIP each carry both in full (~19.9 MB extra compressed, ~45% of the download). Derive the .com at install time: copy ghoztty.exe and flip the Subsystem field (the same edit src/build/patch_subsystem_main.zig makes), from the existing MSI custom-action DLL, with a RemoveFile row so uninstall cleans it and upgrade/repair regenerate it. Validate: MSI shrinks by ~20 MB; after install, repair, upgrade and uninstall the .com is present/current/gone; 'ghoztty +list --json > f' from PowerShell still writes output; Defender leaves the derived file alone. Decide separately whether the portable ZIP keeps shipping both (it has no installer step) - default: it does, and READ-ME-FIRST says why. Rejected alternatives and measurements are in T1077's progress log.
