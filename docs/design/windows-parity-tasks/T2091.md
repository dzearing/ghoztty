# T2091 - Stacked panes on Windows need Mac's hardening: strips stay put on focus, divider drags chain-collapse, resizers live only in the gutters, a dragged strip gets its own drop targets (main 2811a3043)

## Summary

Mac 2811a3043: focusing a pane already on show never moves the row (sticky run); a column emptying into its row keeps its strips; undo restores the saved stack state; stash/kill/viewer close/window-becomes-key never hand the caret to a strip; a pane dropped on a strip stays minimized. Divider drags past a minimum chain-collapse the next pane and restore in reverse. Every resizer (dividers, stack grips, run-edge grip, sidebar edge) lives in the gutters, strips get gutters too (flat style: 6pt). A dragged strip targets slots between cards/strips, window edges, a screen edge (new window), the sidebar - never split/swap over a pane - with previews. Mac also added a fuzz test of random operation sequences; do the same over the pure layout.
