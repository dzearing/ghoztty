# T3581 - Pasting a file copied in Explorer (or from an image pane) into a terminal pane pastes nothing; Mac pastes the file's path

## Summary

Nothing in src/apprt/win32 reads CF_HDROP (grep, 2026-11-23), so a terminal paste of a clipboard that holds only files - Explorer's ctrl+C, and now an image pane's ctrl+C beside its picture (T1909) - pastes no text. Mac's terminal pastes a copied file URL as its path. Windows shape: when CF_UNICODETEXT is absent and CF_HDROP is present, paste the path(s), quoted per the pane's shell flavor, space-separated. Reader: image_clipboard.dropFilesPaths. Validation: unit tests for the quoting per flavor, plus an acceptance row that puts a CF_HDROP on the clipboard, pastes into a pane and reads the path back with +read.
