## In plain terms

The Windows window itself (the title bar, tabs, side rail, little overlay
badges, and the timers and threads behind them) costs memory and CPU even when
you are not doing anything. This audit read that code, double-checked every
claim, and queued a fix for each real waste it found. The biggest: every
background thread reserves and pins 16 MB of memory up front, which is about
half of what Ghoztty keeps after you close a batch of panes.
