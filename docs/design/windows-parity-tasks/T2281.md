# T2281 - On glass, Windows dims and thins unfocused panes; Mac now changes only the rim and glow with focus - the focused pane's rim is 34% white against 10%, and every pane's sheet and content are the same (Mac 9da9618f8)

## Summary

Mac 9da9618f8: the focused pane keeps its backlight glow and gets a lighter rim (34% white vs 10%); its glass sheet and content are the same as every other pane's. An unfocused pane used to get a thinner sheet and fade its terminal (89848fd59, ported to Windows as T2086), so focusing a pane read as the pane itself lighting up - Mac removed that. Remove the unfocused thinner sheet and the unfocused-split-opacity fade on glass on Windows (flat style is untouched). Supersedes T2106 (easing that fade over 250ms), which is closed by this intake.
