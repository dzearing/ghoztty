# T3766 - Settings Font row is Mac's installed-font picker on Windows - a menu of the monospaced families DirectWrite knows, Default removes the key, fallbacks kept and counted - not the font-family value list

## Summary

Gap: on Windows the Settings window's Appearance > Font row edits `font-family` as its value list (T2586's note, T2681 left Mac's `.font` control out; `settings_pages.zig` header says so). Mac's `FontControl` (macos/Sources/Features/Settings/SettingsRowView.swift) is a picker over the installed fixed-pitch families: Default (JetBrains Mono) removes the key, a pick replaces the FIRST value of the user's file and keeps the fallbacks, "+N fallback" sits beside it with the rest as its tooltip, and a primary that is not installed is listed "(not installed)" with "X isn't installed - Ghoztty uses the next font." under it.

Linux landed it in T3765, and the rules are already shared and unit-tested in `src/apprt/win32/settings_controls.zig` (`fontFamilies`, `hasFamily`, `fontChoices`, `fontChoiceIndex`, `fontPick`, `fontFallbackLabel`, `fontNotInstalledText`). What is left for Windows is the drawing and the family list:

- Enumerate the monospaced families with DirectWrite (`IDWriteFontCollection` from `GetSystemFontCollection`; a family counts when a face reports `IDWriteFont1::IsMonospacedFont`), feed the names through `fontFamilies`, and keep every family (any spacing) for the not-installed test.
- Draw the Font row as the curated popup (the same native menu the picker rows use), Default first; a pick goes through `fontPick` + `SettingsModel.setList`, Default through reset. "+N fallback" beside it, the fallbacks as chips on a row below (Linux's shape) once the file names a font.
- `ipc_settings.zig`: the same seam shape as GTK's (`--op=choose --key=font-family`, `fallback`, `fallback_tooltip`, `fallback_chips`; list-add/list-remove on the fallback chips with index 0 = the file's second value), so `test/win32/settings-window.ps1` reads like `test/linux/settings-window.sh` F1-F8.

## Validation criteria

- [ ] settings-window.ps1 gains the F1-F8 checks of test/linux/settings-window.sh (the items are exactly the monospaced families DirectWrite lists; a pick replaces only the first value; a fallback chip's x removes that fallback; a missing primary is marked and warned; Default removes every line), green on the test desktop
- [ ] Painted correctly: an Appearance page screenshot with the picker, "+1 fallback" and the fallback row, inspected by eye
