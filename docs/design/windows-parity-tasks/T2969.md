# T2969 - PA-R03: each pane compiles its own shader programs and keeps its own GPU copy of the shared font atlas; put pane GL contexts in one share group

## Summary

PA-R03 (audit-1, T2959; F2 stages 2-3 of the core auditor). OpenGL.zig:473-477 makes a per-pane hglrc current; each pane compiles five programs (opengl/shaders.zig:113-116) and owns its own atlas textures (generic.zig:431-442) although the CPU atlas is already shared through SharedGrid. Fix after PA-R02: a GL share group so panes share one atlas texture pair per grid and one program set. Risk: threading and lost-device recovery across a share group. Cost estimated at 1.25 MB+ per pane of atlas plus per-context driver state.
