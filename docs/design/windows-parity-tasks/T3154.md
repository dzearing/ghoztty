# T3154 - relay_suspend.launchAsync leaks the relay account path it joins at every app start (the DebugAllocator leak report at a clean quit names it)

## Summary

Audit-3 (T3101). baseline-3's Debug gpa_leak_report (cycle phase, clean quit) has exactly one leak line: std.fs.path.join in relay_account.accountPath (src/remote/relay_account.zig:122), called from relay_suspend.launchAsync (src/remote/relay_suspend.zig:639) from App.init (src/apprt/win32/App.zig:1223). launchAsync never frees `path` after isSignedIn. Fix: defer alloc.free(path) (check isSignedIn and the async paths do not keep it), and add a unit test or make the perf baseline's leak_lines a checked zero. The Mac app shares relay_suspend.zig? check before closing - if it does, the fix is shared core.
