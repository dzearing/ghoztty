# T3617 - Linux L11b5: a pane drag shows a ghost card of the pane and previews where it will land, and the pane grows a hover grab handle with the mode off

## Summary

Follow-up of T3564. Today GTK draws its default drag icon and no drop preview. Port: the ghost card (win32 pane_drag_ghost.zig sizing, at most 220x150 in the pane's shape, a card with the pane's background, title strip and content snapshot via pane_snapshot.zig, set with gtk_drag_source_set_icon); the live drop preview overlay per hover (win32 drop_highlight.zig rects; a swap fills the centre box with a swap glyph; quiet spots that would leave the pane in place show nothing); and the hover-revealed grab handle at the top of a pane that starts the same drag with rearrange mode off (win32 pane_grab_handle.zig), its cursor an open hand.
