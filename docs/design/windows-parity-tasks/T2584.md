# T2584 - Settings window on Windows: open_config / Ctrl+, opens a searchable page sidebar over the config schema, with All Settings (Mac 9287de0ff)

## Summary

Mac 9287de0ff: Cmd-, / Preferences / the open_config action open a Settings window instead of the file ('Open Config File...' stays one click away). Searchable sidebar of pages; every row shows the key's docs, a changed-from-default dot and a reset; bad values are shown inline and never written; changes apply live through the config reload; a key set by a later config-file include is read-only with an Open link. Advanced -> All Settings lists every schema key automatically (a new Config.zig key appears with no hand-kept list). Windows: App.openConfigFile today ShellExecutes the file; build a native win32 Settings window on the design system (docs/design/win32-design-system.md + docs/claude/win32-ui.md) with the page sidebar, search, the generic row (docs, changed dot, reset, inline rejection), the Advanced page (config file path + Open Config File, includes, backups/Restore, All Settings), wired to the writer (dep). The curated pages are the follow-up task. Mac reference: docs/reference/settings.md.
