# T3636 - Linux L11g4: the GTK Settings window has the theme picker - One theme vs Light and dark, tabs that list only their kind, bundled plus user themes - and the live preview

## Summary

Port the Mac Appearance theme section (docs/reference/settings.md, Themes) to the GTK Settings window: win32 shares theme_catalog.zig and settings_theme.zig (bundled plus user themes from the ghostty themes folder; a user theme wins a name clash; light vs dark by background luminance). Light and dark stores theme = light:A,dark:B with each tab listing only its kind and a hand-edited mismatch warned; switching seeds the other slot from the same family (Latte to Mocha). Plus the live preview the Appearance page shows (win32 settings_preview.zig). Seam ops theme-mode, theme-pick, theme-tab, theme-filter as win32 names them.

## In plain terms

On Linux, Settings > Appearance had no way to pick a color theme and no
preview of what the terminal will look like. Now it has the Mac's theme
picker - one theme, or a light and a dark one that follow the system - with a
small colored sample of every theme, a filter, and a live preview card that
redraws as you change the theme, font, size, opacity, padding or cursor.
