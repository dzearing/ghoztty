# T1634 - The remote Activity Monitor's caveat rows have no hover text

## Summary

RemoteActivityMonitorView puts help text on the rows a reader is most likely to mistrust: the capped-process-table warning, the unverified-CPU detail, the spawned-only filter and the single-row count. Win32's Activity Monitor says none of it, so a truncated table and a caveated number look like plain facts. Same shape as T812 (a pure text deriver plus a track-mode tooltip); file after T1633 if the chooser's hover plumbing is worth sharing.

## In plain terms

The Activity Monitor's control bar shows a process count, a "List truncated"
warning, a "Show all" checkbox and Kill / New Process buttons, but on Windows
hovering any of them said nothing. So "4 of 321" or a truncated table looked
like plain facts. Now each one explains itself on hover, in the same words the
Mac app uses.

## Goals

- [x] The count explains the spawned-only filter ("Showing 4 Ghoztty-spawned of 321 total processes.") and is the plain count once Show all is on
- [x] The "List truncated" badge says the agent capped the table
- [x] Show all, Kill and New Process explain what they do; Kill names the process, or counts several
- [x] One shared tooltip control for the chooser and the panel, instead of a second copy

## What landed

- `help_tooltip.zig` — the chooser's comctl32 tooltip control (T812/T1633),
  made generic over its set of child controls; `chooser_tooltip.zig` is now an
  instance of it, so the chooser and the panel share one implementation.
- `activity_help.zig` — pure, none-lane: Mac's words for each surface
  (`RemoteActivityMonitorView.swift:990-1070`), the badge precedence that
  mirrors `badgeText`, and `textHit`, so only the drawn words of the badge and
  the count answer, not the slack in their slots.
- `activity_hover.zig` — the panel's state machine: painted surfaces (badge,
  count) via `WM_MOUSEMOVE` + a show-delay timer + a track tip; real controls
  (Show all, Kill, New Process) via the `WM_SETCURSOR` a child forwards, with
  subclass tools comctl32 shows itself. Logs the
  `activity help tooltip target=/dropped/shown` oracle.

Not in scope, by design:

- **"% CPU unverified"**: win32 does not mark the CPU column at all yet — that is
  T1549. `activity_help.cpu_unverified_detail` holds Mac's sentence (verbatim)
  ready for it, and this plumbing is where its label's tip goes.
- **Per-cell table tips** — T1548.
- **"Refresh failed"** has no `.help()` on Mac either.
