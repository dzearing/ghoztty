# T3569 - Linux L11g: the Settings window on GTK - open_config opens a visual editor that makes one surgical edit to the config file per change

## Summary

Port docs/reference/settings.md: the open_config action opens a Settings window (not the file); the config file stays the source of truth and every change is ONE surgical edit to only that key, keeping comments and blank lines; the same file-selection rules, repeatable keys, the generated catalog (no hand-kept list) and the same pages. win32 already has the model in Zig (SettingsModel.zig, SettingsCatalog.zig, SettingsSources.zig, settings_line_edit.zig, settings_live.zig) - share the pure parts with GTK instead of a third implementation; the window itself is libadwaita (AdwPreferencesWindow). Upstream GTK has its own config/open path in class/config.zig to replace, not keep beside.
