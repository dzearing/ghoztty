# T2979 - PA-R13: each pane-glide backdrop slice is copied twice, uploaded as a brand-new texture and forces a full cell rebuild

## Summary

PA-R13 (audit-1, T2959). generic.zig:2327 dupes the incoming backdrop, generic.zig:2289 dupes it again for the pending image, image.zig ~906 does not replace a texture in place, and generic.zig:2337 markDirty()s, re-shaping every row although cells do not depend on the backdrop. A glide sends one slice per moved pane per tick (apprt/win32/Surface.zig:6264-6265; quarter resolution, ~315 KB at 1400x900). Fix: take ownership instead of copying, glTexSubImage when the size is unchanged, and request a redraw without markDirty. Risk low. Feature is Windows-only though the file is shared.
