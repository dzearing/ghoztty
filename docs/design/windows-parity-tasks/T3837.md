# T3837 - Linux: Change Window Title edits the tab, so the user can never change or clear a window-wide title pin (a script's, or since T3702 the user's own)

## Summary

GTK maps prompt_window_title to Tab.promptTabTitle (application.zig ~1301 and the prompt_title .window arm ~3270), and the sidebar's name puts the window-wide pin (Window.title_override) over the tab's. So a window that carries a window pin - +new-window --title, +rename, or since T3702 a sidebar group move over a window pin, which a script's +rename now refuses to touch - keeps it forever: the user's prompt writes a tab pin nobody sees. Mac Change Window Title sets and clears the window's own pin (and win32's does). Fix: prompt_window_title edits the window pin when one is up (setTitleOverrideBy(.user), empty clears it, after which +rename works again), else the tab pin as now. Extend test/linux/cli-sidebar-groups.sh: after G17, the window title prompt cleared from the seam lets +rename through.
