# T1878 - The Windows pane sidebar cannot scroll: a long list (many panes, or all windows) runs off the bottom, and Mac's project headers stay pinned while their windows scroll under them

## Summary

Found while building T1829. The Windows pane sidebar lays its rows out from
the top and never scrolls: a window with many panes, or the all-windows outline
across several windows, runs off the bottom of the panel (and of the rail's
card) with no way to reach the rest; the roster is also capped at 64 items.
Mac's list is a ScrollView, and in the all-windows scope its project headers
are STICKY - pinned at the top while their windows scroll under them, on a
backdrop so the rows passing beneath stay legible (b4a3216cc).

Wanted: wheel and scrollbar scrolling in the pinned panel, the open card and
the rail (the design system's overlay scrollbar), the selected row kept in view
as focus moves, sticky project headers in the outline, and hit-testing / drop
geometry / tooltips that follow the scroll offset.

## Validation criteria

- [ ] a list taller than the panel scrolls with the wheel, and the rows past the fold are reachable
- [ ] the rail scrolls the same way
- [ ] the focused pane's row is scrolled into view when focus moves
- [ ] a project header sticks to the top while its windows scroll beneath it
- [ ] clicks, drops and tooltips land on the scrolled rows (acceptance script)
