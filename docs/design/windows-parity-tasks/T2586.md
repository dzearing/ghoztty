# T2586 - Settings Appearance page: live preview, font/cursor/window, and the light and dark theme picker over bundled + user themes (Mac 9287de0ff)

## Summary

Mac ThemeCatalog.swift: bundled themes plus the user themes folder (user wins a name clash); light vs dark by background luminance. 'Light and dark themes' stores theme = light:A,dark:B and each tab lists ONLY its kind so the slots cannot be mixed; a hand-edited mismatch shows a warning; 'One theme' stores one name; switching to light and dark seeds the other slot from the same family (Latte <-> Mocha). The page has a live preview. Windows: port the catalog (pure logic, unit-tested: luminance split, clash rule, family seeding) and build the Appearance page with its preview on the Settings window. Mac reference: docs/reference/settings.md 'Themes'.

**Split (2026-11-04):** this task lands the catalog, the Appearance page and
a working theme picker. Mac's tile grid (preview tiles, light/dark tabs,
filter field) is **T2682**; the live preview at the top of the page is
**T2683**.

## In plain terms

The Settings window now opens on an Appearance page, like Mac's. You can
pick a color theme from every bundled theme plus any you dropped into your
own themes folder - either one theme all the time, or a light one and a dark
one that switch with Windows' light/dark mode. Each of those two choices only
lists themes of the right kind, and switching on light & dark fills in a
matching partner (Catppuccin Latte pairs with a Catppuccin dark theme). Font,
cursor and window settings sit underneath with friendly names.

## Windows translation (recorded decisions)

Mechanism calls, not experience forks, so recorded here rather than filed:

- Window drops `background-blur` and `macos-titlebar-style`: the win32
  renderer never blurs the terminal background and the title bar is
  Ghoztty's own tab strip; neither key does anything here.
- Balance padding is Off / On / Centered instead of Mac's switch:
  `window-padding-balance` is an enum here with a third value, `equal`, that a
  switch cannot reach (the drift test caught the toggle on the first lane run).
- The theme picker is native popup menus until T2682 brings Mac's tiles; a
  light/dark slot's menu lists only its kind, and One theme's menu has Light
  themes / Dark themes submenus - Mac's tabs, as menus.
- Font is the `font-family` value list until a font picker lands (T2681
  covers the remaining native controls).
- "Use: Light & dark" seeds with Mac's rule exactly: the FIRST theme of the
  other kind sharing the family word, so Latte pairs with Frappe (Mac's
  docs example says Mocha, but its code picks the first match, and parity
  follows the code).
