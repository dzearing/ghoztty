# T2473 - Closing a window must give back all its memory: measure private bytes, GPU memory and handle count across repeated open/close of a split window and prove nothing per window is retained

## Summary

Mac 1bc34a8d7 found every closed window kept its panes alive (~100 MB each, unbounded) via a retain cycle. Windows has no ARC, but the same invariant (docs/reference/memory.md 'A closed window frees every pane in it': renderer+IO threads, D3D swap chain, ConPTY/agent session, WebView2 for viewers) is unproven here. Build an acceptance script that opens and closes N windows with splits + a viewer, and asserts process private bytes / GPU dedicated memory / GDI+USER+kernel handle counts return to baseline within a tolerance; fix whatever it finds.
