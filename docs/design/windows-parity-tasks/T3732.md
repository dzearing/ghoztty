# T3732 - Linux: a side panel's resize edge shows the gutter bar too - the viewer contents panel's handle (and the pane sidebar's edge once it resizes) lights the 4px accent bar on hover and drag, as Mac SidePanelResizeHandle

## Summary

Follow-up of T3626, which lit the bar on every stage gutter. docs/reference/stacked-panes.md 'The gutter bar' also covers the edge of a side panel (Mac SidePanelResizeHandle.gutterBar; win32 T2265 gutter_bar.single). On GTK the viewer TOC has a col-resize handle (src/apprt/gtk/ViewerTOC.zig ~141) that shows no bar; reuse gutter_bar_rules (one-edge: drag full, hover half) and the .gutter-bar CSS class. Acceptance: viewer-toc.sh hover/drag the handle and find the accent in a capture-pane --window picture.

## In plain terms

On Linux, the thin edge you drag to resize a markdown viewer's CONTENTS card
gave no visual cue: on the Mac (and Windows) a blue bar lights along it when
you point at it and glows fully while you drag. Now it does the same on
Linux - half-bright on hover, full while held, gone when you let go.

## Goals

- [x] the contents card's resize edge shows the 4px accent bar, half on hover, full while dragged
- [x] the bar stays lit if the pointer runs off the edge mid-drag, and goes out on release or a lost grab
- [x] the bar moves with the edge (it is laid out inside it)
- [x] acceptance covers it from the seam and from the window's own pixels
- [ ] the pane sidebar's edge: not applicable yet - the GTK pane sidebar has no resizable edge; when it gains one it reuses `gutter_bar_rules.single` and `.gutter-bar` (handed to T3825, the sidebar grip task, as a progress note)
