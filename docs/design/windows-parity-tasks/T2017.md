## Summary

Either the menu gained two rows the model lacks or the model is stale. ## In plain terms

The automated check for the Windows app menu said the menu had two extra rows and looked like a different menu. The menu itself was fine. A leftover fake "update available" record from another test made the app show a "Download Update 9.9.9" row at the top, and the check counted that as a broken menu. The check now recognises those optional update rows and still catches any real change to the menu.
