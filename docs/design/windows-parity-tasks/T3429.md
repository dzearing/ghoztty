## In plain terms

After an update installs, Ghoztty is supposed to clean up the temporary copy of itself it used to run the installer. Sometimes that copy was still locked for a moment when Ghoztty started, so it was left behind until the launch after that, and the test that checks the clean-up failed on a busy machine. Now Ghoztty keeps trying for a few seconds in the background and says in its log what it could not delete.
