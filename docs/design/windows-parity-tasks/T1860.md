# T1860 - The desktop-launch audit does not see a GUI auto-launched through cmd /c: ipc-relay.ps1 opened its windows on the user's desktop and the audit stayed green

## Summary

Found in T1837 (2026-10-11): ipc-relay.ps1's Run-Cli ran Start-Process cmd.exe -ArgumentList '/c <exe> +new-window ...', which auto-launches the app on the USER's desktop, and DesktopLaunchAudit.ps1 only recognises Start-Process or call-operator launches of the exe itself. T1837 moved ipc-relay onto Invoke-OnTestDesktop; this task teaches the audit the cmd /c shape, sweeps test/win32 for other hits, and demonstrates the new rule goes red on a planted case.
