# T3781 - Linux: panes in a GTK window that is not the one in use draw output at full rate; send the renderer's pace (T3761)

## Summary

T3761 added a shared renderer pace (renderer/pace.zig, core Surface.paceCallback): outside the window in use a pane presents output-driven frames at most 20 fps, 4 fps when only a sliver of its window shows. The GTK frontend never sends it, so every visible window's busy panes draw at full rate. Send .full for the active window and .background for the others (GTK/Wayland exposes no reliable coverage, so glimpse may not be derivable; say so if not), once the Linux Phase 1 baseline is up.
