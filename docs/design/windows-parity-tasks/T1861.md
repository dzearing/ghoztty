# T1861 - Prove a stashed pane stays stashed through local-agent in-place recovery (replaceTabLeaf now carries stash_seq; no harness drives it)

## Summary

T1838 made Window.replaceTabLeaf copy stash_seq to the replacement pane, so an agent restart no longer un-stashes stashed terminals, and the root-rebuild fallback re-applies the manifest stash. stash-restore.ps1 covers the app-restart path only. Extend test/win32/agent-recovery-tabs.ps1 (or a sibling): stash a pane, kill the local agent, let in-place recovery run, assert the pane is still stashed (+list --json) and hidden, and that the leaf-swap and root-fallback paths both hold.

## In plain terms

If you tuck a terminal pane away (stash it) and the background helper that keeps
your shells alive hiccups, Ghoztty rebuilds every pane on the spot. A fix last
month made stashed panes stay tucked away through that rebuild, but nothing
checked it. Now an automatic test forces the rebuild both ways it can happen and
confirms the stashed pane stays hidden, keeps its shell, and can still be brought
back.

## Goals

- [x] a harness that drives in-place agent recovery with a stashed pane on the LEAF SWAP path
- [x] the same on the ROOT FALLBACK path (tree changed shape during the re-dial)
- [x] a guard-due row so editing the stash/recovery modules obliges a re-run

## Validation criteria

- [x] Leaf swap: after recovery s1 is still `stashed` in `+list --json`, P/Q are not, two HWNDs visible, s1 kept its shell pid, all three surfaces were replaced, no root fallback logged - `test\win32\stash-recovery.ps1` B1-B9, green via `acceptance-parallel.ps1 run -Scripts stash-recovery.ps1` (31 assertions, 2026-11-22)
- [x] Root fallback: Q closed inside the blocked re-dial, app logs `replacing the whole root` then `restored stash in tab=0 stashed=1`, s1 still stashed and hidden, no abort/re-entry - same run, C1-C11
- [x] The stashed pane is live afterwards and `+restore` brings it back - D1-D3
- [x] `-NegativeControl` (B6 inverted) fails: `stash-recovery: 1 FAILURE(S) (30 assertions passed)`
