# T3749 - A pane can open one WSL distro: --shell=wsl:<distro> opens it in the distro's home, an unknown distro is refused naming the installed ones (T3735 foundation)

## Summary

Child of T3735. The shared base the shell pickers read: --shell=wsl:<distro> on +new-window/+split opens wsl.exe -d <distro> --cd ~ (a bare wsl opens the default distro at ~), --command runs inside that distro, and a distro that is not installed is refused with the installed list, read from the HKCU Lxss registry key so nothing ever boots WSL (src/apprt/win32/wsl_distros.zig).

## In plain terms

You can now open a terminal on one particular Linux distro with `ghoztty +new-window --shell=wsl:Ubuntu` (or `+split`). It starts in that distro's home folder instead of a slow Windows-drive folder. If you misspell the distro, Ghoztty tells you which ones you have instead of opening a broken pane. The menus that let you pick a shell come next, built on this.

## Goals

- [x] `--shell=wsl:<distro>` opens that distro at `~`; a bare `--shell=wsl` opens the default distro at `~`
- [x] `--command` with `wsl:<distro>` runs inside that distro, still keeping the pane alive
- [x] an explicit `--working-directory` replaces the `~`; the CLI's own auto-filled cwd does not
- [x] a distro that is not installed is refused, naming the installed ones, without starting WSL
- [x] the installed-distro list exists for the pickers (`src/apprt/win32/wsl_distros.zig`)

## Where

- `src/apprt/ipc/args.zig`: `wslDistroSpec`, `isWslShell`, `shellProgram`, `wslInteractiveArgv`; `wrapShellCommandArgv` handles `wsl:<distro>`
- `src/apprt/win32/IpcHandlers.zig`: `wslInteractive`, `explicitFolder`, `agentShell`, `shellRefusal`
- `src/apprt/ipc/verbs.zig`: optional `shellRefusal` hook in `viewRefusal`
- `src/apprt/win32/Surface.zig`: a local-agent override's argv is kept for a pane with no command (it was dropped, so the pane opened bare `wsl.exe`)
- `src/apprt/win32/wsl_distros.zig`: the HKCU Lxss registry read and catalog rules
