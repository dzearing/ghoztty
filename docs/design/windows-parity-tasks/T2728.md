## Summary

origin/main 8ffccb882; last merged 004a5cc77. Non-merge commits:

- 593c755c2 fix(pane-sidebar): scrolling all windows no longer queries every
  window per row -> no parity owed. The Mac cost was AppKit-specific: every
  sidebar row is its own `HoverTrackingView`, each re-synced on every scroll
  frame and each asked `NSApp.orderedWindows` (a WindowServer round trip)
  whether another window covered it. The Windows sidebar is one HWND whose
  rows are hit-tested in-process; its covered-by-another-window check is a
  single `WindowFromPoint` for the whole column (`PaneSidebar.pointerOn`,
  `src/apprt/win32/PaneSidebar.zig:4882`, used by `resyncHover`), never one
  per row. The behaviour the fix preserves (a row covered by another of the
  app's windows is not hovered) already holds there.
- 8ffccb882 chore(release): v1.53.1 release notes -> no parity owed (Mac
  release notes).

Both touch `macos/`, `docs/reference/` and `release-notes/` only, so the merge
should be conflict-free.
