# T2319 - pane-sidebar-drag asserts the T2304 row slide and held row only in the rail; cover the expanded panel too

## Summary

T2304's motion (rows sliding to open a gap, held row following the pointer, settle) runs in both sidebar modes, but test\win32\pane-sidebar-drag.ps1 drives it only on the mini rail. Add expanded-panel cases (list reorder + tray to list) with the same slide/held/settle log oracles and a mid-drag capture.

## In plain terms

When you drag a pane's row up or down the pane sidebar, the other rows slide
apart to make room and the row you hold follows the pointer. That was only
checked automatically on the narrow icon rail; the wide expanded panel was
never driven. Now the test opens the wide panel and checks both kinds of drag
there too, so a break in the wide panel's motion goes red instead of
shipping.
