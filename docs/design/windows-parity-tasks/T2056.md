# T2056 - skip-visibility audit is red: 14 acceptance scripts print SKIP without counting it in their verdict line, and per-turn scoped sweeps let them in

## Summary

test\win32\skip-visibility.ps1 B1 fails on 2026-10-17 with SkipAuditPending empty: build-cache, caption-bar, daily-publish, fail-transcript, ghoztty-cleanup, install-maintenance, install-prepare, install-restart, ipc-remote, msg-timer-ids, tab-strip, update-apply, viewer-close, viewer-feedback-capture each have a SKIP site that records nothing and/or a verdict line with no skip count (e.g. build-cache D8, added 2026-09-26 by T999). SkipAudit.ps1 is unchanged since 2026-09-16, so these joined while the audit was in force: find why the scoped harness sweep (T1958/T1969) did not go red when each was edited, then convert all 14 (count each skip, pass -Skipped to Write-TestVerdict) until B1 is green. It blocks every turn's validate through the harness-floor guard row.

## In plain terms

Some of our automated tests quietly skip a check (no second monitor, no WSL,
a release build) and still end with a plain "ALL PASS", so the one line
anybody reads hides that part was never tested. Fourteen tests did this. After
this lands they all say how many checks they skipped in that final line, and
the audit that looks for this now fails the next test that forgets.

## Goals

- [x] every one of the 14 scripts counts its skips and names the count in its verdict line
- [x] the two false positives (an assertion on another tool's log, fixture text) are read correctly, not papered over
- [x] the audit stops being excused in the harness floor, so a new violator fails it
- [x] the "why did nobody notice" question answered

## What was done

- **Why it slipped through:** not a scoped-sweep bug. `skip-visibility.ps1` sat
  in `$HARNESS_FLOOR_PENDING` against T1123 since 2026-08-22, so every sweep ran
  it red, reported PENDING, and failed nothing (41 of 41 runs, per T1955). Any
  number of new violators could join under that excuse. The entry is gone.
- **Conversions (12):** a `$script:skipped++` at each uncounted site and the
  count in the verdict line - `-Skipped $script:skipped` on `Write-TestVerdict`
  (build-cache, install-maintenance/-prepare/-restart, msg-timer-ids,
  update-apply, viewer-close, viewer-feedback-capture) or the canonical
  `(n SKIPPED)` suffix on a hand-printed ALL PASS (caption-bar, ipc-remote, the
  install-* self-test branch, ghoztty-cleanup, whose count used to arrive
  through an indirect `$note` the audit could not read). tab-strip only needed
  its `Assert-Wash` site counted; its verdict already reported.
- **Analyzer fix:** `SkipAudit.ps1` treated only `Assert`/`AssertEq`/`Check` as
  assertions, so daily-publish's `AssertMatch '...' 'SKIP.*Docker'` (the text it
  expects in the decider's log) read as two skip sites. Any `Assert*` helper is
  an assertion now; A18 in `skip-visibility.ps1` is the fixture, and it fails
  under the old regex.
- **Marker (1):** fail-transcript writes `SKIP whole run: ...` into a fixture
  transcript; that line carries a `# skip-audit:` marker saying so.
