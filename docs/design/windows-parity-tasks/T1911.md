# T1911 - Ctrl+C at an SVG image pane copies nothing: WIC has no vector codec, so the drawing is never rasterised

## Summary

T1872's copy decodes with WIC, which cannot read SVG; the pane logs 'viewer image copy ... ok=false' and the clipboard is left alone. Mac's NSImage copies a vector as a picture. Translation: ask the page to rasterise the drawing at its intrinsic size (the image.js template already measures it) and hand back PNG bytes over the bridge, or render with Direct2D's SVG document (ID2D1DeviceContext5::CreateSvgDocument). Validation: viewer-image.ps1 K arm on logo.svg reads a 240x120 picture back.
