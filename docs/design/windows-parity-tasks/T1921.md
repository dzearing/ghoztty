# T1921 - The tab-strip guard row covers 2 files, so the elevated default (pane margin, glass strip) turned tab-strip.ps1 red with nobody due to run it; widen it to the files that place the strip and the panes under it

## In plain terms

The tab strip has an automatic check that measures it on screen, but the
"is this check due?" bookkeeping only watched the test script itself, not the
code that positions the strip. So a change to the strip's layout could break
the check and nobody would be told to run it. Now a change to that layout code
makes the check due.

## Goals

- [x] the `tab-strip` guard row covers the modules that place the strip
- [x] a fresh green run of tab-strip.ps1 stamps the widened row

## Summary

The `tab-strip` row in `scripts/guard-due.ps1` covered only
`lib/ChromeGeometry.ps1` and the script, "narrow on purpose" because a run was
thought to cost twelve minutes. T1900 found the harness red under the elevated
default with nobody due to run it. The elevated half was already settled by
T1900 itself (the script pins `--macos-pane-style=flat`; the elevated layout
under the strip is `pane-sidebar-elevated.ps1`'s), so what is left is the
coverage gap: the row now also covers `caption_layout.zig`,
`tab_strip_layout.zig`, `tab_shape.zig` and `icon_button.zig` - the pure
modules that place the caption band, the tabs and buttons, the tab outline and
the strip's icon buttons. Each changed 1-2 times in the last 60 days, so the
row is not always-due. `Window.zig` (the painter, edited constantly) stays out,
as does `pane_elevation.zig` (26 changes in 60 days, and the flat pin means
it does not reach this script). The harness now runs in about 40 seconds, so
the cost argument for narrowness no longer holds.

## Validation criteria

- [x] `guard-due.ps1 check` reports `GUARD DUE tab-strip` naming the four new
      modules as `new` right after the edit (the widened row is live).
- [x] `acceptance-parallel.ps1 run -Scripts tab-strip.ps1 -FailFast`: PASS,
      ALL PASS (94 assertions), 40s; the stamp now records the four modules.
