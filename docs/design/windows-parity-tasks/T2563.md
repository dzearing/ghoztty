## Resolution (2026-11-26)

Already fixed, by 24c267593 (T2594). The `[tripwire] (warn): untripped
point=read` text is shared stderr from `src/tripwire.zig`'s own passing test
(the T1662 trap, `scripts\lib\LaneVerdict.ps1`). The error return trace in the
same 2026-10-31 log blames `PaneDesk.zig:185:52`, the
`expectEqual(section, backing.section)` handle check - with sizes 64x48 then
70x40, the second is under a quarter of the first's section, so `keeps()` maps
a new one and the check passed only when Windows reused the closed handle
value. T2594 changed the sizes to 128x96 / 140x80 / 128x96 and added a
comptime assert that every size stays inside `Backing.keeps`.
