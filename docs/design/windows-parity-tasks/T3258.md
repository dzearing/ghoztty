# T3258 - Convert agent/chooser acceptance suites onto their own agent lineage, batch 1 of 6 (T1495 split)

## Summary

Scripts in this batch (test\win32\<name>.ps1): agent-attach-refused, agent-open-refused, agent-session-cap, agent-shell-integration, agent-autostart, agent-pipe. Each: Set-GhozttyTestAgentLineage after the CleanSlate dot-source with TestDesktop beside it, -ScopeToLineage on every Stop-RepoGhoztty/Reset-GhozttyTestState, Get-GhozttyAgentStateDir in place of hardcoded local-agent-debug, and any private ghoztty-agent.exe enumeration narrowed to this run's lineage. Run each standalone and read what changed.

## In plain terms

Six of the background checks for the session agent used to start by killing
every Ghoztty helper process the repo had running, including ones belonging to
somebody else's live terminal panes. After this change each check runs its own
private helper and only ever cleans up what it started, so two checks can run
side by side and the loop's own panes are never touched.

## Goals

- [x] each of the six scripts mints its own agent lineage before launching anything
- [x] every kill in them is scoped to that lineage
- [x] no private "kill every process named X" left in them (agent-pipe's remote-test-client sweep now matches only its own per-PID pipe)
