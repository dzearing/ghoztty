# T791 - activity-monitor.ps1's -NegativeControl inverts nothing in the multi-row kill section

## Summary

Section M (T293) asserts the N>1 kill wiring on the box, and its load-bearing claim is a SAFETY one: every row visible while it clicks is one of its own throwaway victims. Nothing permanently proves those assertions can fail. The script's -NegativeControl switch inverts D's and L's claims and says so in its header; M is not in it. Teeth were demonstrated only by accident, twice, during T293's development (a stray non-victim row while Show all was still on, and a victim the sampler had not picked up yet) - which is evidence about that day, not a control the suite keeps running. Add an M arm to -NegativeControl: invert the shown==3 claim (assert a table holding something else is fine) and the aggregated-banner claim (assert the single-failure sentence), so a run with the switch MUST fail on both.

## In plain terms

One of our test scripts has a switch that deliberately asks the wrong
questions, so we can watch it go red and know its checks are wired to
anything at all. The part of that script that clicks rows and kills
processes - the part where getting it wrong would kill something that is not
ours - was never covered by that switch. Now it is, so the checks that keep
the script pointed at its own throwaway processes are proven to be capable of
failing rather than assumed to be.

- [x] `-NegativeControl` fails on M2's aggregated-banner claim.
      Same run: `FAIL M2 (inverted): the batch named PID 56396 in a

- [x] The three pre-existing inversions still fire, so the new arms did not

- [x] The inversion is of the CLAIM, not of the guard: `$safeToClick` keeps
      reading the real row count, and the negative run's own
      `M1 every process in the batch really died (still alive: )` and
      `M2 nothing from the batch is left running` both PASSED - it never
      clicked a row it did not own.
- [x] An ordinary run is still green: `ALL PASS (210 assertions)`, which
      re-stamped the `activity-monitor` guard.
