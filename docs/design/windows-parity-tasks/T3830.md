# T3830 - Floor summaries quote zig's 'while executing test X' line, which names the last test run, not the failing one - name the failing test from the 'X failed:' line instead

## Summary

T3696 lost its diagnosis to this: scripts/linux/floor.sh (grep -m12 'error: ' at line ~80) printed both zig lines, and the reader took 'while executing test remote.ssh_transport...spawnChannel' as the failure when the failing test was the keepalive one on the ''<name>' failed:' line. zig 0.15.2 lib/std/Build/Step/Run.zig:1370 builds that prefix from next_index-1 (the last test handed out), and Run.zig:1615-1628 emits the real per-test failed/leaked/logged-errors lines. Make the floor summary lead with a FAILED TEST: <name> line from the latter and label or drop the prefix line. Check scripts\floor-lane.ps1 (Windows) for the same shape and fix it in the same change if it has it. Negative control: a deliberately failing test early in a binary must be the one the summary names.
