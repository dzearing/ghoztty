# T1802 - Reveal in File Explorer button in the viewer nav bar

## Summary

Mac commit d31fbeec6 (merged 9d9d906f6, 2026-10-03): a folder button beside
Home reveals the file the pane is showing in Finder, with it selected. The
button is present only while the pane shows a LOCAL file (markdown, code,
HTML, image); a website or a diff hides it. It follows the pane's current
location, not where the pane was opened. A path that no longer exists opens
the nearest surviving ancestor folder instead of doing nothing, and that
fallback also applies to the banner/link-menu "Reveal in Finder".

Windows already has the action: `ViewerPane.performLinkMenuAction`
`.reveal_in_explorer` runs `explorer.exe /select,"<path>"`
(`src/apprt/win32/ViewerPane.zig` ~4127; the banner twin is in
`BannerOverlay.zig` ~2156). Missing: the nav-bar button (a design-system icon
button with the tooltip "Reveal in File Explorer"), showing and hiding it by
mode, following navigation, and the nearest-ancestor fallback for both
callers.

## In plain terms

A side pane showing a document, code file, web page file or picture now has a
folder button next to Home. Clicking it opens File Explorer with that file
selected, so you can find it on disk without copying the path. If the file was
deleted in the meantime, Explorer opens the closest folder that still exists
instead of doing nothing. Website and diff panes do not get the button.

## Goals

- [x] Folder button beside Home, only for a pane showing a local file
- [x] It follows the pane as it navigates to other files and away from them
- [x] A missing file opens its nearest surviving folder - from the button, the
      viewer link menu and banner links alike
- [x] Folding into the "..." menu on narrow panes keeps the command reachable

## Surprise found and fixed

viewer-narrow-pane.ps1 section E went red: as the pane narrowed past the first
fold into "...", the address field grew (119 -> 124 px), because folding two
commands into one control frees a slot and the field took it. Latent before
this task; the extra button moved the bands onto the script's widths. The
layout now pins the field at its designed minimum while anything is folded,
which makes it monotone; unit test "narrowing the pane never widens the
address field" walks every width.
