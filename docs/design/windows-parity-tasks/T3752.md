# T3752 - Restart Pane with Shell: replace the focused pane's shell in place, keeping its pane id and slot, with the close-confirm rule when something is running (T3735)

## Summary

Child of T3735. A palette entry plus a pane context-menu item; the pane keeps its id, name and position, its process tree is replaced by the chosen shell (agent-backed panes: close the session and open a new one in the same surface). Confirm first when a program other than the shell is running (the close-confirm rule). Acceptance: a test that restarts a pane on another shell and asserts same pane id, new shell process.

## In plain terms

If a pane is running the wrong shell, you can now swap it for another without closing the pane. Right-click the pane and pick **Restart Pane with Shell**, or type "restart" in the command palette, then choose PowerShell 7, Windows PowerShell, Command Prompt, or one of your WSL distros. The pane stays where it is, keeps its name, and anything that addresses it by id still finds it. If a program is still running in it, Ghoztty asks first, the same way closing the pane would.

## Goals

- [x] a pane can be restarted on a different shell in place (same id, name, slot, tint)
- [x] an agent-backed pane's old session is ended, not left running unseen
- [x] a busy pane asks first (the close-confirm rule)
- [x] the pane context menu has a "Restart Pane with Shell" submenu
- [x] the command palette has "Restart Pane with Shell: <shell>" rows
- [x] an acceptance test proves same pane id and a new shell process

## Design (recorded, no decision filed - mechanism only)

- The swap is `Window.replaceTabLeaf` (T399's in-place leaf rebuild), handed the departing pane's id through `Surface.Overrides.pane_id`, so `$GHOZTTY_PANE_ID` in the new shell names the same pane. Unlike recovery, the old surface is marked CLOSE first (`setSessionCloseIntent(true)`), so its agent session and everything under it end. Name, tint and blade/stack state are carried; the new pane is focused if the old one was.
- Folder: a WSL shell starts in the distro's home (`wsl.exe -d <d> --cd ~`, T3749); a Windows shell keeps the old folder only when it is a Windows path (a Linux cwd from a WSL pane means nothing to cmd). Per-shell starting folders are T3754.
- Palette entries are flat rows ("Restart Pane with Shell: <shell>") snapshotted with the "Focus:" jump rows rather than a nested sub-list: typing "restart" or a shell's name finds them. T3751 (sub-lists for New Tab/Window/Split with Shell) may fold these into its sub-list mechanism.
- Menus run inside the surface being replaced, so every user entry defers through `WM_APP_RESTART_PANE` to the top of the loop (the reentrancy `Surface.close` posts WM_CLOSE to avoid).
- The list is `settings_controls.common_shells` found on PATH, with the bare wsl.exe replaced by one entry per installed distro (`wsl_distros.listInstalled`, registry only - never boots WSL). T3750 (lane A) is building the shared catalog with Git Bash; when it lands, `pane_restart.installedChoices` should read it.
- Not offered for a pane on another machine (its shells are that machine's, not this list).
- No CLI verb: the Mac has none and the CLI surface stays identical; the test drives the debug-only `restart-pane` IPC seam (`ipc_restart_pane.zig`).

## Validation criteria

- [x] Same pane id, name and pane count; new shell process and new session; old shell gone - `test/win32/restart-pane.ps1` B.1-B.7 (agent-backed) and D.1-D.4 (plain ConPTY), ALL PASS 27 via `acceptance-parallel run -Scripts restart-pane.ps1`.
- [x] The new shell's `$env:GHOZTTY_PANE_ID` is the pane's id - B.7.
- [x] A busy pane (ping running) answers confirm_needed and is left untouched; a confirmed restart replaces it and the ping ends - C.0-C.5.
- [x] The list offers cmd and Windows PowerShell, never a bare wsl.exe, WSL entries labelled "WSL: <distro>" - A.1-A.5; unit tests in `restart_shell.zig`.
- [x] Negative control: `-NegativeControl` inverts B.1 and the run goes red (1 FAILURE).
- [ ] WSL arm (`-Wsl`): not run by the loop (never start WSL unasked); to be run by hand.
