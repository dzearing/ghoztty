# T1537 - A dragged pane can be dropped on the tab strip to become its own tab

## Summary

Split out of T1532, which bundled four separate drops. This is the SAME-WINDOW
half: in rearrange mode, dragging a pane onto the tab strip previews and then
commits a new tab holding that pane, at the index under the pointer, and
resting the pointer on an existing tab button for 500ms switches to that tab so
the drag can continue into its layout.

The pure resolver already answers both questions — `pane_drop.resolve` returns
`.new_tab{ window, index }` for a point on the strip, and `pane_drop.hoveredTab`
is the dwell result for the timer — and neither has a caller. What is missing is
the Window.zig integration: feeding `tab_bar_rect` / `tab_button_rects` into the
candidate (`stripRegions()` already publishes both in client coordinates), a
preview for the new-tab drop, the commit, and the dwell timer.

No cross-window relocation is involved: every pane in a window's tabs is already
a child of the same HWND, so a new-tab drop is a pure tree edit (remove from the
source tab's tree, seed a new tab's tree with the same `*PaneView`) plus a
refcount that never reaches zero. That is why this half can land before T1538's
`SetParent` machinery.

## In plain terms

Right now rearrange mode lets you move a pane around inside the layout you are
looking at, but there is no way to send it to a tab of its own — you have to
open a new tab and start the work over. After this, dragging a pane up onto the
tab bar makes it its own tab where you dropped it, and hovering over a tab for a
moment opens that tab so you can keep dragging into it.

## Goals

- [ ] The candidate handed to the resolver carries the tab strip's band and its
      tab button rects, so `.new_tab` resolves.
- [ ] A drop on the strip previews where the tab will land.
- [ ] Releasing commits: a new tab at that index holding the dragged pane, with
      the same process and scrollback (pane HWND identity unchanged).
- [ ] A pane that is its window's only pane cannot new-tab itself into nothing.
- [ ] Resting on a tab button for 500ms switches to that tab, the drag
      continuing against the newly shown layout.
- [ ] Acceptance script drives a real drag onto the strip and scores it.
