# T3769 - Linux: the GTK Settings seam takes a screenshot of the Settings window (win32's --op=shot), so the theme tiles' and preview's colors are proven in pixels

## Summary

win32's settings seam has --op=shot (a PNG of the window) and its theme/preview tests sample pixels. The GTK seam has none: hl_screenshot is capture-pane, which reads a terminal pane only, so T3636's settings-theme.sh proves the tiles and preview through their CSS rules, widget classes and Pango markup, never through what was drawn. Add --op=shot --path= to the GTK settings seam (gtk_widget_snapshot -> gsk_renderer_render_texture -> gdk_texture_save_to_png, as the pane-drag ghost already renders a texture), then sample a tile's background, the picked ring and the preview terminal's blended color in settings-theme.sh.
