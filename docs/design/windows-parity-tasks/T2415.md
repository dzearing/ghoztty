# T2415 - Collapsing panes into blades is janky and flickery on Windows: the panes do not glide smoothly into their blade positions as they do on Mac

## Summary

User report 2026-10-28 on win-v1.49.1: collapsing panes into blades (the stack fold/collapse into narrow blades, T2283/T2307/T2312) is 'janky as hell': it does not glide gracefully into place, it is flickery and weird. The user cannot name a single defect, so treat it as several until measured: frames where a pane is black/unpainted or shows stale-size content, panes that jump instead of moving, panes moving on different frames from each other, the blade strip or banner/overlays a frame behind, uneven step sizes (judder) even after T2365's vsync clock, and terminal content reflowing at intermediate widths (resizing the grid every frame) instead of being held/clipped while it slides. First record a WGC capture (T2373 camera, release build) of a collapse and an expand at 2, 3 and 4 panes, and list every bad frame by class, then compare frame by frame with the Mac glide (read the Mac stack fold animation code for duration, curve and what it does with content during motion - CoreAnimation slides a layer snapshot, it does not reflow). Fix on the current stack, compatible with T2360. Acceptance: the capture shows every frame fully painted, all moving panes advancing on every refresh with a smooth eased curve matching Mac's duration, no single-frame jumps, no grid reflow mid-glide; and the user sees a graceful glide in the installed build.
