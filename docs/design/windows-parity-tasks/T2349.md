# T2349 - Windows all-windows sidebar: the folds a window/group drag takes at pick-up, and gives back after the drop, snap instead of animating like Mac's fold (foldAnimation)

## Summary

T2337 folds every group (group drag) or every window (window drag) when an item is picked up, and restores them once it settles. Mac runs both through PaneSidebarOutline.foldAnimation; Windows applies them with a plain refresh, so the list jumps. Use the fold transition (startTransition .fold) or an equivalent without fighting the held item's motion; the held header must stay under the pointer while the list folds beneath it (window_order.clamp grabbed).
