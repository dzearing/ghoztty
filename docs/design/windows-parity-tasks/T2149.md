# T2149 - With solid elevated panes, hero mode on Windows sits inside the window margin on the desk, as Mac pads the whole content, hero included

## Summary

Mac TerminalView pads the content by PaneElevation.margin in the elevated style, hero mode included, over PaneDesk. Windows hero (Window.heroRect) uses the grid rect only on glass (T2104); with macos-pane-glass=false the hero stays edge to edge over surfaceRect with no desk round it. Owed: elevated solid hero laid out in gridRect over the desk (no card - Mac's HeroPaneView passes isElevated only with glass), carousel band unchanged.

## In plain terms

With the default raised-card look but see-through panes turned off, hero
mode (one big pane plus a strip of thumbnails) used to run right to the
window's edges, while every other layout sat inside a thin coloured border.
Now hero mode keeps that same border, the way it does on Mac, so turning hero
mode on no longer makes the content jump outwards.

## Goals

- [x] A solid elevated hero tab sits inside the window margin, with the desk painted round it
- [x] The hero pane stays a plain square pane, not a rounded card (Mac raises a card only on glass)
- [x] The flat style's hero stays edge to edge, and the glass hero (T2104) is unchanged
