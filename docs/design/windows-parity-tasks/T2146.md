# T2146 - acceptance-parallel's RED summary names only a script's .log, but Assert helpers that use WriteErrorLine send the FAIL line to the sibling .err.log: drag-perf read '1 FAILURE(S)' with no failing assertion in sight

## Summary

Found in T2134 (2026-10-21). drag-perf.ps1's Assert writes FAIL via $host.UI.WriteErrorLine, which the runner captures to NN-<script>.err.log. The RED line printed only the .log path, which carries 11 PASS lines and a bare '1 FAILURE(S)' verdict. Fix: print the .err.log path in the RED block when it is non-empty, or quote its FAIL lines inline.
