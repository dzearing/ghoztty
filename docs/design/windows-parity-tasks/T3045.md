# T3045 - PA-V13: closing a viewer waits on the GUI thread for its git or feedback worker to finish, freezing the app for up to tens of seconds (ViewerDiffProbe.zig:222)

## Summary

PA-V13 (audit-1, T2963). ViewerDiffProbe.deinit joins its worker (ViewerDiffProbe.zig:222-226, from ViewerPane.zig:1040-1042); a listing is up to six sequential git commands with a 15 s deadline each (git_run.zig:39). The worktree probe (ViewerPane.zig:1030) and the feedback sender (ViewerFeedbackSend.zig:157-160) join the same way. Cost: a whole-app freeze, rare. Fix: a cancel flag checked between commands, terminate the running child on deinit. Risk: job-ownership handoff. Findings: docs/design/perf-audit/audit-1/V-findings.md.

## In plain terms

Closing a diff or git-status viewer while git was still working made the whole
terminal freeze until git finished - seconds normally, up to tens of seconds on
a slow or stuck repository. Now closing the pane stops the git it started, and
the app stays responsive.

## Goals

- [x] closing a viewer stops its in-flight git instead of waiting for it (diff, worktree and feedback workers)
- [x] the 15 s per-git deadline actually ends a stuck git (it used to kill only Git for Windows' launcher, leaving the real git holding the pipe)
- [x] no git left running behind a closed pane

## Validation criteria

- [x] closing a git-status: viewer while a slow git (stub) runs returns promptly - `ViewerDiffProbe` test "closing a pane mid-listing does not wait out a slow git (T3045)" (stub `git.cmd` launcher + 7 s grandchild; bound 2 s, a deliberately loose bound for a loaded box rather than 200 ms); negative control with the cancel removed: red, 44 s run
- [x] no leaked git process or job after the close - each git runs in its own kill-on-close job, ended by `TerminateJobObject` on cancel/deadline and closed after the wait; `git_run` tests "the deadline ends a git whose real worker is a grandchild" (red before the fix) and "a cancel ends the git in flight, grandchild included" prove the tree, not just the launcher, dies (the pipe only reaches EOF when the grandchild holding it is gone)
- [x] a cancelled worker starts no further git - `git_run` test "a worker that was already cancelled starts no git at all"
