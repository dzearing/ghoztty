# T3045 - PA-V13: closing a viewer waits on the GUI thread for its git or feedback worker to finish, freezing the app for up to tens of seconds (ViewerDiffProbe.zig:222)

## Summary

PA-V13 (audit-1, T2963). ViewerDiffProbe.deinit joins its worker (ViewerDiffProbe.zig:222-226, from ViewerPane.zig:1040-1042); a listing is up to six sequential git commands with a 15 s deadline each (git_run.zig:39). The worktree probe (ViewerPane.zig:1030) and the feedback sender (ViewerFeedbackSend.zig:157-160) join the same way. Cost: a whole-app freeze, rare. Fix: a cancel flag checked between commands, terminate the running child on deinit. Risk: job-ownership handoff. Findings: docs/design/perf-audit/audit-1/V-findings.md.
