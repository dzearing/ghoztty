# T2141 - Stacked panes (macOS): a divider or grip drag that jumps straight back from two folds deep leaves one pane folded until the mouse moves again

## Summary

Found by the win32 port of PaneStackFuzzTests (T2129). BaseTerminalController.squeezeRow only unfolds the first item when current.count == 1 && back, but PaneLayout.chain never returns below one; so a fast drag back to the press point from count 2 lands at count 1 and keeps a fold that the next mouse move at the same spot would undo, and a release there leaves it folded. Fix as win32 did in stack_drag.zig squeezeAt (T2129): compute the chain first, then nil when the chained count is 1 and back. Add the PaneStackWindowTests/RowDrag case: two folds deep, one move back to the press, nothing folded.
