# T2271 - The pane-stack fuzz never applies a row drag's all-on-show shares to its tree, so settingRow's ratios through RowDrag.moved are proven by unit tests and stack-collapse-drag.ps1 only, never under random layouts

## Summary

T2263 ported Mac a81db68f9: a gutter drag that leaves the whole row on show sizes the tree's splits (pane_stack_layout.settingRow via Window.applyRowDrag). pane_stack_fuzz.drag calls RowDrag.moved but ignores Step.all_shown, so its tree ratios never move during a drag. Teach the fuzz to apply settingRow to its own tree on all_shown steps (and the noted origin ratios otherwise), and assert a drag let go where it began leaves every split ratio as it found it.
