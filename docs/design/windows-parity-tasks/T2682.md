# T2682 - Settings Appearance: Mac's theme tile grid - preview tiles, light/dark tabs and the filter field in place of the native theme menus (Mac 9287de0ff ThemeSection)

## Summary

Mac draws Appearance > Theme as a grid of preview tiles (`ThemeTile` in SettingsCustomSections.swift, origin/main 9287de0ff): each tile is the theme's background with three lines of sample text in its ANSI colors (green prompt, blue/magenta/red listing, yellow path) and the name underneath, the selected tile ringed in the accent; light/dark tabs (in light & dark mode the tab labels ARE the two picked names), a "Filter N light themes" field, the current theme first, 11 shown then an "All N light themes..." tile. T2586 shipped the same choices as native popup menus (src/apprt/win32/settings_theme.zig) with the catalog's colors already parsed (`theme_catalog.Theme.palette`). Build the tile grid on the Settings window in place of the slot menus, keeping the `theme-pick`/`theme-mode` IPC ops as the oracle and adding the tab + filter state to `--op=state`. Validation: settings-window.ps1 K extended (tab switch, filter narrows, show-all, the selected tile), plus a screenshot inspected by eye against Mac's.
