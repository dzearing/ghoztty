# T714 - The Windows About box carries no links: no fork release for the version, no Help

## Summary

Mac points Help and About at the fork (6ea66423f) and links the version string at the fork's release notes (38d02efe9). The win32 About box (Surface.showAboutDialog) is a plain ConfirmDialog of provenance text with no clickable anything, so there is no way from the app to the release it is running. Pairs with T624 (no bundled release notes / What's New window). Found by the T684 sweep.

## In plain terms

Open About Ghoztty on Windows and you get a block of text: a version, a
commit, a path. None of it is clickable. There is no way from the app to the
release notes for the build you are running, no way to the project, and the
Help menu item quietly opened a different project's documentation site. On a
Mac the same panel links its version at the release that carries it, links its
commit at the fork's history, and offers Docs and GitHub buttons.

After this the Windows About box carries the same row of links — Release
notes, Commit, Docs, GitHub — as real hyperlinks you can click or Tab to and
press Enter on, and Help goes to this project's docs. A build that has no
release page (a development build) simply does not offer that link rather than
offering one that 404s.

## Goals

- [x] Every URL this app points at lives in one place, so a rename cannot
      leave half of them on the old project
- [x] Help opens this fork's docs, not upstream ghostty.org
- [x] The About box carries clickable Docs and GitHub links
- [x] The About box links the running build's commit at the fork's history
- [x] A release build links its version at the release that carries it, using
      the Windows `win-vX.Y.Z` tag
- [x] A development build offers no release link rather than a dead one
- [x] The links are reachable from the keyboard and read in the app's theme
