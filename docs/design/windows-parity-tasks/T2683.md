# T2683 - Settings Appearance: the live preview at the top of the page - theme colors, font, size, padding, opacity and cursor as you change them (Mac 9287de0ff SettingsPreview)

## Summary

Mac's Appearance page opens with `SettingsPreview` (SettingsCustomSections.swift, origin/main 9287de0ff): a 180pt card showing a few terminal lines (`git status -sb`, a branch line, a modified file with `=> != ->` ligature sample, a prompt with the cursor) drawn in the CURRENT theme's colors and font-family/font-size, honouring background-opacity, window-padding-x/y, the elevated pane style (gradient backdrop, rounded shadowed card) and cursor style/color, with a caption "<font> <size>pt . <theme> . N% opaque". It updates as each setting changes. T2586 landed the page and the theme catalog (`theme_catalog.Theme` has bg/fg/cursor/palette) but no preview. Build it as a custom section (`settings_pages.Custom.preview`) at the top of Appearance. Validation: settings-window.ps1 asserts the preview's inputs via `--op=state` (theme/font/size/opacity it renders with) and a screenshot per state change inspected by eye.

## In plain terms

The Appearance page in Windows Settings used to be a list of controls with
nothing showing what they do. Now, as on the Mac, it opens with a small
picture of a terminal drawn in your current theme, font, size, transparency,
padding, window style and cursor - and it changes the moment you change any of
them, so you can see a theme or font before you live with it.

## Goals

- [x] A preview card at the top of Appearance, drawn with the effective theme colors, font family and size
- [x] It honours background opacity, window padding, the elevated/flat window style and the cursor's style, color, opacity and blink
- [x] Mac's corner caption (`<font> <size>pt · <theme> · N% opaque`)
- [x] Follows each change at once (a slider being dragged previews its unwritten value)
