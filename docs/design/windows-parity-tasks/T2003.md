# T2003 - Mac: a restart that finds every session of a window gone drops the window; rebuild it at its frame with fresh shells, as Windows does since T1978

## Summary

Windows half: T1978 (App.deadWindowDisposition). SessionLayoutRestore.presentRestoredSessionWindows drops an entry whose every leaf is POSITIVELY dead (T06b, line ~279: 'all N leaf sessions POSITIVELY dead; dropping entry'), so when the agent has lost every session the user gets one default window instead of their layout. Match Windows: an entry from the local manifest whose every leaf is positively dead is rebuilt - frame, tab group, splits - with each leaf opening a fresh shell in its recorded cwd instead of attaching; only agent-store-only layouts (crash-orphan adoption) keep the drop. Unknown liveness stays as today (kept and rebuilt). Test: ClaudeHookSpec-style unit test for the rule plus an e2e that kills the agent, deletes sessions.json, relaunches, and reads back window count and frames.
