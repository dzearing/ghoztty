# T3708 - Linux L11b5b: a pane drag previews where it will land - the split half, the swap box, the tab button it dwells on

## Summary

Split from T3617, which shipped the ghost card. Port the live drop preview a pane drag shows while it hovers (win32 drop_highlight.zig rects): the half a release would split into, the centre box with a swap glyph for a swap, nothing over a quiet spot that leaves the pane where it is, and the tab button the drag is dwelling on lit (win32 setDwellLit / GhozttyDwellTab; Window.tabDwell() names it, the AdwTab widget is found by Window.tabBarCandidate's walk). Extend the pane-drag debug seam so a headless harness can read the preview for a hover point.

## In plain terms

On Linux, dragging a pane around in rearrange mode gave no hint of where it would land until you let go. Now, as on the Mac and Windows, the spot under the pointer lights up: the half of a pane it would split into (with a line where the new divider goes), a box with a swap arrow in a pane's middle for a swap, nothing at all where letting go would change nothing, and the tab you are resting on lights up before it opens.

## Goals

- [x] the preview is the rect the pane will take, from the same resolution the release uses (split half, top-level half, divider gap, swap box)
- [x] nothing is previewed over a spot that would leave the pane where it is
- [x] the preview is drawn in the Mac's look (accent fill at 30%, 2px seam, rounded swap box with a glyph) and goes away on leave and on release
- [x] the tab button a drag dwells on is lit while the clock runs, and dark again on leave or when the tab opens
- [x] the pane-drag seam can hover a point and read the preview back

## Validation criteria

- [x] split / top-level / insert / swap previews land on the planned rect, with the right seam and glyph - V4-V10 of `test/linux/pane-drop-preview.sh` (headless Weston, via wsl-run), 19/19 ALL PASS
- [x] the preview widget is laid out exactly on the planned rect - V6
- [x] the preview is actually painted: a window-capture pixel inside it moves toward the accent against the same pixel with no preview (27,47,52 -> 35,73,105) - V13

- [x] dwell lighting on, off on leave, off when the dwell fires and opens the tab - V14-V16
