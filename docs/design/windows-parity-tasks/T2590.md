# T2590 - Honor macos-hero-carousel-ratio: hero mode's carousel starts at the configured share until its divider is dragged in that window (Mac 92ab0c9f1)

## Summary

Mac 92ab0c9f1: macos-hero-carousel-ratio (default 0.25, clamped 0.1-0.6) is the carousel's share each time hero mode turns on, until its divider is dragged in that window - from then on the window keeps the dragged share (HeroModeState.isCarouselResized). Windows: Window.tab_hero_ratio + hero_math.clampRatio already clamp 0.1-0.6 and the divider double-click resets the ratio; seed from the key instead of the fixed default and track 'resized in this window'. Unit test in hero_math. Keys arrive with the T2490 merge. Mac reference: docs/reference/stacked-panes.md hero section; HeroCarouselRatioTests.
