# T2309 - A busy Windows sidebar row's sheen is an upright band alone; Mac's glint now leans 45 degrees over a slow seamless drift, and rail tiles carry a glassy lit-from-above rim (Mac dcdc59712, 157b08c48)

## Summary

Mac dcdc59712 + 157b08c48 (ref: main docs/reference/pane-sidebar.md). Busy row/tile sheen is two layers, both sheared 45 degrees ('/', PaneSidebarSheen.slant) and both moving right to left, in phase across tiles: the GLINT (25% white band every 2s, starting and ending fully off the pill, top corner included) and the DRIFT (a wide soft seamless gradient, one period >= 1.5x the row, 2-8% white on dark / 1.5-5% black on light, sliding one period every 5s with no gap) inside a pane card's 0.5pt hairline rim (white 10% / black 8%). Both fade in/out together over 0.6s as work starts and stops. A RAIL TILE (collapsed sidebar only, never a full row) gets a glassy rim: the pane card's 0.5pt hairline lit from above - white 22%->5% top to bottom on dark (32->10% hovered), black 10->4% on light, white 35->10% on the accent pill; it lives in the rail so it crossfades with the rail on expand/collapse, never snapping. Builds on T2279 (rail = rows minus text, upright sheen) - land after it. Windows sheen today: PaneSidebar.zig glyph shimmer (motion.shimmerAlpha).

## In plain terms

When a pane is working, its icon in the sidebar shimmers. On the Mac that
shimmer now leans diagonally and has a slow, soft glow that keeps drifting
between the bright flashes, inside a thin outline, so a working pane always
looks alive; and the collapsed sidebar's icons each sit in a faint glassy
outline that is brighter along the top. Windows showed only an upright
flash; after this it looks like the Mac.

## Goals

- [x] the glint leans 45 degrees ("/") and still starts and ends fully off the pill, top corner included
- [x] a slow seamless drift (one period every 5s, 2-8% white on dark, 1.5-5% black on light) runs under it, inside a busy hairline rim
- [x] drift, glint and rim fade in and out together (the existing 0.6s busy fade)
- [x] rail tiles (never full rows) wear the glassy rim lit from above, brighter hovered, fading with the rail on expand/collapse

## Design notes

- All geometry is pure in `src/apprt/win32/pane_sidebar_motion.zig` (`travel`/`bandLeft`/`sheenAlpha` take the slant; `Drift`; `tileRim`; `cover`, an antialiased rounded-rect hairline the way `pane_elevation` draws a card rim; `Overlay.pixel` layers drift -> glint -> busy rim, faded together, then the tile rim over all, as Mac's layers stack).
- `PaneSidebar.paintOverlay` replaces `paintSheen`: one premultiplied DIB per pill, AlphaBlended under the glyph. `paintPill` takes `tile` so only the rail gets the rim.
- Mac's white-on-accent rim variant has no counterpart: a Windows selection is a neutral pill (T828), so a selected tile takes the ordinary rim (mechanism call, not filed as a decision).
- The rim fades with the rail on expand/collapse for free: the column transition crossfades whole painted snapshots (`transition.composeColumn`).
- With "Animation effects" off the sheen goes entirely, as before; a tile keeps its rim (not motion).
