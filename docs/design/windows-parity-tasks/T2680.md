# T2680 - Settings pages: the live sections - Sessions & Agent's agent status (read without spawning it), Remote Machines' machine list with Host Settings..., Updates' version with Check for Updates, and Pane style's preview cards

## Summary

Follow-up of T2585, which landed the curated pages with their key rows. Mac's pages also carry custom sections (`SettingsStatusSections.swift`, `SettingsCustomSections.swift` on main) that Windows draws as a one-line description today (`SettingsWindow.paintCustom`):

- **Sessions & Agent > Agent**: whether the session agent is running, its pid, its sessions and its build - read WITHOUT spawning it (Mac `LocalAgentManager.liveAgentPid` first; sessions and build only from a running agent). Windows: the `LocalAgent` pipe probe, never `ensureRunning`.
- **Remote Machines**: the read-only machine list with connection status, and "Host Settings..." per machine opening the same prompt as the machine chooser's row menu (`HostSettingsDialog.zig`; Mac moved its prompt into `MachineHostSettings`).
- **Updates**: the running version and "Check for Updates..." (the Windows updater's check action).
- **Panes & Windows > Pane style**: Mac's two preview cards (Elevated / Flat) instead of the plain choice row.

Extend `ipc_settings.zig`'s state with each section's model, and `test/win32/settings-window.ps1` section J with assertions (an agent started by the test is reported; no agent is spawned by opening the page).

## Validation criteria

- [ ] Sessions & Agent shows the agent's live state, and opening the page never starts an agent (assert no new ghoztty-agent process)
- [ ] Remote Machines lists machines and Host Settings... opens the chooser's prompt
- [ ] Updates shows the version and a working Check for Updates...
- [ ] Pane style is two preview cards that write macos-pane-style
- [ ] settings-window.ps1 green with the new assertions
