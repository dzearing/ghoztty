# T2680 - Settings pages: the live sections - Sessions & Agent's agent status (read without spawning it), Remote Machines' machine list with Host Settings..., Updates' version with Check for Updates, and Pane style's preview cards

## In plain terms

The Settings window's Sessions & Agent, Updates and Panes & Windows pages used
to show a sentence where the Mac shows live information. Now Sessions & Agent
says whether the background agent is running (with a green dot, its process id,
its build and its pipe), Updates shows the version and a working Check for
Updates..., and Pane style is two little pictures - Elevated and Flat - that you
click to choose. Anyone opening Settings on Windows sees it.

## Goals

- [x] Sessions & Agent shows the agent's live state without ever starting one
- [x] Updates shows the version, the build and when it last checked, with Check for Updates...
- [x] Pane style is Mac's two preview cards
- [x] Remote Machines and the agent's session count split out (T2686, T2687)

## Summary

**Scope as landed (2026-11-04):** the agent status, the Updates version and the
Pane style cards. Two parts were split off rather than half-built: the Remote
Machines live list needs a background relay fetch to show presence honestly
(T2686), and the agent's session count needs a request to the agent that the
page must not make on the GUI thread (T2687, so Windows reads "Running - pid N"
where Mac reads "Running - N sessions").

Original filing: follow-up of T2585, which landed the curated pages with their key rows. Mac's pages also carry custom sections (`SettingsStatusSections.swift`, `SettingsCustomSections.swift` on main) that Windows draws as a one-line description today (`SettingsWindow.paintCustom`):

- **Sessions & Agent > Agent**: whether the session agent is running, its pid, its sessions and its build - read WITHOUT spawning it (Mac `LocalAgentManager.liveAgentPid` first; sessions and build only from a running agent). Windows: the `LocalAgent` pipe probe, never `ensureRunning`.
- **Remote Machines**: the read-only machine list with connection status, and "Host Settings..." per machine opening the same prompt as the machine chooser's row menu (`HostSettingsDialog.zig`; Mac moved its prompt into `MachineHostSettings`).
- **Updates**: the running version and "Check for Updates..." (the Windows updater's check action).
- **Panes & Windows > Pane style**: Mac's two preview cards (Elevated / Flat) instead of the plain choice row.

Extend `ipc_settings.zig`'s state with each section's model, and `test/win32/settings-window.ps1` section J with assertions (an agent started by the test is reported; no agent is spawned by opening the page).
