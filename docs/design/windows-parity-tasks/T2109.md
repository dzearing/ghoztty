# T2109 - Stacked panes: strips are painted as titled pane-card chrome named by the banner title (live on +set-banner and OSC 7778), and clicking a strip focuses that pane and brings it on show

## Summary

Third slice of T2101. Strips painted in Leaf.elevation order, labelled by pane_sidebar.paneLabel (T2085 hand-off), relabelled live on +set-banner/OSC 7778; a click on a strip tab notes focus in PaneStackState and relayouts. Acceptance: a posted strip click focuses and shows that pane; a strip reads the banner title. Carries T2085's strip-label criterion.

## In plain terms

Since T2108 a row of panes too narrow for all of them shows as many as fit
and hides the rest - but nothing showed where the hidden ones were, so a
user could not see them or get them back with the mouse. Each hidden pane
now shows as a dark strip at the edge of the row with its name running down
it (the banner's title when it has one, so it updates the moment the banner
changes), and clicking a strip brings that pane back on show with the
keyboard in it. This is what Mac does.

## Goals

- [x] Every tucked pane's strip is painted in Mac's strip colour, in the

- [x] The name follows +set-banner / OSC 7778 and title changes live
- [x] A click on a strip focuses the pane and brings it on show; the pointer
