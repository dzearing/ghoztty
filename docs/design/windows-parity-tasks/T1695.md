# T1695 - Confirm Ghoztty windows survive a REAL graphics driver reset (Win+Ctrl+Shift+B), not only the simulated one

## Summary

T1690 made the renderer survive a lost device and proved the rebuild with a debug-only simulated loss (test\win32\gl-device-lost.ps1). A real reset was not triggered because the user's installed terminal runs pre-fix code and would itself go down. Once a release carrying T1690 is installed, press Win+Ctrl+Shift+B with Ghoztty windows open (split panes, a viewer pane, an inline image) and confirm every window stays up and redraws; look for 'graphics device lost (guilty|innocent|unknown)' and 'graphics device rebuilt' in %LOCALAPPDATA%\ghoztty\ghoztty.log and nothing new in exit-log.txt. If the driver still ends the process despite the robust context, the next step is an app-level relaunch into session restore.
