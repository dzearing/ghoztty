# T1829 - The pane sidebar's all-windows scope on Windows: every window as an outline of its panes, grouped by project, sorted, with search

## Summary

Mac all-windows scope (off by default): each window header is a parent row (chevron + the window's name - user title or its focused pane's name, never the raw title with the activity suffix) with its panes indented beneath, only this window has a selection, hairline between windows (55352e377). Windows sorted by name, stable across focus changes; '<project>: <worktree>' windows grouped under a collapsible sticky project header labeled by worktree (b4a3216cc). A search field ANDs terms over window title, pane title, banner and directory; Return reveals the first hit, Escape clears; the hover card stays open while the field has the caret; the This window / All windows switch slides in a consistent direction (7855941f7); the field reads like a native search box and does not jump on focus (e898f5a00).
