The title literal at `src/apprt/win32/AgentIntegration.zig:407` has not changed since T870 (a71191d62). Also `stderr` shows `agent-integration install copilot: failed` just before, and the postmortem reads 0xFFFFFFFF, which is probably the test's own Stop-Process.

Fix: print the title the test actually read, find which dialog it is, and fix whichever side is wrong. Then run `agent-integrations.ps1` green so its guard stamps again.
