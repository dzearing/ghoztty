# T1512 - The remaining acceptance scripts that print their own verdict move onto the shared scorer, and self-verdict becomes a hard kind

## In plain terms

Most of our test scripts decide for themselves whether to print "ALL PASS", by
checking their own failure counter. A run that crashes halfway leaves that
counter at zero, so the script says everything passed - with a truthful-looking
number of checks in front of it, which is what makes it so hard to spot. After
this lands, every script hands that decision to one shared piece of code that
knows whether the run actually reached its end.

## Summary

T1510 added the `self-verdict` kind to `lib\AssertedNothingAudit.ps1` and put it
under a ratchet in section C4 of `test\win32\asserted-nothing.ps1`, standing at
**198** when this was filed. T1511 takes the 79 of those that also stamp a
guard; this task takes the rest, and then closes the class.

Closing it means three things at once, because the three kinds are the same
statement at different strengths: `self-verdict` (the verdict is hand-rolled),
`uncounted-final` (and it names no count - T775's original 36), and
`unarmed-stamp` (and the run was never armed - T1511's 79). When all three
ceilings reach zero, promote them into `Get-AssertedNothingHardKinds` so a newly
filed harness cannot reintroduce one, and fold T775 in here - it is the same
conversion seen from T271's side.

## Direction

Same three-line conversion as T1511, same worked example
(`test\win32\viewer-feedback-capture.ps1`). Batch it; every converted script
gets run green on the box before its batch is committed.

Two shapes need hands rather than a pattern:

- scripts whose top-level `try` has trailing statements after the `finally`,
  where `Complete-TestBody` cannot simply become the try's last statement -
  `viewer-feedback-capture.ps1` grew a scoring `catch` instead, which is the
  stronger answer and the one to copy;
- scripts that deliberately score themselves and say so in a comment
  (`chooser-restore-all-remote.ps1` is the known one). Those take the
  `# asserted-nothing-audit:` marker, stating the reason, rather than a
  conversion - but the marker is a claim somebody has to agree with, so decide
  it per file and never as a way to make the number move.
