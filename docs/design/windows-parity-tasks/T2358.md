# T2358 - The empty stash tray looks like Mac's

## Summary

User report 2026-10-27 (on win-v1.48.1): "this dotted line around the stash
target is not a dotted line. and it's missing an icon we used."

Mac (`macos/Sources/Features/PaneSidebar/PaneSidebarView.swift:1327-1360`,
`PaneSidebarEmptyStashSlot`):
- icon `tray.and.arrow.down`, 12pt rail / 11pt expanded, medium weight
- outline `strokeBorder(..., StrokeStyle(lineWidth: isHot ? 1.5 : 1,
  dash: [4, 3]))`, ink primary at 0.14 rest / 0.30 dragging / ACCENT when hot,
  plus an accent 0.10 fill when hot; eased 0.15s

Windows (`src/apprt/win32/PaneSidebar.zig:3886-3922`, `paintDropSlot` /
`strokeDashed`):
- icon `glyph_stash` = ChromeMinimize 0xE921 - a flat dash, which at 12 DIP
  reads as no icon at all
- outline `ExtCreatePen(PS_COSMETIC | PS_USERSTYLE, 1, ...)` + GDI `RoundRect`:
  always 1 device pixel (Mac's 1pt is 2px on Retina), aliased, and the
  user-style dash on a cosmetic pen around the rounded corners does not read
  as dashed on screen; never accent, never 1.5

## In plain terms

The box at the bottom of the pane sidebar, where you drag a pane to put it
away, did not look like the Mac's: its outline was long uneven dashes rather
than a fine dotted line, and its icon was a flat bar instead of a tray with an
arrow. Now it has the Mac's tray icon and fine dashed outline. While you are
dragging a pane onto it, it lights up in the accent colour, as on Mac.

## Goals

- [x] a tray-with-down-arrow icon: no Fluent glyph on the box is a tray
      (Segoe Fluent Icons E700-F3FF rendered and looked at), so it is drawn
      as a path - `sidebar_symbol.zig` `.tray`, 1.5-unit stroke (SF medium),
      17 DIP box on the rail, 16 beside the label
- [x] the outline is an antialiased stroke 1 DIP wide (1.5 when hot) with a
      4/3 DIP dash that runs on round the corners (`dashed_well.zig`: arc-length
      dash, strokeBorder half-line inset; `dashed_well_dc.zig` tints the DC's
      own pixels by coverage)
- [x] hot = accent outline + accent 0.10 fill + accent mark and label,
      eased over 0.15 s; dragging 0.30; rest 0.14. The sidebar paints it
      itself, so the window's 43% drop-preview wash no longer covers the
      empty tray (Window.zig drops the `.stash_slot` preview when the tray is
      there to light)
- [x] expanded: mark and label centred together, as Mac's `HStack` is
