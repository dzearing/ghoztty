# T3573 - Linux L11k: window modes on GTK - an opt-in single window of workspaces, switched from the pane sidebar all-windows list

## Summary

Port docs/reference/window-modes.md: the window-mode option (separate default, single opt-in; Mac key macos-window-mode, read once at launch). In single mode there is one GTK window and everything that is a window in separate mode is a workspace in it; a parked workspace has no window and counts as hidden (so it pauses like a background window), the hand-off between workspaces, opening/switching/closing, the CLI verbs addressing workspaces as windows, and persistence. win32 counterparts: workspace_host.zig, ipc_workspaces.zig. Needs the sidebar all-windows list (T3558).
