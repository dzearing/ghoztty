# T1575 - A test block outside src/build/ that no test root reaches is still invisible

## In plain terms

Some checks in this codebase may never run. A test written next to a file that
nothing else pulls in is compiled into no test binary at all, so it reads as
coverage in review and can never go red. We just closed that hole for one
directory; this is the question of whether it is open anywhere else.

## Goals

- [ ] Measure: how many files under `src/` carry `test` blocks that no test
      root reaches
- [ ] If the answer is not zero, wire each one in (or record why it cannot be)
- [ ] Keep the answer at zero with a standing check, the way
      `src/build/BuildTestSweep.zig` does for its directory

## Summary

T736 made the src/build/ aggregator enforced: BuildTestSweep walks that directory and fails the test step on a test block no step imports. The same dead-coverage shape is possible anywhere else a file is not reachable from a test root - the main test binary roots at src/main.zig, the agent lane at src/agent_main.zig, and a module nothing imports carries assertions that read as coverage and cannot fail. Worth measuring before building: sweep src/ for files with top-level test blocks that no root reaches, and see whether the answer is zero (in which case this becomes a standing check like BuildTestSweep) or a list (in which case it is also a batch of work).

## Validation criteria

- [ ] A sweep over `src/` reports every file with a top-level `test` block that
      is unreachable from `src/main.zig`, `src/agent_main.zig` and the other
      test roots - run, with its output recorded here
- [ ] Every file it names is either imported by a root or carries a written
      reason it cannot be
- [ ] The check is standing (a build step or a floor lane), and its teeth are
      demonstrated: an unreachable `test` file turns a lane red by name
