# T2142 - Stacked panes: a pane dragged onto a folded strip swaps with it and stays folded there, as on Mac (strips are not drop targets on Windows yet)

## Summary

Mac 2811a3043 (PaneMoveCoordinator swap + isMinimized): a pane dropped on a
strip trades places with it and stays minimized there, and a pane that was a
strip is a drop target again once on show. On Windows `collectPaneSlots`
skips tucked cards, so a strip is no drop target at all and a release over it
does nothing. Publish strip rects as swap-only candidates (no split quadrants
on a 36-DIP strip) and commit through `PaneStackState.swap`, which exists and
is unused by Window. Raised by T2127's progress note on T2128.
