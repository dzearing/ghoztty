# T1965 - An enrolled Windows machine is reachable through the relay with no manual start, and stops being reachable on sign-out or revocation, as an enrolled Mac now is (main 6dfb31232)

## Summary

Intake 2026-10-15: main 6dfb31232 makes an enrolled Mac host by itself - while relay.env holds a credential the relay confirms belongs to the signed-in account, the app keeps a relay agent running (separate LaunchAgent, --relay --headless --exit-on-revoke), reconciled at launch, sign-in and network-back; sign-out stops it before reporting signed out; a dead/revoked credential stops it; an unreachable relay changes nothing. Windows carries the relay uplink inside the session agent (T546, sharing.json toggle). Verify the user-visible contract matches: after sign-in the box appears on the relay without a manual start and survives an agent kill and an app relaunch; sign-out or revocation takes it off; an unreachable relay leaves it alone. Build what is missing the Windows-native way (HKCU Run / scheduled task, not LaunchAgent).
