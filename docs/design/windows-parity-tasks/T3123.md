# T3123 - perf-baseline.ps1 has no glide/fold/hero phase, so memory an animation keeps after it ends is never measured (T3001 had to use a log meter)

## Summary

T3001 fixed panes holding two full-size snapshot copies after a glide/hero/drag; its validation asked for perf-baseline -Phase cycle private_mb before/after a fold at 1400x900, but perf-baseline has no step that folds a stack, toggles hero or drags a pane. Add a phase that runs each animation N times at 1400x900 and reports private_mb/commit delta after landing, so a regression in what animations retain shows up in the baseline rather than only in a log-line oracle.
