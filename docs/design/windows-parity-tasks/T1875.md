# T1875 - Windows undo only covers closes: Mac's Cmd+Z also undoes opening a split, tab or window and moving or stashing a pane

## Summary

Mac registers an undo for every split-tree change that names an undoAction (BaseTerminalController.replaceSurfaceTree: new split, close), for New Tab / New Window (TerminalController), and for pane moves and stashes (PaneMoveCoordinator 'Stash Pane' and the move groupings). T1825 brought only the close half to Windows (CloseUndo.zig). Extend the same stack: an undo of a new split/tab/window closes it (without parking - nothing to bring back), and a pane move or stash undo puts the pane back. Verify the exact Mac set against BaseTerminalController/TerminalController/PaneMoveCoordinator before building.
