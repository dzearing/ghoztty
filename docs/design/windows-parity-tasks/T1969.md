# T1969 - Let the heavy harness-floor audits scan only the scripts a turn changed (foreground, argv-hazard, unroll-count, neuter, persistence-flag: ~8 min of the ~13-min scoped sweep)

## Summary

T1958 scoped the per-turn harness floor by MEMBER: every turn-tier member still sweeps the whole suite, because no audit takes a file subset and the ratchet audits (unroll-count baseline, neuter registry, asserted-nothing ceiling) count across the suite. The scoped sweep is therefore ~13 min, of which foreground-audit (133 s), argv-hazard (110 s), unroll-count (104 s), neuter (97 s) and persistence-flag (58 s) are ~8 min. Give each a -Only <paths> mode that scans just the changed top-level scripts, keeps whole-suite ratchet arithmetic correct (a changed file's contribution replaces its verified one, or the ratchet half runs whole), and have harness-floor.ps1 -Scoped pass the changed paths through. Prove each mode with a planted violation in a changed script (caught) and one in an unchanged script (left to the daily sweep).

## In plain terms

Every time the loop finishes a piece of work it re-runs a family of checks over
its own test scripts. Five of those checks re-read all ~300 scripts even when
the turn touched two, and that took about eight minutes of every turn. Now they
read only the scripts that actually changed (when that is provably safe), so the
same check takes seconds. The full read still happens once a day and whenever a
shared piece changes.
