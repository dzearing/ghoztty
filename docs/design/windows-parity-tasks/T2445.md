# T2445 - Collapsed all-windows rail shows one tile per window (window glyph on the pane pill, no pane tiles or dividers, click raises, tooltip is the full title, a grid pane dropped on a tile joins that window) - Mac 9e2e2902a

## Summary

Mac 9e2e2902a (docs/reference/pane-sidebar.md 'Collapsed, all windows is one tile per WINDOW', PaneSidebarWindowTile, test theAllWindowsRailIsOneTilePerWindow). The 'this window' rail keeps listing panes; reordering stays the expanded list's alone.

## In plain terms

With the sidebar collapsed to its narrow rail and showing all windows, every pane of every window used to get its own little tile, so ten windows meant a long column of look-alike icons. Now the rail shows one tile per window, with a window icon: click one and that window comes to the front, hover it and its full title shows. The narrow rail for just this window still lists its panes.

## Goals

- [x] All windows' rail is one tile per window, in the list's order, no pane tiles, no dividers, no group headers
- [x] The window glyph on a pane tile's own pill and rim
- [x] Click raises the window; the tile is selected for this window, or the one just clicked
- [x] Tooltip is the window's full title
- [x] Reordering stays the expanded list's: a tile never starts a drag
- [ ] A grid pane dropped on a tile joins that window -> split to T2449
- [ ] Busy rolled up onto the tile -> T2447
