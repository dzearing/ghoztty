# T1768 - 126 acceptance harnesses still have no guard-due row, so editing the code they score obliges nobody to re-run them

## Summary

scripts\guard-due.ps1 uncovered (T996) lists them. Work the list down by giving each harness a row plus an update -Guard tail, or an $UncoveredExempt entry with a real reason. Batch by family (session-*, chooser-*, ipc-*, viewer-*, window-*).

## In plain terms

Many of the project's on-box test scripts are not tied to the code they test,
so someone can change that code and nothing reminds them to re-run the test.
This task ties each test to its code, a family at a time, until
`guard-due.ps1 uncovered` lists none. Nobody using the terminal notices
directly; what changes is that a regression in those areas gets caught at
commit time instead of slipping through.
