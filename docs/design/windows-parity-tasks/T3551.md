# T3551 - GTK SessionLayout.zig's unit tests are compiled by no test binary: zig build test -Dapp-runtime=gtk matches none of them

## Summary

Found in T3420 (2026-11-22): zig build test -Dapp-runtime=gtk -Dtest-filter=firstLeaf (or viewerRestore, or layoutPathFrom) trips the test-filter guard - 'matched no tests', 84/84 other tests passed - so the test blocks in src/apprt/gtk/SessionLayout.zig never compile in any lane, the T3397 ones included. The none lane cannot take the file (it imports GTK classes). Either move the pure parts (layoutPathFrom, firstLeaf, the viewer restore mapping) into a std-only gtk/session_layout_rules.zig the none lane already reaches (the viewer_scheme.zig / viewer_toc.zig pattern), or reference SessionLayout from the GTK test root so -Dapp-runtime=gtk compiles it. Done when a filtered run of each of those three names matches and passes in WSL.
