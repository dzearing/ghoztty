# T1746 - Machine chooser session cards have no Show / Resume buttons like Mac rows do

## Summary

Filed by the T1633 chooser comparison; summary written at the 2026-09-26 triage.

Every live session row in Mac's chooser detail carries a small button on its
trailing edge: **Show** ("Bring this session's window to the front") when the
session is already open in a window here, **Resume** ("Resume this session in a
new window") when it is not, beside the kill button
(`sessionDetailRow`, `macos/Sources/Features/Remote/MachineChooserView.swift`
~L815-900). The win32 chooser resumes a session only by double-click or Return
on the row (`src/apprt/win32/MachineChooser.zig` resume path, T320), so the
action is invisible until you guess it, and nothing tells you a row is already
open versus detached. Fix: the per-row Show/Resume button with Mac's labels and
tooltips, wired to the existing resume/focus path.

## Validation criteria

- [ ] A live, not-open session row shows a Resume button; clicking it resumes exactly as Return does (on-box chooser script).
- [ ] A session already open in a window shows Show instead, and clicking it focuses that window without opening a duplicate.
- [ ] Exited sessions show neither; tooltips match Mac's wording.
