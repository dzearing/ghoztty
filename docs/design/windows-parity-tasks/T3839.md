## In plain terms

A few test scripts can only work by taking over the real screen (they photograph
see-through windows, or click real notifications). The automated loop is never
supposed to run those while someone is using the machine, but its routine test
sweep started one anyway and flashed test windows over the user's desktop. Now
the sweep skips them, says so by name with the reason, and does not count them
as failures; and the bookkeeping that tracks "which tests are owed" no longer
holds the loop hostage over a test only a person can run.
