# T2112 - Focus glow: soften the inner ramp - the glow is brightest right at the card edge; fade it in from the edge while keeping the outer falloff

## Summary

User report (2026-10-21, interactive window, screenshot of a 3-pane debug
window with the middle pane focused): the focus glow "feels not quite soft
enough on windows ... the inner edge of the glow shouldn't be as bright but
the outer edge is fine."

Lead: `src/apprt/win32/pane_elevation.zig` `glowAlpha` (T1834). The glow is
a 4 DIP band (`GLOW_STROKE_DIP`) centred ON the card edge, blurred with
sigma 2 DIP (`GLOW_SIGMA_DIP`) and masked to the outside of the card. The
band's profile peaks at d = 0, so after the mask the light is at full
strength (`glowOpacity`: 24% dark / 50% light) on the very first desk pixel
past the card and only falls from there - a hard bright line hugging the
card, read as a bright inner edge. The card's own rim highlight ("its rim is
a touch brighter", same section) sits right next to it and adds to the line;
check whether that rim is part of what reads as too bright.

Fix direction: keep the outer tail (reach ~8 DIP, `glowReachPx`, still short
of the 10 DIP gap) but ramp the alpha IN over the first few DIP outside the
edge - e.g. move the band's centre outward / multiply by an inner ease so the
peak sits ~2-3 DIP out and the pixel touching the card is noticeably dimmer.
Tune against the user's screenshot at 1.5x and 1.0x scale.

Platform symmetry: the win32 glow is a port of Mac `PaneFocusGlow`
(9755dc1f7 / 51573daf0 / 7966780ae, a blurred `.stroke(lineWidth: 4)` masked
off the card) and has the same edge-peaked profile. Translate the softened
profile to Mac too (e.g. an outward-offset stroke / extra inner mask), or
file the `seat: mac` half when this lands.

## Validation criteria

- [ ] `glowAlpha` at the first pixel outside the edge is clearly below the profile's peak, and the peak sits outward of the edge (unit test in the `none` lane).
- [ ] The outer falloff is unchanged in reach: `glowReachPx` still < the elevated gap at every scale, and alpha at the gap is ~0 (existing T1834 tests stay green).
- [ ] On-box: a 3-pane window's focused pane shows a soft halo with no bright line hugging the card (screenshot compared with the 2026-10-21 report).
- [ ] Mac half landed or filed as a `seat: mac` task.
