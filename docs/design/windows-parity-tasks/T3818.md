# T3818 - Linux: the Remote Activity Monitor on GTK - a connected remote window's pill opens it on the window's own connection

## Summary

Mac's MachinePillCapsule and win32's pill (T610, ActivityMonitor.zig) open the Remote Activity Monitor when a CONNECTED (or reconnecting) remote window's pill is clicked, reusing the connection the window already holds. The GTK app has no Activity Monitor at all, so T3675's pill only logs that click. Port the monitor (per-session CPU/memory of the far machine, rebinding to a fresh connection after a reconnect swap the way win32's ActivityMonitor.rebindBorrowed does) and wire RemotePill.clicked's .activity arm to it.
