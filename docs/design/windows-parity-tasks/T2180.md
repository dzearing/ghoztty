# T2180 - Convert fixed-sleep handshakes to bounded predicate waits in tab-strip.ps1 (first of the ten worst harnesses; the other nine split to T3679-T3687)

## Summary

Split out of T1228 (2026-10-22); see T2179 for the census. Originally the ten
harnesses carrying the most bare `Start-Sleep` sites (activity-monitor,
pane-banner, hero-mode, relay-account, split-divider, palette-order,
activity-monitor-remote, menu-bar, conformance, tab-strip) - about 285 bare
sites by T2179's 2026-11-24 baseline, far more than one context holds.

**Split on 2026-11-24**, as the card itself allowed: this task converts
`tab-strip.ps1` (5 bare sites in the baseline) and lands the shape; each of the
other nine is its own card - activity-monitor T3679, pane-banner T3680,
hero-mode T3681, relay-account T3682, split-divider T3683, palette-order T3684,
activity-monitor-remote T3685, menu-bar T3686, conformance T3687.

For each bare sleep: if it is a real product settle (a debounce, an animation
the assertion is ABOUT), mark it `# settle: <reason>`; otherwise replace it with
a bounded wait on the predicate the next assertion actually reads, whose
timeout fails with what never happened (T1164's M5 is the model). Then lower
the file's baseline in T2179's ratchet.

## In plain terms

Some of the automated tests waited a fixed few seconds and assumed the app had
finished by then. On a busy machine that guess is wrong and the test fails for
no real reason. The tab-strip test now waits for the thing it actually needs -
the window to exist, the window to reach its new size - and says exactly what
never happened if it times out.
