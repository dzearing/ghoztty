# T2180 - Convert fixed-sleep handshakes to bounded predicate waits in the ten worst harnesses (activity-monitor, pane-banner, hero-mode, relay-account, split-divider, palette-order, activity-monitor-remote, menu-bar, conformance, tab-strip)

## Summary

Split out of T1228 (2026-10-22); see T2179 for the census. These ten harnesses
carry 273 of the 2006 bare `Start-Sleep` sites in `test\win32`:
activity-monitor (45), pane-banner (35), hero-mode (34), relay-account (32),
split-divider (29), palette-order (27), activity-monitor-remote (27), menu-bar
(24), conformance (23), tab-strip (22).

For each bare sleep: if it is a real product settle (a debounce, an animation
the assertion is ABOUT), mark it `# settle: <reason>`; otherwise replace it with
a bounded wait on the predicate the next assertion actually reads, whose
timeout fails with what never happened (T1164's M5 is the model). Then lower
each file's baseline in T2179's ratchet. Split further if the batch runs long:
one harness green and re-stamped is a better close than ten half-done.

## Validation criteria

- [ ] every bare sleep in the ten files is either a predicate wait or a `# settle: <reason>`
- [ ] each converted harness is green on the test desktop and its guard row re-stamped
- [ ] T2179's baseline for these files is lowered to what is left
