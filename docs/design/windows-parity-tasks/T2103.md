# T2103 - +list says whether a pane is minimized into a stack, on Mac and Windows alike

## Summary

T2082 asked for +list to report a pane's minimized state with the Mac seat confirming the field; Mac's +list carries no such field today (checked 2026-10-20: nothing in macos/Sources reports isTucked over IPC). A CLI field on one platform only is the divergence the project does not ship, so this lands both halves: a Windows field from pane_stack_layout's Leaf.is_tucked, and a Mac-seat half (file it seat: mac when the Windows half lands) with the same name and shape.

## In plain terms

When a row has more panes than fit, Ghoztty folds the extras into thin strips at the edge. Scripts and agents asking `ghoztty +list` could not tell which panes were folded away. Now the listing tags those panes `[minimized]` (and `"minimized": true` in `--json`), so a script knows the pane is running but not on show.

## Goals

- [x] `+list --json` writes `"minimized": true` on a pane folded into a strip, and nothing when it is not
- [x] the text listing tags the same panes `[minimized]`
- [x] a background tab reports the strips it shows when selected (`Window.stackGridForTab`, which reads without reordering the stacks)
- [x] the Mac half is filed for the Mac seat (T2148)
