# T1559 - The installed ghoztty plugin hands agents a month-old copy of the skills and hooks that now live in this repo

## Summary

Found while landing T718. The plugin cache under .claude/plugins/cache/dzearing-claude-marketplace/ghoztty/0.10.0 was snapshotted 2026-08-21 and nothing refreshes it: its process-feedback skill and both hook scripts predate a month of repo changes, and an agent loading ghoztty:ghoztty rather than the app-installed ghoztty gets the old instructions.

## In plain terms

Coding agents on this box were reading a frozen August copy of Ghoztty's
instructions from an old standalone plugin. That plugin is now gone: the app
removes it at launch and installs its own copy of the instructions, which
matches what this repo ships today.

## Goals

- [x] the stale standalone plugin no longer feeds skills or hooks to agents
- [x] the skills agents do load match the repo's current copy

## Resolution

Already fixed, by two earlier changes rather than by this turn:
a71191d62 (T870, 2026-08-15) made the app ship the skills and hooks itself,
and **964fd7702** (T2806, 2026-11-07) made every launch settle the old
plugin, uninstalling its registration through `claude plugin uninstall`.
The next morning's launch did exactly that: the 0.10.0 cache carries
`.orphaned_at` = 1794150564634 (2026-11-08 07:09 local), Claude Code's own
"no longer installed" mark, so it is swept rather than loaded.
