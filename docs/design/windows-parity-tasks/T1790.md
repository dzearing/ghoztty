# T1790 - a window toggled opaque with toggle_background_opacity shows its background darkened by background-opacity: premultiplied colour on an opaque surface

## Summary

Found by T1787 (pre-existing: the old LWA_ALPHA path showed the same framebuffer). The renderer writes the background premultiplied by background-opacity (load_color in shaders/glsl/common.glsl), so when toggle_background_opacity turns per-pixel alpha OFF, DWM shows rgb*opacity as opaque: #101010 at 0.6 reads as #0a0a0a, and a white background at 0.6 would read as mid grey. Check what Mac shows for a toggled-opaque window (does its renderer keep alpha, or switch the background to the configured colour?) and match it - most likely the renderer needs to know the window is opaque and draw bg alpha 255.
