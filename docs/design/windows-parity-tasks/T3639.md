# T3639 - Linux L11h2: the shortcut guide's Run button shows on hover as well as on the selected row, as on the Mac

## Summary

T3570 landed the GTK keyboard shortcut guide (src/apprt/gtk/ShortcutGuideWindow.zig). Mac (docs/reference/keyboard-shortcuts.md, Search and keyboard) offers Run on hover OR selection; GTK shows the play button only on the selected row. Add a GtkEventControllerMotion per runnable row that shows its button while the pointer is over it (and hides it on leave unless selected). Extend test/linux/shortcut-guide.sh through a pane-mouse-style hover seam or the guide seam.

## In plain terms

In the Linux keyboard shortcut guide, the little "play" button that runs a
shortcut only appeared on the row you had selected. On the Mac it also
appears on whatever row the mouse is over, so you can run something with
one click without selecting it first. Linux now does the same.

## Goals

- [x] The Run button shows on the row under the pointer as well as on the selected row
- [x] Leaving a row hides its button again, unless that row is selected; non-runnable rows never get one
- [x] A test seam drives the hover the way the row's pointer tracking does, and the acceptance script checks it
