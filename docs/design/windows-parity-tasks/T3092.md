# T3092 - The window-presenter path keeps a hidden pane's two slot textures after its targets are released (T2975 freed only the composition path's staging texture)

## Summary

OpenGL.hiddenTargetsReleased (T2474/T2975) frees the render targets and, on the composition path, the shared staging texture; a pane on the window presenter path (present_link, T2615) keeps both slot textures (pres_cap, grown in Target.grow_bucket steps) for as long as it is hidden. Check whether the presenter still reads them while the pane is not composed, free them if not, and extend hidden-window-memory.ps1 to run under that path.
