# T1819 - A pane that was running a full-screen TUI (Claude Code's default renderer on Windows) comes back from a reboot with nothing above the interrupted notice: the restore leaves the alternate screen and drops its last frame

## In plain terms

When the computer restarts while a pane is running a full-screen program -
which is how Claude Code runs in every Windows pane now - the restored pane
shows only the "Session interrupted" message and a fresh prompt. Whatever the
program last showed (the end of the conversation) is gone. On the Mac the same
pane comes back with that last screen above the message.

## Summary

Measured by `test\win32\session-reboot-tui.ps1` (T1817), arm H4: the tuiB pane
(primary-screen line, then `?1049h` + absolute frames, last frame `FINAL-B`)
is persisted correctly - the session-layout manifest's `screen_snapshot` holds
`FINAL-B` before the kill (B8) - but after the reboot nothing of it is above the
notice. Cause, from the code: `Remote.threadEnter`'s restore path paints the
snapshot (which re-enters the alternate screen, since the formatter reproduces
the differing modes), then emits `restore_history.alt_screen_exit` so the fresh
shell is not stranded on a screen with no scrollback - and leaving the alt
screen discards its rows. `restore_history.zig` documents this as a deliberate
pre-D78 trade-off. Also lost: the primary screen UNDER the full-screen app
(`BEFORE-TUI-B`), because `session_snapshot.write` serializes only the ACTIVE
screen.

The Mac (main 7e78aacf4, `session-persistence.py --reboot-tui`) asserts both
`BEFORE-TUI-B` and `FINAL-B` above its lost-session notice.

Fix shape (mechanism is this seat's call): before leaving the alternate screen
on the restore path, carry its visible rows onto the primary screen as plain
history (format the alt screen's content without modes, exit alt, paint the
rows) so the notice fold takes them into scrollback; and consider persisting the
primary screen beneath an active alt screen so the line under the TUI comes
back too. Shared termio code - keep the `none` lane tests in
`restore_history.zig` and add one for the alt-screen carry.
