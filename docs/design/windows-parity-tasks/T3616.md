# T3616 - Linux L11b4: dragging a pane into ANOTHER window splits, swaps or inserts there, the cross-window half of the one drop resolver

## Summary

Follow-up of T3564. Each window's split tree already has a GtkDropTargetAsync for the private pane mime type, and the compositor delivers the drop to the window under the pointer, so a drop in another window reaches that window's SplitTree.dropPaneAt. Teach it a dragged pane that lives in a different tree: SplitTree.moveTo / swapWith / insertAtTopLevel / insertInGap across the two trees, install both, refuse a move that would empty the source window, and keep the moved pane's agent session alive (Mac finishRelocation).
