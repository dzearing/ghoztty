# T3053 - PA-V21: dragging or hovering the viewer contents card and find card re-measures and repaints everything on each mouse move (ViewerTOCPanel.zig:2283)

## Summary

PA-V21 (audit-1, T2963). Dragging the card width re-measures every row (ViewerTOCPanel.zig:2283-2287, :939-941, :812-878) and re-renders the card DIB (:1509-1549) per mouse move; row hover repaints the whole card unbuffered (:2289-2293), with a linear hitRow (:1500-1503); the find card measures its count text per mouse move (ViewerFindBar.zig:770-779, :537-551). Cost (estimated): ~6,000 text measures per move for a 2,000-file diff. Fix: cache label widths, render the DIB on settle or in steps, invalidate only the changed rows, cache the count width. Risk: low. Findings: docs/design/perf-audit/audit-1/V-findings.md.

## Validation criteria

- [ ] a width drag over a 2,000-file diff stays under one frame per move (drag timing log)
