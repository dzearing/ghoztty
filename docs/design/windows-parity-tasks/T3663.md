# T3663 - Stacked panes: a screen reader is told when strips appear or go (UIA StructureChanged on the window's strip provider)

## Summary

T2122 exposes tucked strips as UIA buttons, re-resolved on every call, but raises no UiaRaiseStructureChangedEvent when a relayout tucks or untucks a pane, so a reader already parked on the window keeps a stale child list until it re-walks. Raise ChildrenInvalidated on the root (strip_uia_provider.Root) when the set of strips changes (compare uiaStrips view_addr sets after layoutSplits), only while a client is listening (UiaClientsAreListening).
