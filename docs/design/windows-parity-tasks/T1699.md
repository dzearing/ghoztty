# T1699 - Viewer: Ctrl-click on a cross-site target=_blank link opens a side pane where Mac's Cmd opens a window

## Summary

Follow-up to T926. On Mac, Cmd-click on a `target="_blank"` link out of a live page takes the popup path, so it opens a Ghoztty window. On Windows, Chromium reports a Ctrl-click on ANY link as a new-window request, and T926 cannot tell a `_blank` link from a plain one, so both open a side pane. Investigate whether the page can say which it was: `links.js` could report the anchor's `target` on a capture-phase click, or `NewWindowRequestedEventArgs2.Name` might carry it. Low user impact, because Ctrl-Shift already gives a window.
