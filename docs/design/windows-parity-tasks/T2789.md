# T2789 - go-loop-health degrades the non-owner lane for a missing digest it is forbidden to write (T2115 morning owner)

## Summary

go-loop-health.ps1 reports lane b DEGRADED ("today's digest is missing - go.md step 0.5, write ...") every morning between 05:00 and lane a's first post-05:00 turn. Lane b may not write that digest: morning-owner.ps1 refuses it (exit 3, "lane a ... owns today's digest", T2115), and go-loop-exec's claim honours that refusal. Seen 2026-11-05 06:12 and 2026-11-07 06:12.

So the health line tells the controller to fix something only the other lane can do, and its remedy text tells the lane to break T2115. A degrade the reader must learn to ignore stops being a signal.

Fix: in go-loop-health.ps1, when Get-DigestState says missing, ask morning-owner.ps1 the same way go-loop-exec does. If this lane is refused (exit 3), report `digest=owed-by-a` (or similar) and do NOT degrade. The owning lane keeps today's behavior. Add a case to the health harness for a non-owner lane past 05:00 with no digest.
