## Summary

T2543 films the caption band on the compositor at rest and with minimize pressed, on a one-tab window (no tab strip). Extend scripts\comp-desk-onscreen.ps1 so both arms carry two tabs, and add a hover frame scored like the press frame; the CAPTION_FREEZE negative control must go red on both.
