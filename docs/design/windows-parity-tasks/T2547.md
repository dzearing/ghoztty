# T2547 - Film the tab strip and a caption hover on the compositor caption visual: comp-desk-onscreen opens a second tab and holds a hover so the T2543 band match covers the strip and the hover state

## Summary

T2543 films the caption band on the compositor at rest and with minimize pressed, on a one-tab window (no tab strip). Two states share the path but are not filmed: (1) the tab strip - the oracle window needs a second tab, and there is no CLI verb for a tab, so it takes a keybind delivered off the input desktop or a test seam; (2) a hover - a posted WM_NCMOUSEMOVE is cleared by TrackMouseEvent at once because the real cursor is not over the ghost, so it needs a hold (a debug seam that pins caption_hover, or a posted move re-sent right before the grab, scored on several grabs). Extend scripts\comp-desk-onscreen.ps1 so both arms carry two tabs, and add a hover frame scored like the press frame; the CAPTION_FREEZE negative control must go red on both.

## In plain terms

An experimental drawing path (off by default) moves the window's title bar
onto the graphics compositor. Its screen test only photographed a window
with one tab and nothing under the pointer, so the tab strip and the hover
highlight on the title-bar buttons were never checked. Now the test opens a
second tab and holds a hover, and both are compared pixel for pixel against
the ordinary drawing path.

## Goals

- [x] every arm's window carries two tabs, so the filmed band holds a tab strip
- [x] a hovered frame (maximize lit) is filmed and scored like the pressed one
- [x] the CAPTION_FREEZE negative control goes red on the hover and the press

## Design

- Tab: `--keybind=f9=new_tab`/`f8=previous_tab`, keys POSTED straight at a
  pane hwnd (no `SetActiveWindow`/foreground grab - the run is on the input
  desktop, where the interactive `Send-TestKeys` path would steal focus).
- Hover: new debug-only seam `GHOZTTY_COMP_CHROME_HOLD_HOVER`
  (`Window.holdCaptionHover`, via `chrome_comp.debugKnob`): the caption hover
  survives `WM_NCMOUSELEAVE` and arms NO tooltip (a tip is its own window and
  would pop over the user's desktop). Set in every arm, reference included.
- Band height: `chrome_comp.capUpload` logs `chrome caption surface: WxH` on
  each resize; the script scores the LAST one (the strip grows it 40 -> 50).
