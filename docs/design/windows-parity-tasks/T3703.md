# T3703 - The website's Windows download button hands out Ghoztty-Setup.exe instead of the bare MSI

## Summary

T2198 publishes Ghoztty-Setup-<version>-x64.exe beside the MSI on every win-v release, but dist/website/update-windows-links.py still rewrites the site's win-msi-link to Ghoztty-<v>-x64.msi, so a new user downloading from the site never meets the front door that explains a refused install (T2197). Point the primary Windows download at the setup asset, keep the MSI reachable as a secondary 'MSI for managed deployment' link, and extend test/win32/website-windows-download.ps1 to assert both hrefs after a rewrite.

## In plain terms

Every Windows release now carries the friendlier Ghoztty-Setup.exe, but the
website's release step only knew how to point at the MSI. After this, the
release step also moves the site's Setup download to each new release, as
soon as the page has a Setup button. The page itself changes in T2199, once a
release that actually contains the Setup exe exists, so nobody is ever handed
a link that goes nowhere.

## Goals

- [x] The release step's link rewriter knows the setup asset's name and retargets the page's setup link
- [x] It still releases cleanly against today's page, which has no setup link yet, and says so out loud
- [x] A broken page (setup link doubled) still fails the release, like every other link
- [x] The harness proves all three shapes and that the setup name agrees across its three writers

## Design notes (2026-11-24)

- **Split from T2199 on purpose.** No win-v release has the setup asset yet
  (win-v1.56.24 is MSI/ZIP/symbols; the first one with it is the first
  publish after b8fdcd776). Two things therefore cannot happen in one change:
  putting a setup link on the deployed page now would hand out a 404 until
  the next release, and making the anchor REQUIRED now would fail that very
  release's website step against a live page that has never carried it.
- So `win-setup-link` is in `OPTIONAL_IDS` in `update-windows-links.py`:
  absent prints a `note:` naming T2199; present is held to exactly-one like
  every other anchor. T2199 adds the anchor to the page and drops it from
  `OPTIONAL_IDS` in the same change.
