# T1722 - next ranks the 350 non-M1 P2 todos level with the 43 M1 P2s, so the convergence number barely moves while the queue drains

## Summary

Within a priority band next sorts by order then id, and milestone plays no part. On 2026-09-23 the loop closed 35 tasks and 8 were M1; the P2 band holds 43 M1 todos behind 350 non-M1 ones, mostly harness and tooling cards with lower ids. Rank M1 ahead of non-M1 inside a band (after priority, before order), with a K-section style acceptance leg in parity-tasks-seat.ps1 and the go.md step 1 ordering text updated.

## In plain terms

The loop picks its next job from a queue, and that queue ignored which jobs
count toward the milestone the progress number measures. With the urgent work
done, it was working through hundreds of older behind-the-scenes cards first,
so the number on the dashboard barely moved on its busiest day. Now, among jobs
of equal importance, the ones that count toward the milestone go first.
