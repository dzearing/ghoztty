# T3010 - PA-M10: renderer row lists preallocate 3x the column count per row, 0.7-5.5 MB per pane where 1x is typical (renderer/cell.zig:118)

## Summary

PA-M10 (audit-1, T2961). src/renderer/cell.zig:118-122 inits fg_rows with size.rows + 2 lists of capacity size.columns * 3 of 32-byte CellText. Estimated 0.73 MB at 170x45, ~5.5 MB at 480x120 per pane. Fix: start at 1x columns and let lists grow. Risk low (a few allocations on the first frame with decorations). Shared core, pairs with PA-R12 (reallocation on resize); the fix serves macOS too. Baseline: docs/design/perf-audit/baseline-1.json (T2958); findings: docs/design/perf-audit/audit-1/M-findings.md.
