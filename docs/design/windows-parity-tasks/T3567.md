# T3567 - Linux L11e: stacked panes on GTK - a minimum pane size, rows that cannot fit stack into strips, gutters and the gutter bar, glides, focus brings a pane forward

## Summary

Port docs/reference/stacked-panes.md: a pane is never narrower/shorter than the configured minimum (macos-pane-min-width/-height, 225x125 default); a row that cannot fit becomes a run on show plus minimized strips with the pane name down them; gutters own the resizers (drag, gutter bar), tree changes keep collapses, glides animate a change in what is on show, a side pane opened without focus still comes on show, focus brings a pane forward, collapses persist with the window. The layout is ONE pure function on Mac (PaneLayout.compute) and win32 already has it in Zig (pane_layout.zig, pane_stack_layout.zig, pane_stack_state.zig, pane_stack_fuzz.zig) - move those to shared code so GTK and win32 compute the same layout, then build the GTK widget side. Depends on pane style (cards and strips share the look).

**As landed (2026-11-23):** the win32 engine is pure and GTK already imported win32's pure modules in place (`pane_layout.zig`, `pane_drop.zig`), so nothing moved: GTK imports `pane_stack_grid`/`pane_stack_state`/`stack_drag` the same way. This task is the core - one stage the shared layout places, the minimum, run + strips, focus brings a pane forward, every gutter a row drag, `+list minimized`. Split out: glides + elevation T3625, gutter bar + double-click T3626, persistence + undo T3627, featured side pane T3628, live relabel + strip drag + columns T3629; flat gutter line T3624.

## In plain terms

On Linux, splitting a window again and again used to squeeze every pane thinner until the terminals were unusable. Now a pane never gets narrower than a set minimum: when a row runs out of room, the extra panes fold into slim labelled strips at the edge, and clicking a strip (or switching to that pane) brings it back while another folds away. Dragging the space between panes resizes them, and dragging far enough folds a pane away; dragging back undoes it.
