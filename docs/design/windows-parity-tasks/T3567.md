# T3567 - Linux L11e: stacked panes on GTK - a minimum pane size, rows that cannot fit stack into strips, gutters and the gutter bar, glides, focus brings a pane forward

## Summary

Port docs/reference/stacked-panes.md: a pane is never narrower/shorter than the configured minimum (macos-pane-min-width/-height, 225x125 default); a row that cannot fit becomes a run on show plus minimized strips with the pane name down them; gutters own the resizers (drag, gutter bar), tree changes keep collapses, glides animate a change in what is on show, a side pane opened without focus still comes on show, focus brings a pane forward, collapses persist with the window. The layout is ONE pure function on Mac (PaneLayout.compute) and win32 already has it in Zig (pane_layout.zig, pane_stack_layout.zig, pane_stack_state.zig, pane_stack_fuzz.zig) - move those to shared code so GTK and win32 compute the same layout, then build the GTK widget side. Depends on pane style (cards and strips share the look).
