# T3546 - Linux L9j-4: screenshots into the GTK feedback composer from the app's own render

## Summary

The composer's + button and Ctrl+Shift+S take a pane screenshot, and pasting an image inserts an [Image #N] chip with the stable-number carousel. Wayland and headless Weston have no global capture, so the picture comes from our own render: webkit_web_view_get_snapshot for the page, gtk_widget_snapshot / gsk_renderer_render_texture -> GdkTexture -> PNG for the whole pane (linux-port.md translation table). Build the capture once and share it with T3359 (the headless harness screenshot). Images land in the report's images/ folder with pixel size and byte count. Depends on L9j-2.
