# T2259 - A wsl pane's prompt has not been proven to reflow live on resize: prompt-reflow.ps1 covers cmd and Windows PowerShell only, since starting WSL is the user's call

## Summary

T2251 proved Mac a81db68f9's live prompt reflow on Windows for cmd and Windows
PowerShell, local and agent-backed (`test\win32\prompt-reflow.ps1`), and found
that conhost's post-resize paint ends cmd's `133;I` input region - fixed with
the ConPTY prompt-row pacing rule (`Termio.conptyPromptRow`). A wsl pane was
not run: WSL's bash integration marks its prompt with `133;B` (open input,
like PowerShell), so it should take Mac's path, but its prompt arrives through
wsl.exe inside the ConPTY and nobody has watched it. Starting WSL is the user's
call on this box (it once took 28 GB), so this waits for a box where WSL is
already up, or the user's go-ahead.

Add a section E to `prompt-reflow.ps1` with `--command=wsl.exe`, SKIPPED (not
failed) when no distro is running.

## In plain terms

The test that proves a prompt redraws smoothly while you resize a window covered cmd and PowerShell, but never WSL. It now covers WSL too, whenever WSL is already running. The first runs show that a WSL prompt does NOT redraw live (it waits, the old way), and that a resize can join a command and its output into one line. Both are filed as their own fixes.

## Validation criteria

- [x] With WSL already running, section E MEASURES a wsl bash prompt (`prompt-reflow.ps1 -Wsl`, Ubuntu, 3 runs): divider drags held 80/80 and applied twice, never a cap release - as A-D. The window-resize storm is NOT live: 57/57 decided debounce, filed as T3742; the resize also joins the echo row with its output, filed as T3743. Section E is their oracle and stays red until they land.
- [x] With WSL not running, section E reports SKIP with the reason and never starts WSL: `Get-RunningWslDistro` makes no wsl.exe call without a vmmemWSL/vmmem process, otherwise only `-l --running`, and the pane runs `wsl.exe -d <running distro>` so a stopped default distro is never booted (by construction; not exercised live this turn, because WSL was up). The default run (A-D) is unchanged: ALL PASS, 80 assertions, via acceptance-parallel.
