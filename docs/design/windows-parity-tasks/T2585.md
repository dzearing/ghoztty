# T2585 - Settings window curated pages: Panes and Windows, Terminal (no env, Mac 3a183ffd1), Keyboard, Sessions and Agent, Remote Machines, Updates (Mac 9287de0ff)

## Summary

Mac SettingsPages.swift is presentation only (which keys on which page, labels, control types) and SettingsPagesTests fails when a curated key or enum option drifts from the schema or a key sits on two pages; a popup also lists any schema enum value with no curated label. Pages: Panes and Windows (pane style, glass, dimming, macos-window-gradient, macos-pane-sidebar, macos-pane-min-width/-height, macos-hero-carousel-ratio, new windows); Terminal (shell, starting folder, scrollback, shell integration, copy and paste, mouse, notifications - Mac 3a183ffd1 DROPPED Environment variables from this page, env stays only under All Settings); Keyboard (non-keybind settings + the shortcut guide hook); Sessions and Agent (reads the agent WITHOUT spawning it); Remote Machines (read-only status + Host Settings..., reusing HostSettingsDialog.zig the way Mac moved its prompt into MachineHostSettings); Updates. Windows: the same curated table in Zig with the same drift unit test against schema_json, rendered on the T2584 window. Mac reference: docs/reference/settings.md 'Pages' and 'Catalog'.

## In plain terms

The Settings window (Ctrl+,) used to have a single page listing every raw
setting by its config name. It now opens on friendly pages like Mac's - Panes
& Windows, Terminal, Keyboard, Sessions & Agent, Remote Machines, Updates -
where settings have plain names and on/off switches or drop-down choices, and
a setting that only applies in some style says so. Search finds the friendly
rows first, and the full list under Advanced links each setting back to its
page.

## Windows translation (recorded decisions)

Mechanism and platform calls, not experience forks, so recorded here rather
than filed:

- Keyboard drops Mac's `macos-option-as-alt`, `macos-shortcuts`,
  `macos-auto-secure-input` (the win32 runtime reads none of them; they drive
  macOS-only facilities). The page keeps the shortcut guide card.
- Updates drops `auto-update-channel`: the Windows updater follows the
  published releases and has no tip channel.
- Pane style is a choice row (Mac's preview cards are T2680).
- `copy-on-select = true` reads "On" (Windows has no selection clipboard).
- "Shell for scripted windows" names the Windows shell flavors in its hint.
- Mac's segmented controls are drawn as the same popup as pickers.
- Appearance is not in this task (its theme/font/preview work is separate).
