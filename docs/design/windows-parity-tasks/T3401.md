# T3401 - Mac: confirm a multi-argument -e runs intact in an agent-backed pane after the T3396 quoting fix

## Summary

T3396 changed shared core (src/Surface.zig, Command.posixShellString in src/config/command.zig): a LOCAL POSIX agent now receives an -e argv quoted word by word instead of joined with spaces. Validated on Linux only (test/linux/session-agent.sh S11b). The Mac rides the same path, so check on a Mac debug build that ghoztty -e /bin/sh -c with a two-command script runs both commands inside the inner sh, and that +sessions shows the quoted command.

## Validation criteria

- [ ] on a Mac debug build, `ghoztty -e /bin/sh -c 'echo $$ > /tmp/f; exec /bin/sh -i'` writes `/tmp/f` and leaves a live pane (session persistence on)
- [ ] `ghoztty +sessions` shows that session's command quoted (`/bin/sh -c '...'`)
