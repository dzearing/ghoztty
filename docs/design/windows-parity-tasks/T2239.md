# T2239 - One overlay popup move costs about 770us of UI-thread time during a splitter drag; find out what the move is doing

## Summary

T1350 clocked the chrome moves that are left after T1345: at 8 panes, 4 SetWindowPos calls on layered popups (2 scrollbars, 2 dim washes) cost 3092us of a 41582us mouse move - about 770us each, which is far more than a plain window move should cost. Collapsing popups could save at most 2 of those 4; making each move cheap would save most of all 4. Measured while a GPU-heavy game was running on the box, so re-measure on an idle box first, then find what the move synchronously triggers (WM_WINDOWPOSCHANGED handlers, a DWM sync, a repaint) with drag-perf.ps1's mean_chrome_move_us as the oracle.
