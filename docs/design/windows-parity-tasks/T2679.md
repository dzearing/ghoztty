# T2679 - Sweep the Apps & Features rows earlier updates orphaned: every box that took in-app updates from 1.43.4 to 1.52.10 still lists one dead 'Ghoztty' per release, and T2327's fix only stops new ones

## Summary

T2327 moved RemoveExistingProducts early so an upgrade no longer leaves the replaced release's HKCU Uninstall\{ProductCode} key behind. It does nothing for the rows already there: this box lists 44 (1.43.4..1.52.8), each a listed key whose product Windows Installer no longer knows (no LocalPackage, no hidden registration), and clicking Uninstall on one runs msiexec /x against nothing. Remove them on the user's behalf: an HKCU Uninstall key whose DisplayName is the product name, whose UninstallString is 'MsiExec.exe /X{code}', and whose {code} is not a registered product (MsiQueryProductState unknown) is an orphan of our own writing. Candidates: the MSI (a deferred CA after RemoveExistingProducts), the app at launch beside PathInstaller's self-heal, or ghoztty-cleanup.ps1. Never touch a key whose product is registered. Acceptance: arp-version.ps1 C1 goes green on this box; a throwaway-identity orphan (arp-orphan.ps1 B produces one) is swept by the shipped mechanism.
