# T1924 - The pane sidebar's all-windows list opens with every other window folded and the caption counts windows, as on Mac (main 321e61d7c)

## Summary

Mac 321e61d7c: in the all-windows scope every window starts folded except THIS window (decided only when the list opens; later focus moves never unfold). State records flips from the default (toggledWindows), so a window opened while the list shows arrives folded; flips are forgotten when the scope is left, like the search; a search still unfolds everything. The ALL WINDOWS caption carries a window count styled like a project header's count. Windows has folding (pane_sidebar_outline.zig folded/project_folded) but defaults every window open and has no caption count.
