# T3540 - split-plane.py pub-ifies only self.f() calls, so a moved test calling an owner-private method (roster.clear()) compiles only until a filter reaches it

## Summary

scripts/split-plane.py makes an owner fn pub when moved code calls it as self.f(...), but not when it is called on any other receiver (a test's roster.clear()). Zig analyzes a test body only when the test is selected, so the gap compiles under a -Dtest-filter that skips it and fails only when the lane (or a filter) reaches that test - T1783 hit it at the teeth check. Fix: treat <ident>.f( where f is an owner non-pub fn as a method use too (or pub-ify every owner fn named after a dot in moved code), and add a case to the script's check.
