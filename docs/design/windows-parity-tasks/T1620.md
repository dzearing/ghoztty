# T1620 - findClaude's PATH and well-known-location search has no test at all

## Summary

Seam audit (T796) finding. Both scripts that exercise the Claude migration set GHOZTTY_CLAUDE_EXE at a stub, so AgentIntegration.findClaude only ever returns from its override branch; the PATH walk and the well-known-install-location fallback underneath it - the code every real user hits - have no coverage of any kind, and AgentIntegration.zig carries no unit tests. Wanted: 
one-lane unit tests over findClaude with a synthesized PATH (hit on .exe/.cmd/.bat, miss, empty override meaning 'no claude'), which needs the search split from the process-global getenv the way other resolvers here are.

## In plain terms

When Ghoztty needs to talk to Claude Code (to tidy up the old Claude plugin),
it first has to find the `claude` program on the machine. Nothing tested that
search: the tests always pointed it straight at a fake. Now the search runs
under unit tests covering every place it looks and the order it looks in.

## Goals

- [x] the search is split from the live environment and filesystem (`src/apprt/win32/claude_locate.zig`)
- [x] unit tests cover PATH hits on .exe/.cmd/.bat, misses, the override, and the well-known install locations
- [x] `findClaude` uses the split search, behavior unchanged for real users

## Validation criteria

- [x] PATH hit on `.exe`, `.cmd`, `.bat`; extension order inside a dir; PATH order beats extension order - `claude_locate` tests, none lane (`floor-lane.ps1 -Lane none -Filter claude_locate` PASS)
- [x] miss everywhere is null and probes every candidate in the documented order - same tests
- [x] empty override = no claude (no probe at all); a set override that is missing never falls back to PATH - same tests
- [x] well-known locations (`%USERPROFILE%\.local\bin`, `%USERPROFILE%\.claude\local`, `%APPDATA%\npm`) catch an install PATH misses, and PATH outranks them - same tests
- [x] the tests are really compiled in: negative control (one expectation broken) turned the filtered none lane red naming the test, reverted
- [x] floor green: `floor-lane.ps1 -Lane all` lib/none/win32/agent PASS; `claude-integration.ps1` ALL PASS (124 assertions) on the rebuilt Debug exe
