# T2883 - Land the deactivation arms T1378's sweep found but did not write: chooser list rim, feedback-bar key ring, Settings commit-on-deactivate

## In plain terms

Some highlights in Ghoztty's dialogs are meant to show only while that dialog
is the window you are typing into. Our tests check that they go away when you
move to another control inside the same dialog, but not when you click away to
another window entirely. This adds the missing check for the three places
T1378's sweep found.

## Summary

T1378 swept `test\win32` for "only while focused" claims written before T568
gave the harness `Set-TestActiveWindow` / `Clear-TestActiveWindow`. It landed
two arms (quick-terminal autohide; the Activity Monitor table's selection
emphasis on deactivation) and found three more sites whose product code reacts
to `WM_KILLFOCUS` / `WM_ACTIVATE` but whose acceptance only moves focus
within the window:

- **Machine chooser list rim** - `MachineChooser.zig` repaints the list on
  `WM_SETFOCUS`/`WM_KILLFOCUS` (~line 3303). `test\win32\chooser-selection.ps1`
  pins "list does not hold focus" only by leaving focus in the chooser's search
  field (section B). Owed: rim present with the list focused, gone after
  `Clear-TestActiveWindow`, back after `Set-TestActiveWindow`, gone again with
  a sibling (the terminal window) active.
- **Viewer feedback bar key-focus ring** - `ViewerFeedbackBar.zig` clears
  `key_focus` on `WM_KILLFOCUS` (~line 2459). No `viewer-feedback*.ps1` asserts
  the ring leaves when the pane's window is deactivated.
- **Settings window commit-on-blur** - `SettingsWindow.zig` commits an edit on
  `WM_KILLFOCUS` (~line 3344, Mac's `onChange(of: focused)`).
  `settings-window.ps1` commits through IPC; nothing asserts that clicking
  away to another window commits a typed value.

Checked and NOT owed (already asserted): Activity Monitor focus ring (L7 of
`activity-monitor.ps1`), command palette / find bar dismissal (section I of
`overlay-zorder.ps1`), pane sidebar hover resync and rename
(`pane-sidebar-hover-resync.ps1`, `pane-sidebar-rename.ps1`), viewer TOC
emphasis (`viewer-toc-emphasis.ps1`).

## Validation criteria

- [ ] chooser-selection.ps1 gains a deactivation arm (Clear / Set back / sibling), ALL PASS
- [ ] a viewer-feedback harness asserts the key ring leaves on deactivation and returns with it, ALL PASS
- [ ] settings-window.ps1 asserts a typed value commits when the Settings window loses activation, with a control that does not commit without the deactivation, ALL PASS
