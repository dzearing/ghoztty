# T2263 - Windows stacked-row drags do not follow Mac's one gutter rule: the row is a pure function of where its gutter is, a drag brings out at most one pane, and dragged back the row is exactly as it was (Mac a81db68f9 PaneLayout.dragged)

## Summary

Split from T2253. Mac a81db68f9 rewrote PaneLayout so a row's layout is a pure function of its gutter position (PaneLayout.dragged): a drag only collapses panes and brings out at most one - a strip pulled out by its gutter comes out alone, the other side tucking away to make room - and dragging back restores the row exactly. Verify what win32 stack_drag.zig (T2124 RowDrag chain-collapse) already does against Mac's PaneLayoutTests/PaneStackWindowTests from a81db68f9, then port the difference.

## In plain terms

Dragging the line between side-by-side panes on Windows used an older Mac
rule: you had to push well past a pane's smallest size before it folded into
a strip, a pulled strip could only come back from certain edges, and the
divider moved differently from the grips between stacked panes. Now every
such line behaves the same way as on the Mac today: where you hold it decides
the whole row, panes fold away one at a time as soon as they no longer fit,
pulling a strip out brings out just that one pane, and dragging back to where
you started puts everything back exactly.

## Goals

- [x] One rule for every gutter of a row (divider, grip between cards, grip at the run's edge): `pane_stack_layout.dragged`, a port of Mac `PaneLayout.dragged`
- [x] A drag only collapses panes and brings out at most one; strips on the far side stay strips
- [x] Back where the drag began, the row is exactly as it was (including a row stacked for want of room staying unpinned)
- [x] All of the row on show: the tree's split ratios size it (`settingRow`, Mac `SplitTree.settingRow`); part of it folded: the tree as the drag found it
- [x] A grip at every edge where the run meets its strips, not only when there is room to widen (Mac a81db68f9 grip rule)
- [x] The old 48-DIP `restack_distance` threshold is gone, as on Mac
