# T3389 - Signing back in does not bring back a relay window opened from the CLI (Mac replays RemoteSessionManifest on sign-in)

## Summary

Mac's relayAccountDidSignIn replays RemoteSessionManifest through the launch restore path. Windows' restoreRelayWindowsForSignIn replays only relay_suspended through RestoreAllRelay .only, which rebuilds from the FAR agent's layout blobs - and those never describe a window this app opened with +new-remote-window, so such a window does not come back on sign-in (it does come back at the next launch since T3352, because sign-out keeps its relay_manifest entry). Route sign-in through RelayWindowRestore.start (the T3352 record) and make sure the two replays cannot both attach one session (paneForSession guard + the record's in-flight mark).

## In plain terms

If you open a window on another machine from a script and then sign out of
your Ghoztty account, the window closes but its shell keeps running over there.
Signing back in used to bring back only the windows that machine had a saved
layout for, so the script's window stayed gone until the next restart. Now
signing in brings it back too, the way the Mac app does, without opening any
window twice.

## Goals

- [x] Sign-in replays the relay-window record (Mac's sign-in path), after the layout rebuild
- [x] A window the layout rebuild brought back is not attached a second time by the record replay
- [x] The replay never drops the record entry of a window that is already open
- [ ] An end-to-end sign-in check on the box (T3584)

## Validation criteria

- [x] Record logic: a replay skips entries owned by open windows and leaves them out of flight; a rebuild supersedes only its own sessions on its own machine - `relay_manifest.zig` unit tests (none lane, `floor-lane.ps1 -Lane all`)
- [x] Builds and the four zig lanes stay green - `floor-lane.ps1 -Lane all`
- [ ] A real GUI sign-in against a live relay and agent brings back a `+new-remote-window` window attached once - NOT RUN: the live relay's OAuth exchange calls Google, so no offline sign-in can reach `restoreRelayWindowsForSignIn`; filed as T3584
