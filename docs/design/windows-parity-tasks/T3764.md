# T3764 - Mac: measure whether 50 cascaded windows of busy panes make the app slow, as they do on Windows

## Summary

T3740 found that on Windows 50 cascaded windows of busy panes burn ~11 cores (every window shows a strip, so every pane draws). The Mac uses the same visibility rule (a window is seen unless opaque windows cover all of it but the corners), so check whether the Mac app has the same cliff: open 50 cascaded windows each with a pane printing ~12 lines/s and measure ghoztty CPU, open-next-window time and keystroke latency against 2 windows. File what you find; if the cost per visible busy pane is high there too, the frame cap in the Windows follow-up should land on both platforms.
