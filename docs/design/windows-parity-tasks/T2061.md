## In plain terms

Many of the Windows test scripts paused for a fixed moment and then checked,
once, which control had the keyboard. On a busy machine the app sometimes
moves the keyboard a beat later than that pause, so the test fails even though
the app is fine. After this change the tests keep checking until the keyboard
arrives (or a timeout passes), and "the keyboard is NOT here" checks watch for
a while instead of glancing once. Nobody using the terminal notices; the test
runs just stop crying wolf.
