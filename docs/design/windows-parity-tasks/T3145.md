# T3145 - PA-V27: a viewer snapshot still being captured when the pane releases its snapshot lands afterwards and is never freed until the next release or pane close

## Summary

Audit-3 (T3101), area V, verified at d0d874326. ViewerPane.releaseSnapshot returns early when snap_in_flight_since_ms is set (src/apprt/win32/ViewerPane.zig:5524), and the landing path (Window.zig:8163) installs the late picture with nothing scheduled to free it, so the DIB stays until the next release event on that tab or the pane closes. Fix: record a release-pending flag and free the picture when the in-flight capture lands. Detail: docs/design/perf-audit/audit-3/V-findings.md.
