# T1846 - The pinned pane sidebar on Windows cannot be resized, and pulling the rail's edge out does not pin it

## Summary

Follow-up of T1828 (Mac 7855941f7). The pinned panel's trailing edge drags between 180 and 380 DIP and never unpins under a drag; pulling the mini rail's edge past 120 DIP pins it open. Width is one preference shared by every window.

## In plain terms

On a Mac you can grab the right edge of the pinned pane list and drag it wider
or narrower, and pulling the slim unpinned rail outward pins it open. On
Windows the list was stuck at one width and its edge did nothing. After this,
the edge drags on Windows too, between the same limits, and every window
shares the width you pick.

## Goals

- [x] The pinned panel's edge drags its width between 180 and 380 DIP, and stops there
- [x] Pushing the panel narrow never unpins it (Mac dropped the old unpin-on-drag)
- [x] Pulling the rail's edge out past 120 DIP pins it open
- [x] The open (hover) card's edge drags the same width
- [x] One width for every window: open windows follow, new windows start from it
