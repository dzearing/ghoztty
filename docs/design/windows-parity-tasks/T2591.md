# T2591 - Windows has no keyboard shortcut guide: Mac's searchable shortcuts window (Help menu, Cmd+/, palette) lists the live config's bindings with plain names, custom badges, key search, click-to-run and a printable cheat sheet

## Summary

Mac 1b7ebbcc8 (2026-10-31) added a keyboard shortcut guide: a searchable window of the EFFECTIVE keybindings (defaults merged with the live config's overrides and unbinds, via the new shared ghostty_config_keybinds_json in src/config/keybind_list.zig and ghostty_input_action_keys), curated plain-language names/descriptions/categories per action tag (with a test that fails when an action has no curated entry), CUSTOM/GLOBAL/TABLE/BUILT-IN badges, families collapsed (Ctrl+1..8), key-combo search in any modifier order, keyboard navigation, click-to-run for safe actions, a printable cheat sheet, and live reload on config change. Opened by Help > Keyboard Shortcuts, the new app-scoped show_keyboard_shortcuts action (Mac default Cmd+/), or the command palette ('Show Keyboard Shortcuts'). Windows needs the native equivalent: handle the show_keyboard_shortcuts apprt action in the win32 frontend, a Windows default chord (Ctrl+/ unless taken; record the choice), a window built to the win32 design system, the same curation table shared or ported, and the palette entry (comes free from src/input/command.zig after the merge). Spec: docs/reference/keyboard-shortcuts.md on origin/main. Needs T2490 first (the shared core arrives with the merge).
