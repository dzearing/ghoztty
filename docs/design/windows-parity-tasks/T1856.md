# T1856 - An elevated window's divider drag repaints the whole desk every mouse move: 17.9ms paint per move in Debug against 169us for the flat line (drag-perf)

## Summary

T1831's PaneDesk.paint copies the cached desk, rasterises every card's shadow ring and BitBlts the whole content area on every layout pass. drag-perf measured 17,938us of paint per move with the default elevated style against 169us flat (Debug): still under the 33ms two-frame budget, but about 100x. Options: blit only the union of the cards' old and new shadow rings plus the moved gap; cache each card's shadow sprite per size; skip the memcpy by compositing straight into the window DC's clip. Measure Release too.
