# T2462 - Blades: close T2457 on a release-build frame capture of a collapse and an expand at 1x and 4K - content opacity monotonic, 0 terminal resizes during the tween, no content before the presized frame on expand, no frame over 16.7 ms

## Summary

The T2457 close condition, as its own task so it is not lost behind the mechanism work: portable zip of a published release in temp (never the installed copy), capture a collapse and an expand frame by frame at 1x and 4K, attach the numbers. Needs the user's desktop to be idle (frame capture cannot run on the test desktop), so park as blocked(needs idle box) when the box is busy.

## In plain terms

This is the final check that folding a pane into its blade, and opening it
back up, looks smooth on the build users actually install - on a normal
screen and on a 4K one. On a normal-size window it already keeps up. On a
4K window the published build still draws about 40 pictures a second
instead of 60, so this check waits for that speed-up (T2732) and then
needs one recording made on the real screen while nobody is using it.

## Goals

- [x] Measure the published release off-screen at 1x and 4K (2026-11-05, win-v1.53.4)
- [ ] 4K glide under 16.7 ms a frame on the release - waits on T2732
- [ ] Live on-screen capture of a fold and an unfold (opacity only falls / rises, nothing shown before the presized frame) - needs the user to start it, go.md forbids the loop

## Validation criteria

- [x] 1x release frame time: glide tick mean 6.5 ms, max 13.6 ms (<= 16.7) - drag-glide.ps1 on the published win-v1.53.4 portable in the release sandbox, ALL PASS 9
- [ ] 4K release frame time <= 16.7 ms - measured 19.4 ms mean / 34.4 ms max (drag-glide.ps1 -Width 3800 -Height 2100 -TravelPx 2600 -StepPx 24, same build): FAILS, cost is placement (T2732)
- [x] 0 terminal reflows during the tween: per-tick resize work 4 us mean at 4K (WM_SIZEs with the grid held, T2459); debug proof in T2459 (2 applied per drag)
- [ ] Content opacity monotonic on screen, and no content before the presized frame on expand - live WGC capture (chainfold.ps1 -Live / record-chainfold.ps1): NOT RUN, input-desktop script the loop may not start

How to repeat the off-screen half: unpack the release portable zip under
`temp\`, then in one PowerShell process dot-source
`test\win32\lib\Isolation.ps1`, run `Set-GhozttyTestIsolation -Tag t2462
-ReleaseSandbox`, set `GHOZTTY_TEST_ALLOW_RELEASE=1` and
`GHOZTTY_STACK_TRACE=ring`, and call `test\win32\drag-glide.ps1 -ExePath
<release exe>` (T2731 turns this into a harness arm).
