# T2980 - PA-R14: Pipeline.deinit leaks the framebuffer and vertex array it created

## Summary

PA-R14 (audit-1, T2959). renderer/opengl/Pipeline.zig:50-56 creates fbo and vao; deinit (:72-74) destroys only the program. Five FBOs and five VAOs leak per shader re-init (blending or custom-shader config change); the context delete reclaims them at pane close. Fix: destroy both in deinit. Risk none. Also from the same audit: OpenGL.zig:206-208 snap_*/probe_* FBO/RBOs are never explicitly freed (matters only in a share group, i.e. after PA-R03). OpenGL-only.
