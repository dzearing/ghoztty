# T3806 - A release whose asset upload gets a GitHub HTTP 502 is lost: win-v1.56.27 failed at 'Publish win-v release' and nothing retried the upload

## Summary

Release (Windows) run 45651252053 for win-v1.56.27 (2026-11-25 16:07Z) built every artifact, then gh's asset upload of Ghoztty-portable-1.56.27-x64.zip got 'HTTP 502: Error creating policy' from uploads.github.com and the step exited 1; no release exists for the tag. daily-publish only noticed an hour later (PUBLISH DID NOT LAND) and the next request cut 1.56.28, so the work shipped late and the version number has a hole. A 502 from the upload host is transient: retry each asset upload (a few attempts with backoff) inside the publish step of .github/workflows/release-windows.yml, and/or let daily-publish re-run a failed tag's workflow once (gh run rerun --failed) before walking the patch. Acceptance: the workflow's upload loop retries on a non-zero gh exit, demonstrated by a dry-run that injects one failure.
