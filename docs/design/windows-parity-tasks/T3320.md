# T3320 - fixed-ports.ps1 C1 is red at HEAD: the port-name rule reads REPORT_TIMEOUT_MS as a port, and relay-signin-live.ps1 passes a literal 127.0.0.1:49152 redirect twice

## In plain terms

One of our test-hygiene checks makes sure no test hard-codes a network port
(two tests that pick the same port collide when they run side by side). It is
red right now, for two different reasons: it mistakes a timeout named
`REPORT_TIMEOUT_MS` for a port because the name contains the letters "port",
and one sign-in test really does use a fixed port number twice.

## Summary

Found by T1617 slice 2 (2026-11-21, lane b) while re-running `fixed-ports.ps1`
after wrapping its count. The red is NOT from that wrap: `$found` was built
with `$found = @(); $found += ...`, so it was always an array, and the copy of
the script at HEAD (11458bea9) is red identically. Section C reports:

```
relay-signin-live.ps1:292 literal-endpoint :: $v = Get-GoogleAuthVerdict -ClientId $liveId -RedirectUri 'http://127.0.0.1:49152'
relay-signin-live.ps1:325 literal-endpoint :: $cv = Get-GoogleAuthVerdict -ClientId $bogus -RedirectUri 'http://127.0.0.1:49152'
update-failure-visible.ps1:452 literal-assignment :: $REPORT_TIMEOUT_MS = 4000
FAIL C1 every acceptance script draws its ports (found 3 fixed)
```

1. **False positive in the rule.** `test\win32\lib\FixedPortAudit.ps1:81` is
   `if ($name -match 'port' -and (Test-IsPortNumber $num))` - a substring
   match, so `REPORT_TIMEOUT_MS` (from T2344, 9e10aa23a) is a "port". Match
   `port` as a word part instead (e.g. `(^|_)port(s)?($|_)` or a camel-case
   boundary, case-insensitive), and add a B-section fixture for the
   `REPORT_*` shape in both directions.
2. **relay-signin-live.ps1 (T915, c392b2204).** Decide whether 49152 is a port
   the test listens on (then draw it from the allocator like every other
   script) or a fixed redirect URI string Google's verdict endpoint is only
   asked about and never bound (then a stated exemption at those two lines is
   correct). Read the script before choosing.
