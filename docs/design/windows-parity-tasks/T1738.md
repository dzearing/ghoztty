# T1738 - Mac: check that dragging a tab's only pane onto the tab bar moves its tab (T1542 parity)

## Summary

On Windows (T1542), dragging a pane that is alone in its tab onto the tab strip
in rearrange mode now MOVES that tab to the spot under the pointer, with the
same insertion caret a new-tab drop shows. Dropping it where the tab already is
shows no caret and does nothing. Before T1542 the gesture did nothing at all.

Nobody has checked what the Mac build does with the same gesture (a lone pane
dragged onto the native tab bar). Try it on the Mac debug build. If Mac already
moves the tab, close this citing the check. If Mac does nothing or refuses, give
it the same behaviour, so the two platforms agree.

## Validation criteria

- [ ] On the Mac debug build, dragging a lone pane onto the tab bar ahead of
      another tab moves its tab there; the tab keeps its title and session.
- [ ] Dropping it where it already is changes nothing.
