# T2062 - validate does not flag a task-file frontmatter key that the README field table does not list; only parity-tasks-seat section T does, and only when that harness is due

## Summary

T1049 added section T to test/win32/parity-tasks-seat.ps1: it fails when any task file carries a frontmatter key with no row in docs/design/windows-parity-tasks/README.md's field table, or a key the table marks Retired. That harness only runs when guard-due says the tracker CLI changed, so a hand-written task file with an invented key (the failure T1049 was about) can sit in the tracker until the next unrelated edit to parity-tasks.ps1. Moving the same check into `parity-tasks.ps1 validate`, reading the table out of the README so the two cannot disagree, would catch it in the turn that writes the file. Being a new validate refusal, it needs a demonstration in test/win32/gate-negatives.ps1 (T1133).
