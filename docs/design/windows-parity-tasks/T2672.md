# T2672 - First live divider-flicker.ps1 -Live run with T2647's classified reading on an idle box: the vertical matrix reports bite / torn / ghost apart, Lc 0 with -Control bite above 0 on the same build, and the green full matrix stamps divider-flicker-live

## In plain terms

The check that films a divider drag can now tell three different glitches
apart: a pane banner covering the pink line, the line's top part lagging a
moment behind the rest, and a leftover sliver of the old line. Nobody has
filmed a real drag with it yet. That has to happen on a quiet machine, because
the check photographs the screen.

## Summary

T2647 taught `test\win32\lib\DividerFlickerScore.ps1` to classify each bitten
frame (BITE / TORN / GHOST). It is proven on synthetic frames (B3, B5-B7) and by
re-scoring the 2026-11-02 live captures offline (`docs\design\t2647-rescore.ps1`):
every ghost frame T2651 named classifies as a ghost, and of T2648's four frames
two are torn and two are real shrink-side bites from before T2642's final fix.
What is left is the live half, on an idle box (`Get-UserPresence` absent):

```
powershell -NoProfile -File test\win32\divider-flicker.ps1 -Live -Orientation vertical
powershell -NoProfile -File test\win32\divider-flicker.ps1 -Live -Orientation vertical -Control bite
powershell -NoProfile -File test\win32\divider-flicker.ps1 -Live -NoViewer -Panes 1 -Orientation vertical
powershell -NoProfile -File test\win32\divider-flicker.ps1 -Live
```

Record the torn and ghost lines per cell into T2648 and T2651. They are the
baseline each fix is measured against.
