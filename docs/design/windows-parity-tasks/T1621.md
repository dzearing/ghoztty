# T1621 - Extend the seam audit past env vars to seeded stores and staged config

## Summary

T796 built the seam registry over ENV seams only - the mechanically enumerable half. The same 'a seam you set says the unset case is untested' rule applies to the other seams a script stages: a seeded account/session store, a planted HKCU value, a staged config file, a canned feed on disk. Those have no single spelling to grep for, so the enumeration needs a different handle (probably the isolation helpers in test\win32\lib\ - whoever writes a store is calling one of a small number of Seed-* / New-* helpers). Worth doing only if a defect of that shape actually appears; filed so the scope limit of T796's registry is recorded rather than implied.
