# T1805 - Mac: command palette has no way to restart Ghoztty or its background agent (mirror of the Windows task)

## In plain terms

This is the Mac side of T1804. Add the same two palette commands, Restart
Ghoztty and Restart Ghoztty and background sessions, with the same names and
the same confirmation wording as Windows.

## Summary

Neither platform has a user-invoked restart. On Mac, the only restart flow
is the forced-upgrade alert (`LocalAgentManager.makeUpgradeAlert`). See T1804
for the full design: the two commands, what each costs the user, and the
confirmation rules. Mac-native translation:

- Restart Ghoztty: relaunch the bundle (`NSWorkspace` open of
  `Bundle.main.bundleURL` after this process exits). With persistence on,
  panes re-attach to the agent over the AF_UNIX socket.
- Restart background sessions: `launchctl kickstart -k` on THIS build's
  LaunchAgent label. The debug label is not the release label, so the
  installed app's agent is untouched. The confirmation reuses the upgrade
  alert's safe-default button pattern.
- Put the commands in `TerminalCommandPalette.swift` next to "Update Ghoztty
  and Restart", and add a matching app-menu item.

## What Windows shipped (T1804) - match it exactly

Names (palette): **Restart Ghoztty** and **Restart Ghoztty and Background
Sessions**. Both are also found by typing "relaunch". Windows also puts them in
the File menu just above Exit; on Mac, put them in the application menu above Quit.

When each one asks (`src/apprt/win32/app_restart.zig` `prompt`):

- Restart Ghoztty with persistence on: no question.
- Restart Ghoztty with persistence off: ask, titled "Restart Ghoztty?", with
  "Session persistence is off, so restarting Ghoztty closes every open
  terminal and ends the programs running in them. Your windows open again
  empty."
- Restart Ghoztty and Background Sessions: ask whenever the agent reports a
  live session, or the count is unknown. Title "Restart Ghoztty and its
  background sessions?" The body names the count ("closes your 3 open
  terminal sessions"), says they can't be carried across, and ends with "To
  restart Ghoztty without losing anything, use Restart Ghoztty instead." With
  zero live sessions it does not ask.
- Buttons are Restart / Cancel. Cancel is the Enter default.

After the relaunch, a notice titled "Ghoztty Restarted" says either "Your
terminal sessions kept running." or "Your terminal sessions were started
fresh." (`update_reopen.zig`, reasons `restart` / `restart_sessions`).

## Validation criteria

- [ ] Same command names and wording as T1804 on Windows.
- [ ] Restart Ghoztty with persistence on keeps every session (same session
      ids, scrollback intact, layout restored).
- [ ] Restart background sessions names the session count, defaults to the
      safe button, and restarts only this build's LaunchAgent.
