# T3184 - Single-window mode: closing a workspace - the one on show hands the window to the one shown before it, a parked one closes in place (sidebar x included), a close that needs confirming shows it first

## Summary

Ctrl+Shift+W, the caption X, +close, sidebar x, last pane exiting: on-show close shows the previously shown workspace; the last one closes the window; parked close runs the same session close intents and manifest removal as a window close without showing (Mac 51e6e5aba); a confirm-close puts a parked workspace on show first; undo close returns it on show; if the window closes with workspaces left (not at quit) the next gets a window of its own. Child of T3136 (split 2026-11-16). Design (T3136 Details): ONE shared top-level HWND; every workspace keeps its own Window controller; the workspace on show owns the HWND (GWLP_USERDATA, chrome, sidebar), a parked Window has hwnd=null and its pane child HWNDs are reparented (adoptPane-style SetParent, Window.zig:7278) under a hidden park host so they survive the shared HWND closing. Spec: docs/reference/window-modes.md. Acceptance goes in test/win32/single-window-mode.ps1 (one section per child).

## In plain terms

With "All in one window" on, Ghoztty keeps one window and switches between
workspaces inside it. Closing the workspace you are looking at used to close
that window and pop up a brand-new one for the next workspace; now the same
window simply shows the workspace you were on before. Closing a workspace you
are not looking at removes it without touching the window, and closing the
very last one closes the window.

## Goals

- [x] Closing the workspace on show (caption X / Alt+F4, +close, close_window) hands the SAME window to the one shown before it
- [x] Closing a parked workspace (+close, sidebar x, its last shell exiting) closes it in place: sessions end, it leaves the manifest and the CLI names
- [x] The last workspace's close closes the window
- [x] A close that has to ask puts a parked workspace on show first, so the dialog has a window
- [ ] Undo of a workspace close brings it back on show - filed as T3200 (single-mode workspace closes skip undo for now)
