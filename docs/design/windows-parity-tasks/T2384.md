## In plain terms

To measure how smoothly a window or pane follows the mouse, the lab has to
move the mouse itself, precisely and on a known clock, so "the mouse got here
at time t" can be lined up against "the screen showed it at time t'". This
adds that robot hand: it moves the pointer a thousand times a second along a
scripted path, writes down exactly when each move happened, refuses to run
while someone is using the computer, and lets go the instant a person grabs
the mouse.

## Goals

- [x] Path builder: MoveTo / Press / Hold / Line / Shuttle / Release, one sample per tick at the planned QPC offset
- [x] 1 kHz player on a high-resolution waitable timer + final spin, every point stamped (planned vs sent)
- [x] SendInput absolute/virtual-desktop in physical pixels with an exact normalisation
- [x] Presence gate (lib\UserPresence.ps1) before any injection; dry run and caller sinks bypass it without touching input
- [x] Abort on the user taking the mouse; the held button is always released, where the user put the cursor
- [x] Stamp export for the T2390 report

## Design

`test\win32\lib\FrameLabInput.ps1` (C# via Add-Type): `GliPathBuilder`,
`GliPlayer.Play` on a dedicated Highest-priority, per-monitor-DPI-aware
thread, and an `IGliSink` seam: `GliSendInputSink` (real) and
`GliRecordingSink` (the harness: records sends, simulates a user taking the
mouse at a chosen send, or a cursor lagging N points behind). Wrappers:
`New-FrameLabPath`, `Invoke-FrameLabInput` (gated), `Resolve-FrameLabInputGate`
(pure), `ConvertTo-FrameLabInputStamps`.

Decisions (mechanism, so made here, not filed):
- Normalisation `ceil(v*65536/w)`, decoded `floor(n*w/65536)`: exact for every pixel of 8 widths up to 11520. The real decoder's behaviour is checked on the first live run (T2389).
- User-takeover = cursor farther than TolerancePx (3) from every one of the last 16 sent points, on two checks in a row; a cursor 4 points behind is not a user (negative control D6). Keyboard input is not watched; the presence gate's idle window covers a user who is typing.
- Timer: high-res waitable timer to ~300 us before the tick, then spin. Measured here: p50 44 us, p95 281 us, max 722 us late, 0 of 2000 a period late, 1000.1 Hz.
