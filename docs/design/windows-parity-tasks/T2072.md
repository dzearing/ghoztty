# T2072 - Confirm release.yml's extracted appcast publish (publish-appcast.sh) runs green on the macOS runner at the next Mac release

## Summary

T1089 moved the appcast clone/edit/push-with-retry out of `.github/workflows/release.yml` into `dist/website/publish-appcast.sh` + `update-appcast.py`. The Windows box proves its logic in `test\win32\website-windows-download.ps1` section H, but under Git Bash and GNU tools; the real caller is the macOS runner (bash 3.2, BSD `date`/`mktemp`). At the next `v*` release, read the "Update appcast and deploy to GitHub Pages" step log: it must say `appcast pushed (attempt N)` (or `already up to date`), and gh-pages `appcast.xml` must carry exactly one item for that version with a non-empty edSignature.

- [ ] gh-pages appcast.xml has exactly one item for that version, with the DMG url, length and a non-empty edSignature
