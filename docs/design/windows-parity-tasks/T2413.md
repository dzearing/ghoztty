# T2413 - The collapsed pane-sidebar rail shows a + (new window) tile that Mac's rail does not have (PaneSidebarView.swift: 'Not in the rail, whose header is the expand button alone'); confirm against current Mac main and either drop it or, if Mac grew one, draw it with sidebar_symbol .plus

## Summary

Found during T2357: after the icon port the rail + is the one remaining Fluent glyph in the rail, and Mac's header code says the rail has no + at all.

## In plain terms

When the pane sidebar is collapsed to its narrow rail, a small + sits at the top of it. This task asked whether the Mac rail really has that + and whether ours draws it the right way. It does, on both: Mac added the rail + after this task was filed, and the Windows rail already matches it.

## Goals

- [x] Confirm against current Mac main whether the rail has a +
- [x] Make the Windows rail match (already done by T2407)

## Findings (2026-11-09, lane b)

- **Mac grew the rail +** after T2357 read the old comment. On origin/main (85d13e526), `PaneSidebarView.swift` draws `PaneSidebarRailAddSlot` at the top of the rail: help "New pane" in the this-window list (`thisWindowList`), "New window" in the all-windows list (`listContent`). The comment "Not in the rail, whose header is the expand button alone" is about `headerButtons` (the panel header), not the rail's list.
- **T2407 (64bac933c) already ported it**: `pane_sidebar.zig` lays out `rail_add`, `pane_sidebar_add.railAdd` picks pane vs window by scope, and `PaneSidebar.zig` paints it and gives it the scope's tooltip.
- **The glyph is right as it is.** `PaneSidebarRailAddSlot` is a `PaneSidebarItemButton(symbol: "plus")`: an SF Symbol in the same item-button component as a group/window header's +, pencil and x. Windows draws all of those with `paintRowButton` and the Fluent stand-ins (`glyph_add` for SF `plus`). `sidebar_symbol .plus` is Mac's `PaneSidebarSymbol.plus`, the *panel header's* hand-drawn + (`PaneSidebarHeaderButton`). Drawing the rail + with it would make the rail diverge from Mac, so the suggestion in this task's title does not apply.
