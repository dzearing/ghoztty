# T3791 - Linux window header-bar title is too bold: use semibold (600)

## Summary

User report 2026-11-25, looking at the Linux build on the real WSLg screen: "the header font is too bold, try semibold?" The window's header-bar title (libadwaita's `.title` in the AdwHeaderBar - "Ghostty" / "~" in the 2026-11-25 screenshots, see T3783) renders at Adwaita's default bold (700). Set it to semibold (600). Same pass: any other header-bar / tab / pane-header label we style bold where the Mac uses a medium or semibold title weight - compare against the Mac's titlebar and tab title weights (docs/reference/ for the Mac's values) and list each one changed. The debug-build banner is out of scope (debug only).

Fix in the runtime CSS (src/apprt/gtk, the same place the theme CSS is built), not by a per-widget Pango override, so every window and the Settings window pick it up. Mind the existing `style.css:140` hsl() parse warning seen in the same log - fix it if it is ours.

User directive on the same report: the Linux build "really needs to be as high quality as the mac version" - see T3793 for the side-by-side pass.

## In plain terms

The Linux window's title at the top read heavier than the Mac's. It, and the
other titles in the window chrome, now draw at semibold, the weight the Mac
uses, so the Linux build looks like the same app.

## Goals

- [x] The header bar's title draws at semibold (600)

## Weight review (Linux vs Mac)

| Label | Before | Now | Mac reference |
|---|---|---|---|
| Header-bar title (`windowtitle .title`, `headerbar .title`) | 700 (Adwaita) | 600 | `.titleBarFont` - semibold |
| `.heading` (Settings section titles, sidebar headers, the config toast, a modified setting's name) | 700 (Adwaita) | 600 | `SettingsView.swift:30` and `PaneSidebarView.swift:1005/1189` - semibold |
| Minimized pane strip (`.pane-strip`) | 400 | 600 | `PaneStackTab.swift:208` - semibold 11 |
| Shortcut guide badge (`.ghoztty-badge`) | bold | 600 | `ShortcutListView.swift:281` Badge - semibold 9.5 |
| Picked theme tile name (`.gz-tile-name.gz-picked`) | bold | 600 | `SettingsCustomSections.swift:299` - semibold when selected |
| Banner markdown bold and headings (`banner_markup.zig`) | bold | kept | content the user wrote, not chrome |
| Tab overview's empty state / New Tab button | 800 / 700 | kept | Adwaita's AdwTabOverview; the Mac has no tab overview |
| Debug-build banner | 600 (via `.heading`) | - | out of scope (debug only) |
