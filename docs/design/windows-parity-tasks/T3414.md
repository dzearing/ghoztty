# T3414 - Linux L9e: find in page in every viewer mode (find.js, live count, Ctrl+F/G)

## Summary

Inject src/viewer/find.js as a WebKit user script so it reaches websites too; a floating card at the pane top-trailing corner with a live n/m count, Enter/Shift-Enter and Ctrl+G stepping, Escape closing while keeping the query, the not-searching second line, 5000+ cap. An image pane declines the chords.

## In plain terms

On Linux a document, code file or website open beside the terminal had no
way to search it: Ctrl+F did nothing. Now Ctrl+F opens a small find box in
the pane's top corner that highlights every match, shows "3 of 17" as you
type, and steps through matches with Enter, Ctrl+G or F3 - the same find the
Mac and Windows panes have. Escape closes it and remembers what you searched.
