# T3566 - Linux L11d: pane style on GTK - elevated cards on a gradient desk, glass panes, focus rim/glow and unfocused dimming, --color window gradients

## Summary

Port docs/reference/pane-style.md: the elevated/flat pane styles, the window gradient desk (and --color / --split-color tinting it, see the GTK colour card), glass panes when elevated, focus shown by rim and glow only, and unfocused-pane dimming. GTK translation: CSS on the split-tree widgets plus a snapshot-time desk gradient; config keys keep their Mac names where the meaning is the same. win32 counterparts: pane_elevation.zig, chrome_glass.zig, viewer_glass.zig. Parity is behavior and information, not pixels.

**Scope as landed (2026-11-23):** the desk, the elevated cards, the focus rim and
glow, the flat style on a reload, and the `--color=random` window gradient. The
rest is split out: glass panes (and the no-wash-on-glass dimming rule) are
T3622; the gradient surviving a relaunch and the desk running under the pane
sidebar and header bar are T3623; the flat style's 6px gutter is T3624.
Unfocused dimming on solid cards is upstream's `unfocused-split-*` wash, which
GTK already draws, exactly as Mac's elevated-without-glass keeps it.

## In plain terms

On Linux every pane used to sit edge to edge on a plain grey window. Now, like
on the Mac and Windows, each pane is a slightly raised card with rounded corners
floating on a soft coloured gradient, with an even gap between the cards and
around the window's edge, and the pane you are typing in has a soft light behind
it. A window you open yourself gets its own colour, so windows side by side are
easy to tell apart.

## Goals

- [x] The window's gradient desk painted behind the panes, from the same palette maths as Mac and Windows (one seed is one gradient everywhere)
- [x] Panes are rounded cards with one 10px gutter between them and around the edge, and no divider line over the desk
- [x] The focused pane of several is backlit, with a brighter rim
- [x] `macos-pane-style = flat` puts the panes back edge to edge, on a config reload too
- [x] A hand-opened window gets its own gradient (`macos-window-gradient`); `+new-window --color=random` gives one instead of tinting the terminal; `#hex` still tints
- [ ] Glass panes - T3622
- [ ] Gradient survives a relaunch; desk under the sidebar and header bar - T3623
