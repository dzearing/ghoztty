# T3545 - Linux L9j-3: quoting a selection from a GTK viewer page into the feedback composer

## Summary

The Quote/Copy toolbar (shared src/viewer/selection.js, shadow-root UI) as a WebKitUserScript in every page of the GTK viewer, its messages on the viewerTOC handler; Quote opens the composer and inserts the passage as a quote block with headingId/blockSelector/offsets, and sourceLine resolved natively at send time for file viewers (win32 viewer_feedback_report's search); Copy uses the GDK clipboard. Depends on the composer card (L9j-2).

## In plain terms

On Linux, selecting text in a viewer pane now shows a small Quote / Copy
toolbar, the same one Mac and Windows have. Quote opens the feedback box with
that passage dropped in as a quoted block, and the filed report says exactly
where it came from (which section, which paragraph, which line of the file).
Copy puts the text on the clipboard.

## Goals

- [x] The shared toolbar shows on a selection in every GTK viewer page
- [x] Quote opens the composer with the passage as its own block, at the caret
- [x] The report quotes it in the body and carries its context and source line
- [x] Deleting the block in the composer drops it from the report
- [x] Copy writes the GDK clipboard
