# T2034 - Closing a whole window still leaves its panes' banners on screen for the undo window: T2012 hid a closed pane's popups but not a closed window's

## In plain terms

Closing a window that shows banners left those banners floating on screen for
about five seconds after the window itself vanished: the same thing the user
reported for a single pane, on the path where a whole window closes. Now they
go away with the window.

## Summary

T2012 (lane B) hides a pane's popups when the pane is parked, and on SWP_HIDEWINDOW. Closing a window's last tab, or +close of a window while another is open, parks the WHOLE window: CloseUndo.parkWindow hides the top-level, which neither hides owned popups nor sends the panes a hide, so every banner in that window stays up for undo-timeout. Proven on the box: close-overlays.ps1 section 5 is red without a fix. Also covered here: the search bar and command palette popups join hideOverlays, and the no-undo close paths and +rearrange's departing leaves hide popups at once rather than at the last unref.
