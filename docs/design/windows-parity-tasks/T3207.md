# T3207 - single-window-mode.ps1 never drives a shell exiting inside a workspace that is waiting out its close undo (T3200 expireParkedWindow path)

## Summary

T3200 added Window.removeTabSlot -> CloseUndo.expireParkedWindow for a closed single-mode workspace whose last shell exits during the undo window. No harness reaches it: the workspace's names are unregistered while it waits, so +send-keys cannot type exit into it. Needs a seam (or a short-lived command like --command='cmd /c timeout 2') to make the shell exit during the undo, then assert closed_for_undo drops to 0 before the timeout and no crash.
