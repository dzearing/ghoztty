# T3049 - PA-V17: hidden git-status: and loopback viewers keep waking every few seconds, and a minimized window still re-resolves loopback servers (ViewerPane.zig:7526)

## Summary

PA-V17 (audit-1, T2963). The diff timer (ViewerPane.zig:2146, 2 s) and worktree timer (:1291, 15 s) keep firing while hidden and only drop the tick in the handler (:7541, :7526); the worktree gate is IsWindowVisible, which reads true for a minimized window. Cost: idle wakeups, and a TCP-table fetch per 15 s when minimized. Fix: KillTimer on hide, re-arm on show (the catch-up exists), gate on self.visible. Risk: low. Findings: docs/design/perf-audit/audit-1/V-findings.md.
