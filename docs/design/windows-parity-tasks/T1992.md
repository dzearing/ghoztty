# T1992 - Measure Mac's focus glow on a real pane and match Windows to it: pane_elevation reads SwiftUI blur(radius: 4) as sigma 2, which may make the Windows glow brighter and tighter at the edge than Mac's

## Summary

Follow-up from T1990. The white ring the user reported was the web page's card colour, not the glow. The glow is still unmeasured: pane_elevation.zig GLOW_SIGMA_DIP=2 assumes SwiftUI's blur radius is 2 sigma. If SwiftUI's radius IS sigma, the Windows peak just outside the card is about 1.75x Mac's. Capture a focused pane's edge on the Mac (dark desk, 2x) and compare its luminance profile with paintGlows; adjust GLOW_SIGMA_DIP (and the shadow reading, which makes the same assumption) to match.
