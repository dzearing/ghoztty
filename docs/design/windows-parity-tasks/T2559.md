## In plain terms

On the new, faster drawing path (still opt-in), a pane's status banner was
still a separate little window glued on top of the pane and moved by hand
every time the pane moved, which is how it could trail its pane by a frame.
Now the banner is drawn as part of the pane's own picture, so it moves with
the pane for free, and its links, collapse chevron and clicks still work.
Nothing changes on the default drawing path.
