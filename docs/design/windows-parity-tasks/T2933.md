# T2933 - On the default drawing path (no GHOZTTY_COMP_CHROME) a divider drag still cuts ~1.6 pane regions a frame (SetWindowRgn on a child whose own swap chain the region clips), and 1-3 of them a run stall 2-7 ms off-CPU: give the default path's card corner a shape that does not need a per-frame region, or retire the path

## Summary

T2932 landed the per-frame region hold for the composition path
(`GHOZTTY_COMP_CHROME=1` + `GHOZTTY_COMP_PANE_TREE=1`): there the pane's
visual carries the card shape and the desk is a visual, so the window region
clips nothing on screen and is cut once at drag end (1734 -> 31 calls a probe
run, worst `cards_us` 1.18 -> 0.53 ms).

The default path - what the release runs today - has no chrome host and each
pane presents through a swap chain on its OWN child window
(`composition swap chain ... tree=false`). There the window region is what
clips that swap chain to the rounded card, and the GDI desk paint
(`WS_CLIPCHILDREN`) fills the corners the region gives back. Holding a stale
region mid-drag would leave a grown pane's new edge clipped (a desk gap) and a
shrunk pane's corners square. The T2932 probe on the default path:
`stack trace rgn-cut-in-drag tree=0 desk_visual=0` on every one of 1612 cuts -
the hold correctly never engages - and the T2874 stall remains (1-3 ticks a
run over 1.5 ms, worst 2.1-3.1 ms).

Directions, none tried yet:

- Round the pane's OWN DirectComposition target visual (a rounded
  `IDCompositionRectangleClip`) and keep the window region a plain rect that
  only changes at drag end; the corner pixels then need the desk under them,
  which the child window does not have - the open problem.
- Make the composition path the default (the T2360 track; T2843 measures its
  glide cost, T2576 its GDI-child audit) - then T2932 covers it.
- Measure whether a rect region (`CreateRectRgn`) stalls as often as a rounded
  one; if the stall is the window-manager transaction rather than the GDI
  build, only fewer calls help.

T2874's probe and analysers: `glide-probe.ps1`, `rgn3.py`, `tickrgn.py`
(session 97a4449e scratchpad; copies in session 8d80a733's).

## Validation criteria

- [ ] T2874 probe, release, default path, 3 runs: no tick with `cards_us` over 1.5 ms
- [ ] the card's rounded corner intact on every drag frame (pane-elevation / blade-shadow / stack-fold-slide green, plus a mid-drag film or pixel probe)
