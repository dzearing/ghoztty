# T1666 - A direct: command in the config cannot express an argument containing a space

## Summary

config.Command.parseCLI splits a direct: value on bare spaces (src/config/command.zig), so 'command = direct:C:\Program Files\Git\bin\bash.exe' becomes two argv elements and there is no spelling that produces one. The shell-form has the same problem but at least has quoting rules. T862 fixed the internal callers by constructing .direct programmatically; the CONFIG surface still has no escape. Shared core, so it is a Mac question too. Options: honour quotes in the direct split, or document that direct: is for space-free argv only and make the failure loud.
