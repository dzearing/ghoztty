# T3607 - Linux L10f: drag pane sidebar rows (panes, windows, groups) and the stash tray on GTK

## Summary

Split from T3558. The GTK pane sidebar (PaneSidebar.zig, pane_sidebar_all.zig) lists every window and searches, but nothing drags: dragging a pane row reorders its window's panes (win32 pane_sidebar_reorder/pane_sidebar_order), a window row or project header reorders the all-windows list (pane_sidebar_window_order keys, persisted under the config root), a grid pane dropped on another window's row joins that window (pane_sidebar_cross_drop), and dragging a pane into the stash tray stashes it - which needs +stash/+restore served on GTK first (T3596). docs/reference/pane-sidebar.md 'Drag to reorder', 'Reordering windows and groups', 'Stashing invariants'.
