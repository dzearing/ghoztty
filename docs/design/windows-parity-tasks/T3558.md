# T3558 - Linux L10c: pane sidebar all-windows list and its search on GTK

## Summary

The second half of docs/reference/pane-sidebar.md on GTK (after L10b): the all-windows list grouped by window and its search. Re-scoped 2026-11-23 when claimed: dragging rows (panes, windows, groups) and the stash tray moved to T3607 (which needs +stash/+restore on GTK, T3596 - that was never this card's to serve); group editing (the window-row menu, the project/Ungrouped headers' + / x / pencil) moved to T3608; a row's own tools, hover tint and busy sheen stay T3606.

## In plain terms

On Linux the pane sidebar only ever listed the panes of the window you were in. Now its header has a button that lists every open window instead, folded to one row each (open one to see its panes), with project windows grouped together, and a search box that finds a pane in any window by its name, banner or folder - clicking a result jumps to it. A first launch starts in this view, as on the Mac.
