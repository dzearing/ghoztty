# T1983 - Every acceptance script that launches the app runs isolated, so two loop lanes cannot drive each other's test app

## In plain terms

When two copies of the loop test on the same machine, a test in one copy
could open its window inside the OTHER copy's test app and grade the wrong
build, because a few tests still used the one default address every debug
build shares. Now every test that starts the app gets its own private address,
and a new test that forgets is caught automatically.

## Summary

Split from T1937 item 3. Audit the ~179 test/win32 scripts without Isolation.ps1: isolate any that launch the debug app, prove the rest do not, and extend the isolation audit so a new unisolated launcher is a finding (with a teeth check).

## Findings

- The "179 without Isolation.ps1" were mostly already isolated: they set a
  hand-rolled `$PID` suffix. A sweep of all 400 scripts found 251 that launch
  the app; 245 already held a run-unique `GHOZTTY_PIPE_SUFFIX`.
- The hazard is real, not theoretical: the app's pipe IS its single-instance
  lock (`IpcServer.zig`), and every debug build derives the same default
  `ghoztty-debug-<user>`. An unsuffixed launch in lane B therefore JOINS lane
  A's test app instead of starting its own.
- The old audit (isolation-meta B) could not see it: it only asked scripts
  that run a `+verb`, and it accepted dot-sourcing CleanSlate.ps1 as a claim -
  which drops the pane's socket but falls back to exactly that shared default.
- Unisolated launchers fixed (run-unique suffix added): `registration-sites`,
  `share-machine`, `install-prepare`, `upgrade-resume-readiness`. Proven not to
  launch the app and marked with a reasoned `# isolation: none - ...`:
  `build-fresh-guard` (only `+version`), `cleanslate-audit` (a cmd.exe copy),
  `stderr-launch-capture` (marker reworded so its reason is on the line).
- `upgrade-resume-readiness` section F also launched its app with a bare
  `Start-Process` on the USER's desktop; moved onto the test desktop
  (`Start-OnTestDesktop` + `Invoke-OnTestDesktop` for its `+new-window`).
- Filed: T1993 (P0 - outside the parallel pool, 283 scripts' literal
  `D:\git\ghoztty` defaults make lane B grade lane A's exe) and T1994 (P1 -
  both lanes' debug builds share one debug local agent). Both now gate T1986.
