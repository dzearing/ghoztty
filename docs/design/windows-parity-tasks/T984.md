# T984 - The viewer-panes harness does not re-run when the pane it tests changes

## Summary

scripts\guard-due.ps1's viewer-panes row covers only test\win32\viewer-panes.ps1 and one other file, so an edit to src\apprt\win32\ViewerPane.zig - the 389 KB module that harness is the acceptance for - never makes it due. T934 changed that module substantively and the gate stayed quiet; the run was done by hand. Add the pane's own runtime files to the row (and audit the other rows for the same shape of hole).

## In plain terms

The automated check that proves viewer panes (the side panes that show a
document, a web page or a diff) still work was only re-run when the test
itself changed, not when the viewer code did. Now any change to the viewer
pane's code makes that check "due", and a commit is refused until it has
been run green against the new code.
