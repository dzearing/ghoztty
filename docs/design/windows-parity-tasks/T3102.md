## In plain terms

The Mac build fixed a pane that could freeze for seconds when a program sent
a burst of queries, a background session host that could run out of memory
when the app stopped reading, and a restored pane whose cursor came back in
the wrong column. Those fixes live in code both builds share, so this brings
them into the Windows build and makes sure nothing Windows-specific broke on
the way in.
