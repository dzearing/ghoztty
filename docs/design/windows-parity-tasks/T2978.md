# T2978 - PA-R12: every grid resize reallocates all rows+2 glyph lists, each with 3x columns capacity

## Summary

PA-R12 (audit-1, T2959). renderer/cell.zig:118-122 Contents.resize allocates fresh ArrayListCollection(rows + 2, columns * 3) and frees the old one on every column/row change. Cost estimated: ~47 allocations and ~0.7 MB per step at 160x45, plus ~0.7 MB steady per pane from the 3x capacity; part of the resize CPU (baseline resize cpu_pct 13.8 release / 31 debug). Fix: reuse existing lists with ensureTotalCapacity and start at 1x columns. Risk low. Shared code.

- [ ] perf-baseline.ps1 -Phase resize: cpu_pct not worse and allocation count per resize step down (allocator counter or trace)
