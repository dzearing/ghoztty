# T2484 - Mac: confirm terminal title pacing (T2428, src/termio/title_pace.zig) on macOS - a pane that re-titles per line no longer floods the app thread, and the window/tab title still ends on the last title

## Summary

T2428 moved title pacing into the shared termio core: the newest OSC 0/2 title is held and sent at most once per 16 ms, with a trailing send on a new termio timer (Thread.title) so the last title always lands. On Windows it cut set_title from ~13,000/s to ~34/s under a cmd echo loop. On macOS: build, run a loop that sets a new title per line (e.g. `i=0; while true; do printf '\e]2;t%d\a' $i; i=$((i+1)); echo line; done`), check the main thread is no longer busy, and that the title settles on the last value when the loop stops. Also run the none lane's title_pace tests.
