# T2006 - A lane-B acceptance script run BY HAND (not through acceptance-parallel) still dials lane A's debug agent: the lineage T1994 gives runner phases is not minted for a direct run

## Summary

Found in T1994. T1994 closed the gap for every phase of
`scripts\acceptance-parallel.ps1` (workers already had a lineage; main,
exclusive, serial and confirm runs from a non-literal checkout now get
`GHOZTTY_AGENT_INSTANCE=apm-<runnerPid>`). A script started directly -
`powershell -File test\win32\<x>.ps1` from D:\git\ghoztty-b - still inherits no
lineage, so its debug app dials the box's default debug agent, which is lane A's.

Fix sketch: where a script resolves its repo (CleanSlate.ps1 / Isolation.ps1
already know the exe path), mint a run-unique lineage with
`Set-GhozttyTestAgentLineage` when that repo is a linked worktree
(`Get-LoopLaneId` in scripts\lib\LoopLane.ps1 is not 'a') and none is set - and
refuse the T2005 hardcoders there the same way the runner does.

## In plain terms

The second test lane on this box has its own copy of the code, but when a test
there was started by hand it still talked to the first lane's background
session service, so its results could mix in the other lane's sessions. Now a
hand-started test in the second lane gets a private session service of its own,
and a test that cannot work that way refuses to run instead of borrowing the
first lane's. Nothing changes in the first lane.

## Goals

- [x] a hand run in a non-literal checkout mints its own agent lineage (`aph-<pid>`) with its autostart teardown armed
- [x] a lineage-hostile script is refused there, the same set the runner refuses
- [x] the literal checkout is untouched
- [x] the guard and the runner cannot drift apart unnoticed

## Validation criteria

- [x] A fixture run by hand from a fake linked worktree records its own agent lineage; from the main worktree it records none (lane A unchanged). - checkout-guard.ps1 E1/E4/E6, through acceptance-parallel (ALL PASS, 30 assertions); -NegativeControl turns E1-E3 red.
- [x] A lineage-hostile script run by hand from a linked worktree refuses instead of dialing lane A's agent. - checkout-guard.ps1 E2 (refused before the body, names the reason); E7 proves guard == runner on every test\win32 script.
