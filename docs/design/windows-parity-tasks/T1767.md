# T1767 - The OpenGL loader's path log line can overrun its buffer on a long non-ASCII install path

## Summary

src/renderer/gl_loader.zig logPath converts up to max_path (1024) UTF-16 units into a 1024-byte buffer with the unbounded std.unicode.utf16LeToUtf8; an install path over ~341 three-byte characters panics at startup. It is a log line, so truncate via utf16_text.toUtf8Truncating (or size the buffer 3x). Found by T991's sweep; outside src/apprt/win32 and src/remote/agent, which T990/T991 covered.
