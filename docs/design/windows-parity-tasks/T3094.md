# T3094 - go-loop-health reports stalled(by=idle) during a normal turn handoff, while the pane is already working

## Summary

Twice in a row (2026-11-14 20:43:08 and 22:43:08) the 2h -Postmortem tick read DEGRADED 'stalled(by=idle): the session is idle ... after ~120m with no completed turn' while the pane tail showed a live spinner (turn ending / /reset-context in flight), and a plain re-run 8-13 s later read HEALTHY with turn+1 and turn_age=0m. The watchdog in the same minute logged session=working. The idle verdict is taken from a probe that sees the composer between the turn's last output and the continuation landing. Fix: before calling a stall, require the idle reading to persist across a short re-probe (or agree with the watchdog's session state), so a turn boundary is never reported as a go.md step 7 failure.
