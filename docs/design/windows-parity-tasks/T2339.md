# T2339 - Windows pane sidebar renames in place: hovering a window, project group or terminal pane row shows a pencil that turns its name into an edit field, as on Mac

## Summary

Mac 379a352ef + a13bf6f43. Pencil first among the row's hover buttons; field takes the caret with text selected; Return or click-away keeps, Escape cancels, unchanged name pins nothing; the row's drag source steps aside while editing. Window field holds the whole title incl. '<project>: ' (typing 'a: foo' moves it to group a as foo; empty = follow the window's own title); any window rename redraws every sidebar. Group field: each window retitled '<new>: <name>', group keeps its place; empty ungroups. Terminal pane field sets its title like Change Pane Title; that name outranks a banner title. Viewers get no pencil. a13bf6f43 also fits the tray divider. Mac ref: docs/reference/pane-sidebar.md 'Rename in place'.

## In plain terms

On Mac hovering a window, group or pane in the sidebar shows a pencil; clicking it lets you type a new name right there. Windows has no way to rename from the sidebar. After this it does, and renaming a group renames all its windows.

## Goals

- [x] Pencil first among each row's hover buttons (windows, groups, terminal panes; not viewers)
- [x] Field takes the caret with text selected; Enter or click-away keeps, Escape cancels, unchanged pins nothing
- [x] Window rename can move it between groups ('a: foo'); empty follows the window's own title
- [x] Group rename retitles its windows; empty ungroups them
- [x] Pane rename sets its title as Change Pane Title does and outranks a banner title
- [x] The stash tray's divider is as wide as a row's fill, with as much space below it as above (a13bf6f43's other half)
