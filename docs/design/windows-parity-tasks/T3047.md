# T3047 - PA-V15: every viewer re-reads and loads all fourteen page assets, whatever kind of pane it is (viewer.html:8)

## Summary

PA-V15 (audit-1, T2963). src/viewer/viewer.html:8-22 (shared with Mac) loads 14 assets (~470 KB by wc -c, incl. 129 KB highlight.js and 125 KB markdown-it) for every pane, image and diff included; the resource handler re-reads them from disk per load and sends no cache header (ViewerPane.zig:5133-5139). Cost (estimated): ~0.5 MB read+copy on the GUI thread per load plus a few MB JS heap per renderer. Fix: a process-wide asset cache (or @embedFile) and per-mode lazy scripts; the page side is shared, Mac half T3057. Risk: low. Findings: docs/design/perf-audit/audit-1/V-findings.md.
