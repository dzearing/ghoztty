## Summary

Mac main 7e2d0a9da: each window title records who set it. User = the sidebar rename field, Change Window Title, a sidebar drag into/out of a group; script = +rename, +new-window --title, the sidebar group + naming its new window. While the user's title is up, +rename changes nothing (not even a clear) and fails with an error naming the user's title; once the user clears it scripts may rename again. +list --json gains title_set_by_user per window (layout.md on main documents it in the skill). The flag persists with the title: AppKit restorable state and the session-layout + remote manifests (true or absent; older state decodes as script). CLI surface must match Mac exactly. Refs: docs/reference/cli-commands.md and macos/Resources/Ghoztty/skills/ghoztty/layout.md on main; Mac tests UserWindowTitleTests.
