# T3635 - Linux L11g6: the GTK Settings window has the Sessions & Agent and Remote Machines pages - agent status read without spawning it, remote hosts with Host Settings

## Summary

Port the Mac Sessions & Agent page (reads the agent without spawning it: live agent pid first, sessions and build only from a running agent) and the Remote Machines page (read-only status plus Host Settings..., the same prompt as the machine chooser row menu) to the GTK Settings window, through the GTK LocalAgent and whatever T3563 lands for the chooser. win32 counterparts: settings_live.zig, settings_remote_view.zig.

## In plain terms

On Linux, the Settings window's "Sessions & Agent" page did not say whether
the background helper that keeps your shells alive was running, and there was
no "Remote Machines" page at all. Now Sessions & Agent shows whether it runs
(and which build), without starting it just because you looked, and Remote
Machines lists your other machines with an online/offline dot and lets you
set each one's default folder and shell - the same as on the Mac and Windows.

## Goals

- [x] Sessions & Agent shows Status, Running build, This app's agent and Socket, read without starting an agent
- [x] Remote Machines shows the account line and every enrolled machine with its presence and defaults, without waiting on the network
- [x] Host Settings... edits a machine's default folder and shell (Mac's prompt, presets, empty = remote default)
- [x] An acceptance script proves it in the headless harness, with a negative control
