# T2241 - A batched splitter drag at 8 panes misses the two-frame budget (41.6ms a move), with paint at about 21ms of it

## Summary

drag-perf.ps1 section D failed twice on 2026-10-24 (T1350): worst batched mean 38.9-41.6ms against a 33.3ms budget, and the paint term alone was 18.9ms at 2 panes and 21.7ms at 8. On 2026-09-04 a whole 8-pane move was 15.8ms. Both runs were taken while the user had a GPU-heavy game (Valheim) running, which may be all of it - so first re-run drag-perf on an idle box. If paint is still ~20ms, it is a regression since September and the paint term needs breaking down (glass desk, card regions, elevated style all landed since).

## In plain terms

A test in October said that dragging a divider between eight panes was too slow, with drawing taking about 21 ms per move. That measurement was taken while a 3D game was running on the same machine. Measured again on an idle machine, the drag takes about 14.5 ms per move (well inside the 33 ms target) and drawing takes about 1.3 ms. The slowdown was the game, not the terminal. The test now records how busy the graphics card was, so a slow reading taken during a game says so.
