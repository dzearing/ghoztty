# T1630 - When a caught crash is heap-shaped and the dump is mini, say so and offer the full-memory arm right there

## Summary

T808 added crash-catch.ps1 -ArmFull, but it is only discoverable from -Status. The moment it would actually help is the moment a caught crash reports a heap-corruption exception (0xC0000374 and friends) out of a dump that holds no heap: the reader should name that gap and print the one-line offer, so the next occurrence is investigable instead of the investigation ending at 'mini dump, no memory'.
