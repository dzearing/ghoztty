# T3144 - PA-R22/PA-W19: hero mode frees and re-allocates each pane's snapshot landing buffer on every 150 ms capture

## Summary

Audit-3 (T3101), area R, verified at d0d874326. T3001 frees the renderer's landing buffer once the pixels are in the DIB (src/apprt/win32/Surface.zig:2853, freeSnapBufferLocked), and snapRequest re-allocates it when the length differs from 0 (Surface.zig:2664-2672). Hero mode re-captures every 150 ms, so each tile allocates and frees a pane-sized buffer (several MB at 4K) per capture. Fix: keep the buffer while a repeating capture (hero) is active and free it only when hero mode ends, as the one-shot paths already do. Detail: docs/design/perf-audit/audit-3/R-findings.md.
