## In plain terms

Every time a turn touched a test script, it paid a 24-minute check of the
whole test suite before it could finish. Now a turn only checks what it
changed since the last good check, about 13 minutes, or nothing at all when
nothing relevant changed. The two slowest checks, which have never caught
anything in 41 runs, move to one full check each morning. If that morning
check is ever missed, the next turn runs the full check by itself.

## Goals

- [x] The two slow cross-suite audits run once a day, not on every turn.
- [x] A turn's sweep runs only what changed since the floor was last green.
- [x] A shared-library edit, or a missed morning sweep, still forces the full set.
- [x] The morning digest step runs the full sweep and reports it.

## Design (2026-10-15, mechanism-only, so the loop's call)

- `scripts\lib\HarnessFloor.ps1`: rows carry `Tier` (`daily` for
  `test-reach-audit` and `command-resolve-audit`) and `Owns` (files outside
  `test\win32\` only that member reads: `scripts\vt-escape-scan.ps1`).
  `Get-HarnessFloorScope` compares the live fingerprint with
  `temp\harness-floor\verified.json` and answers `current` (nothing changed:
  no run, stamp), `scoped` (every turn member, plus any member whose own
  script or Owns file changed) or `full` (nothing verified, a shared file
  changed, or the last green full sweep is over 26 h old).
- Scoping is by MEMBER, not by file: every turn member still sweeps the whole
  suite, because no audit takes a file subset and the ratchet audits count the
  whole suite. Per-file scanning for the five heavy audits is T1969.
- `scripts\harness-floor.ps1 -Scoped [-PlanOnly]`; a scoped sweep records
  itself (`kind: scoped`) and is completed by a red-rows re-run exactly like a
  full one (T1955), but only a full sweep restarts the daily clock. First run on
  a box bootstraps `verified.json` from a green or completed full-run record.
- `floor-lane.ps1 -Lane harness` runs `-Scoped`; `-HarnessFull` is the daily
  full sweep. The guard row's run line is `-Scoped`.
