# T1893 - suite-run.ps1 crashes with 'Key cannot be null' instead of 'no scripts selected' when -Include matches nothing (an empty selection becomes @($null), count 1)

## Summary

Seen T1848: -Include 'rearrange-drag,...' (no .ps1 suffix) matched nothing, the run printed '1 script(s)' and died at the resume ContainsKey($r.Name) with a null key. The empty-selection guard at line ~995 never fires because @(Remove-ExcludedScript ...) wraps a $null return into a 1-element array. Fix: filter nulls (or return ,@()) and add a negative case to test\win32\suite-run.ps1; consider also matching a bare name without .ps1.
