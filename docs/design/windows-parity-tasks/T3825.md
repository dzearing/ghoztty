# T3825 - Linux L10i: the GTK pane sidebar's edge grip resizes the panel (180..380, tucks into the rail under 120), one width every window shares

## Summary

Split from T3695. docs/reference/pane-sidebar.md Modes: the gutter beside the sidebar is a grip in both modes; dragging it resizes the panel between 180 and 380, pulling the rail's gutter past 180 brings the panel out, pushing it under 120 tucks it back into the rail, all within one drag. The width is shared by every window and persisted with the flags (win32 pane_sidebar_prefs carries it). GTK today has a fixed card width (rows.cardWidth). Seam: a --grip=<x> drag step; headless test of the width, the tuck and the shared value.
