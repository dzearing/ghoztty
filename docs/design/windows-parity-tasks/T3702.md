# T3702 - Linux: a window title pinned from the pane sidebar (a group move, Create Group, the Ungrouped pencil) is not protected from a later script +rename

## Summary

T3608 pins the group title on the GTK tab (Tab.setTitleOverride), or on the window when it carries a window-wide pin, but GTK has no title provenance: a script's +rename sets Window.setTitleOverride, which outranks the tab pin in pane_sidebar_all.name, so a script can rename a window out of the group the user just put it in. win32 records who pinned it (setTitleOverrideBy(.user), T2404) and Mac windowTitleIsUsers refuses a script rename over a user title. Port that provenance to GTK (class/window.zig title_override, the IpcHandlers rename) and extend test/linux/cli-sidebar-groups.sh: group a window from the sidebar, +rename it from the CLI, expect the group title to stay.

## In plain terms

When you put a Linux window into a group from the pane sidebar, its title
becomes `<group>: <name>`. A script could then rename that window and quietly
pull it out of the group you chose. Now a script's rename is refused with a
message naming your title, exactly as on the Mac and Windows; a title a script
set itself can still be renamed by a script.
