# T3142 - PA-R21: a released pane's 1x1 render target is really 256x256 because of the grow-only bucket, and the release log under-reports what it freed

## Summary

Audit-3 (T3101), area R, verified at d0d874326. OpenGL.initTarget passes grow_only on win32 (src/renderer/OpenGL.zig:1343-1350), and Target.capacityFor rounds every side up to grow_bucket = 256 (src/renderer/opengl/Target.zig:34-37), so the 1x1 placeholder a released pane keeps is 256x256x4 = 256 KB, and the release log counts it as freed. Fix: bypass grow_only for the release placeholder (or for sizes under the bucket) and log the real capacity. Detail: docs/design/perf-audit/audit-3/R-findings.md.
