# T3802 - Linux: closing a window with live shells logs five adw_tab_view CRITICALs during its teardown

## Summary

Found by T3665's cli-undo.sh W section: every GTK window destroyed while its panes still run (a plain +close --force, W12, and a parked window's undo expiring, W10) logs, right after 'Destroying EGL context', five 'error(glib): CRITICAL: Adwaita: adw_tab_view_get_n_pages / _get_selected_page: assertion ADW_IS_TAB_VIEW (self) failed' lines: something reads the window's tab view after Window.dispose's disposeTemplate cleared it. Ruled out: removing the window from the GtkApplication before disposeTemplate (no change), and SessionLayout (persistence off in that run). Next: run with G_DEBUG=fatal-criticals under gdb in the harness for the stack. cli-undo.sh P2 tolerates exactly this signature, citing this card; remove that exception when fixed.
