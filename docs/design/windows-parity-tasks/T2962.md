## In plain terms

The background helper that keeps your terminal sessions alive (so they
survive closing the window) and the channel that scripts use to drive the
terminal both cost memory and CPU even when nothing is happening. This task
reads that code closely, finds every place it uses more than it needs or
never gives memory back, and puts each fix in the queue.
