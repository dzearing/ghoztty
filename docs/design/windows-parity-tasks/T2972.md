# T2972 - PA-R06: every drawn frame re-uploads all cell buffers to the GPU, row by row, even when one row changed

## Summary

PA-R06 (audit-1, T2959). generic.zig:1993-1995 syncs uniforms, every bg cell and every fg row list per frame; opengl/buffer.zig:96-119 issues one setSubData per row list (rows + 2 GL calls) and only ever grows (len = total * 2, :108). Dirty-row tracking exists in rebuildCells but the upload ignores it. Cost estimated: ~29 KB bg + up to ~230 KB fg and ~48 GL calls per frame at 160x45. Fix: OpenGL swap_chain_count = 1 (OpenGL.zig:40) means the buffer holds the previous frame, so give each row a fixed slot and upload only dirty rows; skip uniforms when unchanged; cheap interim: one concatenated glBufferSubData. Risk medium: cursor-first/last instance ordering must be kept.
