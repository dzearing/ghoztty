# T1897 - Elevated Windows panes with a per-pane background tint sit in a ring of the config background, because the card fill ignores the tint

## Summary

Follow-up of T1851. paintPaneDesk fills every terminal card with config.background, but a pane given its own tint (Surface.background_tint, the banner already reads it) paints that tint, so its rounded corners and rim show the config colour around it. Set Card.fill from the tint for a solid card; for a glass card decide whether the tint should be the glass tint. Validate with pane-elevation.ps1 and a tinted pane.
