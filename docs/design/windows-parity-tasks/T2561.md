# T2561 - On-screen glide oracle cannot see a strip face: an unfolding card's content is drawn by a layered popup (StripFace) that a window capture never contains, so no film has checked the opening card's picture on either present path

## Summary

Found in T2513: scripts\comp-glide-hold-onscreen.ps1 films the main window with WGC; the opening card reads empty until it lands live on both paths while the log says the face is up (frame=1, content_alpha 0->255). Film the face too - a second --film-hwnd of the StripFace popup composited at its window rect, or a capture of the face's own HWND per frame - and score the opening card's block like the live ones.

## In plain terms

When a pane slides out of (or into) its thin strip, the card's picture during
the slide is drawn by a small separate overlay window. The on-screen film that
checks glides only recorded the main window, so on the two everyday drawing
paths it never actually saw the opening card's picture. Now the film records
the overlay too, and the check fails if the opening or folding card is missing.
