# T2505 - Folded blades are opaque on Windows: on Mac a blade is glass, semi-transparent, so the window gradient reads through it while it folds and once folded. Make Windows blades the same glass, in the same atomic present as the fold (user 2026-10-30: part of the jank)

## Summary

The user watched the T2485 chain-fold runs and reported that the blades are not
glassy or semi-transparent, so the window gradient does not show through them.
They called this part of the jank: the eye reads an opaque slab arriving as a
hard change. The full quote is in the progress log.

Mac draws a folded blade, and a blade mid-fold, as the pane's glass sheet
(GLASS_TINT over the desk gradient; see T2160/T2281, done for strips at rest).
On Windows the blade, and the fold face that hands over to it, comes out opaque
in the chain-fold. Find which surface is opaque: the UpdateLayeredWindow face,
the strip pass, or the composition visual. Make it alpha-composited over the
live desk gradient, and keep it in the same atomic present as the fold (T2485).
A translucent blade drawn in its own pass would bring back the
background-clear flicker the user also reported.

## Validation criteria

- [ ] Per-region capture: a folded blade's pixels track the desk gradient behind it (a blade over two gradient stops differs top to bottom the way the desk does), at rest and on every fold frame
- [ ] Mac side-by-side at the same theme shows the same glass tint within tolerance
- [ ] No frame of the T2485 chain-fold capture shows a blade region at the background-clear colour

Validate by sampling a banner pixel and a blade pixel over the same desk gradient stop - they must match within tolerance.
- 2026-10-30 09:55: User 2026-10-30 ~08:55: "but you can't see each other through them? :) we need to find a good balance of perf and visuals". Controller reading: blades show the DESK GRADIENT through them, not each other or the pane content behind them. So no true alpha stacking of overlapping layers. Each blade is the desk gradient at its own position with the banner glass tint over it. That can be resolved in the desk paint itself (gradient + tint, one pass, same atomic present as the fold) with no per-blade layered window and no back-to-front blending. That is the perf/visuals balance asked for: Mac-like glass, no extra composition cost, and no out-of-order pass to bring the T2485 flicker back. If a blade overlaps another mid-fold, the front blade covers the one behind it rather than showing it through. Record the per-fold frame time before and after; it must not rise.
