# T2454 - A fold-glide frame on a 4K window still costs ~22 ms in release after T2450: every pass copies the whole desk, refills every card interior and BitBlts the whole window, though only the cards beside the dragged divider changed

## In plain terms

Dragging a divider so panes fold away glides smoothly on an ordinary window
now, but on a very large (4K) window each frame of the glide still takes longer
than one screen refresh, so it steps. The app redraws the whole window's
background and every pane's backing on each frame, even though only the panes
next to the divider moved.

## Summary

Split from T2450 (2026-10-29), which made the card shadows cheap (bench: 19.7 ms
-> ~0.5 ms at 3800x2050 @2x; 5.0 -> ~0.1 ms at 1x). What is left of a desk paint
at 4K is full-window work done on every pass:

- `PaneDesk.paint`: `@memcpy(comp, desk)` over the whole window (~1.7 ms at 4K);
- `pane_elevation.paintCards`' card pass: a `memset` of every solid card's whole
  interior (~3.9 ms at 4K in the bench), though an opaque pane child window
  covers almost all of it and the parent is clipped there anyway;
- `blit`: a `BitBlt` of the whole content area.

Measured with the T2450 glide probe (5 panes in a row, a viewer second, the first
divider dragged 720 DIP out and back on the background test desktop, release
build in a `-ReleaseSandbox`), window 3800x2050 px @1.25: `divider drag`
`mean_paint_us` 20791 -> 13032 across T2450, `divider glide` `mean_us` 31756 ->
22589. At 1875x1125 the glide went from `late=41 fps=53` to `late=5 fps=59`, so
`late=0` (T2448's carried criterion) is still not met there either.

Directions: (b) from T2450 - recompose and blit only the rects of cards whose
geometry changed (old and new bbox plus shadow reach), keeping `comp` between
passes; and skip filling a solid card's interior that its child window covers
(the rim band and the corners still need it). Profile the 5 late ticks at
1875x1125 first: if they coincide with `viewer_ticks`, the viewer is the cost.

The probe is `glide-probe.ps1` in the T2450 session scratchpad; T2451 is the
harness that should own this shape permanently.

## Goals

- [x] a divider-drag frame recomposes only the bands round the card and strip
      edges that moved, not the whole desk
- [x] the per-pixel costs that still ran over those bands (the gutter bar's
      four `erf`s a pixel, a gliding card's blade shadow over its whole
      interior, the shadow patch rebuilt per rectangle) cut to table lookups
- [x] the layout pass blits only what changed (plus whatever the window holds
      invalid), not the whole content area
- [ ] `late=0` at 1875x1125 - one late frame in ~650 is left: split to T2455

## What landed

- `PaneDesk`: `comp` is kept between paints; `Memo.dirty` diffs the inputs
  into up to 24 rectangles - for a big card or a gliding strip, a band from
  `pane_elevation.edgeInnerPx` inside each moved edge to the furthest reach
  outside it (all four when its shadow strength or collapse changed), else its
  whole box - and `composeRects` composes each in a scratch buffer with the
  geometry moved into it. Lights' rings are lifted off first and re-based
  after. `.full` on a size, desk, style or count change, or past 3/4 of the
  window.
- `pane_elevation.prepare`/`paintCardsWith`: the shadow's corner patch is
  built once per style (was ~0.1-0.3 ms per call, so per rectangle).
- `blade_shadow.paint`: skips the masked interior, and takes each straight
  side's alpha from a per-column/per-row table.
- `gutter_bar.paint`: column terms once, row terms per row, in `alphaAt`'s own
  order.
- `Window`: the layout pass and `repaintPaneDesk` set
  `pane_desk.blit_changed_only`; the desk then blits its rectangles, every
  light's strips and the window's current update box (`GetUpdateRect`, read
  just before the desk paint) - so the full `ValidateRect` after the pass
  still covers nothing it did not paint. A hero tab blits whole as before.
- `divider glide` line gains `desk_partial`, `desk_compose_us`,
  `desk_blit_us`, `desk_partial_permille`.

- [x] `mean_paint_us` at 3800x2050 under 4 ms, before/after numbers recorded - `divider drag mean_paint_us` 13032 (T2450's after-number on this code) -> 3811 / 3899; `desk_compose_us` ~7.7 ms (first partial build) -> 2.6-2.7 ms, `desk_blit_us` ~2.0 -> 0.6-0.7 ms. Release `-ReleaseSandbox` glide probe on the background test desktop
- [x] pane_elevation / PaneDesk pixel tests unchanged - the existing pane_elevation, blade_shadow and gutter_bar tests pass unchanged; new bit-exact tests: partial compose == whole compose (9 glide shapes x glass/solid x 1x/1.5x, a lit ring), blade tables == the per-pixel reference (540 shapes, Debug and ReleaseFast), gutter-bar tables == `alphaAt` per pixel (both modes).
