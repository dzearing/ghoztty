# T2454 - A fold-glide frame on a 4K window still costs ~22 ms in release after T2450: every pass copies the whole desk, refills every card interior and BitBlts the whole window, though only the cards beside the dragged divider changed

## In plain terms

Dragging a divider so panes fold away glides smoothly on an ordinary window
now, but on a very large (4K) window each frame of the glide still takes longer
than one screen refresh, so it steps. The app redraws the whole window's
background and every pane's backing on each frame, even though only the panes
next to the divider moved.

## Summary

Split from T2450 (2026-10-29), which made the card shadows cheap (bench: 19.7 ms
-> ~0.5 ms at 3800x2050 @2x; 5.0 -> ~0.1 ms at 1x). What is left of a desk paint
at 4K is full-window work done on every pass:

- `PaneDesk.paint`: `@memcpy(comp, desk)` over the whole window (~1.7 ms at 4K);
- `pane_elevation.paintCards`' card pass: a `memset` of every solid card's whole
  interior (~3.9 ms at 4K in the bench), though an opaque pane child window
  covers almost all of it and the parent is clipped there anyway;
- `blit`: a `BitBlt` of the whole content area.

Measured with the T2450 glide probe (5 panes in a row, a viewer second, the first
divider dragged 720 DIP out and back on the background test desktop, release
build in a `-ReleaseSandbox`), window 3800x2050 px @1.25: `divider drag`
`mean_paint_us` 20791 -> 13032 across T2450, `divider glide` `mean_us` 31756 ->
22589. At 1875x1125 the glide went from `late=41 fps=53` to `late=5 fps=59`, so
`late=0` (T2448's carried criterion) is still not met there either.

Directions: (b) from T2450 - recompose and blit only the rects of cards whose
geometry changed (old and new bbox plus shadow reach), keeping `comp` between
passes; and skip filling a solid card's interior that its child window covers
(the rim band and the corners still need it). Profile the 5 late ticks at
1875x1125 first: if they coincide with `viewer_ticks`, the viewer is the cost.

The probe is `glide-probe.ps1` in the T2450 session scratchpad; T2451 is the
harness that should own this shape permanently.

## Validation criteria

- [ ] `divider glide` (GHOZTTY_PERF) on the probe's folding row with a viewer pane, release build: `late=0` at 1875x1125 and the mean glide tick under one 60 Hz period at 3800x2050
- [ ] `mean_paint_us` at 3800x2050 under 4 ms, before/after numbers recorded
- [ ] pane_elevation / PaneDesk pixel tests unchanged
