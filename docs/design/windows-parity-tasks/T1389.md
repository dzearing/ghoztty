# T1389 - Nothing catches a ninth hand-written font size appearing outside the type ramp

## Summary

T310 counted seven copies of `px(15, scale)` and T313 retired them; T583 then found an EIGHTH that the sweep had walked straight past because it was spelled differently (`const FONT_H: f32 = 15.0`), and it sat on the most-looked-at surface in the app for three weeks. The lesson is not that the count was wrong, it is that the count was a one-time grep. Nothing today would notice a ninth. Add a check that fails when a win32 UI module names a font height that `type_ramp` does not - a source scan in the none lane over `src/apprt/win32/*.zig` for `CreateFontW` heights and float/int size constants, with an explicit allowlist for the deliberate exceptions (the terminal font, Consolas code spans) so an exception has to be declared rather than merely existing.

## In plain terms

Ghoztty's dialogs share three text sizes. Twice now a stray, hand-picked size
slipped past a one-off search and stayed on screen for weeks. This adds a check
that runs whenever the Windows UI code changes and fails the moment a new
hand-picked size appears, unless someone writes down why it is allowed.

## Goals

- [x] A sweep that finds hand-written font heights in every win32 module (literal `CreateFontW` heights and font-named size constants), judged against the sizes read out of `type_ramp.zig`
- [x] A deliberate exception must be declared with a reason; a declared exception whose site is gone fails the run
- [x] It re-runs on any edit to the win32 frontend (guard row `type-ramp`)
- [x] The off-ramp sites it found today are either declared exceptions or filed (T2885)

## Design note

The Summary asked for a source scan in the `none` zig lane. It landed as a
`test\win32` source audit instead (`type-ramp-audit.ps1` +
`lib\TypeRampAudit.ps1`), the same shape as `tree-swap-audit.ps1`: a Zig test
cannot enumerate the module directory without depending on the runner's cwd,
and a hand-listed `@embedFile` set is exactly the one-time count this task
exists to retire (a NEW module would be outside it). The guard row covers
`src\apprt\win32\*.zig`, so the check is tied to every edit of the code it
reads, and `validate` refuses a commit while it is due.

The Summary's example exceptions turned out not to be sites: the terminal font
is built by the core font stack, not `CreateFontW`, and the banner's Consolas
code spans take their height from the ramp-anchored banner scale. What the
first sweep actually found: a face-presence probe (`icon_button_paint`, never
drawn), the drag ghost's Mac-matching 10 pt title, and the find bar / palette /
link preview sizes in `Surface.zig` (13 and 16, filed as T2885). Four
hand-written sizes that equal a ramp size are reported as `hand-ramp`
(informational) and also listed on T2885.
