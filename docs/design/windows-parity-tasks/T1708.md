# T1708 - Re-point viewer-feedback-carousel.ps1 from the RichEdit fallback to the web composer

## Summary

viewer-feedback-carousel.ps1 reads chips out of the RichEdit and presses Backspace/Tab into it before driving the carousel keys on the band. Move the chip oracle and the page-side keys (Backspace beside a chip, Tab out of the box) onto the web page; the band-side Home/End/Left/Enter stay window messages. Split out of T1703, which landed the pattern on viewer-feedback-alpha.ps1: arm ONE DevTools port per script with Enable-WebViewCdp before the first launch, open the composer, Find-CdpComposer (pass -Exclude for pages an earlier app used), then type with Send-CdpComposerText / Send-CdpKey, paste pictures with Send-CdpComposerImage, and read back with Get-/Wait-CdpComposerText (test\win32\lib\WebViewCdp.ps1). Chords NATIVE owns (Ctrl+Enter, Esc) still go through the band's window messages. Assert Wait-ComposerSurface 'web' instead of pinning 'richedit'. When done the script no longer calls Set-ComposerSurface 'richedit' or reads a RichEdit50W, which is what T1704 needs before it deletes the fallback.

## In plain terms

The test for the row of picture thumbnails under the feedback box was still
exercising an old hidden text box that users never see. It now drives the real
feedback box, so a thumbnail bug users could hit is one the test can catch, and
the old hidden box can be deleted.

## Goals

- [x] Pictures are pasted into the real (web) feedback box, and its text is read back from that page
- [x] Keys that belong to the text (Backspace beside a picture, Tab out of the box) go to the page; the strip's own keys stay on the band
- [x] Nothing in the script asks for or looks for the old RichEdit box

## Validation criteria

- [x] The script no longer asks for the RichEdit fallback and asserts the composer opened on the web surface -- `Set-ComposerSurface 'richedit'` and the RichEdit50W lookup are gone; the run asserts `Wait-ComposerSurface 'web'` (PASS, got 'web')
- [x] Every editing arm drives the web page (or is retired with its replacement coverage named) -- pastes via Send-CdpComposerImage, chip reads via Wait-/Get-CdpComposerText, Backspace via Send-CdpKey, Tab out as WM_APP_COMPOSER_CHORD; Home/End/Left/Enter stay band window messages (strip holds focus). No arm retired.
- [x] The script runs ALL PASS on the box -- `test\win32\viewer-feedback-carousel.ps1` ALL PASS (59) on the fresh Debug build, first run
