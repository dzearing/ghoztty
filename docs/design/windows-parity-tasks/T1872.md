# T1872 - Ctrl+C in an image viewer pane copies the picture to the clipboard (Mac 1d513083a, split from T1803)

## Summary

Mac's image pane copies the image on Cmd-C (ViewerImageView, commit 1d513083a). On Windows an image pane is a WebView2 page and Ctrl+C with nothing selected copies nothing. Translation: claim ctrl+c in an image-mode ViewerPane (viewer_accel pane chord, image mode only), decode the file with WIC and put CF_DIBV5 + PNG on the clipboard. Validation: a test-desktop script presses ctrl+c at an image pane and reads the clipboard's image dimensions back.

## Validation criteria

- [ ] Ctrl+C at a focused image pane puts the image on the clipboard (dimensions read back by a test-desktop script).
- [ ] Ctrl+C in a markdown/website pane is unchanged (the page's own copy).
