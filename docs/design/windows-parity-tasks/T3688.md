# T3688 - Lift tab-strip's Resize-AndSettle and Wait-LaunchedTop into a shared test lib so the sleep conversions stop re-writing them

## Summary

T2180 converted tab-strip.ps1 by adding two local helpers: Wait-LaunchedTop (Wait-TestWindow, naming a dead GUI) in place of 'Start-Sleep -Seconds 4' after Start-OnTestDesktop, and Resize-AndSettle (window rect reaches the requested size, the pane child leaves its pre-resize rect and holds it for QuietMs) in place of 'Set-TestWindowSize; Start-Sleep 1200'. That launch/resize/sleep pair recurs in dozens of harnesses (caption-bar, chrome-merged-row, close-glyph-white, chrome-paint-clip, close-confirm-idle, comp-chrome, ...) and in the nine T3679-T3687 conversion cards. Move both into a small test\win32\lib file with a guard-due row and LIB COVERAGE, point tab-strip at it, and name it in T3679-T3687 so each conversion reuses it.
