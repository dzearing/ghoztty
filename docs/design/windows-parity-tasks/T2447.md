# T2447 - A window's busy rolls up: a folded window row and every window rail tile sheen while any of its panes (stashed included) is working - Mac 9e2e2902a

## Summary

Mac 9e2e2902a (PaneSidebarWindowActivity per window, PaneSidebarWindowHeader.showsBusy, tests PaneSidebarWindowRollUpTests). Open window rows do not sheen (the busy pane row under them already does). Same sheen as a pane's; only that row redraws.

## In plain terms

When a pane is busy, its row in the sidebar shimmers. But fold a window's
list away, or collapse the all-windows sidebar to its rail of window tiles,
and that shimmer disappeared with the pane. Now a folded window's row and a
window's rail tile shimmer whenever any of that window's panes is working,
including put-away (stashed) ones, the same way the Mac does.

## Goals

- [x] A window's busy is rolled up from all its panes (stashed included, and panes a search hides)
- [x] A folded window's header sheens with it; open, it does not (the pane's own row does)
- [x] Every window rail tile sheens while its window is busy
- [x] Only those pills repaint each frame, and the sheen fades in/out on its own (not shared with a pane's)
