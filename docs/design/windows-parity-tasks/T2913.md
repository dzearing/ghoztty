# T2913 - Git-status diff viewers and animated images pause in hidden windows on Windows: no polling or GIF frames while covered or minimized, one catch-up when shown (port of Mac 68a8344f0, split from T2909)

## Summary

Part (5) of the Mac 68a8344f0 port, split from T2909. Mac: ViewerView.startWatchingDiff skips the git-status: poll while the window cannot be seen and refreshes once when shown; ViewerImageView.advanceFrame stops an animated image on its frame and goes on when shown. Windows: the git-status poll lives around ViewerPane.zig / viewer_diff.zig / ViewerDiffProbe.zig, GIF playback in the viewer image path (gdiplus_decode.zig). Gate both on the window being seen (Window.occluded / minimized; ViewerPane.setVisible already gets hidden state from applyOcclusion), with one catch-up on reveal. Live web pages need nothing (WebView2 throttles occluded pages itself). Acceptance: a covered git-status viewer runs no git while covered and shows a change made meanwhile within a poll of being revealed; a covered GIF stops advancing.
