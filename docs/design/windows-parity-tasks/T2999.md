# T2999 - PA-W15: a failed terminal pane init leaks its two event handles, and the new-tab path also leaks the Surface (Surface.zig:904, Window.zig:3893)

## Summary

PA-W15 (audit-1, T2960). Surface.initOnce creates frame_event and swap_release (Surface.zig:904, :907) with no errdefer closing them (the first errdefer, :955, covers only the HWND), and the retry re-assigns self.* (:891) over them. Window.zig:3893-3894 `const surface = try alloc.create(Surface); try surface.init(...)` has no destroy on failure, unlike the sibling callers (:4309, :16796). Failure path only: 2 handles (+1 Surface) per failed pane creation. Fix: errdefer CloseHandle for both events and errdefer alloc.destroy(surface) at :3893. Risk none.

## Validation criteria

- [ ] a unit or fault-injection test fails initOnce after the events are created and asserts they are closed
- [ ] none and win32 lanes green
