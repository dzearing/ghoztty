# T1548 - Activity Monitor rows have no hover detail: Name, %CPU, Window / Pane and Path carry no tooltip

## Summary

Mac puts a .help() on every process-table cell (RemoteActivityMonitorView.swift:1082-1142): the Name cell shows the full command, the Path cell the whole path, and the Window / Pane cell a multi-line detail naming the window, the pane, its position, its directory and its tty. The win32 panel has no tooltip infrastructure at all, so a truncated cell simply loses that information. T709 ported the Window / Pane column and deliberately left the detail string behind, since building the first row tooltip in this panel is its own piece of work; PaneAttribution.detail is the text to port once there is somewhere to put it.
