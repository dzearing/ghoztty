# T3799 - Linux AppImage: the session agent runs from the FUSE mount, which disappears when the app exits

## Summary

In an AppImage launch LocalAgent.spawnDetached starts the agent from the app's own binary path, /tmp/.mount_*/usr/bin/..., and the AppImage runtime unmounts that when the app process exits. An agent outliving the app (the point of session persistence) then faults on its next page-in, and the agent autostart unit (T3398) would name a path that does not exist after logout. Decide how the agent survives (copy the agent binary and its few libraries to a per-version dir under ~/.local/share/ghoztty/appimage/<sha>/ on first launch and run it from there, or have AppRun refuse persistence with a clear message), and prove it in test/linux/package-appimage.sh: quit the app, the agent and its panes live, relaunch re-attaches. Also: a CLI verb run through the AppImage that starts the GUI would run it from the verb's short-lived mount.
