# T3593 - tab-strip, pane-banner and resize-flicker still SKIP a silent debug oracle as 'release build?', so a probe that missed passes; key the skip on the exe's build mode like tab-tooltip (T1920)

## Summary

T1920 fixed tab-tooltip.ps1: it now reads the build mode from the exe (Assert-GhozttyIsolatedBuild / +version) and only a non-Debug build may skip the oracle arms; a Debug build whose probe logs nothing FAILs and names where it aimed. The same defect stands in three more harnesses, at these sites: tab-strip.ps1 (T204 hover trigger ~1130, T737 freeze oracle ~1729), pane-banner.ps1 (Note-Skip at ~713, ~760, ~988, ~1120, ~1602, ~1957) and resize-flicker.ps1 (surface erase ~355, divider drag ~437, window resize ~706). Each says 'release build?' and skips when the oracle line is missing, which on a Debug build means the probe missed. Fix: capture the mode once, skip only when it is not Debug, otherwise Assert false with the probe's coordinates. Validation: each harness green on Debug, plus a -NegativeControl (or equivalent forced miss) run per harness that goes red. drag-glide, drag-perf and frame-clock already throw on a missing oracle, so they are out of scope.
