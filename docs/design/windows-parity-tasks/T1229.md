# T1229 - Soak runs leave their sandbox directories in TEMP forever

## In plain terms

The long-running stress tests build a throwaway workspace on disk and then never
delete it. Ten of them are still sitting there, the oldest from mid-July, each a
full copy of a terminal's state directory. Nothing about a test run should still
be on the disk six weeks later.

It turned out to be every isolated test, not just the stress tests: 188
throwaway workspaces were on disk. Each run now deletes its own when it ends,
even when it crashes half way, and the next test run sweeps up after one that
was killed outright.

## Goals

- [x] an isolated run deletes its sandbox when it exits, throw included
- [x] a killed run's sandbox is collected by the next clean slate, never a live run's
- [x] the standing sweep names what is left and must read zero
- [x] soak reports are kept, but only the newest 20 run directories

## Summary

Ten ghoztty-soak sandbox trees dated back to 2026-07-16 are still on disk under %TEMP%\ghoztty-soak. Same class of litter as T1168 - a run's private state outliving the run - but on the filesystem, and no sweep looks for it either. The registry half is now guarded by harness-process-leak.ps1 section R; the file half has nothing. A soak run should remove its own sandbox on the way out, and the standing sweep should be able to name what is left.

## Validation criteria

- [x] A `-ReleaseSandbox` run that throws mid-run leaves no sandbox behind - S11 of `test\win32\harness-process-leak.ps1` (child process through the real `Set-GhozttyTestIsolation`), with S12 as its teeth (`GHOZTTY_TEST_KEEP_SANDBOX=1` keeps it).
- [x] The sweep takes only dead-owner sandboxes: live owner kept (S1), exited owner and reused pid taken (S2/S3), unmarked legacy dir kept while recent and taken after a day (S4/S5), sweep names and removes exactly those (S6-S8), collects a kept sandbox once its owner is gone (S13).
- [x] The delete never walks into a junction and refuses %TEMP% itself (S9/S10).
- [x] Standing arm: S14 swept 145 leaked sandbox dirs on this box on 2026-10-22, then read 0 left. Run: `acceptance-parallel.ps1 run -Scripts harness-process-leak.ps1` ALL PASS (57 assertions).
- [x] The clean slate (`Reset-GhozttyTestState`) runs the same sweep as its crash backstop and reports `SandboxesSwept`.
