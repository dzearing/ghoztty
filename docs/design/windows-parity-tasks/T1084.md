# T1084 - split-dim.ps1 has two red overlay-color assertions: the pixel probe returns nothing at all

## In plain terms

One of the test scripts checks that the dimming overlay over an inactive split
paints the right color. That check has stopped working: it reads no color at
all - not the wrong color, nothing - so the script has been reporting two
failures every run. Nothing about the dimming feature is being measured.

## Summary

`test\win32\split-dim.ps1` scores `2 FAILED / 27 passed`, deterministically:

```
FAIL  default: overlay paints the background color #101014 (got )
FAIL  custom:  overlay paints the configured fill #ff0000 (want 255,0,0, got )
```

The `got` is EMPTY, which is the tell: the probe returned no pixel rather than a
wrong one. Confirmed **pre-existing** during T351 by running the file as it
stands at `HEAD` (before that sweep touched it) twice - identical two failures -
so it is not fallout from the CleanSlate conversion.

The likely cause is the layered-overlay pixel-probe path: `GetPixel` skips
layered windows, and `CopyFromScreen` is dead on the background test desktop the
harness now runs on (T267 / TestDesktop). Whichever it is, an empty reading must
fail LOUDLY as "the probe did not run" rather than as "the color is wrong" - the
two need different fixes and the current message points at the wrong one.

## Goals

- [x] confirm whether the two red colour assertions still reproduce
- [x] make an empty reading fail as "the probe did not run", never as a wrong colour

- [x] the negative control still turns the color assertions over -

      `custom: ... (want 16,16,20, got 255,0,0)`

## Resolution

The empty reading itself was already fixed by T1283 (76da6337f, 2026-09-02):
the uniform-bitmap guard refused the single-colour overlay capture, the probe
caught the throw and returned nothing. `-Sync -AllowUniform` on the probe fixed
it. What T1283 left was this task's second half: an empty `$fill` still printed
as `got ''` against a colour, the message that sent two tasks after the wrong
cause. That now fails under its own label.
