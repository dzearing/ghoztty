# T3659 - The stranded-commit threshold counts Linux-only and chore commits, so Windows releases are cut for work that changes nothing in the Windows build

## Summary

daily-publish.ps1's T1588 stranded threshold (30) counts every commit behind the last release. On 2026-11-23/24 lane L's WIP and Linux-only commits (src/apprt/gtk, test/linux, scripts/linux) plus chore/stamp commits pushed it over twice (win-v1.56.19 at 22:49, win-v1.56.20 at 04:14), and eight Windows releases went out in 24 hours - each one an update offer in the user's terminal, several carrying nothing a Windows user can see. Count only commits that touch what the Windows release builds (exclude src/apprt/gtk/, test/linux/, scripts/linux/, docs-only and chore(guard)/stamp commits), and say in the REQUESTED line how many of the counted commits were Windows-relevant. Acceptance: a new section in test\win32\daily-publish.ps1 with 40 Linux-only commits behind a release stays under the threshold, and 30 win32 commits still trip it.
