# T2248 - Nothing stops a new acceptance oracle from sleeping a flat interval between input and a pixel capture

## Summary

T1372 converted every acceptance site that posted input, slept a flat interval
and then asserted on a capture (six of them; the table is in T1372.md), and
added `test\win32\lib\PaintWait.ps1`'s `Wait-TestPaint` as the replacement.
That was a hand sweep (input within 4 lines before a `Start-Sleep`, a pixel
capture within 5 after), and a hand sweep says nothing about the next script.

Turn the sweep into a ratcheted audit in the house shape (cf.
pixel-oracle-audit, click-coord-audit): an analyzer in `test\win32\lib\`, run
against fixtures in both directions; a NEGATIVE control (a pre-T1372 file read
from git is flagged, the file as it stands now is not); an exemption marker that
needs a reason, for a sleep before a NEGATIVE claim (nothing arriving is the
claim - activity-monitor J's band-click control is the standing example); and a
guard row plus a harness-floor membership so a new site fails the commit.
