# T2512 - Composition step 2b-ii: 9-pane glide on screen with the composition present - 0 torn/blank pane frames (WGC frame stream of an opaque bottom ghost), knob off recorded beside it

## Summary

T2488 built the on-screen oracle (`scripts\comp-present-onscreen.ps1`: an opaque bottom-of-z-order ghost window, a Windows.Graphics.Capture whole-frame grab via `ghoztty-comp-spike --grab-hwnd`, and capture-pane glyph agreement) and proved one STILL frame right way up and glyph-equal on both present paths. Left: stream WGC frames through a 9-pane glide (a split or sidebar drag driven over IPC, never the real pointer) and score every pane region of every frame for blank or torn, with GHOZTTY_COMP_PRESENT on, and the same run with it off recorded beside it. `GHOZTTY_TEST_NO_OCCLUSION=1` is needed, as in the T2488 script.

## In plain terms

The new, smoother way of drawing terminals had only been checked on screen
with everything standing still. This films nine terminals while a divider is
dragged between them and checks every single frame: no terminal ever shows up
empty or split in two. The old drawing path is filmed the same way beside it
for comparison, and it does show a glitch the new one does not.

## What landed

`scripts\comp-present-glide.ps1`. The app runs as an opaque ghost window at
the bottom of the z-order on the input desktop (`GHOZTTY_DEBUG_GHOST=bottom`,
`GHOZTTY_TEST_NO_OCCLUSION=1`). It has nine named panes, each running a
one-line cmd script that fills its grid with its own solid colour, and a
`+rearrange` puts them in an even 3x3 grid (1500x900, so no column folds into
strips). Two divider drags (the root column divider, and a row divider in the
first column) are POSTED to the window as mouse messages. `Send-TestMouse` is
not used, because it calls `SetCursorPos` and on the input desktop that would
move the user's cursor. `ghoztty-comp-spike --film-hwnd` records every frame
DWM composes. Per frame, per pane colour:
blank = under half the settled frame's area; torn = the left edge spreads more
than 4 px across rows, or more than 2 rows are missing inside the region (the
left edge holds still under a resize whether or not the shell repainted).
Motion is proven by distinct pane layouts on film: a drag HOLDS the terminals'
size and moves the cards, so the panes' sizes alone do not change.
`-ScoreOnly` re-scores kept films; `-NegativeControl` blanks pane 5 and tears
pane 7 on alternating frames.
