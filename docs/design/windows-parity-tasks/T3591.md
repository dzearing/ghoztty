# T3591 - Linux: a parked (closed, undoable) pane whose shell exits is let go at once, not brought back dead by Ctrl+Shift+Z

## Summary

T3384's src/apprt/gtk/CloseUndo.zig parks a closed pane with its surface handlers disconnected (it is out of the split tree), so if its shell exits during undo-timeout nothing notices: the entry waits for the expiry and an undo in the meantime puts back a pane whose process has already exited. win32 lets it go at once (LayoutUndo.paneGone / CloseUndo's child-exit path). Port: watch a parked surface's child exit (or check core().child_exited on undo) and finalize that entry, then try the next. Extend test/linux/cli-undo.sh: close a pane, kill its shell, undo, assert the pane does not come back.
