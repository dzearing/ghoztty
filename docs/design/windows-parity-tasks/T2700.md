# T2700 - Settings Appearance > Theme's Use row lacks Mac's row accessories: no (i) doc toggle and no Reset beside 'Use' (Mac SettingRowAccessories key theme), so the theme can only be reset from Advanced

## Summary

Mac's ThemeSection labels its `Use` row with `SettingRowAccessories(model: model, key: "theme", ...)`: the modified dot, the (i) that opens the key's documentation, and Reset, shown on hover like every curated row. Windows' Theme section (T2586, re-painted as the tile grid in T2682) draws `Use` as a bare label, so the theme's doc is not reachable from Appearance and resetting it means finding `theme` under Advanced. Reuse `paintRow`'s accessory buttons (`iconButton` with `.info` / `.reset` keyed `theme`) beside the Use label, and the doc block under it when toggled. Validation: settings-window.ps1 K clicks the painted `reset:theme` and `info:theme` hits on Appearance.
