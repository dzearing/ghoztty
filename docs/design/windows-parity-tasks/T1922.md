# T1922 - Watch an elevated divider drag on the real desktop: the card corners must stay clean now that the region cut skips its redraw (T1906 left this NOT RUN)

## Summary

T1906 moved `applyCardRegions` ahead of the desk paint in `layoutSplits` and
dropped `SetWindowRgn`'s redraw for the elevated style (41 ms -> 0.6 ms a
mouse move). Correctness rests on the desk paint (`GetDC` on the
`WS_CLIPCHILDREN` parent) painting the corners a re-cut region gives back.
The test desktop cannot observe it: its capture re-renders the window rather
than reading the composite, and it scored the broken order (cut after paint,
no redraw) green as well. Needs eyes, or a probe of the live DWM composite, on
the user's desktop - which the focus rule forbids while the user is present.

## Validation criteria

- [ ] On the input desktop (user away, or the user does it), drag a divider
      between two elevated cards slowly, then fast, both ways: no square,
      stale or terminal-coloured corner pixels appear mid-drag or after.
- [ ] Same with a pane that has a rearrange header and one with a banner.
