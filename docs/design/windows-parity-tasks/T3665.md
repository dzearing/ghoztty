# T3665 - Linux: closing a window (or its last tab) can be undone, as on Mac and Windows

## Summary

T3590 made a closed TAB undoable on Linux (src/apprt/gtk/CloseUndo.zig). Closing a whole window, or the last tab of a window (which closes it), still ends every pane at once. win32 T1874 parks the window hidden and out of App.windows under the shared owner key so any other window's undo reaches it; the last window is never parked. Port: hide the GTK window and keep it out of +list/targeting/sidebars while parked, park under a shared owner, restore on undo, extend test/linux/cli-undo.sh.

## In plain terms

On Linux, closing a whole window (or its last tab, or its last pane) used to
end every shell in it at once. Now, for a few seconds afterwards, pressing
Ctrl+Shift+Z in any other open window brings the closed window back with the
same shells still running, and Ctrl+Shift+Y closes it again. Mac and Windows
already work this way. The last window open still closes for good, because
nothing would be left on screen to press undo in.

## Goals

- [x] A closed window waits, hidden and out of every list, with its shells alive
- [x] Any other window's undo brings it back; redo closes it again
- [x] Its last tab or last pane closing parks the window whole
- [x] The undo expiring ends its shells; `+close --force` never parks
- [x] The last window, the quick terminal and single-window-mode workspaces (T3790) are not parked
