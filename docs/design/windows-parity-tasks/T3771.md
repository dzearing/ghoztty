# T3771 - A wsl:<distro> --shell sent to a REMOTE window's agent is not expanded: the remote agent is asked to run 'wsl:Ubuntu' as a program

## Summary

Carried from T3749 via T3754. IpcHandlers sends nonEmpty(args.shell) verbatim on the remote_dialed branches (+new-window --from-focused, +split in a remote window), so a wsl:<distro> spec reaches a remote agent unexpanded. Decide by machine: a Windows remote agent should get wsl.exe -d <distro> --cd ~ (verb_args.wslInteractiveArgv), a non-Windows one should be refused with a clear error before anything opens. Acceptance: a remote-window +split --shell=wsl:X against the fake relay/agent harness asserts the OPEN carries wsl.exe, never wsl:X.
