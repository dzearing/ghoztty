# T2173 - Typing 'agent' in the Windows command palette puts 'Restart Ghoztty and Background Sessions' above 'Set Up Agent Integrations…': keyword-only matches sort in alphabetically with title matches

## Summary

Since T1804 the palette also matches a command's hidden keywords, and matches are listed alphabetically, so a row found only by a keyword can outrank a row whose title contains the query. 'agent' selects the restart row first; Enter on it starts a restart flow. Mac filters titles only (CommandPalette.swift filteredOptions) and has no keywords, so this ordering is Windows-only. Rank title matches above keyword-only matches (keep alphabetical within each band), with a none-lane test in commands.zig/palette_order.zig. Found by T2171.

## Validation criteria

- [ ] Typing `agent` in the palette selects "Set Up Agent Integrations…" first; "Restart Ghoztty and Background Sessions" is still listed below it.
- [ ] Typing `relaunch` still finds both Restart rows (keywords keep working).
- [ ] A none-lane unit test pins title-match-before-keyword-match ordering.
