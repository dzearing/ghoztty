Mac 321e61d7c measured 40 windows / a dozen busy panes: the shimmer and question ring re-ran the whole sidebar update every frame (86-99% of a core idle, 31-50ms a scroll step), fixed by moving both onto Core Animation (<1% idle, ~8ms a step). Windows draws the shimmer/badge in pane_sidebar_motion.zig; measure the same scenario (idle CPU, scroll-step cost) and fix if it repaints the whole list per frame or recomputes drop targets while scrolling.
