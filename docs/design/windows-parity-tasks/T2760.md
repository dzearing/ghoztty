# T2760 - agent-integrations.ps1 canary went red once (T2749 due sweep, alone re-run 2026-11-06 ~11:52) and nothing on disk now says which user surface moved: make the canary diff its manifest and name the changed paths, then decide whether the path is volatile (e.g. ~/.copilot) or a real leak

## In plain terms

One of our tests checks that running it never touches your real Claude and Copilot settings. Three times on 2026-11-06 that check said "something changed" but could not say what, so nobody could tell a real leak from a false alarm. Now it names every file that moved. It also stops watching a folder that Claude Code rewrites by itself every few minutes, which is what tripped it.

## Goals

- [x] a red canary names the paths that moved (added / removed / changed), not one opaque hash
- [x] the diff is proven able to speak (doctored-manifest self-check inside the harness)
- [x] decide volatile vs leak: `~\.claude\skills\synced\` is Claude Code's own cloud-skill sync cache; excluded

## Summary

`Get-CanaryManifest` (test/win32/agent-integrations.ps1) hashed path|length|mtime over the real user's integration surfaces and compared one SHA, so a mismatch said nothing. It now returns the manifest lines, and `Compare-CanaryManifest` prints `canary moved: + / - / ~ <path>` for each difference before the assert.

Volatile vs leak: at claim time `~\.claude\skills\synced\<id>\manifest.json` and `.last-complete-round` had been rewritten at 09:45:52, four minutes before any test ran. That subtree is Claude Code's cloud-skill sync cache, rewritten on its own schedule, and no Ghoztty source writes it (searched `src/` for `synced` and `last-complete-round`: no writer; the installer writes NAMED skill dirs beside it, and those stay watched). The slower alone re-run (59s vs 39s) is more likely to straddle a sync round, which matches all three sightings being alone-only. This is an INFERENCE: the 2026-11-06 runs predate the diff, so the mover was never named. If the canary goes red again, the log now names the path; anything outside `synced` is a real finding.
