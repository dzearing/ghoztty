# T1561 - float-on-top.ps1 reads a pane id from a +list --json field that does not exist, so section B always falls back

## In plain terms

One of our test scripts tries to find out which terminal pane it is looking at,
asks the app for the answer, and reads the reply out of a box that has never
existed. It then quietly guesses instead. The test still passes, because the
guess happens to work - which is the problem: nobody has checked in a long time
whether it is measuring the thing it says it measures.

## Summary

`test\win32\float-on-top.ps1` section B does:

```powershell
$w = @(($json | ConvertFrom-Json).data.windows)[0]
if ($w) { $paneId = @(@($w.tabs)[0].panes)[0].id }
```

A tab in `+list --json` has no `panes` array. Its pane layout is a TREE under
`splits` (`{"type":"leaf","terminal":{"id":...}}` / `{"type":"split","left":…,
"right":…}`), measured 2026-09-14:

```json
"tabs":[{"id":"0","splits":{"type":"leaf","terminal":{"id":"B74C8F26-…"}}}]
```

So `$paneId` is always `$null`, the script always prints
`SETUP NOTE: no pane id from +list --json, falling back to the window's auto name`
and targets `window-1` instead. The fallback happens to hit the right pane in a
one-window run, which is why nobody noticed.

Found while re-measuring T720.

## Where to look

- `test\win32\float-on-top.ps1` — the `$paneId` block ahead of section B.
- Any other harness reading `.panes` off a tab: `grep -rn '\.panes' test\win32\`
  before fixing, since this idiom was probably copied.
- The shape to walk is the `splits` tree; a helper in `test\win32\lib\` is
  better than a fourth copy of the walk.

## Validation criteria

- [ ] `float-on-top.ps1` resolves a real pane id from `+list --json` and the
      `SETUP NOTE` fallback line no longer prints on a healthy run.
- [ ] The fallback stays, but says which thing it fell back to and why — a
      silent guess is what made this invisible.
- [ ] Every other `test\win32\` reader of a tab's panes is checked and fixed or
      confirmed correct, named in the progress log.
- [ ] `float-on-top.ps1` green end to end.
