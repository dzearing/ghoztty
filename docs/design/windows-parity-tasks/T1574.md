# T1574 - A force-killed GUI fixture is reported as a CRASH in the postmortem

## Summary

A script that tears down its own app with Stop-Process -Force before Remove-TestDesktop leaves the launch unmarked as a deliberate kill, so Write-TestDesktopPostmortems reads its 0xFFFFFFFF exit code and prints 'CRASHED - unnamed NTSTATUS' with a stack-less report. Observed on window-composite.ps1 during T778 (fixed there by letting Remove-TestDesktop do the killing); pane-capture.ps1 has the same shape, and the pattern is easy to copy. Either mark the launch killed from the script's own teardown or teach the postmortem to recognise a harness-issued force kill.
