# T3018 - PA-I04: the agent's session ring appends one byte at a time with a 64-bit modulo per output byte (session.zig:493-496)

## Summary

PA-I04 (audit-1, T2962). src/remote/agent/session.zig:493-496: `for (src) |b| { self.buf[widx] = b; widx = (widx + 1) % cap; }` with a runtime cap, so every output byte of every session costs a divide (several ns/byte against well under 0.1 ns for memcpy), under the store-wide lock (PA-I05). Fix: two @memcpy segments (to the end, then wrapped). Risk trivial; existing ring tests cover it. Shared agent code: Mac half filed. Findings: docs/design/perf-audit/audit-1/I-findings.md.
