## Method

Two numbers per turn, both read from evidence that already exists:

1. **Claim to close**: the task file's `## Progress log`, last `claimed` line to
   last `status: in-progress -> done` line. Same definition T1955 used.
2. **Phase minutes**: the loop session transcripts
   (`%USERPROFILE%\.claude\projects\D--git-ghoztty\*.jsonl`, one per turn
   because every turn ends in `/reset-context`). Each Bash/PowerShell tool call
   is timed from its `tool_use` to its `tool_result`. A call that went to the
   background is timed to the `<task-notification>` that names its
   `<tool-use-id>`. Without that, every harness-floor run reads 0 minutes,
   because those runs are backgrounded. Classification is by command text:
   `floor-lane.ps1 -Lane harness` = harness, other `floor-lane.ps1` = lanes,
   `acceptance-parallel` or `test\win32\<x>.ps1` = accept, `zig build` = build.
   `val` = lanes + harness + accept. A turn's window runs from the call that
   printed `CLAIMED: T<id>` to the `set-status ... -Status done` call.

Blind spots: time spent waiting in a `Monitor` call is not attributed to the
command it waits on. Its background notification covers the same span, so this
does not double count. Background runs that never sent a notification are
missed.

```powershell
param([datetime]$Since = '2026-10-16T04:16')
$dir = Join-Path $env:USERPROFILE '.claude\projects\D--git-ghoztty'
foreach ($f in Get-ChildItem $dir -Filter *.jsonl | Where-Object { $_.LastWriteTime -ge $Since }) {
    $uses = @{}; $task = $null; $first = $null; $last = $null
    $sum = [ordered]@{ lanes = 0.0; harness = 0.0; accept = 0.0; build = 0.0 }
    foreach ($line in [IO.File]::ReadLines($f.FullName)) {
        if ($line -notmatch '"timestamp"') { continue }
        try { $o = $line | ConvertFrom-Json } catch { continue }
        if (-not $o.timestamp) { continue }
        $ts = [datetime]$o.timestamp; $c = $o.message.content; $done = @()
        if ($o.type -eq 'user' -and $c -is [string] -and $c -match '<tool-use-id>(\w+)</tool-use-id>' -and $uses.ContainsKey($Matches[1])) {
            $done += @{ id = $Matches[1]; txt = '' }
        } elseif ($c -is [array]) {
            foreach ($b in $c) {
                if ($b.type -eq 'tool_use' -and $b.input.command) { $uses[$b.id] = @{ ts = $ts; cmd = [string]$b.input.command } }
                elseif ($b.type -eq 'tool_result' -and $uses.ContainsKey($b.tool_use_id)) {
                    $txt = ($b.content | Out-String)
                    if ($txt -match 'running in background with ID|moved to the background') { continue }
                    $done += @{ id = $b.tool_use_id; txt = $txt }
                }
            }
        }
        foreach ($d in $done) {
            $u = $uses[$d.id]; $cmd = $u.cmd
            if (-not $task -and $d.txt -match 'CLAIMED: (T\d+)') { $task = $Matches[1]; $first = $u.ts }
            if ($cmd -match 'set-status \S+ -Status done') { $last = $ts }
            $min = ($ts - $u.ts).TotalMinutes
            if ($cmd -match 'floor-lane\.ps1.*-Lane harness') { $sum.harness += $min }
            elseif ($cmd -match 'floor-lane\.ps1') { $sum.lanes += $min }
            elseif ($cmd -match 'acceptance-parallel|test[\\/]win32[\\/][\w-]+\.ps1') { $sum.accept += $min }
            elseif ($cmd -match 'zig build') { $sum.build += $min }
        }
    }
    if (-not $task -or -not $last -or $first -lt $Since) { continue }
    "{0} {1,-6} turn={2,4:N0} val={3,4:N0} lanes={4,4:N0} harness={5,4:N0} accept={6,4:N0}" -f $last.ToLocalTime().ToString('MM-dd HH:mm'), $task, ($last - $first).TotalMinutes, ($sum.lanes + $sum.harness + $sum.accept), $sum.lanes, $sum.harness, $sum.accept
}
```

- **The lane cut worked**: four parallel lanes take ~7 min, down from 17-20 (T1959).

- **Acceptance is now the biggest phase.** T1984 and T1939 each spent 41

  cost. The time outside validation (code, reading, tracker) is still 10-50
  min per turn.
- 2026-10-14 is not a clean baseline: T1017-T1027 were small doc-sized turns
  that pull its medians down. T1955's own phase table (~50 min validation in
  a 64-min turn) used three larger turns. The final reading should be compared
  against both.
