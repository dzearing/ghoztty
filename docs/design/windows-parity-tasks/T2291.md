# T2291 - Collapsing or expanding the Windows pane sidebar snaps; on Mac the grid's cards glide from where they were, each terminal resizes once after the motion, and the card's width animates on the same curve while rail and panel crossfade (Mac 543489bca; split from T2274)

## Summary

Seed the grid glide (the T2270/T2287 glide machinery) from the column shift, resize terminals once at the end, animate the sidebar card width on the same curve, crossfade rail and panel content inside it.

## In plain terms

Opening or closing the pane list on Windows used to jump: the list changed
size in one frame and every terminal snapped to its new place. On Mac the
list's card grows or shrinks smoothly while the rail's icons fade into the
full list (or back), and the terminals beside it slide over to their new
places, only resizing once they arrive. Windows now does the same.

## Goals

- [x] Collapse, expand, hide and show tell the grid the column moved, and the grid's cards glide over from where they were (Mac `noteColumnShift`), each terminal held at its size until it lands
- [x] The column's width animates over 240 ms on Mac's curve (0.2, 0.8, 0.2, 1) while the frame it left fades out and the new mode's fades in, both cut at the column's edge
- [x] A second click mid-glide leaves from the frame as drawn; animations off (or RDP) still snap
- [x] Hide/show: the grid glides, the column just goes (Mac's hidden mode has no column to animate)
