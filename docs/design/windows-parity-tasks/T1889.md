# T1889 - The Windows pane sidebar's row question badge is a bare ? disc where Mac shows a 'question' capsule

## Summary

Follow-up of T1843. Mac PaneSidebarQuestionBadge in a full row and a window header is the word 'question' in an accent capsule (9.5pt semibold, 15pt tall, inverted on the accent selection pill); Windows paints the rail's corner '?' disc in rows and headers too. The breathing ring (T1843) should follow the capsule shape.

## In plain terms

When a pane is waiting for an answer, the Mac sidebar marks its row with a
small blue pill that says "question". Windows showed only a round "?" dot
there. After this, a waiting row (and a window's heading in the all-windows
list) shows the same "question" pill, gently pulsing; the narrow icon rail
keeps its little "?" dot, as on Mac.

## Goals

- [x] rows and window headers paint the "question" capsule instead of the "?" disc
- [x] the breathing ring follows the capsule's shape
- [x] the rail's corner keeps the "?" disc

## Validation criteria

- [x] chip geometry (status-chip height, sm padding, never narrower than tall, ring follows capsule) - unit tests in `pane_sidebar.zig` (3 T1889 tests), none PASS 255s + win32 PASS 361s
- [x] a pinned-panel row with a question logs a chip of the status-chip height and at least twice as wide as tall - `test\win32\pane-sidebar-activity.ps1` section 4: ALL PASS (34), logged `question chip w=75 h=20` at 125% (status chip = 15+5)
- [x] the rail paints no chip (still the corner disc) - same script, section 3 PASS
- [x] floor lanes green - `scripts\floor-lane.ps1 -Lane all` (lib/none/win32/agent PASS) + `-Lane harness` PASS; pane-sidebar family 8/8 ALL PASS; chrome-theme red on a pre-existing test-fixture hit, filed T1918

## Decisions made here

- Mac's 9.5 pt / 15 pt / 6 pt capsule maps onto the design system's STATUS CHIP
  (§3.1 named exception): caption 12 DIP semibold, one caption line + `sm` tall
  (16 DIP), `sm` padding. Same chip as the chooser's count badge.
- Mac inverts the chip on its accent selection pill; Windows has no accent pill
  (selection is a neutral fill plus the accent bar), so there is no inverted
  variant and the ring always breathes.
