## Summary

Needs the input desktop (DWM composes only it, and WGC refuses any other). Since T2463 that does NOT need an idle box: `scripts\comp-spike.ps1 -Live` runs the spike as an invisible ghost window (alpha 1/255, click-through, bottom-most, never activated) with the user present. Deliverable: the spike report table (old path vs composition, frame intervals, misses under stall) appended to T2360.

## In plain terms

Before rebuilding how Ghoztty animates, we needed proof on the user's own
screen that the new way (the system compositor running the animation) really
is smooth, and stays smooth when the app is busy. This run measured it: the new
way draws a fresh frame on every screen refresh even with the app frozen for
half a second, while today's way manages about one in three and freezes along
with the app.
