# T1034 - Sweep for other hooks that document a caller they never got, the way signalFrameDrawn did

## Summary

T1031 found Surface.signalFrameDrawn documented as 'called by the renderer thread after SwapBuffers' with NO caller anywhere in the tree - so the synchronous-present wait it feeds had been sitting on an event nobody set, expiring after its 16ms timeout, since the day it was written. Nothing was red: the code compiled, the tests passed, and the feature simply did not exist. That is a CLASS of defect, not one bug. Wanted: an audit over src/apprt/win32 and src/remote for pub functions whose doc comment names a caller ('called by', 'invoked from', 'the renderer thread calls') and which no call site references, plus a decision on each hit (wire it, or delete it and its comment).

## In plain terms

Once, a piece of the app was written to wait for a signal that nothing ever
sent, so a feature quietly never worked even though everything looked green.
This task checked the Windows app and the session agent for any other piece
built that way - none were found - and added a check that runs automatically
so the next one is caught the day it is written instead of months later.

## Goals

- [x] Sweep src\apprt\win32 and src\remote for functions, fields and constants
      whose doc comment names a caller ("called by", "set by", "posted by",
      ...) that no code line references
- [x] Sweep every WM_APP_* window message for a handler with no sender (the
      exact shape of signalFrameDrawn's never-set event) or a sender with no
      handler
- [x] Decide each hit: none to decide - zero live instances
- [x] Make the sweep standing: a guarded acceptance audit, not a one-off

## Result

Swept 2026-10-17 at c4bed44bc: **234** caller-documented declarations and
**54** window messages, **zero** findings. The nearest misses were all
legitimate, checked by hand: seven messages whose sender is indirect
(`WM_APP_TRAY` via `uCallbackMessage`, the three viewer messages via
`probe.attach(hwnd, MSG)`, `WM_APP_HERO_SNAP` posted as `Window.WM_APP_HERO_SNAP`,
and two `WM_APP_TEST_*` posted by number from `dpi-change.ps1` /
`fullscreen-exit.ps1`), and ~20 hooks with exactly one caller, each the one
their comment names. `signalFrameDrawn` itself has its caller since T1031
(`src/renderer/generic.zig`).

Durable half: `test\win32\unwired-hook-audit.ps1` over
`test\win32\lib\UnwiredHookAudit.ps1`, guard row `unwired-hook` covering all
of `src\`, `build.zig` and the test scripts (a caller is lost when the
CALLER's file changes, which may be anywhere). The census is C# (~2 s); the
first PowerShell-per-line version took 108 s. A test block is not a caller and
a comment is not a caller; a string mention is (`@field(x, "name")`).
