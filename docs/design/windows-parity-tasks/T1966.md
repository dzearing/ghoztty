# T1966 - A script-opened background window (+new-window without --focus) must open at the last window's saved size and position, not a default frame (main ec6c793d7)

## Summary

Intake 2026-10-15: main ec6c793d7 fixes Mac's background-presentation path (orderInBackground skipped showWindow's frame setup, so a +new-window without --focus came up at the 800x600 placeholder). Since T1797 the Windows CLI also opens windows in the background by default. Check that path on win32 applies the same initial frame as a focused new window (saved size/position restore, cascade/centering) and add an acceptance check that compares the two.

## In plain terms

When a script or agent opens a Ghoztty window without asking for focus, the
window appears behind what you are doing. It already came up at your usual
window size and position, but if you work with windows maximized, it came up
small. Now it opens maximized like any other new window, still without
pulling you out of the app you are in.

## Goals

- [x] Confirm a background window gets the same remembered size and cascade position as a focused one (it did: both are decided when the window is created, before either show path)
- [x] A remembered maximized state is honored by the background show too, without activating the window
- [x] Restoring that window down returns it to the remembered size
- [x] An acceptance harness compares the background and focused paths

## Validation criteria

- [x] Background and `--focus` windows open at the remembered W x H and cascade 30px each: arm A of `test\win32\background-window-frame.ps1` (19/19 ALL PASS)
- [x] With maximized memory the background window opens maximized, covers the work area, does not activate, and restores down to W x H: arm B of the same harness
- [x] The oracle can see the gap: `-NegativeControl` fails (1 FAILED), and the harness's first run against the style-only fix caught the overwritten restore-down rect (2 FAILED) before the placement hand-back landed
- [x] `maximizedFrame` rect rule: unit tests in `window_placement.zig` (none + win32 lanes)
- [x] Floor: `floor-lane.ps1 -Lane all` ALL LANES PASS
