# T3590 - Linux: closing a tab or a window can be undone (Ctrl+Shift+Z), as on Mac and Windows

## Summary

T3384 made a closed PANE and a +rearrange-omitted pane undoable on Linux (src/apprt/gtk/CloseUndo.zig). Closing a tab, a tab's last pane, or a whole window still ends every pane at once. Mac and win32 (T1825/T1874: tab and window entries, a closed window owned by the shared key so any window's undo reaches it, Close Other Tabs grouped) park those too. Port: park the tab's split tree (or the window's tabs) on the GTK undo stack, restore the tab at its index / reopen the window, and extend test/linux/cli-undo.sh.
