# T3590 - Linux: closing a tab or a window can be undone (Ctrl+Shift+Z), as on Mac and Windows

## Summary

T3384 made a closed PANE and a +rearrange-omitted pane undoable on Linux (src/apprt/gtk/CloseUndo.zig). Closing a tab, a tab's last pane, or a whole window still ends every pane at once. Mac and win32 (T1825/T1874: tab and window entries, a closed window owned by the shared key so any window's undo reaches it, Close Other Tabs grouped) park those too. Port: park the tab's split tree (or the window's tabs) on the GTK undo stack, restore the tab at its index / reopen the window, and extend test/linux/cli-undo.sh.

Split on 2026-11-24: this card is the TAB half. The window half (closing a
whole window, or its last tab, which closes it) is T3665.

## In plain terms

On Linux, closing a tab used to end every shell in it at once, with no way
back. Now, for a few seconds after you close a tab (or close every other tab,
or close a tab's only pane), Ctrl+Shift+Z brings it back where it was, with
the same shells still running; Ctrl+Shift+Y closes it again. Mac and Windows
already work this way.

## Goals

- [x] A closed tab waits, hidden, with its shells alive, and undo puts it back at its position
- [x] Redo closes it again; the undo expiring ends its shells
- [x] Closing a tab's only pane parks the tab, not just the pane
- [x] Close Other Tabs / Close Tabs to the Right come back with ONE undo
- [x] An undo in another window never reaches it
