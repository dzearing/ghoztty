# T2311 - Windows sidebar rows, tiles and window headers can touch; Mac keeps a 4pt gap between any two sidebar items in both modes and a clear 6pt band above and below each sticky project header (Mac 157b08c48)

## Summary

Mac 157b08c48 (ref: main docs/reference/pane-sidebar.md): nothing in the list touches. A row's pill is inset PaneSidebarRow.gap/2 (2pt) top and bottom, as is a window header's hover fill, so any two items - pills, rail tiles, window headers, the stash tray's well - are at least 4pt apart in both rail and expanded modes. A sticky project header gets a clear 6pt gap above and below its band (PaneSidebarOutline.headerGap) so it never touches a row's hover or the tray's well. Port to PaneSidebar.zig layout (DIP-scaled), with a layout unit test that no two item rects touch.

## In plain terms

In the pane sidebar, rows, rail tiles and window headers sat a single pixel
apart, so hover highlights and selection pills could visually touch, and a
project's heading crowded the rows around it. The Mac keeps a small clear gap
between every item and some breathing room around each project heading; now
Windows does the same, in both the narrow rail and the full list.
