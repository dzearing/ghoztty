# T2192 - A deleted portable copy leaves its owned PATH entry and HKCU\Software\Ghoztty\PathEntry behind; ghoztty-cleanup does not remove them

## Summary

Since T2169 a portable launch writes one owned user-PATH entry recorded at HKCU\Software\Ghoztty\PathEntry. Launching any other copy re-points it, but deleting the portable folder (or uninstalling everything) leaves a PATH entry naming a missing dir plus the record. Mac leaves a dangling ~/.local/bin link the same way, so this is cleanup, not parity: teach scripts\ghoztty-cleanup.ps1 (and consider the MSI uninstall) to drop the recorded entry when its dir no longer holds ghoztty.com, and remove the record.
