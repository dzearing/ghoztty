# T3415 - Linux L9f: viewer links - routing, live-page origin rule, popups to the browser, right-click menu

## Summary

Per viewer-panes.md Links: markdown/code links (http(s) to the browser, relative .md/.html to a viewer split, other files to their default app via xdg-open/portal); live-page same-origin rule (host + written port; file:// inside the page directory); only a user click on a main-frame link is routed; target=_blank/window.open to the default browser unless Ctrl-clicked; links.js user script in all frames and the native menu shared with banner links.

## In plain terms

On Linux, clicking a link in a document or web pane used to either do nothing or wander off inside the pane. Now it behaves as on the Mac and Windows: web links open in your browser, a link to another document opens it beside the one you are reading, a website follows its own links but sends you to your browser when you leave it (hold Ctrl to keep it in Ghoztty), and right-clicking any link gives Ghoztty's own link menu.
