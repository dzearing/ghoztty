# T3030 - PA-I16: the agent's in-process ConPTY child never closes the shell's process handle, one handle and kernel process object per ended session (pty_child.zig:778-849)

## Summary

PA-I16 (audit-1, T2962). src/remote/agent/pty_child.zig terminateFn (:778-849) closes the pty handles and joins threads but never CloseHandle(self.pid) (on Windows posix.pid_t is the process HANDLE, :287); the only CloseHandle calls in the file are job and test code (:193, :243, :1947, :1976), and CommandCore closes hThread only (:396). Cost: one process handle plus a retained process object per ended session on the in-process path (GHOZTTY_AGENT_PTY_HOLDER=0, non-recording agents per T1278, the holder-spawn fallback at :1119); harmless in a holder, which exits. Fix: CloseHandle(self.pid) after the reap in terminateFn. Risk low. Findings: docs/design/perf-audit/audit-1/I-findings.md.
