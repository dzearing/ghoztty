# T3305 - PA-W21: pooled pane windows (up to 16 per workspace) are never destroyed when a workspace closes in place (Surface.zig:1554)

## Summary

parkWindow (Surface.zig:1554-1570) parks closed pane HWNDs as children of the shared window; a workspace that closes in place (Window.zig:22885, :22895-22902) never drains its pane_pool, and the shared HWND lives on, so the hidden children (and their USER objects) accumulate per closed workspace. Fix: drain/destroy the pool on in-place close. Cost inferred. Audit-4 (T3151), Fable 5.2 area finding at c9af15802; cites read at HEAD by the owning turn.
