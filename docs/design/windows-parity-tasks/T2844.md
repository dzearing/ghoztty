# T2844 - A busy pill's compositor sheen lies OVER its glyph and text (Mac's is a background): lay the pill's text and glyph over the sheen on the column's tree so the glint never dims the label in light mode

## Summary

T2801 moved a busy pill's sheen (drift + glint + busy rim) onto the sidebar's
composition tree (`pane_sidebar_sheen_comp.zig`). That tree is a TOPMOST
DirectComposition target on the sidebar's GDI window, so it composes over
everything GDI drew - including the pill's glyph and label. Mac's sheen is a
`.background` of the row (`PaneSidebarRow.swift` `PaneSidebarBusySheen`), under
the text.

On dark the white glint over light text is invisible; on light the 25% white
glint lightens the dark label for the 0.8 s it crosses. Fix: give each placed
pill a fourth, top piece - the pill's glyph and text with real alpha - so the
order on the tree is drift, band, rim, TEXT. One route: render the pill's
content twice (on black and on white, same ink) and recover per-pixel alpha
(`a = 1 - (white - black)`, colour = black / a); re-render it whenever the
row's text, selection, hover or theme changes (the paint already knows - the
row repaints). Alternative: a non-topmost target with the GDI pill cut out -
rejected so far, because a child window's redirection surface is opaque.

## In plain terms

While an agent works, its row in the pane sidebar shows a soft moving shine.
Since T2801 that shine is drawn on top of the row's name instead of behind it.
In dark mode you cannot tell; in light mode the name briefly fades a little
each time the shine passes. This puts the name back on top.

## Validation criteria

- [ ] unit test: the recovered text layer composited over the fill reproduces the GDI pill within 8-bit rounding (black/white recovery)
- [ ] light theme, busy row: a WM_PRINTCLIENT frame is unchanged, and the tree's piece order is drift, band, rim, text (log)
- [ ] the text piece re-renders on hover/selection/rename (log count)
- [ ] NOT RUN unless the user starts it: an input-desktop film of a light-mode busy row
