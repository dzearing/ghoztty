# T1487 - A block is only recorded when the watchdog acts, so the screen learns about it up to an hour late

## Summary

The blocked state the dashboard bar (T1484) reads is written by Add-Ineffective, which only runs when the watchdog takes a recovery action - so the first observation lands after the stall arms fire (45m) plus the rearm hold-off. The classifier is cheap and the watchdog already runs every 5 minutes; stamping the verdict on the observing tick rather than on the action would cut the time between a block starting and the screen saying so from tens of minutes to one poll. Clearing has the same shape: an unblocked tick should clear the record rather than waiting for a turn to complete.
