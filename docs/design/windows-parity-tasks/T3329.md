# T3329 - Linux L0: cap WSL2 memory and route every Linux script through one wrapper that refuses to run uncapped

## Summary

WSL2 has taken 28 GB on this box before. Ask the user to add a cap to %USERPROFILE%\.wslconfig (memory=8GB, autoMemoryReclaim=gradual) - the file is theirs, do not write it unasked. Then add scripts/linux/wsl-run.ps1: the ONLY way a Linux build/test is started from Windows. It refuses (exit 2, plain message) when .wslconfig has no memory= line, names the distro explicitly (Ubuntu, not the default, never docker-desktop), and runs the repo via its /mnt/d path or a clone inside the distro (measure both; /mnt is slow for zig builds). Nothing in the Windows floor, sweeps or go-loop may call it. Plan: docs/design/linux-port.md.
