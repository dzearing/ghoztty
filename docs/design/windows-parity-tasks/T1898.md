# T1898 - A website in an elevated Windows viewer pane is assumed to have a white page, so a dark site sits in a light corner ring

## Summary

Follow-up of T1851. ViewerPane.cardColors knows the page colour of the documents this app renders (viewer.css by scheme) but a website or loose .html file brings its own, and it guesses white. Read the real document background (getComputedStyle of body/html after navigation, posted over the existing viewer bridge) and repaint the card when it arrives. Validate with a dark-background html file in pane-elevation.ps1.
