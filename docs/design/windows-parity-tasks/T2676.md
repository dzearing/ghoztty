# T2676 - Settings Advanced page on Windows: config file path + Open Config File, the include list, backups with Restore, and the Saved / Show change / Undo toast (Mac 9287de0ff)

## Summary

Split from T2584. The parts of Mac's Advanced page that are not All Settings
(`SettingsCustomSections.swift`, the config-file / includes / backups
sections): the path of the file Settings writes with Open Config File... and
Reveal; the files Ghostty also loads (`SettingsSources.sources`, includes
marked, each with Open); Backups listing `ConfigFileStore.backups` with
Restore... (`SettingsModel.restoreBackup`, itself undoable). Plus the
"Saved - Show change - Undo" toast every write raises
(`SettingsModel.last_change`, `undoLastChange`, with the "changed since"
refusal shown when the file moved on). Needs the window shell (T2675).

## In plain terms

On the Mac, Settings > Advanced shows which config file your changes go
into, the other files that are loaded alongside it, and your automatic
backups, and every change pops up a small "Saved - Show change - Undo" note.
On Windows the Advanced page had only the raw list of every setting, and a
change happened silently with no way back. Now Windows has the same: the file
with Open in Editor and Show in Explorer, the other files with Open, Restore
for backups, a peek at the file's text, and the Saved / Undo note after every
change - which refuses to undo if you have since edited the file yourself.

## Goals

- [x] Advanced > Config file: the file's name and path, Open in Editor, Show in Explorer (and a note when it is a link)
- [x] Every other file Ghostty loads, in load order, tagged "also loaded" / "included", each with Open
- [x] Backups with Restore... (dated list, Show Backups in Explorer, a confirmation first); restoring is itself undoable
- [x] The "Current file" disclosure
- [x] The toast after every write: message, "applied live - backed up first", Show/Hide Change, Undo, dismiss; goes after 6s unless expanded
- [x] Undo over an outside edit refuses with Mac's words and leaves the file alone

## Decisions made in passing (mechanism, not experience)

- The All Settings title and filter used to be pinned over Advanced's list;
  with the Config file section above them (Mac's order) they now scroll with
  the list, so the filter never sits over a section it does not filter.
- Restore's confirmation is a Windows message box (OK / Cancel) - the native
  counterpart of Mac's confirmation dialog, same title and text.
- A refused Undo is also said in the toast itself (Mac shows it only on the
  Advanced page); the toast then stays up until dismissed, so the refusal is
  seen wherever the user is.
- "Show in Explorer" selects the file (`explorer /select,`), and opens the
  folder when the file does not exist yet (`banner_link.revealTarget`).
- The Current file view shows the first 14 lines and says how many more
  there are, instead of Mac's scrolling box inside a scrolling form.
- Two debug-only seams: `GHOZTTY_SETTINGS_SHELL_DRY` records what Open /
  Show in Explorer would launch instead of launching it, and `--op=toast_ms`
  sets the toast's lifetime so the harness can watch it time out.
