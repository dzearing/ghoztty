# T1061 - The claim's cache clear can delete a build out from under a lane running in another window

## Summary

T1054 wired scripts\build-cache.ps1 sweep into go-loop-exec.ps1 claim. Within the loop window that is safe by construction - a claim runs at turn start, before this turn builds anything. It is NOT safe with respect to the OTHER window: the user routinely keeps a second Claude window on this repo that files tasks, audits, and sometimes runs a lane or an acceptance script, and that window is deliberately unmarked so the loop never touches it. If the loop claims a turn while that window is mid-build, the whole-cache clear takes .zig-cache and the global cache away underneath it; the visible result is a compile failing on a generated file that vanished, which reads as red code - the same class of misleading failure T1054 exists to remove. Two candidate fixes, both cheap: (a) decline the clear while any zig build process is alive and say so in the claim line, retrying next turn; (b) take the same advisory lock git-commit-guard.ps1 uses, so a lane can hold it. (a) is probably enough and needs no cooperation from the other side. Acceptance: a section in test\win32\build-cache.ps1 that stages a long-lived fixture process matching the lane predicate and asserts sweep declines and says why.

## In plain terms

When the build cache gets too big, the loop wipes it at the start of a turn.
If another window (or the second loop lane, which shares the same cache) was
in the middle of a build at that moment, that build would suddenly fail with
a confusing "file not found" error that looks like broken code. Now the wipe
waits until nothing is building, and says so; the next turn tries again.

## Goals

- [x] an over-limit sweep declines while any zig compiler, build runner or cache-resident test binary is alive, and names it
- [x] the deferral is a retry, not a stand-off: with the build gone the next sweep clears
- [x] a person's `clear -Force` still clears, with a warning naming what it may break; `-IgnoreBusy` overrides the sweep
