# T3849 - Linux: a website on a glass pane is not told the terminal background's light/dark, as Mac and Windows tell it

## Summary

T3720 holds only template pages (markdown/code/diff/image) to the glass sheet's scheme. Mac (window appearance follows the terminal background) and win32 (viewer_glass.pageScheme sets the WebView2 profile scheme whenever the pane is on glass) also tell a website or a rendered .html file on glass the terminal background's prefers-color-scheme. On Linux such a page still follows the app's libadwaita style (the desktop wins over a light terminal under window-theme = auto). Its sheets are cross-origin or not ours, so the T3720 page-side rewrite does not apply; needs another mechanism (e.g. a per-view override if WebKitGTK grows one, or a web-process extension). Low impact: the page keeps its own background.
