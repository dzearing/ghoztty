# T1489 - a tab has no specular sheen, so it reads flatter than the banner card beside it

## Summary

The banner card paints a specular sheen (white bulging down into its top, fading away) UNDER its rim; a tab paints the rim alone. T679 matched the two rims exactly, which leaves the sheen as the remaining difference between the two surfaces: a tab is a flat fill with a lit edge, the card is a lit surface. Whether a chiclet a third of a card's height should carry the same sheen is a judgement call - it may read as a smudge at that size - so this is a look-at-it-on-screen task, not an obvious port. Nobody has reported it.
