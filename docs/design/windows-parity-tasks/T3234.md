# T3234 - Idle CPU regressed: one idle pane now costs 0.88-0.90% of a core in exact cycles, against 0.47-0.59% at cbc185f67 (baseline-4, T3151)

## Summary

perf-baseline idle phase (release, 1 window, 1 cmd pane, 60 s): cpu_cycle_pct 0.901 in baseline-4 (424c9e5ab) and 0.875 on a repeat run, against 0.466-0.594 over ten T3111 runs at cbc185f67 (docs/design/perf-audit/t3111/*.json). Debug reads 0.877. Cycle counts are exact (T3111), so this is outside noise. Bisect cbc185f67..424c9e5ab with -Build Release -Phase idle; candidates in the idle path: T3061 wake coalescing (5059acb10), T3074 shared chrome device (1cde0416f), T3095 (99efd0c58), the single-window series (T3182-T3212). Use idle.wakeup_attribution.top_threads_by_cycles in both JSONs to name the thread first. P1 rather than the audit rule's P0: the controller has the single-window port ahead of perf work (T3151 triage-reason).

## In plain terms

A Ghoztty window sitting at an idle prompt now burns about twice as much
processor time as it did a few days ago. Nothing visible changed; you would
notice it as battery drain on a laptop, or as background load with many panes
open. When this lands, an idle pane costs what it did before (or less), and we
know which change caused the rise.

## Verdict (2026-11-18)

**No code regression.** The rise is box drift. Interleaved ReleaseFast idle runs on the test desktop, same session, cpu_cycle_pct:

| arm | run 1 | run 2 |
|---|---|---|
| T3111 base binary (4c8a7cd4f, built 11-15, untouched) | 0.736 | 0.686 |
| cbc185f67 (fresh build) | 0.713 | 0.685 |
| HEAD 46725f243 | 0.741 / 0.748 | 0.758 / 0.716 |

The 4c8a7cd4f binary read 0.502-0.547 on 11-15. Today the same bytes read about 35% higher, and HEAD sits about 3% above them, inside the spread. Per-thread: the renderer and GL driver threads cost the same on every arm today. NVIDIA driver unchanged since 10-28; same boot (11-12); Balanced plan. Cause of the drift not pinned (likely core placement or background load); the comparison method is fixed in T3242. Raw JSON: docs/design/perf-audit/t3234/.
