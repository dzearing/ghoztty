# T2228 - The dashboard's per-lane rows show the turn number but not whether the OTHER lane is turning

## Summary

T1298 put the turn clock on the loop card for the lane the dashboard is served from. lanesState() in scripts\task-dashboard.js gives every other lane only its turn number, and the user's board is served from lane a - so a lane-b turn stalled for fourteen hours still reads 'running, turn 62' there. Carry turnAgeMs/turnStalled per lane (same fallbacks and 180-min threshold as loopState) and render the stalled wording in laneRows; extend section F of test\win32\task-dashboard.ps1 with a two-lane fixture.

## In plain terms

The task dashboard lists every copy of the work loop running on this PC, one
line each. For the copy the board is served from it already says when the
loop is alive but stuck; for every other copy it only said "running, turn 62",
even if that copy had been stuck for fourteen hours. Now each line says how
long its current turn has run, and a stuck copy reads "alive, but not turning"
in the warning colour, the same words the main loop card uses.

## Goals

- [x] the server reports each lane's turn age and stalled flag, on the same rule (and the same 180-minute threshold) as the main loop card
- [x] a lane whose owner process is gone carries no turn clock, so a dead lock never reads as a stall
- [x] the lane rows say "alive, but not turning - no turn has finished in Xh" for a stalled lane, and "(this turn Xm)" for a healthy one
- [x] a two-lane (three-lane) fixture proves it from outside, plus a rendered-page check
