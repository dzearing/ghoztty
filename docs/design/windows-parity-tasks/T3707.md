# T3707 - docs/reference/pane-rearrange.md still says a move that would empty the source window is refused; the Mac code allows a last pane to join another window since fd7385c42

## Summary

pane-rearrange.md (A drag never closes a window) says a move that would empty the source window is refused. PaneMoveCoordinator.allows has allowed joining an EXISTING window, a window's last pane included, since fd7385c42 (2026-09-10); only .newWindow/.tile and a lone pane's new tab beside its own window are refused. The Linux port (T3616) nearly implemented the stale rule from the doc. Rewrite the paragraph to the code's rule.
