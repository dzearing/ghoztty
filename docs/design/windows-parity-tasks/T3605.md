## Summary

**Re-measured 2026-11-23 after T3551:** the SessionLayout half is done - its pure tests (restoreSize, frameFromSize, viewerRestore, firstLeaf, layoutPathFrom) moved to std-only `src/apprt/gtk/session_layout_rules.zig`, which every lane runs, and a filtered `zig build test -Dapp-runtime=gtk -fno-sys=gtk4-layer-shell` matches each name in WSL. The Linux floor (scripts/linux/floor.sh) runs lib/none/agentx/agent only. Give the floor a gtk lane that reaches src/apprt/gtk's test blocks (refAllDecls from the gtk test root, or a gtk unit-test step), prove it with a filter that now matches restoreSize, and keep test-reach-audit D5 consistent with it (T3539).

## In plain terms

The Linux version's own window code has a set of self-checks (keyboard
shortcut labels, desktop-portal handling, the GTK widget classes) that nothing
ever ran, so a change could break them and no one would hear about it. The
one command that checks a Linux change now runs them too.
