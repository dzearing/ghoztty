# T3753 - The tab strip's + button gets a dropdown of the installed shells, and the window menu's New Tab gets the same submenu (Windows Terminal convention) (T3735)

## Summary

Child of T3735. A chevron beside + (or a right-click on +) opens the shell catalog as a native popup menu; the window menu's New Tab becomes a submenu with the same list. Follows docs/design/win32-design-system.md. Acceptance: a menu-read test (MN_GETHMENU) that the entries match the catalog, and that picking one opens a tab on that shell.

## In plain terms

Opening a tab always gave you the one default shell. Now a right-click on the
tab strip's + drops down the list of shells on this PC (PowerShell, Command
Prompt, Git Bash, one entry per WSL distro), and File > New Tab in the window
menu opens onto the same list. Pick one and the new tab runs that shell; a
plain click on + still opens the default one straight away.

## Goals

- [x] a right-click on + shows the shell list, hung from the button
- [x] File > New Tab is a submenu with the same rows (Default Shell first, under the New Tab chord)
- [x] a pick opens a tab on that shell, with session persistence off and on, starting where a plain new tab would (WSL: the distro's home)
- [x] Restart Pane with Shell lists the same shells (it had its own list without Git Bash)
- [ ] a visible chevron beside + - filed as T3768
