# T1807 - Mac: Shift-clicking a remote window's close button closes it without the Disconnect/Close confirmation (mirror)

## In plain terms

This is the Mac side of T1806. A modifier-click on a remote window's close
button skips the Disconnect/Close question and disconnects: the window
closes and the session keeps running.

## Summary

The Mac remote-close confirmation came in with 830ba93cd ("Disconnect option
when closing a remote window"). T1806 has the design and the recorded
assumption that the shortcut means Disconnect. Mac question to settle and
record: use Shift for cross-platform symmetry, Option for the macOS idiom, or
accept both. Accepting both is the likely answer, because Shift must work for
the symmetry rule.

## Validation criteria

- [ ] A modifier-click on the red close button of a remote window shows no
      sheet. The window closes, and the session is still live and
      re-attachable.
- [ ] A plain click still shows the confirmation.
