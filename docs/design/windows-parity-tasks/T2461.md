# T2461 - Blades: the carried fold's face is a fresh full-card DIB plus a per-pixel band fill and blend every frame - measure it on a 4K window and keep every frame of the fold under 16.7 ms (T2457 perf)

## Summary

T2457's carried fold paints the whole visible card into the strip face each frame: StripFace.begin creates a new DIBSection per frame, fillGlass maps every pixel through the glass LUT, blendContent blends every pixel, makeOpaque walks it again, then keep() copies it. At 4K the first frames of a fold cover a ~2000x2000 card. Measure (drag-perf style frame timing) on a release build at 4K; if over budget, keep one DIB across the glide, fuse fill+blend+opaque into one pass, and skip the band where content alpha is 255.
