## In plain terms

Every morning the loop writes a short digest of yesterday's work, sorts the
new tasks and reads what changed on the Mac side. With two loops running,
both did it, and one loop's 40 minutes were thrown away. Now only one loop
does the morning write-up; the other skips straight to real work, and takes
over the write-up only when the first loop is not running.

- [x] A one-command check the turn runs first, with a named refusal
