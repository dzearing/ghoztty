# T3751 - Command palette: 'New Tab with Shell', 'New Window with Shell', 'Split Right/Down with Shell' open a sub-list of the installed shells (T3735)

## Summary

Child of T3735. Palette entries whose second step lists the shell catalog; picking one opens the tab/window/split on that shell through the same path as --shell=<spec>. Acceptance: a test that drives each entry and asserts the new pane's shell process (always-run arm with pwsh/cmd; WSL arm opt-in -Wsl).

## In plain terms

Until now the command palette could only open a new tab, window or split on
your one default shell. Now it has "New Tab with Shell…", "New Window with
Shell…", "Split Right with Shell…" and "Split Down with Shell…". Pick one and
the palette shows the shells you have (PowerShell, Command Prompt, Git Bash,
each WSL distro); pick a shell and the new tab, window or split opens on it.
Escape takes you back to the command list.

## Goals

- [x] four palette rows that open a second step listing the installed shells (the Settings > Shell list)
- [x] picking a shell opens the tab / window / split on that shell, the same way `--shell=<spec>` does, with session persistence on and off
- [x] Escape in the shell step goes back to the command list; a filter that matches no shell opens nothing
- [x] the rows are hidden in a window on a remote machine (the list is this machine's shells)

## Validation criteria

- [x] Unit: `the four '… with Shell' rows: one per target, local windows only`, `ShellTarget.prompt names what the pick opens` (commands.zig); the menu coverage test (`every command is either placed in the menu or omitted`). `floor-lane.ps1 -Lane all`.
- [x] Acceptance: `test/win32/palette-shell-pick.ps1` ALL PASS (37 assertions) via `acceptance-parallel.ps1 run`, persistence on AND off: Split Right / Split Down / New Tab with Shell > Windows PowerShell open a powershell.exe pane (a split keeps the window/tab count, a tab adds one); New Window with Shell > Git Bash opens a bash.exe window; New Tab with Shell > Git Bash (a spaced path) opens bash.exe; positive control: the first pane is cmd.exe. Negative controls: a no-match shell filter + Enter keeps the palette open and opens nothing; Escape goes back (the next 'New Window' runs as a command); Escape on the command list closes.
- [x] WSL arm (W1): Split Right with Shell > WSL: Ubuntu runs `wsl.exe -d Ubuntu --cd ~`. It ran because a distro was already running (the T1751 gate), so nothing was booted.
- [x] `-NegativeControl` inverts A1 and the run goes red (1 FAILURE), so the oracle discriminates.
- Note: PowerShell 7 is not installed on this box, so its row was not driven; it reaches the same code as Windows PowerShell with a different spec.
