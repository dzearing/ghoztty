# T3180 - Single-window mode: read macos-window-mode once at launch on Windows and offer it in Settings > Panes & Windows (takes effect at next launch)

## Summary

Latch Config.@'macos-window-mode' (separate|single, already parsed in src/config/Config.zig:3466) once at app start into a win32 WindowMode.current, with a test override; a Settings toggle on the Panes page with the Mac wording and a 'takes effect at next launch' hint. Separate stays byte-for-byte the current behaviour. Child of T3136 (split 2026-11-16). Design (T3136 Details): ONE shared top-level HWND; every workspace keeps its own Window controller; the workspace on show owns the HWND (GWLP_USERDATA, chrome, sidebar), a parked Window has hwnd=null and its pane child HWNDs are reparented (adoptPane-style SetParent, Window.zig:7278) under a hidden park host so they survive the shared HWND closing. Spec: docs/reference/window-modes.md. Acceptance goes in test/win32/single-window-mode.ps1 (one section per child).
