# T3762 - Every open window costs about 55 MB of memory and 22 MB of GPU memory, so 50 windows hold nearly 4 GB

## Summary

T3740 measured each single-pane window at ~55 MB private and ~22 MB GPU (50 windows: 2.75 GB private, 1.1 GB GPU, same on Debug and release), plus ~4 threads, one of them an unnamed GPU-driver thread per pane (each pane owns its own GL context) that burns ~20% of a core while the pane draws. Census where a window's 55 MB goes (cdb !address/!heap, as window-close-memory.ps1 -HeapCensus does) and what the 22 MB GPU is (swap chain, intermediate targets, per-pane atlas textures), then share what can be shared (atlas textures / one context per window or per app) so window 50 costs a fraction of window 2. Acceptance: window-count-scale.ps1 records per-window private and GPU and asserts a budget below today's.
