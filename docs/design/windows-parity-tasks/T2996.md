# T2996 - PA-W12: strip-label fonts and brushes are created and destroyed on every strip paint although a cached pair already exists (Window.zig:13769, 10118)

## Summary

PA-W12 (audit-1, T2960). paintStripBandsAndNames creates both rotated fonts per call (Window.zig:13769-13776, stripFont = bare CreateFontW at :13912) and two brushes (:13763/:13765); the same per-paint font shape is at :10118, :10423 and :10610. A cached pair already exists (strip_label_across/down, :14153-14156, invalidated on scale). Runs on every paint of a window with tucked panes; under PA-W04 that is ~10 Hz. Fix: use the cached fonts and brush_cache.CachedBrush. Risk low.
