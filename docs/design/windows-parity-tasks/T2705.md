# T2705 - Pane drop targets that would leave the pane where it is still react on Windows; Mac now shows no target or preview there, and previews swap as a center box with a swap glyph and splits with seams

## In plain terms

On the Mac, while you drag a pane, places where dropping would change nothing
no longer light up, and the highlight now shows more clearly what will happen
(a box with a swap symbol for a swap, lines where the new dividers go for a
split). On Windows a pointless spot still lights up as if dropping there would
do something. After this lands, Windows highlights only real moves and draws
the same clearer previews.

## Summary

main intake 2026-11-04, from 30d13ea14 (`PaneMoveCoordinator.wouldLeaveInPlace`,
`SplitTree.hasSameLayout`, `PaneDropFeedbackView.swift`):

- **No-op suppression**: for a split, divider or edge candidate, the session
  makes the move on a copy of the tree and compares layouts (sizes aside, a run
  of same-axis splits read as one row). Equal -> no target, no preview, and a
  release does nothing. In A | B dragging A: B's left triangle, the divider and
  the window's left edge are all quiet. A stashed pane is not on the grid, so
  every place is new to it.
- **Previews**: a split, top-level insert and divider insert fill the landing
  area with seams where new dividers run; a swap fills the center box itself
  with a swap glyph.
- Pane zones are now drawn as four triangles + center box on Mac (the hit
  geometry is unchanged: diagonals, 34% center box floored 44pt, capped 60%).

Windows today: `pane_drop.zig` only treats the dragged pane itself as a no-op.
`DropHighlight.zig` / `drop_highlight.zig` draw the highlight.

## Validation criteria

- [ ] Pure `hasSameLayout`-equivalent + would-leave-in-place check with unit tests (A | B cases from the Mac doc; same-axis run read as one row; stashed pane always new)
- [ ] Acceptance: in A | B dragging A, B's left triangle, the divider and the left window edge show no highlight and a release changes nothing
- [ ] Swap preview is the center box with a swap glyph; split/insert previews show seams (off-desktop capture)
