# T1554 - No on-box oracle proves a sign-out DETACHED the far session instead of ending it

## Summary

T713 makes relay sign-out close the account's windows with T1390's DetachPin, so the sessions keep running on the far machine. relay-account.ps1 section 7b cannot measure that: the agent's shells sit behind a PTY holder that escapes the process tree (a descendant count is always 0) and the agent's --relay mode takes no --sessions-file, so there is no roster on disk to read. The claim currently rides on remote-disconnect.ps1 proving the same pin spares a far session in the direct-TCP case. Give section 7b a real oracle - either teach --relay mode to accept --sessions-file, or add a wire probe that lists the far agent's sessions.
