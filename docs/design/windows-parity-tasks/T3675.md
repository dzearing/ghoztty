# T3675 - Linux L11a-3: a GTK remote window shows its connection - the pill naming the machine and link state, and reconnecting in place when the link drops

## Summary

Port the connection pill and in-place reconnect (win32 remote_pill.zig, RemoteReconnect.zig; Mac's remote surface chrome) to GTK. Today a Linux remote window's link state is only visible in +list (connection.state, RemoteLink.listState); when the link drops, nothing on screen says so and nothing re-dials. Show the machine and state on the window (libadwaita, parity is behavior and information), drive the shared connection's reconnect/reattach ladder, and let the user retry or Disconnect from it. Split from T3563.
