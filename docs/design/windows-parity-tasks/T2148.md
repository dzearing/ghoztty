# T2148 - Mac +list marks a pane minimized into a stacked row's strip: JSON minimized=true and text [minimized], matching Windows T2103

## Summary

Windows +list (T2103) writes an additive 'minimized': true on a terminal/viewer leaf that is laid out as a strip of a stacked row (PaneLayout tucked), placed right after 'stashed' and omitted when false, and the text listing prints '  [minimized]' after '[stashed]' (shared src/cli/list.zig already does). Add the same field to TerminalData in macos/Sources/Features/IPC/IPCMessage.swift (encodeIfPresent, after stashed) fed from PaneLayout's tucked set for the pane's window, then drop 'minimized' from the win32-only exemption in src/apprt/ipc/list.zig's T370 golden test.

When it lands, also teach the ghoztty skill in BOTH copies at once (macos/Resources/Ghoztty/skills/ghoztty/SKILL.md and src/apprt/win32/assets/ghoztty/skills/ghoztty/SKILL.md, which hook-json.ps1 pins byte-identical). Add a bullet after the stashed one along these lines: "A pane folded into a stacked row's strip is running and targetable too; `+list` marks it `[minimized]` (JSON: `"minimized": true`)." T2103 held this back so a Mac agent is never taught a field Mac does not report yet.
