# T3668 - Linux L8d-4: a new tab in a remote GTK window opens on its machine

## Summary

Follow-up of T3597 (GTK +new-remote-window). A NEW TAB in a remote window
(keybind / menu / tab-bar button) opened a LOCAL pane, since only splits
inherited the RemoteLink (split_tree.newSplitAt); the Mac and win32 (`addTab`'s
T68 `buildRemoteInherit`) open it on the same machine, in the active pane's
remote cwd, running its command.

The card first bundled four follow-ups; the other three are split out
(2026-11-24): relay windows coming back at relaunch is **T3671**, per-host
shell/cwd defaults is **T3669**, a real relay dial end to end is **T3670**.

## In plain terms

On Linux, pressing "new tab" inside a window that is connected to another
machine opened a tab on your own computer instead of on that machine. Now the
new tab opens on the same remote machine, in the folder you were in, the way
it already does on the Mac and Windows.
