# T3706 - Linux L11b6: undo puts back a pane drag - an in-tab, cross-tab or cross-window drop is one undoable step, as on the Mac

## Summary

Follow-up of T3616. Every pane move on the Mac goes through PaneMoveCoordinator.commit / crossWindowCommit with undoAction 'Move Pane', grouped across the two controllers, so Undo (Cmd+Z) puts the pane back - including a window the move emptied and closed. On GTK SplitTree.dropPaneAt, dropArriving and Window.dropOnTabBar/adoptFromWindow call SplitTree.rearrange directly, so no drag is undoable, and a window a drag empties is destroyed outright (CloseUndo never parks it). Port: record the move on src/apprt/gtk/CloseUndo.zig (both trees, the tab index, and the emptied window to reopen), undo/redo it, and extend test/linux/cli-pane-drag.sh and cli-undo.sh.
