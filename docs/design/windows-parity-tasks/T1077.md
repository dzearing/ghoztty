# T1077 - The Windows download nearly doubled in size: ghoztty.com is a byte-for-byte second copy of the whole terminal

## Summary

win-v1.34.0 ships Ghoztty\ghoztty.exe (33,428,480 bytes) beside Ghoztty\ghoztty.com (33,428,480 bytes) - the same terminal built twice, once GUI-subsystem and once console-subsystem. The MSI went 21.6 MB (win-v1.33.0) -> 41.4 MB and the portable ZIP 20.3 MB -> 39.9 MB in one release. The twin is correct and load-bearing (T245: a bare console shim gets quarantined by Defender, and without the .com a bare 'ghoztty' from PowerShell writes nothing), so this is not a proposal to drop it - it is a proposal to stop paying for it twice. Worth weighing: a .com that is a genuinely small launcher signed/shaped so Defender leaves it alone; sharing the payload between the two PE files; or accepting the size and saying so on the download page so a 40 MB download is not a surprise.
