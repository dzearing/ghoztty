# T3051 - PA-V19: the feedback composer redraws its whole glass band into a new bitmap on every hover, caret or status change (ViewerFeedbackBar.zig:1862)

## Summary

PA-V19 (audit-1, T2963). ViewerFeedbackBar.zig:1862-1870 renders the glass band into a fresh DIB per paint, with no GlassHeadCache unlike the nav bar (ViewerNavBar.zig:1537, T2695); hover/press/caret changes invalidate the whole band (:2379, :2439). Cost (computed): ~150k pixels per paint at 1400 wide, only while the composer is open on glass. Fix: reuse pane_elevation.GlassHeadCache keyed on top. Risk: low. Findings: docs/design/perf-audit/audit-1/V-findings.md.
