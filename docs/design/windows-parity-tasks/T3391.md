# T3391 - Linux: a relay window open at quit does not come back at the next launch (port T3352's relay window record)

## Summary

T3352 gave Windows the counterpart of Mac's RemoteSessionManifest: src/apprt/win32/relay_manifest.zig (pure, none-lane tested) plus RelayWindowRestore.zig (launch worker: token, dial, probeSessionTimeout, reopen). The GTK frontend needs the same: register on relay open, capture the first pane's session id, remove on deliberate close, keep on quit/sign-out, replay at launch off the main thread. The record module has no Win32 dependency and can likely move to a shared apprt location.
