# T1756 - Mac: a window opened after the session agent failed to start says it is not persisted (T1693 parity)

## Summary

Windows T1693: when the local-agent resolve fails (spawn failed, or unresponsive past the deadline) and for the 15s cooldown after it, a new local window opens as a plain shell and its first terminal pane now carries a fixed-literal banner ('Not persisted - the session agent did not respond / could not be started, so this window will not survive quitting or restarting'). The banner is left out of the saved layout. Mac LocalAgentManager.sharedConnectionForNewSurface returns nil silently in the same states (lastConnectFailureAt cooldown, bounded-wait timeout). Port: record why the connect failed, and set the same banner text (src/apprt/win32/persistence_notice.zig) on the first pane of a window opened without the agent; exclude it from SessionLayoutManifest capture. Missing-binary stays a startup notice; protocol skew stays with the mandatory-update path.
