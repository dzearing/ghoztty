# T3367 - Linux L7c: +close and +focus work against the GTK app

## Summary

+close and +focus are served by the GTK frontend. +close is idempotent (an absent target succeeds; a name held by panes in several other windows fails rather than closing one at random, T2250) and closes a pane, a tab or a window as the Mac does. +focus raises a window/pane: Wayland refuses focus stealing, so it goes through xdg-activation and says so when the compositor declines.
