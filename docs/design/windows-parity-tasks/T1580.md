# T1580 - A video in a viewer pane cannot be scrubbed, because the page host answers whole files only

## Summary

T750 widened the MIME table so a <video> element in a rendered .html pane finally gets video/mp4 instead of application/octet-stream. Playback is only half of it: servePageResource reads the whole file and answers 200 with no Accept-Ranges header and no handling of a Range request, so the engine cannot seek. A long clip buffers from the start and the scrubber does nothing. The same gap applies to <audio>. Mac's ViewerSchemeHandler has the same shape, so this moves on both seats.
