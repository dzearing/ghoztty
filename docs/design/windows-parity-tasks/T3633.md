# T3633 - Linux L11g5: the GTK Settings window has Advanced > Config file - where the file links to, the other files and includes, Backups with Restore, and the undo toast with Show Change

## Summary

Port the Mac/win32 Advanced > Config file section (win32 settings_advanced.zig, settings_advanced_view.zig) and the change toast to the GTK Settings window: the file path and its symlink target, the other config files and includes in load order, the backups list (ConfigFileStore.backups) with Restore... (itself backed up first, SettingsModel.restoreBackup), and the toast after each change with Undo (SettingsModel.undoLastChange, refused with the changed-since sentence when the file moved on) and Show / Hide Change (SettingsModel.lineDiff). Seam ops restore / undo / show_change / dismiss like win32.

## In plain terms

On Linux, the Settings window's Advanced page only showed the config file's
path and an "Open File" button. Now it shows what the Mac shows: which file
Settings writes (and where it links to), the other config files Ghoztty also
reads, the automatic backups with a Restore menu that asks first, and the
file's text. After every change a small notice says what was saved, with
Show Change and Undo, and slides away after six seconds.
