# T3667 - Linux L8d-3: the GTK stash survives a relaunch, and resize, equalize, swap and pane drops respect it

## In plain terms

On Linux you could already tuck a pane out of sight (stash it) and bring it
back. But a restart brought every stashed pane back on screen, and resizing,
evening out or swapping panes still counted the hidden ones, so dividers you
could not see moved and a hidden pane could be swapped into view. Now a
restart keeps hidden panes hidden, those layout commands act only on what is
on screen, and Alt-clicking a hidden pane in the sidebar swaps it with the
pane you are in, as on the Mac and Windows.

## Goals

- [x] The session manifest records each stashed pane's place in its tab's stash, and a relaunch stashes it again in that order
- [x] A keyboard resize moves a divider on screen, never a split a stash collapsed
- [x] Equalize evens out the panes on screen only; a collapsed split keeps its ratio
- [x] `swap_split` swaps with a neighbour on screen, never a stashed pane
- [x] The pane-drop resolver judges a drop over the panes on screen
- [x] Alt-click on a stashed sidebar row swaps it with the focused pane
