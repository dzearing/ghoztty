# T3031 - PA-I17: each hosted session runs a second headless terminal that preheats 4 pages and keeps up to 4 MB of scrollback beside the 2 MB raw ring (grid_snapshot.zig, session.zig:931)

## Summary

PA-I17 (audit-1, T2962). Every session feeds its output to both the raw ring and a GridEmulator (session.zig:931-932 `self.ring.append(at, bytes); self.feedEmulator(bytes);`), whose terminal has max_scrollback_bytes (4 MiB, grid_snapshot.zig ~:94-100) and inherits page_preheat = 4 from PageList.zig:34 on page_allocator (:327). Cost (estimated): ~1.6-2 MB committed at a session's first byte (most of the ~3 MB per session that stacks do not explain), up to ~6 MB per busy session, and every output byte is VT-parsed twice (agent and app). Fix: preheat 1 page for the headless emulator (ties to T3003 / PA-M03's preheat change); consider serving gap-fill from the emulator so the raw ring can shrink. Risk low for preheat, medium for the ring. Shared agent code: Mac half filed. Findings: docs/design/perf-audit/audit-1/I-findings.md.
