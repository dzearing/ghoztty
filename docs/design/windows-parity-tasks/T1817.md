# T1817 - Windows port of the --reboot-tui restore scenario

## In plain terms

After the computer restarts (or the background session keeper restarts), a
restored Windows terminal pane should look exactly as it did, with a working
prompt, no stray characters typed into the shell, and nothing going blank when
the pane is resized. The Mac proved this with a scripted scenario; Windows has
the same shared code but nobody has proved it here yet.

## Summary

Split from T1800 (Mac commit 7e78aacf4, merged on this branch by T1796). The
Mac reproduced 14 failures with `scripts/e2e/session-persistence.py
--reboot-tui` and fixed them in shared code: content-only HISTORY replay
(`grid_snapshot` scrollback, `<id>.hist`) instead of the raw ring, client
inbound-ring per-channel overflow plus FLOW resume, `drainRing` yielding on big
replays, panes waiting for their real size instead of the 49x17 placeholder,
`Attached.replay_len` plus the discard-watermark clamp, live-cwd re-sampling,
orphan snapshot sweep, extended VT mode resets, and soft-wrap/OSC 133 kept on
restored rows.

T1800 itself landed the one piece that was explicitly POSIX-only (per-child
input writer threads, now on Windows too). What is left is the Windows proof:
an on-box acceptance script, run on the background test desktop, that kills
and restarts a debug `ghoztty-agent.exe` (by ExecutablePath, never by name)
with a TUI and a pwsh pane mid-session, re-attaches, and asserts the outcomes
below. Any assertion that fails is a defect to fix here (or a new task).

## Validation criteria

- [ ] Restored pane shows the exact pre-restart history (content match).
- [ ] No terminal query replies are answered into the new shell (no stray
      `^[[...` text at the prompt).
- [ ] No keyboard/mouse/bracketed-paste modes left on after restore.
- [ ] A live prompt answers typed input after restore.
- [ ] The restored pane opens at its real size, not 49x17.
- [ ] A pane resize after restore does not blank the restored output.
- [ ] The script runs on the background test desktop and takes no foreground;
      it has a guard-due row.
