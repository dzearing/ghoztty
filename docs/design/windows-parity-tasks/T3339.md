## In plain terms

On Linux a script (or a program inside the pane) can now pin a note above a
terminal - a status line, a checklist, a small table, clickable links - and it
stays there while the terminal scrolls and clears, exactly as on Mac and
Windows. The terminal moves down to make room instead of hiding under it. The
pane's busy/idle/question state can be set the same way and is reported by
`ghoztty +list`.
