# T1754 - The palette's update row does not look or read like Mac's, and there is no Cancel or Skip Update beside it

## Summary

Found landing T1676, which made the Windows row conditional like Mac's. What is still different (TerminalCommandPalette.swift updateOptions): Mac titles the row 'Update Ghoztty and Restart' (Windows: static 'Install Available Update', no version), shows it emphasized in its own section ABOVE the rest with the version as a badge, and pairs it with 'Cancel or Skip Update' (updateViewModel.state.cancel()), which dismisses the offer. Windows has no palette way to dismiss an offer, and no per-version skip at all - check what the badge/menu row should do after a skip before building (the offer record in update_badge.zig would need a skipped-version field).
