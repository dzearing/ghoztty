# T3279 - Hero carousel preview tiles on Windows are elevated cards like Mac d40352d30: soft drop shadow, hairline rim (20%/40% hover/60% selected white, black on light themes), the selected tile backlit like a focused pane with its light masked outside the card, 5 px corner radius, unselected pictures at 70%

## Summary

Port Mac d40352d30 (HeroCarouselView.swift CarouselTile; docs/reference/pane-style.md hero section). Windows carousel is src/apprt/win32/HeroCarousel.zig. Mac visuals port faithfully (2026-10-25 directive).

## In plain terms

In hero mode the strip of small pictures beside the big pane used to be flat
rectangles with a thin coloured outline, and the ones you were not looking at
faded so far their edges almost vanished. On Mac they are now little raised
cards: each sits on a soft shadow with a faint light edge, and the one you have
selected glows softly from behind. Windows now draws them the same way.

## Goals

- [x] every tile sits on a soft drop shadow (Mac: radius 6, 3 down, 32% dark / 14% light)
- [x] a hairline rim that never fades: white 20/40/60% (normal/hovered/selected), black 14/25/35% on a light theme
- [x] the selected tile backlit by white light outside its edge only (55% dark / 90% light), never over its picture
- [x] pictures at 100% selected / 85% hovered / 70% otherwise, translucent over the band like Mac's
- [x] 5 DIP rounded corners, antialiased, on the design-system radius table
