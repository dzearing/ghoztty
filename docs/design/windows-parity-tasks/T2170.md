# T2170 - Confirm on a real install that Apps & Features shows the release number

## In plain terms

T2168 changed the installer so Windows Settings > Apps shows the release
number (e.g. 1.43.4) instead of a date code (26.10.2290). Everything that could
be checked without a real install of the new package has been. This task is
the last step: once a release with the fix is out, look at a real install and
confirm Settings shows the right number, exactly once.

## Summary

What T2168 proved (2026-10-22, d850eeb47): the WXS generator emits the hidden
flag and the HKCU entry; build-msi.sh's read-back fails the build without them
(install-restart E8/E9); Fork CI's wixl compile + read-back went green on the
real package; verify-release-assets checks a published package for both;
arp-version-check pairs the hidden registration with the listed entry
(arp-version B8-B11) and every harness that counts entries counts the listed
ones (update-real-msi and update-graceful green on real throwaway installs of
pre-fix packages).

What it could not prove: what Windows writes for a package carrying the fix.
Two routes, either closes this:

1. `powershell -NoProfile -File test\win32\install-walkthrough.ps1 -Msi <the
   release's Ghoztty-<v>-x64.msi>` - a throwaway identity, so nothing of the
   user's is touched. B4b must pass, C6 must count exactly one entry. Its act
   D puts an msiexec dialog on the user's desktop (go.md's NEVER PULL FOCUS
   rule), so this route is NOT RUN unless the user asks for it.
2. After the user's terminal takes the update:
   `powershell -NoProfile -File scripts\arp-version-check.ps1` reads ARP
   VERSION OK, and `test\win32\arp-version.ps1` arm C goes green (its guard is
   acked to this task until then).

Also look once at Settings > Apps > Ghoztty by hand if the user is at the box:
Modify still opens the Repair / Cancel prompt (T1300), Uninstall removes it.

## Validation criteria

- [ ] install-walkthrough `-Msi <published fixed MSI>` B4b and C6 green.
- [ ] arp-version C1 green against the user's updated install (guard stamped).
- [ ] Exactly one Ghoztty line in Apps & Features (arp-version `listed` OK).
