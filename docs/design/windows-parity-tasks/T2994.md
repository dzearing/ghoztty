# T2994 - PA-W10: the pane stack grid is heap-built four or five times in one chrome paint (Window.zig:11593)

## Summary

PA-W10 (audit-1, T2960). stackGridOfTab allocates via the GPA (Window.zig:11593 buildWith; pane_stack_grid.zig:86) and runs computeBuilt on each call. One elevated paint calls it from gutters (:13292), collectSlots (:5188 via :14253), tuckedStrips (:13849 via :14351), the gutter bar (:14396), and paintStackStrips again. Estimated a handful of alloc/free + layout computes per paint, growing with pane count; also every repaintPaneDesk. Fix: build once per paint and pass it down, or cache keyed on a tree/rect/scale generation. Risk low-medium (staleness mid-glide).
