# T3838 - win32: a script's +rename hides a tab title the user pinned from the pane sidebar (a group move on a window with no window-wide pin)

## Summary

win32 pinWindowName (PaneSidebar.zig ~6669) pins the TAB's title (setTabTitlePin) when the window has no window-wide pin, and renameWindow (IpcHandlers.zig ~1220) only refuses over a user's WINDOW pin (window_title_owner.keptFromScript). groupName puts title_override over tab_title_pinned, so a script's +rename of that window hides the group title the user just set - the script moves the window out of the user's group. Mac protects it (a Mac window is the tab, windowTitleIsUsers). Linux closed the same gap in T3702 with pane_sidebar_all.renameKept: refuse while any tab of the window carries a pin, naming the targeted tab's first. Port that rule (window_title_owner) and add a step to S7 of test/win32/window-title.ps1: group a tab-pinned window from the sidebar, +rename it, expect the refusal and the title kept. docs/claude/cli.md's 'which +rename never touches' sentence changes with it.
