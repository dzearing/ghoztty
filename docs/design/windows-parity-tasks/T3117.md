# T3117 - PA-W03 remainder: the tab strip re-measures every tab title with GetTextExtentPoint32W on every strip paint; cache the measured width per title and font

## Summary

T2987 stopped the caption and strip painters running for paints whose clip misses their band, and stopped them allocating a DC + DIB per paint. The third part of PA-W03's fix was not done there: `paintTabBar` (Window.zig, the `prefer[i]` loop) still calls `textWidth(tabBellPrefix)` + `measureTitleText` for EVERY tab on every strip paint, so a spinner title (10 strip paints/s) measures N titles ten times a second though only one changed.

Fix: cache the preferred width per tab keyed on (title bytes or a hash, bell prefix, font handle / em, scale), invalidated on font or DPI change; measure only tabs whose key moved. Keep `measureTitleText`'s fixed-cell treatment of the animated glyph (T60) - the key must be the measured string, not the raw one, or the cache misses every frame.

## Validation criteria

- [ ] unit test: the cache returns the stored width for an unchanged key and re-measures on a title / font / scale change
- [ ] a strip paint with N tabs and one changed title measures one title (probe counter or trace)
- [ ] tab-strip.ps1 (T235/T249/T737 sizing sections) stays green
