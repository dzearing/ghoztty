# T3549 - Linux: a restored window comes back at its recorded size, and its tabs keep their pinned titles

## Summary

T3397 restores the GTK app's windows, tabs, splits and panes but not the window's size (the manifest's frame) or a tab's pinned title. Wayland gives a client no window position, so position stays the compositor's; size can be recorded (gtk.Window default size) and set before present, and tab title overrides captured into Tab.title. Mac: frame + titleOverride restore (docs/reference/session-persistence.md, What a relaunch restores).
