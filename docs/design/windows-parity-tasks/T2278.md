# T2278 - Windows sidebar icons are not coloured per pane: on Mac each pane has its own hue, its sidebar icon is drawn in it, and hovering a row or tile tints that pane's card (Mac 075d787d1, dc2bbab6b, 75dc046e3)

## Summary

Mac 075d787d1: each pane gets a hue by golden-ratio steps along its tree position; hovering a tile or row tints the pane's card in that hue (in 0.12s, out 0.2s). dc2bbab6b: the hover tint is a 10% wash with a 45% rim. 75dc046e3: only the GLYPH carries the hue (no tinted tile glass); hues are light and soft on a dark theme, deeper on a light one, so icons contrast with the sidebar; unfocused icons only slightly quieter. Windows sidebar draws monochrome icons/monograms.
