# T3287 - relay-account.ps1 section 9 races its own retry: the pending-revocation record reads back without the device token or relay, and relay.env is already gone (1 of 4 runs, parallel worker, 2026-11-20)

## Summary

Seen once in an acceptance-parallel worker run (20261120-135331, 00-relay-account.log lines 115-118) while the same build ran section 9 green alone and in two other runs. The armed record was read after the retry had already finished (record cleared, relay.env deleted), so the three read-back asserts failed while every later assert passed. The asserts read state the retry is free to consume; read the record once at arm time, or hold the revocation relay down until the read-back is done.
