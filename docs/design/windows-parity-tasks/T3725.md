# T3725 - Remote web viewer: the agent's page requests honour that machine's HTTP proxy for public hosts

## Summary

T2221's agent-side requests go direct: the std HTTP client is built with no proxy, so on a remote machine that reaches the internet only through HTTP_PROXY/HTTPS_PROXY (a corporate box) a page's public resources fail with network_failed while its localhost dev server works. Honour the agent machine's proxy settings (env vars on Mac/Linux, the WinHTTP/IE proxy on Windows) for non-loopback hosts, never for loopback.
