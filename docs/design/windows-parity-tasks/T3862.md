# T3862 - PA-R26: every window activation or deactivation forces a full frame on each terminal pane of the active tab and rebuilds the storage an idle pane had released

## Summary

From audit-5 (T3316). Window.zig:5153-5177 (applyView -> syncPace) sends a .pace change to every terminal pane of the active tab when inUse() flips; renderer/Thread.zig:456 marks every message except reset_cursor_blink as force_frame, and :548 applies it. So each focus change between windows pays one forced frame per pane, and an idle pane re-creates the frame storage it had released (the PA-R20 path, T3141). Introduced by 7ce6815435 (T3761). Fix: do not force a frame on a pace change that lowers the cap, and only on a rise when output is actually held. Detail: docs/design/perf-audit/audit-5/R-findings.md.
