# T3294 - Restart Ghoztty and Background Sessions quits and relaunches anyway when the agent kill was refused, so the user's sessions silently survive the command that promised to end them

## Summary

When terminateAgent refuses (T771: app in the agent's own kill-on-close job, measured by app-restart.ps1 R5), restartApp(.app_and_agent) logs 'background agent stopped=false (the relaunch starts a fresh one)' and quits for the relaunch guard regardless. The log line is false (the relaunch re-attaches the SAME agent) and the user, who confirmed a dialog saying their sessions would end, gets a relaunch with every session intact and no word why. Decide the honest outcome (stay up and say so, matching Mac's equivalent), implement it, and extend R5 to assert it.

## In plain terms

"Restart Ghoztty and Background Sessions" asks you to confirm that your
running terminals will end. When Ghoztty was itself started from inside one
of those terminals, it cannot stop them without closing itself too. It used
to restart anyway: the window came back with every session still running and
nothing said why. Now it does not restart. Everything stays as it was, and a
notice explains why and what to do instead.

## Goals

- [x] The "cannot stop the sessions" case is found before anything changes:
      no relaunch armed, no dropped connection, no quit.
- [x] The user sees a notice saying nothing was restarted, that their sessions
      are still running, why, and what to do.
- [x] The log line no longer claims a fresh agent when none was stopped.

## Design

Mac has no equivalent yet (T1805 is the Mac half of the restart commands and
is still todo), so the outcome follows the summary's "stay up and say so",
the same shape as the existing "could not restart itself, nothing was closed"
notice. `LocalAgent.stopWouldEndThisApp` asks T771's `AGENT_OWNS_JOB` question
up front (`restartForUpgrade` retires the shared connection and `restartApp`
arms the relaunch BEFORE the kill, so the refusal inside `terminateAgent` came
too late to leave things as they were). `restartApp` now returns
`app_restart.Outcome` (`quitting` / `not_armed` / `agent_unstoppable`), and
`showRestartFailed` takes the outcome and shows `app_restart.failedText`. The
agent-update "install now" path takes the same route. `terminateAgent`'s own
refusal stays as the net under it.
