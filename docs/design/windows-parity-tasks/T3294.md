# T3294 - Restart Ghoztty and Background Sessions quits and relaunches anyway when the agent kill was refused, so the user's sessions silently survive the command that promised to end them

## Summary

When terminateAgent refuses (T771: app in the agent's own kill-on-close job, measured by app-restart.ps1 R5), restartApp(.app_and_agent) logs 'background agent stopped=false (the relaunch starts a fresh one)' and quits for the relaunch guard regardless. The log line is false (the relaunch re-attaches the SAME agent) and the user, who confirmed a dialog saying their sessions would end, gets a relaunch with every session intact and no word why. Decide the honest outcome (stay up and say so, matching Mac's equivalent), implement it, and extend R5 to assert it.
