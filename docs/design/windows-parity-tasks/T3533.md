# T3533 - Linux viewer pane cannot be split narrower than its nav bar (~260px); the neighbour pane gets squeezed instead

## Summary

Measured in T3416's viewer-image.sh (2026-11-22): splitting a 399px-wide image viewer pane right left it at 259px, and a second right split did not narrow it at all - the nav bar (back/forward/reload/home/reveal buttons + address entry) has a natural minimum width GTK will not shrink below, so the split tree cannot honour its ratio and the sibling pane absorbs the difference. Mac's nav bar truncates its address field and a pane can be made as narrow as a terminal pane. Fix in Viewer.zig buildBar: let the address entry shrink (small width-chars + hexpand) and/or hide lower-priority buttons below a width, so a viewer pane's minimum width matches a terminal pane's. Acceptance: two right splits of a viewer pane each roughly halve its width (the steps seam's image/state viewport).
