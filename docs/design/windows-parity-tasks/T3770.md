# T3770 - Settings > Shell: a Starting folder per shell (WSL takes a Linux path, default ~), validated as you type; new tabs/splits/windows on that shell start there (T3754 split)

## Summary

The per-shell half of T3754, split off so the inheritance rule could land first. Today every shell starts in the one global 'Start new windows in' folder (working-directory), and a WSL shell always starts at ~. Add a per-shell starting folder: a new repeatable config key (e.g. shell-working-directory = <spec>=<folder>, spec as --shell takes it: pwsh.exe, wsl:Ubuntu) and a Settings > Terminal > Shell list with one Starting folder row per installed shell; the WSL rows validate a Linux path (/..., ~, ~/...), the Windows rows a Windows path that exists. Used wherever a pane opens on that shell with no inherited folder: shell_family.inherit returns null across families today, and that null should become the shell's own starting folder instead of ~ / the global folder. CLI surface is identical on Mac (the key exists there too; Mac rows list its shells) - file the seat: mac half when this lands.

**Scope as landed (this turn):** the key, its behavior on every local spawn path, and a Settings row that takes `shell=folder` values and checks each as you type. The card's *one row per installed shell* presentation is **T3787** (it needs dynamic rows in the static page table). Mac half: **T3736** (already filed; noted with the key). Linux half: **T3737** (noted; the Settings row is a comptime non-Linux branch until then).

## In plain terms

You can now give each shell its own starting folder - for example, your Ubuntu WSL shell can open in `~/src` while PowerShell opens in `C:\src`. Before, every Windows shell opened in the one "Start new windows in" folder and every WSL shell in your Linux home. It applies whenever a new pane has no folder of its own; a pane opened from another pane of the same kind still follows that pane's folder. Set it in Settings > Terminal > Shell > "Starting folder per shell", which tells you right away if a folder can't work (a Windows folder for WSL, or a folder that doesn't exist).
