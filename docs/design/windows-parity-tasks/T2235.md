# T2235 - Ctrl+F in an image viewer pane opens an empty find card where Mac declines Cmd-F (no text to find)

## In plain terms

On a Mac, pressing Cmd-F in an image pane does nothing, because a picture has no text to search. On Windows, Ctrl+F in an image pane opens the find card anyway, and any search there finds nothing.

## Summary

Found by T1327. Mac declines find, quote and copy-selection in an image view (`ViewerImageView.swift`, around the "declined rather than shown" comment). Windows' `ViewerPane.handlePaneChord` sends `.find` to `openFind()` in every mode, image included; only the copy chord is mode-aware (`self.mode == .image and viewer_accel.copyChord`). The fix is to decline `.find` / `.find_next` / `.find_previous` while `mode == .image`.

The Windows skill already says "Ctrl+F finds nothing in an image pane", which is true either way.
