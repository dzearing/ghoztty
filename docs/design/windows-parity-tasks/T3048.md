# T3048 - PA-V16: each diff refresh deep-copies the file list on the GUI thread and joins line counts in quadratic time (ViewerPane.zig:2319)

## Summary

PA-V16 (audit-1, T2963). completeDiff snapshots the whole file list on every completion, patch completions included (ViewerPane.zig:2319-2320, ViewerDiffProbe.zig:501-517); the numstat join is O(n^2) (:600-617, worker). Cost (estimated): n allocations every 2 s; ~25 M compares at 5,000 files. Fix: compare inside complete() before the swap; hash the numstat join. Risk: low. Findings: docs/design/perf-audit/audit-1/V-findings.md.
