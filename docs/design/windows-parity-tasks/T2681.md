# T2681 - Settings curated rows: native controls for sliders, steppers, sizes in MB, colors, shell-integration flags, and shell/folder pickers (those rows edit their value as text today)

## Summary

Follow-up of T2585. `settings_pages.zig` carries Mac's control for every curated row, but only `toggle`, `picker` and `segmented` are drawn as controls; the rest fall back to the All Settings text field (validated, so nothing invalid is written, but not Mac's experience):

- `slider` (Dim unfocused panes - Mac shows 1 - value as a percentage -, Carousel width), `stepper` (Stack panes narrower/shorter than, with the unit), `megabytes` (Scrollback size, bytes shown as MB), `color` (Dimming color, Divider color, with the "Background"/"Automatic" unset label), `flags` (shell-integration-features as checkboxes), `shell` (an existing-executable check, Windows shell flavors), `folder` (a folder picker for working-directory), `text` keeps its placeholder.

Each control writes through `SettingsModel` like the rest; `ipc_settings` gets a way to drive each (set already covers the value path). Extend `test/win32/settings-window.ps1`.

## Validation criteria

- [ ] each control kind draws as its control and writes the same value text the parser accepts
- [ ] the slider for unfocused-split-opacity shows the inverted percentage
- [ ] scrollback-limit reads and writes in MB
- [ ] settings-window.ps1 green with assertions per control kind
