## Progress log

- 2026-11-16 22:33: Found in T3193: Window.init copies the shared window's scale onto a born-parked controller, but each Surface reads its DPI from its own HWND (Surface.updateDpiScale -> GetDpiForWindow), and that HWND is a child of App.parkHost - a 1x1 popup at 0,0, i.e. the primary monitor. With the shared window on a monitor of another scale, the parked grid is computed at the primary's cell size and changes on adopt (adoptWindow -> refreshPaneDpi). Mac: a parked terminal keeps the backing scale of the window it was last in (SurfaceView.backingSize). Fix shape: after creating a pane under the park host, handleDpiChange(dpi of the shared window) instead of null; same for panes made in a parked workspace by +split. Acceptance needs a mixed-DPI box (none here) - unit-test the choice of DPI source.
