# T3042 - PA-V10: the viewer find card deletes its bitmap while it is still selected, which likely leaks a bitmap on every card resize (ViewerFindBar.zig:764)

## Summary

PA-V10 (audit-1, T2963). releaseCardSurface (ViewerFindBar.zig:764-768) calls DeleteObject on card_bmp while it is still selected into card_dc (selected at :745, original never saved), then deletes the DC. Deleting a selected bitmap fails, so each resize, scale or theme change likely leaks one card-sized DIB (inferred, not observed). Fix: delete the DC first, as ViewerTOCPanel.zig:1552-1553 does, or restore the original bitmap. Risk: none. Findings: docs/design/perf-audit/audit-1/V-findings.md.
