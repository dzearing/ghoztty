# T1731 - Walk the first published release that carries the DLL Repair/Cancel action (T1730) with install-walkthrough, no -Msi

## Summary

T1730 validated the DLL custom action against the published 1.36.36 package rewritten to the new authoring; only a real wixl build proves the Binary row and type-1 action wixl emits. Once daily-publish ships a win-v release built after T1730, run test\win32\install-walkthrough.ps1 with no -Msi and confirm D3/D3b/D5 ALL PASS.

## In plain terms

When someone runs the Ghoztty installer while Ghoztty is already installed,
it asks whether to repair or cancel. Pressing Cancel used to end in a
confusing "Error 1722". A fix went in earlier the same day, and this
task confirms it by running the real installer people download. A fix that
passes only in a test copy doesn't count.
