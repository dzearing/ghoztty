# T3065 - PA-C11: a drag selection re-tracks two pins and forces a full rebuild on every mouse event, even when the selection did not change (Surface drag / Screen.select)

## Summary

PA-C11 (audit-1, T2964). src/Surface.zig:5969 and :6115-6128 call Screen.select on every drag event; src/terminal/Screen.zig:2414-2428 always tracks two new pins, untracks the old pair and sets dirty.selection, and single-click drag has no same-selection guard, so sub-cell movement costs a full rebuild each event. Fix: skip select and queueRender when the new selection equals the current one. Risk: low. Shared code: Mac half T3071. Findings: docs/design/perf-audit/audit-1/C-findings.md.

## Validation criteria

- [ ] unit test: a drag event that yields the same selection does not set dirty.selection
- [ ] drag-select harnesses green
