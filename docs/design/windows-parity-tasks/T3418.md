# T3418 - Linux L9i: markdown table of contents side panel

## Summary

Per viewer-panes.md Table of contents: a libadwaita sidebar card of headings (two or more) with scroll-spy selection, click pins the selection, a left gutter in a wide pane with a draggable edge whose width is a shared preference, an overlay toggled from the nav bar under 720 px, open state not restored.

## In plain terms

On Linux, a long markdown document opened in a viewer pane had no table of
contents, so the only way around it was scrolling. Now a list of its headings
sits beside the text, highlights the section you are reading, and jumps to a
section when you click it. In a narrow pane the list hides behind a button in
the pane's toolbar, the way it does on the Mac.

## Goals

- [x] a CONTENTS card listing the headings, nested by level, for markdown with two or more headings
- [x] the selection follows the scroll; a click scrolls there and holds the selection through the scroll
- [x] wide pane: a left gutter the page reserves, with a draggable edge whose width is the shared preference
- [x] narrow pane: an overlay toggled from the nav bar, dismissed by a row click, switching live with the pane width
- [x] open state is not persisted
