# T2422 - Windows all-windows sidebar: every tab of a window titled '<project>: <name>' joins that project group, not only the selected tab (Mac 6bd2962eb tab groups group as one)

## Summary

Mac main 6bd2962eb: every tab of a native tab group titled '<project>: <name>' joins that group, so a tab group groups as one. Windows: work out what a 'tab group' maps to here (tabs in one Ghoztty window); if the Windows all-windows list shows tabs/windows per tab, make every tab of a '<project>: ' window list under that project. If the concept has no Windows counterpart (the list is one row per top-level window), record that with evidence and close. Ref PaneSidebarState.swift in 6bd2962eb.

## In plain terms

On the Mac, a window with several tabs named "projects: manager" showed only
one of its tabs under the "projects" group in the all-windows sidebar; the
other tabs sat loose beside it and stayed visible when the group was folded.
Windows never had this bug - the name belongs to the whole window, so every
tab already joins the group - but nothing proved it. Now a test does.

## Goals

- [x] Decide what a Mac "tab group" maps to on Windows: the tabs of one
      Ghoztty window, each a row in the all-windows list (`gatherAll`).
- [x] Confirm every tab takes the window's title: `groupName` returns the
      window-level `title_override` for every tab `t`, ahead of the tab's own
      pinned title and its pane's name - the same precedence Mac now has
      (`effectiveWindowTitleOverride ?? titleOverride`).
- [x] Prove it on the box, with a demonstration that the check can fail.

## Validation criteria

- [x] A window titled `projects: manager` with three tabs (two opened AFTER
      the title) lists all three under `projects`, side by side - section 10 of
      `test\win32\pane-sidebar-all-windows.ps1` (`order=alpha|ghoztty/feature-2|projects/manager|projects/manager|projects/manager`), ALL PASS 158.
- [x] Folding `projects` hides all three tabs' rows and keeps the header -
      same section, same run.
- [x] Teeth: with `groupName` mutated to honour the window title on the
      selected tab only (Mac's old shape), section 10 went red 3 failures
      (`order=alpha|C:\Users\David|C:\Users\David|ghoztty/feature-2|projects/manager`,
      "1 of 3"); mutation reverted, re-run green.
