# T2118 - Machine chooser detail pane no longer repaints when the selection moves: ipc-machine-chooser.ps1 'the detail pane follows the selection' reads the same pixel signature before and after (659113408 -> 659113408) on clean 3dc80e920

## Summary

Reproduced twice on lane b with T2099 applied and once on a clean build of 3dc80e920 (scratch worktree D:\git\ghoztty-b-t2099-base), so it predates T2099. Either the detail pane stopped following the list selection (user-visible: picking a different machine shows the old one's details) or the harness's selection move no longer lands. Find out which by reading the pane after a real click; bisect from the last green chooser-shape stamp. Acceptance: ipc-machine-chooser.ps1 ALL PASS.

## In plain terms

A test said the machine picker kept showing the old machine's details after
you moved to a different machine. The picker is fine - it does switch from
"This PC" to the machine you moved to. The test was looking at the wrong part
of the window: a strip that only holds the "New Window" button, which looks
the same whichever machine is picked. It now looks at the header where the
machine's name actually appears.

## Goals

- [x] find out whether the picker or the test is wrong
- [x] point the test at where the selected machine's name is drawn
- [x] keep the check able to fail (negative control red)

## Root cause

Test defect, not an app defect. `ipc-machine-chooser.ps1` sampled DIP
300-620 x 60-110 of the client for both "the detail pane renders the
machine's identity" and "the detail pane follows the selection". Since T602
(2026-08-16) the selected machine's glyph, name and subtitle are drawn in the
header BAND (`chooser_layout.zig` `identity_glyph`/`identity_title`, glyph at
DIP 16, band above the rule at DIP 52); the detail column begins at its action
row. So that rectangle held only the "New Window" button, and both claims were
measuring a button. The second went red once nothing else in the strip
differed between the two selections.

Proved with a probe run (not committed): `LB_GETCURSEL` moved 0 -> 1 on the
posted Down, and captures before/after showed the band switch from "This PC /
This machine" to "E2E-Box / Online - e2e.local" with the sampled strip
pixel-identical.
