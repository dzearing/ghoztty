# T3724 - Remote web viewer: a dev server's live-reload WebSocket reaches the remote machine too

## Summary

Dev servers push live reload over a WebSocket (Vite, webpack, Next). WebView2's WebResourceRequested does not intercept WebSocket traffic and T2221's WEB_REQUEST drops Upgrade, so a remote page previewed through the tunnel loads but never hot-reloads. Needs a stream frame pair on web_tunnel (open/data/close, flow-controlled like a session channel) and a page-side shim or a local loopback relay the viewer's page connects to. Decide the mechanism; the experience is that saving a file on the remote box refreshes the preview here, as it does for a local dev server.
