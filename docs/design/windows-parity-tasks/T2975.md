# T2975 - PA-R09: panes on a background tab keep all their GPU surfaces even with hero mode off, and a hidden window keeps each pane's interop texture and back buffers

## Summary

PA-R09 (audit-1, T2959). OpenGL.zig:1536-1544 releases targets only when the whole WINDOW is hidden (T2474), and generic.zig:1261-1263 then shrinks only the GL target; Presenter.texture and the two back buffers survive. A tab switch (Window.zig:4785-4790) hides the panes without any release, by design for hero mode's carousel, even when hero mode is off. Cost estimated: ~16-19 MB per full-size pane survives a window hide; ~22-25 MB per background-tab pane. Fix: on window hide also destroyShared() (begin() rebuilds it when texture == null, gl_comp_present.zig:771-778); keep back buffers for DWM thumbnails. For background-tab panes with hero off, release target + shared texture and shrink the chain; reveal already waits for a frame (carried_hidden). Note: the '1x1' release actually allocates 256x256 (Target.zig bucket). Risk medium: one texture create + ResizeBuffers on tab switch; blank-on-reveal hazard if the reveal wait is bypassed. Mac shrinks occluded targets to 1x1; confirm whether Mac background tabs count as occluded (Mac seat).
