Both read the app's stderr `pane sidebar rows` line and the session manifest; find the shared state (per-user file, timing under load) and fix it, or add `# @parallel-unsafe` with the reason.

## In plain terms

Two of the pane-sidebar test scripts used to fail now and then when the test
runner ran them at the same time as other tests, and pass when run alone. That
made the test runs noisy. They no longer do: a month of runs has them passing
every time beside other tests, so there is nothing left to fix and no reason to
make them run alone (which would slow every run).
