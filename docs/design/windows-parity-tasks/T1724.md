# T1724 - The Mac gives up on restoring windows when its background helper is a few seconds late, and never retries

## Summary

Windows (T976) retries the launch restore for ~55s when the local agent was not reachable yet, then (T1003) closes the untouched blank stand-in window once the real windows are back. macOS SessionLayoutRestore.restoreSessionLayoutWindows logs 'local agent unreachable; keeping N manifest entries for next launch' and stops, so a Mac launch that beats its agent shows only the default window until the next relaunch. Port both halves: a bounded deferred retry, and closing the launch's blank window only if nothing was ever sent to its shell (Termio.input_written, now in the shared core) and it still has one tab and one terminal pane.
