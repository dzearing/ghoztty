# T3174 - perf-baseline viewer.hidden cannot see what T3035's suspend saves: it records renderer private bytes only (unchanged, 80.9 MB vs 76.8-80.1 MB) - add renderer working set, the suspended state per pane, and a heavy live page

## Summary

Filed by T3035. T3035 made a hidden viewer lower its renderer's memory target
at once (`ICoreWebView2_19.MemoryUsageTargetLevel = Low`) and suspend the page
after 30 s hidden (`ICoreWebView2_3.TrySuspend`); `test\win32\hidden-viewer.ps1`
section D proves both happen and that work and show wake it. But
`scripts\perf-baseline.ps1 -Phase viewer` could not show a saving:

| | hidden renderers private MB (3 procs) | hidden tree CPU |
|---|---|---|
| before (T3033 dbg-5..7) | 79.7 / 80.1 / 76.8 | 0.23 / 0.21 / 0.10 % |
| after (temp\T3035-dbg-1.json) | 80.9 | 0.08 % |

Two reasons the phase cannot see it, both measurement gaps:

1. It reads **private bytes** only. A low memory target and a suspend mostly
   give back working set (trimmed pages, dropped caches), not committed
   private memory. Add renderer **working set** (and private working set) to
   the open and hidden blocks.
2. Its pages are tiny (a markdown file, a git-status listing, a static page
   with no timers), so there is little to trim and no timer to freeze. The
   audit's 50-150 MB per hidden viewer estimate assumed a real website. Add a
   heavy live page (scripted timers, a large DOM, images) served from the
   loopback listener.

Also record whether each viewer actually reached suspended in the hidden
span (the app logs `TrySuspend suspended` at debug level; the phase does not
read the app log today), since the phase hides by opening a tab rather than
minimizing and only `hidden-viewer.ps1` has proven the minimize path.

## Validation criteria

- [ ] viewer.open and viewer.hidden blocks carry renderer working set next to private bytes
- [ ] the phase includes a heavy live page and records per-pane suspended state at the end of the hidden span
- [ ] an A/B (`-Exe` on a pre-T3035 build vs head) states the hidden saving in working set and CPU, or states there is none
