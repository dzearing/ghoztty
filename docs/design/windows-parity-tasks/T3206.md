# T3206 - Single-window mode: Restore All switches the window to each workspace it rebuilds in turn instead of parking them behind the frontmost

## Summary

Found in T3187. `App.adoptRestoreAllLocal` / `adoptRestoreAll` build the restored windows in `frontmostLastOrder` and each with `background = false`, so in single-window mode every rebuilt workspace goes on show in turn (one hand-off and desk fade per window) before the frontmost, built last, ends on show. The end state is correct; the path there is a cascade of switches. Fix: in single mode build them parked (`restoreWindowShown(..., background = true)`, as `App.restoreParksBehindShown` does for the launch pass) and show the frontmost one once at the end (`showWorkspace`). Validation: a section in `test/win32/single-window-mode.ps1` that runs Restore All (machine chooser) and counts `workspace adopted the window` log lines - exactly one.

## In plain terms

In "all in one window" mode, pressing Restore All in the machine chooser
flipped the window through every workspace it brought back, one after another,
before landing on the one that had been in front. Now the restored workspaces
come back quietly behind the scenes and the window switches once, straight to
the one that was in front. Building this also found a crash: that final switch
closed the chooser, and the chooser then touched itself after it was gone -
Restore All in single-window mode crashed the app.

## Goals

- [x] Restore All (local and cross-machine) builds workspaces parked in single-window mode
- [x] the frontmost goes on show once, at the end
- [x] the chooser's Restore All reply survives the chooser closing during the rebuild (crash fix)

## Validation criteria

- [x] Restore All in single mode: every rebuilt workspace is present, the frontmost on show, and exactly one hand-off logged - section M of `test/win32/single-window-mode.ps1`, green (265 assertions) through `acceptance-parallel.ps1 run`
- [x] the oracle can fail: with the parking reverted (each built on show) M3 is red - `3: swm-lb,window-2,swm-la` hand-offs
- [x] no crash after the hand-off - the first run of M, before the MachineChooser fix, crashed in `restoreAllFinished` (`self.close` on the chooser the hand-off had cancelled); green after
