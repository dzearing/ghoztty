# T3847 - The Linux headless seat has no pointer, so a real pointer drag (tab, pane, sidebar row) is still NOT RUN

## Summary

T3713 measured that hl_start_seat's sway seat has capabilities 0 and that swaymsg 'seat seat0 cursor set/press/release' reaches no client while no pointer device exists. wtype only makes keyboards, and wlrctl (apt 0.2.2, not installed) makes a short-lived virtual pointer per call, so it cannot hold a button down across a move. Build a held virtual pointer for the harness: a small zwlr_virtual_pointer_v1 client (wayland-scanner and gcc are in the distro, the protocol XML would be vendored under test/linux/lib/) that stays alive while swaymsg seat cursor or the client itself drives press/move/release, as hl_seat_pointer beside hl_seat_keyboard. Then convert the NOT RUN pointer-drag notes in docs/claude/linux.md (pane sidebar row drag, tab/window drag, pane header drag, hover) into real checks.
