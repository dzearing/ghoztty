# T1891 - Windows pane sidebar: another window's rows should say 'Raise its window and focus it / restore it there' like Mac's

## Summary

Found closing T1845. Mac `PaneSidebarRow.rowHelp` gives another window's row its own hint: "Raise its window and focus it" (grid) / "Raise its window and restore it there" (stashed). The Windows panel uses the own-window hints for every row ("Click to focus" / "Click to restore"), so in the all-windows scope the tip does not say the click will raise another window. Fix in `PaneSidebar.syncTips` (row tools, `e.own == false`) plus the rail tile tip's hint line; constants beside `pane_sidebar_hover.rowHint`.
