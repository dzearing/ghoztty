# T1909 - Ctrl+C at an image pane also puts the FILE on the clipboard, so a paste into Explorer makes a copy (Mac writes the file URL beside the picture)

## Summary

Mac's ViewerImageSurface.copy writes the NSImage AND the file URL (main 1d513083a), so pasting into Finder or a terminal gets the file. T1872 landed the picture half on Windows (PNG + CF_DIBV5). The file half is CF_HDROP plus 'Preferred DropEffect' = copy. Check first which readers prefer a file drop over a bitmap when both are present (Outlook, Teams, Word, Slack, Chromium pages) - if any turns an inline picture paste into an attachment, that is an experience gap to file as a decision rather than to ship. Validation: viewer-image.ps1 section K reads CF_HDROP back as the viewed path, and the K1/K2 picture asserts stay green.
