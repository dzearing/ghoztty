# T3760 - Linux L11g2c: Settings search on GTK finds the curated rows on their pages (Mac's searching mode), not only All Settings

## Summary

T3631: typing in the GTK Settings search jumps to Advanced and filters All Settings only. Mac and win32 search every page: a match shows its curated row (label, control) grouped under its page, and All Settings rows follow (settings_pages.rowMatchesText + Reader.matches). Port that mode to src/apprt/gtk/SettingsWindow.zig and extend test/linux/settings-window.sh.

## In plain terms

On Linux, typing in the Settings window's search box used to jump to the
Advanced page and only filter its raw list of every option, so a search for
"scroll" never showed the friendly Scrollback controls. Now it works like the
Mac: the results show the matching controls from every page, grouped under
headings like "Terminal › Scrollback", then the remaining raw options. The
controls in the results are the real ones - changing one there saves it.
