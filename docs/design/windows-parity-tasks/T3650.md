# T3650 - Linux L11k3: single-window mode on GTK - a parked workspace is laid out at the shared window's size, again 0.3s after a resize settles and at once on a tree change, so a switch never changes its grid

## Summary

Parked content keeps the size and scale the shared window has (Mac prepareParkedContent / windowDidResize / layoutParkedContent; win32 T3193, resize_settle_ms in workspace_host.zig). Measure: +list rows/cols of a parked workspace's pane equal what it shows with after a switch, across a resize. Spec: docs/reference/window-modes.md (Size).
