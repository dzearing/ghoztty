# T1831 - Windows panes are still flat: Mac's new default draws panes as raised rounded cards on a soft gradient with even 10pt gutters

## Summary

Mac 91ba7c08c: panes are slightly raised rounded cards (11pt radius, soft two-layer shadow, hairline rim) on a blue-to-teal 'ocean' gradient, separated by a real gap (still the divider) inside a window margin; 'flat' keeps the classic 1px divider with its exact old geometry. fe3f7c8da makes every gutter one 10pt spacing (pane gap == edge margin == rail gutters). Geometry/palette live once (PaneElevation) and are shared with the hidden stashed-pane slots. Windows needs the same look as its default, with flat still available. Config key naming on Windows (macos-pane-style is mac-prefixed) is part of the translation; record the choice. Check the divider hit target (T94) and drag/resize paths still work with real gaps.

## In plain terms

On a Mac, Ghoztty now shows each terminal pane as a softly raised card with
rounded corners, floating on a blue-to-teal background with even spacing
around and between the panes. On Windows the panes still ran edge to edge with
a thin line between them, so the two looked like different products. After
this change a Windows window gets the same cards on the same background by
default, and the old look stays one setting away (`macos-pane-style = flat`).

## Goals

- [x] Panes sit inside a 10 DIP margin with a 10 DIP gap between them, and the gap is still the divider you drag
- [x] Each pane is a rounded card (11 DIP corners) with a two-layer shadow and a hairline rim on the ocean gradient
- [x] `macos-pane-style = flat` keeps the classic geometry exactly; a live reload switches an open window
- [x] Stashed panes are held at the size the elevated grid gives them; the dim wash takes the card's shape
- [x] Follow-ups filed for what this does not cover: sidebar on the desk (T1850), header/banner/viewer corners (T1851), translucent windows (T1852); random per-window gradients (T1832), glass (T1833) and the focus glow (T1834) were already filed

## Decisions recorded

- **Config key.** Windows reads Mac's own `macos-pane-style` rather than a
  renamed key: a user's config file travels between their machines, and one
  key that means one look on both is the parity the setting exists for. The
  Config.zig doc now says it applies on both platforms.
- **Quick Terminal stays flat.** It is one edge-to-edge pane dropped from a
  screen edge; there is no desk to raise it from.
- **How a child HWND becomes a card.** A child window cannot cast a shadow or
  antialias its own corners, so the parent paints the desk, both shadow
  layers, the card fill (terminal background, antialiased corners) and the
  rim; the pane child sits one rim width inside and is clipped to a rounded
  window region whose staircase lies inside the parent's smooth curve
  (`pane_elevation.childRadiusPx`, unit tested). The desk is rendered at a
  quarter size and HALFTONE-stretched, cached per size and theme.
