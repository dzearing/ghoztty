# T1109 - The '--- session restarted ---' divider never prints on a deferred relaunch

## In plain terms

When a session restarts, a line is printed across the pane so you can see where the old output stopped and the new run began. On one restart path that line never appears, so the new output runs straight on from the old with nothing marking the seam.

## Summary

`test\win32\session-relaunch.ps1` scored `1 FAILURE(S)` in the T1094 sweep, out of a long script:

```
FAIL B7 the deferred relaunch printed the '--- session restarted ---' divider
```

Only the DEFERRED relaunch path is affected - the rest of the script, including the immediate path, passes. The likely shapes are the divider being written before the ConPTY is ready to show it (and so overwritten by the first repaint), or the deferred path simply not calling the same write the immediate path does.

Small, but it is the only thing that tells a user their scrollback has a seam in it.
