# T2973 - PA-R07: each new glyph re-uploads the whole font atlas texture in every pane that shares the font, and the atlas never shrinks

## Summary

PA-R07 (audit-1, T2959). font/Atlas.zig:274 bumps `modified` on every set; generic.zig:2005-2020 then calls syncAtlasTexture, which replaceRegion()s the entire atlas (generic.zig:3906) in every pane on its next draw. Growth doubles with no shrink path (Atlas.zig:366 clear does not reclaim). Cost estimated: 256 KB (R8) or 1 MB (BGRA) per new glyph per pane at 512^2, 4/16 MB at 2048^2. Fix: track a dirty rectangle in Atlas and upload only that (sharing the texture across panes is PA-R03). Risk low. Shared code: Mac half filed with the shared-renderer Mac task.

## Validation criteria

- [ ] a unit test asserts Atlas reports a dirty rect covering only the glyph region set since the last sync
- [ ] perf-baseline.ps1 -Phase busy with a CJK/emoji-heavy file shows less GPU upload time than baseline (add the file variant if absent)
