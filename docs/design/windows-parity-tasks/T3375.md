# T3375 - Linux L5d: move +split/+new-window/+rename argument handling and the +list tree walk into apprt/ipc/verbs.zig so GTK (T3370) reuses them

## Summary

Follow-up to T3361 and T3374. The +split/+new-window bodies in src/apprt/win32/IpcHandlers.zig (~600 lines) mix shared argument policy (VerbArgs validation, name-collision via split_name_collision, idempotent focus notes, reply shapes) with win32 window creation; split the policy into verbs.zig over a model (create window/split with a resolved spec, register a name), and move the +list split-tree walk that both frontends now write separately into a shared builder over a small tree-node interface. win32 replies must stay byte-identical (ipc-p1/p2/p3 ALL PASS).

## In plain terms

Opening a window, splitting a pane, renaming a window and listing what is
open from the ghoztty command line were each written twice, once for
Windows and once for Linux, so the two apps could give a script different
errors or pick a different pane to split. Now the rules and the answers are
written once and both apps use them; each app only builds the window or
pane itself.

## Goals

- [x] `+new-window`, `+split` and `+rename` bodies live once in `src/apprt/ipc/verbs.zig`, over a model each frontend implements
- [x] `+list`'s split-tree walk is one shared function (`verbs.listSplitNode`); each frontend supplies only the leaf
- [x] win32 delegates all four with its exact replies
- [x] GTK delegates all four, taking win32's argument order, anchor precedence and sentences

## Validation criteria

- [x] none lane unit tests for each new body (argument errors in win32's order, every anchor failure, idempotent `focused` answers and their notes, name collisions, the ratio, the strip note, the user's-title refusal, the list walk) - `floor-lane.ps1 -Lane all` ALL LANES PASS (Windows), and the none lane in `LINUX FLOOR` ALL PASS at 18f282b0e
- [x] win32 replies unchanged - ipc-p1/p2/p3 ALL PASS (26/20/19 assertions, the counts T3374 recorded)
- [x] GTK serves the moved verbs - `cli-windows.sh`, `cli-close-focus.sh`, `cli-rearrange.sh`, `cli-send-read.sh`, `ipc-server.sh` ALL PASS and LINUX FLOOR ALL PASS (all at 18f282b0e, through `wsl-run.ps1`)
