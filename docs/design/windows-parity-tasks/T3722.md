# T3722 - Validate the wsl-run lease on a real idle boot: -KeepRunning writes it and -Release shuts the VM down

## Summary

T3721 added the -KeepRunning lease and -Release, proven with WSL state faked (wsl-run-guard L1-L15). The real idle-boot path was NOT RUN: Ubuntu was already running at that turn (no lease, so not lane l's to stop). When a lane-l turn starts with no distro running (wsl.exe -l --running -q is empty), run wsl-run.ps1 -KeepRunning -- true, confirm WSL-RUN LEASE recorded with a uuid boot id and that claim prints WSL LEASE HELD, then -Release and confirm the VM is down (running list empty) and -LeaseStatus says NONE. Record both in T3721's validation criteria.

## Validation criteria

- [x] Real idle boot (no distro running, no lease, 44.6 GB free): `wsl-run.ps1 -KeepRunning -- true` printed `WSL-RUN LEASE recorded ... (boot d937cf97-934b-4da2-b636-c9b2f7ec8c30)` - a bare uuid; `-LeaseStatus` and a real `go-loop-exec.ps1 claim` both printed `WSL LEASE HELD: lane l booted the Ubuntu VM`.
- [x] FOUND A DEFECT on the first `-Release`: in the ~3 minutes the claim took, Ubuntu had idled out on its own (WSL stops a process-less distro after seconds), so `-Release` took the "nothing to stop: the VM is already down" branch and called nothing - but `vmmemWSL` was still alive at 1.8 GB. Under the user's vmIdleTimeout=-1 the utility VM outlives its distro, so "no distro running" is not "VM down". Fixed in `scripts/linux/wsl-run.ps1`: with no distro running, `-Release` now runs `wsl --shutdown` (kills no session; a no-op on a VM that is really down). With another distro still running it still stops nothing.
- [x] `test\linux\wsl-run-guard.ps1` 45 pass, 0 fail, stamped: L13 rewritten (distro idled out -> `--shutdown` would run, no `--terminate`, lease cleared); new L16 (distro idled out, docker-desktop running -> nothing would run, VM kept); Z1 nothing booted.
- [x] Real re-run with the fix, both paths: (A) `-KeepRunning` then immediate `-Release` -> `distro terminated, VM shut down`, running list empty, `vmmemWSL` gone; (B) `-KeepRunning`, wait 15 s until Ubuntu idled out (vmmemWSL then held **14.4 GB** with no distro running - what the old branch would have left), `-Release` -> `Ubuntu had already stopped by itself; VM shut down`, `vmmemWSL` gone, `-LeaseStatus` NONE.
