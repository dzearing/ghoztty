# T3722 - Validate the wsl-run lease on a real idle boot: -KeepRunning writes it and -Release shuts the VM down

## Summary

T3721 added the -KeepRunning lease and -Release, proven with WSL state faked (wsl-run-guard L1-L15). The real idle-boot path was NOT RUN: Ubuntu was already running at that turn (no lease, so not lane l's to stop). When a lane-l turn starts with no distro running (wsl.exe -l --running -q is empty), run wsl-run.ps1 -KeepRunning -- true, confirm WSL-RUN LEASE recorded with a uuid boot id and that claim prints WSL LEASE HELD, then -Release and confirm the VM is down (running list empty) and -LeaseStatus says NONE. Record both in T3721's validation criteria.
