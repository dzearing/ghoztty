# T3790 - Linux L11k5b: single-window mode on GTK - undo of a workspace close brings the workspace back on show in the shared window

## Summary

T3652 landed the GTK workspace close (hand-off, in place, frame, last closes the window, confirmations) but undo of a workspace close needs GTK window-close undo first (T3665). Spec (docs/reference/window-modes.md Closing): undo of a close brings the workspace back on show. win32 counterpart T3200: the closed workspace waits for the undo time with its shell running and Ctrl+Shift+Z puts it back on show in the same window. GTK shape: when T3665 parks a closed window, a closed WORKSPACE parks its Window (content held, out of the host) instead of a hidden GtkWindow; undo re-admits it and Workspaces.show()s it. The toplevel's own workspace closing (Workspaces.retire/Window.becomeFrame) today ends its tabs at once and must park them for undo too. Extend test/linux/window-workspaces.sh.
