# T2474 - A minimized or fully covered window should give back its panes' render-target memory and redraw cleanly when shown again (Mac shrinks hidden targets to 1x1)

## Summary

Mac 1bc34a8d7 adds releaseHiddenTargets in shared src/renderer/generic.zig, gated on GraphicsAPI.presented_target_outlives_frame - Metal only (~35 MB back per occluded 1200x800 pane). The win32 build renders through OpenGL (swap_chain_count = 1), which re-presents its last target on a no-op draw, so the shared hook is deliberately off here. Translate the feature, not the mechanism: measure what a minimized / cloaked / fully covered win32 window holds per pane, and if it is material, free it on occlusion (WM_SIZE SIZE_MINIMIZED, DWM cloak, occlusion) and force a full redraw on show, proving no blank or garbage frame on restore.
