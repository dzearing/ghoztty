# T3564 - Linux L11b: pane rearrange mode and pane drag-and-drop on GTK - the per-pane header and one drop resolver for drops inside a tab (tab bar, cross-window, ghost and new window are T3615-T3618)

## Summary

Port docs/reference/pane-rearrange.md, first slice (rewritten 2026-11-23 to what this task delivers; the rest is filed): the Toggle Rearrange Mode action (Ctrl+Shift+., command palette) gives every pane of the window a header with a grip and its title that takes layout space, forces the tab bar visible, and is left with Escape; the header is a drag source, and a pane dropped inside its own tab splits another pane, swaps with it, spans a window edge or fills a divider's gap, through win32's pure resolver (`pane_drop.zig`, `pane_gap.zig`, `pane_layout.zig`, imported in place as GTK already does for other pure win32 modules - no move needed) and the new pure `gtk/pane_drop_apply.zig`. Builds on the GTK +rearrange tree rebuild (T3368). Follow-ups: tab bar + tab dwell T3615, cross-window drops T3616, ghost card + drop preview + hover handle with the mode off T3617, new window on a release over nothing + the header's pop-out button T3618. Dropping onto the pane sidebar is T3558.

## In plain terms

On Linux there was no way to rearrange panes by hand: the Rearrange Mode shortcut did nothing. Now Ctrl+Shift+. puts a small title bar with a grip on every pane; dragging one by it and letting go over another pane moves it there - beside it, swapped with it, along a whole window edge, or into the gap between two panes - with its shell still running. Escape (or the shortcut again) puts the window back.

## Goals

- [x] Ctrl+Shift+. (and the command palette) toggles rearrange mode per window; Escape leaves it
- [x] every pane shows a header above its banner that takes real layout space; new panes in the mode get one too
- [x] the tab bar is forced visible while the mode is on
- [x] a pane dragged by its header and dropped in its own tab splits, swaps, spans an edge or fills a gap, keeping its shell
- [x] a drop that would leave the pane where it is does nothing
- [x] follow-ups filed for the tab bar, cross-window, ghost/preview/hover handle and new-window halves
