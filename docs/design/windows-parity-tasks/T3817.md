# T3817 - Linux: signing out closes the account's relay windows and the next sign-in brings them back (win32 T713/T3389)

## Summary

win32 T713: a sign-out that actually signs out closes every account-backed relay window (App.suspendRelayWindowsForSignOut), keeps their sessions DETACHED on the far agent (T1554), and the same account's sign-in rebuilds them (restoreRelayWindowsForSignIn). On Linux the account row signs out since T3575, but relay windows stay open on a credential that is gone. Port it: on a sign_out ok in MachineChooser.onAccountDone, close the relay windows (RemoteLink relay machines only, never direct --host or local) with RelayWindows told it is a signing-out close so windowDisposed KEEPS their record entries (T3671's note: pass a signing_out flag the way isQuitting is passed); the sign-in replay T3575 already wired (RelayWindows.start skipping open ids) then reopens them. Acceptance: extend test/linux/chooser-account.sh or machine-chooser.sh with a real relay window that closes on Sign Out, its far session still running, and reopens after Sign In.
