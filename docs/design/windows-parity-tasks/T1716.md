# T1716 - clipboard_image.zig has no caller since the composer's RichEdit went (T1704): delete it or give it one

## Summary

The native clipboard-image reader (PNG / CF_DIBV5 / CF_DIB / CF_BITMAP -> PNG) was only ever called from the RichEdit composer's Ctrl+V/WM_PASTE hook. The web composer takes pictures through its page's own paste listener, so since T1704 clipboard_image.zig has zero importers and is not compiled into any lane. Either delete it (and dib_packed.zig if nothing else needs it, with the apprt.zig test import) or wire it to a real caller - e.g. a native 'paste image from clipboard' path the page cannot reach. Dead code that does not even compile is dead code nobody notices is wrong.
