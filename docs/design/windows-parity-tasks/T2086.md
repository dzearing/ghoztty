# T2086 - Glass panes on Windows: unfocused panes are the more see-through ones, fading toward the desk instead of under a background-coloured wash

## In plain terms

With glass panes on, the panes you are not using should be the more
see-through ones, so your eye goes to the focused pane. Before this, every
pane on Windows wore the same heavy sheet, and the unfocused ones were
washed over in the background colour, which made them the MORE solid ones.
Now an unfocused pane is a thin sheet that fades toward the desk behind it,
and the focused pane is the one that stands out.

Scope as landed: the focused/unfocused glass (the first bullet below). Hero
mode as a glass card is T2104. Stacked rows without solid cards is T2105,
which waits on T2082's stacked rows. One resize per slide is already
T2082's validation. Easing the fade in over 250 ms like Mac is T2106.

## Goals

- [x] An unfocused glass pane among several wears the 15% sheet; the focused
      (or lone, zoomed, hero) pane keeps 40%.
- [x] An unfocused glass terminal fades whole toward the desk by
      `unfocused-split-opacity`: its dim wash is the desk under it, never the
      background-coloured sheet.
- [x] A viewer gets the thin sheet and no fade (T1809).
- [x] The card's rim and corners, the rearrange header's material, the
      banner strip and a viewer's nav/feedback bars all lay the same sheet,
      so no seam opens round a thin pane.

## Summary

Mac 89848fd59 (`feat(macos): glass panes - unfocused panes see-through,
stacks and hero glass, one resize per slide`):

- Unfocused glass panes get a thinner sheet (15% tint vs 40%). The whole
  terminal (text and sheet) fades by `unfocused-split-opacity`. The
  background-colored wash is not drawn on glass, because it made unfocused
  panes the MORE opaque ones. Viewers get the thinner sheet only.
- Stacked rows have no solid cards: a tucked card is drawn as its strip
  alone, with its content hidden, and its terminal keeps its last on-show
  size.
- A resizing slide resizes each terminal once, together, after the slide.
  Focus fades animate opacity only (an animated frame had caused 7
  terminal resizes per strip click).
- Hero mode uses the same glass card as a focused pane.
- (The viewer key changes in the same commit are T2087. The command
  palette over a viewer already exists on Windows, `viewer_accel.zig:341`,
  so nothing is owed there.)

Windows today: `pane_elevation.zig:224` `GLASS_TINT = 0.4` for every pane.
The unfocused dim is the separate DimOverlay wash. That is exactly the
combination Mac removed on glass.

Windows translation, as built (mechanism calls, recorded here rather than
filed as decisions - none of them is visible as a difference to the user):

- `pane_elevation.Sheet` `{ t, fade }` and `sheetFor(dimmed, fade)`:
  focused / lone / zoomed / hero = 0.40; dimmed = 0.15, and a dimmed
  terminal's `fade` is the dim wash's alpha (1 - `unfocused-split-opacity`).
  `Window.glassSheetFor` decides "dimmed" exactly as Mac's `isSplit &&
  !isFocusedPane`, on the active tab's visible grid.
- The terminal's own renderer draws only the tint (`1 - t` backdrop
  opacity). The whole-terminal fade (text included) is the EXISTING dim
  popup, which on glass paints the desk slice under the pane instead of the
  fill colour (`DimOverlay.DeskWash`, cropped by `dim_math.cropWash`). That
  is Mac's `content.opacity(1 - u)` over the desk, in the same sRGB blend
  DWM's layered alpha makes, so no shader change was needed. The card's rim
  band (outside the pane child, so outside the wash) is painted with the
  same faded sheet: `GlassLut` folds the fade into its per-channel tables,
  so a faded card costs the paint nothing more.
- A head band (rearrange header, viewer nav bar) takes the card's thin tint
  but never the terminal's fade: it is chrome laid outside the pane child,
  which the wash does not cover. Same for the banner strip's sheet.
- The tint switches in one step on focus change, as on Mac (`tintStrength`
  is not animated there). Mac eases the dimmed opacity; that is T2106.

## Validation criteria

- [x] Pixel oracle (capture-pane + PrintWindow, test desktop): of two glass
      panes the measured sheet tints are 0.388 and 0.137 (Mac 0.40 / 0.15),
      and the one dim wash present photographs as desk (18,38,42), not the
      #000 fill. `test\win32\pane-elevation.ps1` run 1d, ALL PASS (129).
