# T3143 - PA-W18: in merged chrome a caption or tab-strip invalidation still runs both band painters, so every tab hover and label change paints a band that did not change

## Summary

Audit-3 (T3101), area W, verified at d0d874326. T2987 (66a526f79) gates paintCaption/paintTabBar on chromeBandReach (src/apprt/win32/Window.zig:19159-19163), but invalidateTabBar (:18435-18444) and invalidateCaption (:18455-18461) both invalidate a full-width rect (right = 10000) on the same row when the strip is merged into the caption, so the reach test sees both bands and both painters run for every tab hover, caption-button hover or tab-label change. Fix: invalidate only the changed tab or button rect, and make chromeBandReach distinguish the caption controls from the strip within the merged row. Detail: docs/design/perf-audit/audit-3/W-findings.md.
