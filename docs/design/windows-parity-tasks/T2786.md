# T2786 - Today's Mesa/WARP path cannot be priced on an optimized build: GHOZTTY_GL_FORCE_VERSION is Debug-only, so comp-gl-baseline's mesa-warp row exists only for a Debug app whose own code inflates the CPU

## Summary

T2734 priced the Mesa/WARP snap at 193-206 ms per sidebar toggle on a Debug app; the ReleaseFast row is refused because forcedVersion() compiles out of release (by design: an env var must not stop a user's terminal opening). A build option (-Dgl-test-seams) or a sandbox-only seam would let scripts\comp-gl-baseline.ps1 -ReleaseSandbox price the shipped path; until then the release figure is an estimate (~100 ms, from the Debug->ReleaseFast ratio of the GPU glide).
