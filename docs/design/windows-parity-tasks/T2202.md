# T2202 - update-real-msi.ps1 starts the MSI-installed app on the user's desktop (Start-Process $testExe)

## Summary

Found by T1267's widened desktop-launch sweep. `test\win32\update-real-msi.ps1`
installs a published MSI and then starts the INSTALLED app bare
(`Start-Process -FilePath $testExe`, `$testExe = Join-Path $installDir
'ghoztty.exe'`) - a real terminal window on the user's desktop. The old suffix
rule could not see `$testExe` (`t` precedes `exe`); the new alias rule reads it
from the Join-Path.

Fix: start it through `Start-OnTestDesktop` (the script already isolates pipe,
agent lineage and LOCALAPPDATA), then delete its `@user-desktop-launch` entry.
The script needs two published packages to get past section A, so validate
where those can be fetched.
