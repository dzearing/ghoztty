# T1528 - Pane drop resolution: a pure module that turns a drag point into a drop target

## In plain terms

When you drag a pane around in rearrange mode, something has to decide what
letting go right there would mean — split this pane on its left edge, swap the
two panes, put the pane down the whole side of the window, make a new tab, or
make a new window. This is that decision, on its own, with nothing drawn yet:
get it wrong and the highlight lies about where the pane will land.

## Summary

Port Mac's `PaneDropResolver` (b18ee2d77) to a pure win32 Zig module: a screen
point plus a SET of candidate windows in, a drop-target value out. The five
answers are Mac's — a quadrant of a pane splits it, the CENTER of a pane swaps
the two panes, within an edge band of the window's content inserts at the TOP
LEVEL spanning the full side, the tab strip makes a new tab at the index under
the pointer, and anywhere else makes a new window.

Taking a set of windows rather than one is what makes cross-window and
cross-tab drags one code path later (T1532), and taking only rects and points
is what makes the geometry unit-testable in the `none` lane with no GUI.

The one deliberate divergence from the Swift is the coordinate space: win32
screen coordinates grow DOWNWARD, so "nearer the top" is a smaller `y`, and
every up/down comparison in the Swift inverts here.

## Goals

- [x] A pure module with no OS imports resolves a drag point to a drop target.
- [x] The five drop kinds are covered: split, swap, top-level edge, new tab, new window.
- [x] A point over the dragged pane itself resolves to nothing.
- [x] Overlapping windows are arbitrated by z-order.
- [x] A separate dwell query names the tab under the pointer, for T1532's hover-to-switch.

## Validation criteria

- [x] Unit tests in the `none` lane cover each drop kind, the corner tie-breaks, the edge-band suppression on a small window, and the z-order arbitration.
- [x] The module has no `windows.h`/`win32.zig` import, so it compiles in every app-runtime lane.
- [x] Both zig test lanes, `test-agent` and the `lib` build stay green.
