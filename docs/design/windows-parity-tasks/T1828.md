# T1828 - No pane sidebar on Windows: Mac lists every pane in a pinned panel or a hover mini-rail, with busy shimmer, needs-input badges, click-to-focus and drag

## Summary

Mac 597a193cc (design: docs/design/pane-sidebar.md): pinned = flat edge-to-edge panel; unpinned = glass card collapsed to a 68pt mini rail that opens over the grid on hover without resizing any terminal. Rows list grid panes (focused selected) then stashed ones; busy panes shimmer, needs_input shows a question badge, a bell on a stashed pane shows a dot; rail tiles use title monograms (a path title shows its last component). Click focuses/restores, Option-click swaps a stashed pane in, rows drag through the one drop resolver (.stash / .joinWindow targets), right-click menu, trash mode = one-click kill. toggle_pane_sidebar keybind + Window menu items; pinned/hidden persist. Polish: the selected row follows focus (d71c18bb5), trash-mode buttons align (1ec258f14), the mock's icons, animated folds, steady hover (e628f3933, 51573daf0), equal gutters around the rail (557e4f978), the pinned edge resizes and never unpins under a drag (7855941f7). Translate to win32 chrome per docs/design/win32-design-system.md; Windows chord for toggle_pane_sidebar comes from the shared Binding.zig defaults.
