# T3374 - Linux L5c: move the +close/+focus and +set-banner/+set-state verb bodies into apprt/ipc/verbs.zig so GTK (T3367) serves win32's argument handling and wording

## Summary

T3361 created src/apprt/ipc/verbs.zig (shared verb bodies over a per-frontend model) and moved +read and +send-keys. Move +close/+focus and +set-banner/+set-state next: extend the model with what they need (resolve a target to a window-or-pane, close it, focus it, set a pane's banner/state), keep win32's exact replies (ipc-p1/p2/p3 ALL PASS unchanged), and have GTK's handlers delegate so T3367 implements only the model half.

## In plain terms

Closing, focusing, and setting a pane's status or banner from the ghoztty
command line used to be written twice, once for Windows and once for Linux,
so the two could drift into different error messages. Now there is one copy
both apps use, so a script gets the same answers on either.
