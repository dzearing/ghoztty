# T2805 - A finished background sweep whose PowerShell tool host never exits keeps the T2717 probe reading live, so the turn still idles to the 180m backstop

## Summary

T2717's liveness probe works as designed but is beaten by a different failure. 2026-11-07, lane b, T2765, turn 76: the turn backgrounded a due sweep (task bwaw0mn98, 12:45:39, PowerShell tool: acceptance-parallel due > t2765-due2-<PID>.txt; then EXIT and a filtered Get-Content). The sweep FINISHED at 13:26:43 (result file complete: 3 REDs, window-close-memory, pane-close-memory, agent-integrations). But the tool host powershell.exe pid 32644 (parent claude 12384, via cmd 32496) was still alive at 14:12 with no children, 0.25s CPU and no CPU growth, holding bwaw0mn98.output open (0 bytes). So the probe reads HELD = live, the watchdog logs bg=1 bgdead=0, and lane b sat idle from 12:46 until the backstop. The pane shows the usual stack of 'still running in background' lines from earlier turns. Fix direction: (1) the probe should also treat a held output file as dead when the holder's process tree has had no CPU growth and no live child for N minutes (or when the command's own redirect target stopped growing long ago); (2) find why the host does not exit after its child ends (a grandchild holding an inherited pipe is the usual cause, but none was alive; one thread was in ExecutionDelay); (3) go.md: a sweep's result file is the signal - a turn can read it instead of waiting for the notification.
