# T3199 - Mac half of T3037: a viewer's save re-renders only when the pane is visible and the file's size or mtime changed

## Summary

Windows (T3037) now gates the file watcher's debounced re-render: a save landing on a hidden pane (minimized/covered window, background tab) is remembered and rendered once on show; a save that left size+mtime where the last render saw them renders nothing; +reload always renders. Pure logic in src/apprt/win32/reload_gate.zig. Port the same gate to ViewerView's reload debounce on macOS (check whether it already skips hidden panes) and validate a hidden markdown viewer under a 10x/s writer renders 0 times and shows the last save on show.
