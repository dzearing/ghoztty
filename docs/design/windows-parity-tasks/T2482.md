# T2482 - context-menu-real-input.ps1 flashes a Windows Terminal window on the input desktop before each app launch (seen by fullscreen-guard's foreground sampler)

## Summary

T1814's negative control recorded the foreground going CASCADIA_HOSTING_WINDOW_CLASS (Windows Terminal) ~200 ms before every GhozttyWindow, four times per run: some console child of the script (likely a ghoztty CLI call or the app launch) is hosted by the default-terminal Windows Terminal and takes the foreground. It only runs on the input desktop with nobody present, so it is not a presence leak, but it is a stray visible window and adds focus churn the script's own assertions may race. Find the console child and start it CREATE_NO_WINDOW / hidden.
