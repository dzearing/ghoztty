# T2100 - Stacked panes: port PaneStackState - focus history, a row's pin and shares, the run last shown, and a strip restored when its pane takes focus - as a pure module with its tests

## Summary

Mac PaneStackState.swift (86b7e3410, d26e51183): noteFocus/noting, restack(row, Restack), noteItems(items, fits), pin(for:), shares(row, Restack), shownRun, saved/restore. Pure Zig module beside pane_stack_layout.zig, porting the PaneStackStateTests cases that do not need rowsDidChange (that half is T2083). It is the Provider the window hands pane_stack_layout.compute.

## In plain terms

When a row of panes is too narrow to show them all, some become thin strips at
the edge. Something has to remember which panes you looked at last, which rows
you squeezed down by hand, and how you sized the panes still on show — and
bring a strip back out when you click it. This is that memory, written for
Windows and tested on its own; the window starts using it in T2101.

## Goals

- [x] focus history (newest first, 64 kept) and each pane's rank in it
- [x] a row's collapse and slot sizes: restack (one step or a chained drag), resize, snapshot/restore, saved/restore, swap
- [x] focusing a strip brings it on show — the run grows when there is room, slides when there is not
- [x] the stacks as last laid out: the run that sticks, the stack a pane is minimized in
- [x] it is the Provider `pane_stack_layout.compute` reads
- [ ] carrying a collapse across a close/split/drop (`rowsDidChange`, `paneOnShow`) — T2083
