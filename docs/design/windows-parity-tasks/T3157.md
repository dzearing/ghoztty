# T3157 - The idle renderer thread spends 6 Mcycles/s (0.2% of a core) waking 11 times a second with nothing changing on screen

## Summary

T3111's exact per-thread cycle counts (perf-baseline by_group_cycles, docs/design/perf-audit/t3111-idle-cpu.md) show the release renderer thread at 6.1 Mcycles/s and ~11.4 wakeups/s on a 1-pane idle window at a cmd prompt, identical at baseline-1 and HEAD, so not a regression - but about 530k cycles per wakeup with no visible change. The GL and D3D driver threads add another 9 Mcycles/s. Find what each renderer wakeup draws or checks (cursor blink at 600 ms would be ~1.7/s, not 11), and whether frames are presented when nothing changed; measure with perf-baseline -Phase idle (cpu_cycle_pct, top_threads_by_cycles). Child of T2957.
