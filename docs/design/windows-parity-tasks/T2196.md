# T2196 - Release-sandbox harnesses must not register the user's ghoztty:// handler: Set-GhozttyTestIsolation -ReleaseSandbox should turn GHOZTTY_URL_SCHEME off itself

## Summary

update-graceful.ps1 (a -ReleaseSandbox run) re-pointed HKCU\Software\Classes\ghoztty\shell\open\command - the USER'S release scheme - at the GhozttyT1209Test install it then deleted, so ghoztty:// links opened nothing until restored by hand (2026-10-23, caught by acceptance-parallel's state check during T1244). T1244 fixed that one script with GHOZTTY_URL_SCHEME=off; the class of bug lives in Set-GhozttyTestIsolation -ReleaseSandbox, which isolates the pipe, agent and LOCALAPPDATA but not HKCU classes.
