# T3035 - PA-V03: a viewer in a background tab or minimized window keeps its whole renderer: it is paused but never suspended or memory-trimmed (ViewerPane.zig:1834)

## Summary

PA-V03 (audit-1, T2963). ViewerPane.setVisible (ViewerPane.zig:1834-1849) only calls put_IsVisible and ShowWindow; no ICoreWebView2_3 (TrySuspend/Resume) or ICoreWebView2_19 (MemoryUsageTargetLevel) exists in src/apprt/win32. Cost (estimated): 50-150 MB renderer heap per hidden viewer plus page timers on live pages. Fix: add both vtable slots; on hide set MemoryUsageTargetLevel=Low, then TrySuspend after ~30 s; restore Normal on show. Risk: IPC verbs and captures against a suspended page must Resume first; needs a runtime-version fallback. Findings: docs/design/perf-audit/audit-1/V-findings.md.
