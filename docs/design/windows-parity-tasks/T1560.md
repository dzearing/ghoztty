# T1560 - A task that names its own check should be able to prove itself already fixed

## Summary

T719 was fixed by T744 two days after it was filed and then sat open for 34 days. Its whole Summary was one runnable command - a sweep whose empty output IS the definition of done - and nothing ever ran it. stale-scan ranks by a later commit having NAMED the task, which cannot see a sibling task that fixed the same defect without citing it. Proposal: an optional 'verify:' line in a task's frontmatter holding a one-line command whose clean exit means the card is already satisfied, and a stale-scan pass that runs those and reports the ones that now pass. Scope it to commands that are read-only and fast (a sweep, a grep, a script with a -Check switch), never a full acceptance harness.
