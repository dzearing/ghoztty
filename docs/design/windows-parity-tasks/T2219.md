# T2219 - Tunnelled file viewers: remote file fetch with granted roots, live reload push, relative assets, remote git diff (Windows + shared)

## Summary

See docs/design/remote-viewer-tunnel.md (T1297 design). Decision 1/4 + live reload. A --view of a remote path arrives via T2217; the win32 viewer must load its bytes from the agent (rpc fetch scoped to the granted directory, local size cap), serve relative images/.md links from that root through a separate virtual host, re-fetch on agent viewer_changed pushes, and render git-status/git-diff from git output the agent runs remotely (parsing stays local). Feedback reports are written on the remote machine through the proxy.
