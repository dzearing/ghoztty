# T2337 - Windows all-windows sidebar list reorders by drag: a window row among its siblings and a project header among the top level, the order shared across windows and persisted, as on Mac

## Summary

Mac b07b7fa0b, c4dbe30be, 9a1f14230, 97afdaf5a. Reorders the LIST only (no window or pane moves). Siblings slide by the dragged item's pitch (bounded 0.2s, none at drop); the item follows the pointer lifted over a solid backing, kept in its list, glides into place after the new order is laid out; Escape cancels; chevron and x are outside the drag source; click still raises/folds. Dragging a group folds every group first (held header stays under pointer), dragging a window folds every window to its row; folds return after drop/cancel. No hover while dragging; rows re-sync from pointer on land. Order is shared + persisted (keys project:<name>, window:<windowID>); a new window/group lands after its name-order neighbour; closed windows pruned on the next move, never on close; windowID restored with the window so relaunch keeps its place. Mac ref: docs/reference/pane-sidebar.md 'Reordering windows and groups'; tests PaneSidebarWindowOrderTests, PaneSidebarItemReorderTests, PaneSidebarSyncWindowTests.dragReordersAWindowAndAGroup.

## In plain terms

On Mac you can drag windows and project groups up and down in the sidebar's all-windows list to put them in the order you want, and that order sticks across windows and restarts. On Windows the list is always alphabetical. After this, Windows lets you drag them the same way, with the same sliding animation.

## Goals

- [ ] A window row drags among its siblings and a project header among the top level; nothing moves on screen
- [ ] Siblings slide, the dragged item lifts and glides into place; Escape cancels
- [ ] Dragging folds every group (or every window) first and restores the folds afterwards
- [ ] No row hover lights up mid-drag
- [ ] The order is shared, persisted, and a new window lands after its name-order neighbour

## Validation criteria

- [ ] Unit tests for the reorder index, order persistence and new-item placement
- [ ] On-box acceptance: drag a window and a group, order holds in a second window and across a relaunch
- [ ] -NegativeControl goes red
