# T3631 - Linux L11g2: the Settings window on GTK gets the curated pages - Appearance, Panes & Windows, Terminal, Keyboard, Updates - with switches, dropdowns and number fields from settings_pages.zig

## Summary

T3569 landed the GTK Settings window with Advanced > All Settings only (one text field per key). Port the Mac pages (docs/reference/settings.md Pages) through win32's shared presentation catalog src/apprt/win32/settings_pages.zig and settings_controls.zig: a sidebar of pages, each key on its page with its label and control (bool switch, enum dropdown listing any uncurated schema option too, bounded number field, shell picker that only accepts an existing executable), the changed dot, and the All / Changed / Not on other pages filter on All Settings. libadwaita widgets (AdwPreferencesPage/Group, AdwSwitchRow, AdwComboRow, AdwSpinRow). Extend test/linux/settings-window.sh.

## In plain terms

On Linux, the Settings window only had one long list of every raw setting
name with a text box beside each. Now it has the same pages the Mac has -
Appearance, Panes & Windows, Terminal, Keyboard, Sessions & Agent, Updates,
Advanced - with friendly labels and real controls: switches, drop-downs,
number boxes with arrows, sliders, and a shell picker that refuses a shell
that does not exist. A dot marks anything changed from the default, with a
button to put it back.
