# T1890 - A bell on Windows ignores bell-features audio, title and border: no sound file, no bell in the title, no border flash

## Summary

T1843 made ring_bell honor bell-features system (MessageBeep, now off by default as on Mac) and attention (taskbar flash). Mac also honors: audio (bell-audio-path at bell-audio-volume), title (a bell glyph prefixed to the window title while the focused surface's bell is set - BaseTerminalController.computeTitle), and border (SurfaceView BellBorderOverlay). The pane's bell flag now exists on the win32 Surface (Surface.bell, cleared on focus/key), so title and border can key off it.
