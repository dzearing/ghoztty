# T1974 - agent-job-escape.ps1 and relaunch-guard.ps1 build their 'kill-on-close' jobs with no limits at all (nested-struct assignment never reaches the job)

## Summary

Both set $jobInfo.BasicLimitInformation.LimitFlags = 0x2800. BasicLimitInformation is a struct, so PowerShell assigns into a temporary copy and SetInformationJobObject gets 0x0. job-escape-startup.ps1 had the same defect in all five sites until T1970 (New-JobLimits there is the fix). Re-check what each harness's premise assertions actually measured once the jobs carry their flags.

## In plain terms

Two of the tests that prove Ghoztty's background helpers survive a "kill
everything in this group" event were building a group that killed nothing.
They passed, but they were not testing what they said. Now the group really is
the kill-everything kind, the tests check that it is, and they still pass.
