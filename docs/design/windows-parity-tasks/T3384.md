# T3384 - Linux: a closed pane or a +rearrange-omitted pane can be undone (Ctrl+Shift+Z), as on Mac and Windows

## Summary

The GTK app closes a pane at once: +close and a +rearrange layout that leaves a pane out end it with its shell, and there is no undo. Mac (Rearrange Layout / close undo) and win32 (T2234, CloseUndo/LayoutUndo, undo-timeout default 5s) hide the pane and keep its shell until the timeout, and Ctrl+Shift+Z puts it back with its name. Port that: a per-window undo stack in the GTK frontend, the omitted/closed pane hidden and out of +list until undo-timeout expires, undo/redo bindings, and the shared layout_undo logic where it fits. Acceptance: a test/linux script that rearranges a pane out, checks its shell is alive and it is absent from +list, undoes, and checks it is back by name.
