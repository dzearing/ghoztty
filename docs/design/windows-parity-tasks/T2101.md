# T2101 - Stacked panes: the win32 grid lays out through pane_stack_layout - panes stop at 300 DIP, a row that cannot fit shows its run plus titled strips, and a strip click, goto_split, the pane sidebar or a focus link brings the pane on show

## Summary

Window.layoutNode/splitRects/paint/hit-test today walk one binary split at a time; route them through pane_stack_layout.compute (nodes mapped index for index from SplitTree(PaneView), DIP rects scaled by the window DPI, metrics from pane_elevation.gapPx / flat_gap). Strips are pane-card chrome painted in Leaf.elevation order, labelled by pane_sidebar.paneLabel (banner title first; T2085 hand-off), live on +set-banner/OSC 7778. Dividers come from Result.dividers. Acceptance on the test desktop: 4 panes in a window narrower than 4x300 DIP show N + strips; a posted strip click focuses and shows that pane. Covers T2082's acceptance criteria and T2085's strip-label criterion.
