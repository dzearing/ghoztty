# T2340 - Windows pane sidebar rows match Mac's latest look: window rows carry a window icon, every row is one height, grouped windows are not indented, a folded this-window header takes the selection, and a grouped window's Panes list sits under its group header

## Summary

Mac 28f6cde09, 32bc9a6b5, c4dbe30be. Window row icon (macwindow) in a pane row's icon column and spacing, its panes indented one chevron under it. Every row one height (pane row = rail tile = window row, 32pt with gap); project header 32pt sticky; grouped windows not indented (chevrons align); no dividers between top-level windows. This window folded: its header takes the selection pill (accent while key). This-window list starts open and folds on its own, apart from all-windows folds. A '<project>: <name>' window's own Panes list names it '<name>' under its group's header (count, pencil, +, x; folding it folds the group in every list). Mac ref: docs/reference/pane-sidebar.md 'All windows' + 'Rename in place' tail.

## In plain terms

Mac's sidebar picked up several small visual changes: window rows have a little window icon, every row is the same height, grouped windows line up with the rest, and a window that belongs to a project shows its project heading above its own pane list. After this, the Windows sidebar looks the same.

## Goals

- [ ] Window rows carry a window icon in the pane-row icon column
- [ ] Every row (pane, window, rail tile) is one height; project header 32 DIP
- [ ] Grouped windows are not indented; no dividers between top-level windows
- [ ] This window, folded, takes the selection pill
- [ ] A grouped window's own Panes list sits under its group header with the group's count and buttons
