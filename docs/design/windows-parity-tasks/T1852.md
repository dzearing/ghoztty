# T1852 - A translucent Windows window (background-opacity below 1) paints the elevated desk fully opaque: Mac's desk takes the terminal's background-opacity

## Summary

Follow-up of T1831. Mac PaneDesk applies .opacity(backgroundOpacity) so the desktop shows through the gradient. On Windows the desk is BitBlt'd through paintAlphaCorrect; check what alpha the desk and card pixels end up with on a per-pixel-alpha window (syncTranslucency, chrome_alpha) and make the desk take background-opacity while the cards keep the terminal's own. Screen validation needs the user away (T1794 gate); a PrintWindow capture plus the alpha byte is the on-box half.

## In plain terms

If you make your terminal see-through (a background opacity below 100%), the
colourful backdrop that the panes sit on stayed fully solid on Windows, so the
window was only see-through inside the panes. On Mac the backdrop fades with
the rest. After this, the Windows backdrop fades by the same amount, while the
pane cards, their shadows and the tab bar stay as they were.

## Goals

- [x] the desk (gradient) paints at `background-opacity` on a translucent window
- [x] cards, shadows, the focus glow and the busy light keep their own strength over it
- [x] an opaque window paints byte-for-byte as before
