# T3038 - PA-V06: a visible git-status: viewer runs about six git processes every two seconds (ViewerDiffProbe.zig:540)

## Summary

PA-V06 (audit-1, T2963). diff_poll_ms=2000 (ViewerPane.zig:237). Each listing (ViewerDiffProbe.zig:540-623) resolves the repo root with git (repositoryRoot :762-770), runs name-status and numstat per origin (:577-598), lists untracked files, and reads each untracked file up to 2 MB to count lines (:645-683). Cost (estimated at ~30 ms per CreateProcess): ~3 spawns/s, roughly 9% of a core while visible. Fix: cache the repo root per pane; one `git status --porcelain=v2 -z` fingerprint per tick and the full listing only when it moves; cache untracked line counts by size+mtime. Risk: a fingerprint missing a content-only edit; include mtimes. Findings: docs/design/perf-audit/audit-1/V-findings.md.
