# T3038 - PA-V06: a visible git-status: viewer runs about six git processes every two seconds (ViewerDiffProbe.zig:540)

## Summary

PA-V06 (audit-1, T2963). diff_poll_ms=2000 (ViewerPane.zig:237). Each listing (ViewerDiffProbe.zig:540-623) resolves the repo root with git (repositoryRoot :762-770), runs name-status and numstat per origin (:577-598), lists untracked files, and reads each untracked file up to 2 MB to count lines (:645-683). Cost (estimated at ~30 ms per CreateProcess): ~3 spawns/s, roughly 9% of a core while visible. Fix: cache the repo root per pane; one `git status --porcelain=v2 -z` fingerprint per tick and the full listing only when it moves; cache untracked line counts by size+mtime. Risk: a fingerprint missing a content-only edit; include mtimes. Findings: docs/design/perf-audit/audit-1/V-findings.md.

## In plain terms

A pane showing your working tree's changes checks for edits every two seconds.
Each check used to start about six separate git programs, even when nothing had
changed, which quietly burned CPU for as long as the pane was on screen. Now each
check asks git one quick question ("has anything moved?") and only does the full
refresh when the answer is yes, so an idle pane costs one git run per check while
edits still show up just as fast.

## Goals

- [x] an idle poll runs one `git status --porcelain=v2` fingerprint (plus each named path's size+mtime) and stops there when it matches the listing on screen
- [x] the repository root is remembered per pane, so a poll does not ask git for it again
- [x] untracked files' line counts are reused when size+mtime have not moved, instead of re-reading up to 2 MB per file
- [x] a content-only edit to an already-listed file still moves the fingerprint (size+mtime folded in)
- [x] Mac half filed (T3201, seat mac)

## Validation criteria

- [x] perf-baseline.ps1 viewer phase (PA-V01): a visible idle git-status: viewer spawns <=1 git process per tick (process-creation count over 60 s) and app CPU drops accordingly. The unit test asserts exactly 1 per unchanged poll.
