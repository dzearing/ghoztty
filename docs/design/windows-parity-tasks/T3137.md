# T3137 - Session restore on Windows honors the manifest's additive 'frontmost' field (Mac 3f772a2f0): the window that was in front at quit comes back in front

## Summary

Mac 3f772a2f0 adds an additive frontmost field to the session layout manifest (SessionLayoutManifest.swift) so a restore brings the front window back last. Windows session-layout restore (App.zig restore path) should write and read the same field so a manifest restores the same on both platforms, independent of single-window mode. Additive, no agent wire change.
