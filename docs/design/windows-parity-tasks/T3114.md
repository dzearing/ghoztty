# T3114 - A click on a file in a win32 git diff pane waits behind a running listing: give patches their own worker slot (Mac 6c854957d patchQueue)

## Summary

Mac 6c854957d moved ViewerDiffLoader patches onto their own DispatchQueue so a click does not wait behind a listing on a large repo. ViewerDiffProbe.zig keeps ONE worker slot for listing and patch (deliberately, so they never race into git); a requestPatch while a listing runs is deferred until the listing completes. Port: a second slot for patches (patch requests still coalesce to the newest), keeping the listing slot's poll-drop rule. Validation: a slow listing (fake git delay) plus a patch request - the patch completes before the listing. Follow-up of T3107.
