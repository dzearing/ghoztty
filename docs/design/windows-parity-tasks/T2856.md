# T2856 - A pane sidebar collapse or expand with no grid glide to follow (own clock, TIMER_COLUMN), or one whose landing moves mid-glide (an edge drag), is still stepped from the window thread in the composition pane tree

## Summary

T2827 declares only a column glide that follows the grid's (Column.following) and whose landing holds; PaneSidebar.place undeclares it when the landing moves (logged 'pane sidebar column undeclared'), and an own-clock glide (no grid shift planned) never declares. Declare both on Window.declareSidebarColumn: the own-clock one with its own easing curve (transition.column_ms, not the follower), the retarget from where the compositor has the clip (FaceDecl-style reached(now)) to the new landing. Oracle: pane-sidebar-glide.ps1 -Tree extended with an edge-drag retarget leg and an own-clock leg (no 'undeclared' line, landing declared=true); -Tree under GHOZTTY_GLIDE_DECLARE=0 red.
