image panes, find-in-page, clean copy out of Claude Code, and a big round of
fixes to how sessions come back after a reboot — and none of it was in the
Windows build. This brings all of it in, keeps the Windows-specific fixes that
solved the same problems a different way, and proves the Windows build still
builds and passes its checks afterwards.
