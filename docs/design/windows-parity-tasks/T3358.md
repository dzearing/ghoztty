# T3358 - Linux: zig build agent under the default gtk runtime fails at configure (system gtk4-layer-shell missing) although the agent is GUI-free

## Summary

Found in T3332: on Ubuntu 24.04 'zig build agent' (default -Dapp-runtime=gtk) fails with 'unable to find dynamic system library gtk4-layer-shell-0' - the agent's build graph pulls the GUI deps (deps.add on the agent test, shared SharedDeps). It builds with -Dapp-runtime=none, which is what scripts/linux/floor.sh uses. L8 (T3337) needs the GTK app build to produce the agent beside the app, so either the agent artifacts stop taking GUI deps, or the gtk build defaults -fno-sys=gtk4-layer-shell when the system library is absent. Acceptance: 'zig build agent' with no -D flags succeeds in WSL.
