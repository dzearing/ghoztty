# T3245 - PA-V12 remainder: a viewer's resource requests (onWebResourceRequested's takeIfFile stat probes and the resource read) still run synchronously on the GUI thread - answer them from a worker through the WebResourceRequested deferral

## Summary

Split from T3224, which moved the DOCUMENT read (renderFileContent) onto a worker (ViewerDocumentRead). Still on the GUI thread: every resource request the template or a rendered page makes (images and links a markdown file references, an .html page's CSS/JS/fonts) runs up to three statFile probes (takeIfFile) and then reads the resource inside onWebResourceRequested. On a slow or network path each such request stalls every terminal in the window. Fix: park the request on args.getDeferral() the way ViewerImageDecode.request does and resolve+read on worker_pool, answering from the completion post. Validation: latency probe typing in a terminal pane while a viewer loads a markdown file with many images from a throttled path.

## In plain terms

When a markdown file or a web page opens in a side pane, every picture, stylesheet and script it uses was looked up and read on the same thread that draws every terminal and takes their keystrokes. On a slow or network drive a document with a dozen pictures froze typing in every terminal in the window - measured here at over six seconds. Now those files are found and read in the background and handed to the page as they arrive, so the terminals keep responding while the viewer loads.

## Goals

- [x] the template tier's 3-tier `stat` probes and the read run on a worker (`ViewerResourceServe`), the request parked on its WebView2 deferral
- [x] a rendered page's resources (its own root, byte ranges, 206/416) run on the same worker
- [x] every request is answered - a FIFO queue, not "newest wins"; a pane close answers every parked request
- [x] a throttled-path latency probe exists, with a control that proves it can see a stall, and it covers T3224's document read too
- [x] the existing answers and log lines are unchanged (plus `parked=`)
