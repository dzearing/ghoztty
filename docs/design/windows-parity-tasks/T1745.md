# T1745 - Machine chooser rows have no active-session count badge (Mac shows one per machine)

## Summary

Filed by the T1633 chooser comparison; summary written at the 2026-09-26 triage.

Mac draws a small capsule after each machine's name in the chooser's machine
list holding that machine's active-session count, once its roster has loaded
(`countBadge(for:)`, `macos/Sources/Features/Remote/MachineChooserView.swift`
~L235-251: hidden while loading, on failure, or at zero; tooltip
"N active session(s)"). The win32 chooser shows the count only in the SELECTED
machine's detail subtitle (`src/apprt/win32/MachineChooser.zig` ~L2016/L2135,
T335/T602), so the list itself does not say which machines have anything
running until you click through them. Fix: a per-row count capsule in the
machine list, fed from the same roster counts, with the same hidden states and
tooltip. Confirm at claim that no row badge has landed since.

## In plain terms

In the machine picker, you could not tell which machines had anything running
without clicking on each one. Now every machine in the list shows a small
number, like Mac does: how many sessions are running there. Hovering it says
"3 active sessions".

## Goals

- [x] Each machine row shows its session count once that machine's list has loaded
- [x] The number matches the count in the detail header, always
- [x] It updates live when a session starts or ends elsewhere
- [x] Hovering it explains it, in Mac's words

## Validation criteria

- [x] A machine row whose roster has loaded with N>0 live sessions shows an "N" capsule; zero, loading and failed show none — `chooser_row_counts.zig` unit tests (cache, `shown` rule, failure clears) + `chooser_rows.zig` capsule-geometry tests at four DPI scales, in the none/win32 lanes (`floor-lane.ps1 -Lane all`: ALL LANES PASS); on the box, `chooser-help-tooltips.ps1` section G: logged count equals the listed count (2), and a never-loaded machine logs no count (negative control).
- [x] Hovering the capsule shows "N active session(s)" — section G: tooltip target `session-count row=0` reads "2 active sessions", then "3 active sessions"; leaving the capsule drops it.
- [x] The count tracks roster pushes live — section G: opening a session with the chooser up moves the Local count 2 → 3 on a PUSHED roster. `chooser-help-tooltips.ps1` ALL PASS (61 assertions), re-run independently at close.
