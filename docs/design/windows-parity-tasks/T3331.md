# T3331 - Linux L2: lib and none test lanes pass on Linux, with a Linux floor script

## Summary

Run the shared-core test lanes (the ones floor-lane.ps1 runs as lib + none) natively in WSL. Fix POSIX-path breakage introduced by Windows-first work (anything gated on .windows that assumed the only other OS is macos). Add scripts/linux/floor.sh as the Linux floor, launched through wsl-run.ps1. Acceptance: floor.sh all green twice in a row.

## In plain terms

The core of the terminal (the part every platform shares) has thousands of
unit tests, and until now they had only ever been run on Windows and macOS.
This runs them on Linux and fixes whatever turns out to be red, and adds one
command that says whether the Linux floor is green. Nobody sees a change on
screen; it means a future Linux break shows up here first.

## Goals

- [x] `scripts/linux/floor.sh` runs the `lib` and `none` lanes in WSL and ends in one verdict line
