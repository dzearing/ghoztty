Scriptable with Claude Code

One CLI for every window and pane.

Copy any of these into a Ghoztty pane. Each picture is what it produced.

ghoztty +new-window --target=orbit --working-directory=~/src/orbit \
  --command="npm run dev" --split=down --split-command="npm test"

--target names the window, so running the same line again focuses it instead of opening a second one.

ghoztty +split --view=docs/plan.md

The viewer reloads when the file is saved and keeps your place. --view also takes code files, images, HTML pages and URLs.

ghoztty +split --view=git-diff:main...HEAD

Also git-status: for the working tree, or git-diff:<sha> for one commit. Unified or side by side.

ghoztty +set-banner --target="$GHOZTTY_PANE_ID" \
  "## Add API rate limiting\n**PR** [#482](https://github.com/you/orbit/pull/482) · 37 tests passing"

Headings, tables, checklists and links all render. $GHOZTTY_PANE_ID is set in every pane, so an agent always knows its own.

ghoztty +list          # or: ghoztty +list --json

Every window, tab and pane, with names you can target and the activity state of each pane.

ghoztty +send-keys --target=tests "npm test\n"
ghoztty +read --name=tests --lines=6

The trailing \n presses Return. --when-idle waits until a Claude Code pane is ready for input.

ghoztty +set-state --target=migrations --state=needs_input

The window title gains (busy) or (question). For Claude Code you never call this yourself: the installed hooks do.

You don't type these. Your agent does.

Ghoztty ships a ghoztty skill and hooks for Claude Code and GitHub Copilot CLI. Install them once from Ghoztty → Set Up Agent Integrations…, then just ask: “open the plan beside me”, “show me what changed on this branch”, “run the tests in my other pane”. New panes open without stealing focus, so you keep typing where you were.

  • Ask“Add rate limiting, then open the plan and the diff beside me.”
  • Claude runsghoztty +split --view=docs/plan.md
  • You seeThe plan in a side pane, re-rendered on every save.

Easy window management

Dozens of panes, still easy to find.

When several agents each have a window, the sidebar is how you keep track of them.

Every window in one sidebar

Toggle it with ⌃⌘S. Switch on All windows and windows titled project: worktree group under their project.

  • Drag rows to reorder windows and panes, or drop a window into another group.
  • Hover and click the pencil to rename a window, group or pane in place.
  • + buttons open a window, a window in that project, or a split.
  • A busy pane's row shimmers, so you can see which agents are still working.
  • Search by window title, pane title, banner text or directory.

Stash panes you aren't watching

Drag a pane into the tray at the bottom of the sidebar, or press ⇧⌘M. It leaves the layout but keeps running.

  • Click it to put it back in the exact slot it came from.
  • ⌥-click swaps it with the pane you're in.
  • Scripts can do the same: ghoztty +stash --target=logs and +restore.
  • Stashed panes are still there after a relaunch.

Panes stack instead of shrinking

A pane never gets narrower than 225pt. When a row runs out of room, the extra panes tuck into labeled strips at the edge.

  • Click a strip to bring that pane on show.
  • Drag a strip to the tray to stash it, or to a screen edge for its own window.
  • Panes are glass cards on a gradient. Each new window gets its own colors, or pass --color=random.

Hero Mode for the pane that matters

Window → Toggle Hero Mode (⇧⌘Space) shows the focused pane full size with a scrolling carousel of the window's other panes beside it. ⇧⌘↑ and ⇧⌘↓ move between them. It works with viewer panes too.

Claude Code and Copilot friendly

Built for a day of running agents.

Know who needs you, see what each one is doing, and never lose a session.

See which agent needs you

Every pane is idle, busy or waiting on a question. A window shows the most urgent of its panes.

  • Titles gain (busy) or (question), and a question bounces the Dock icon.
  • Busy rows shimmer in the sidebar.
  • With Claude Code it's automatic: a pane stays busy while subagents run and only asks when there is a real prompt.
  • Copilot CLI gets the banner hooks and goes idle when a session stops.

Banners that stay current

The installed hooks keep a card above each agent's pane: the task, the goal, what you last asked, its status, what landed and the PR.

  • Updated as you prompt and when each turn ends.
  • Collapses to one line with its chevron.
  • The sidebar shows a pane's banner title, so rows read like a task list.

Links that jump back to a pane

ghoztty://focus/<window-or-pane> brings that window or pane to the front, even out of the stash tray. Put them in reports, dashboards or banners your agents write.

Focus is the only thing a link can do. It can't run commands.

Sessions survive restarts

Shells run under a background agent, so quitting Ghoztty, a crash or an update doesn't end them. Relaunch and you get the same processes back, with layout, split sizes, titles and scrollback.

After a reboot each pane reopens as a fresh shell in its last directory, with its old scrollback. On by default. ghoztty +sessions lists them.

Terminals on your other machines

File → New Remote Window opens a shell on another machine running the Ghoztty agent, such as a Windows box with the installer below. Sign in with Google and enroll the machine once.

Both sides connect out to a relay, so it works through NAT and firewalls. Remote panes get the same banners, viewers and states.

Get started

Two minutes to set up.

  1. Install Ghoztty

    macOS: open the DMG and drag Ghoztty to Applications. Windows: run the per-user installer. Both set up the ghoztty command for you.

  2. Set up your agents

    Choose Ghoztty → Set Up Agent Integrations… to install the skill and hooks for Claude Code and Copilot CLI. The banner hooks use jq (brew install jq).

  3. Ask

    “Show me the diff for this branch.” “Open the README beside me.” “Start the dev server in a pane below.”

The Windows build is not code-signed, so SmartScreen shows “Windows protected your PC” the first time you run it. Choose Run anyway — on some versions of Windows that button is behind More info first. This is a way to override the warning, not a sign the file is trusted, so only do it for a download from this page.

On some machines Microsoft Defender goes further than a warning and quarantines the files, naming Trojan:Script/Wacatac.C!ml. The !ml ending means Defender’s machine-learning model guessed rather than matched a known threat, and a new unsigned program is exactly what it guesses about. To get the files back, open Windows Security → Protection history, find the Ghoztty item and choose Restore, then run the installer again. Every Windows build is compiled in the open by GitHub Actions from this repository’s release workflow, so you can check where your download came from before you do.
